What is a program library?

1 · Program libraries contain pre-written and tested modules.  переклад? Бібліотеки програм містять заздалегідь написані й перевірені модулі.
2 · A module can be called by another program.°  переклад? Модуль можна викликати з іншої програми.
3 · Program libraries save programmers time in writing and testing new functions.°  переклад? Бібліотеки програм економлять програмістам час на написання й перевірку нових функцій.
4 · Libraries allow less experienced programmers to include complex things.°  переклад? Бібліотеки дозволяють менш досвідченим програмістам додати складні речі.
5 · Using libraries can simplify the whole programming process.°  переклад? Бібліотеки можуть спростити весь процес програмування.
Practice 1 · біля дошки Book library or program library?

📖 Book library

If you borrow a book from a book library, you need to return it after the set period of time.

💻 Program library

If you use code from a program library, you can use it indefinitely.

1 · You need to return it after the set period of time.  book чи program? A book library.
2 · You can use it indefinitely.  book чи program? A program library.
3 · It contains pre-written and tested modules.  book чи program? A program library.
4 · Readers borrow and read books without paying a fee.  book чи program? A book library.

import random

random_number.py
import random randomNumber = random.randint(0, 100) print(randomNumber)
The 0 is the smallest number that will be randomly generated.  переклад? 0 — найменше число, яке може випасти.
The 100 is the largest number that will be randomly generated.  переклад? 100 — найбільше число, яке може випасти.

Line 1: what does import random do?

Англійською, потім клацни.

It imports the library random into the program. Then we can call its functions.°

Can it output 100? Can it output 101?

Що виведе?
