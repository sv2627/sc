Today · Mad Libs

What is Mad Libs?

The game asks the user for words: people, animals, places, numbers. At the end, it puts the words into a story.

1 · The game asks

Give me a name? → Olena
Give me a place? → the moon
Give me a noun? → sofa

Користувач не знає, яка буде історія.

2 · The game says

Olena went to the moon.
They brought a sofa.

Слова стають в історію — і часто виходить смішно.

The code · Гра рядками
🧩

Mad Libs as a program

start
say Let's play madlibs for 2 seconds
ask Give me a name? and wait
set Name to answer
ask Give me a place? and wait
set Place to answer
ask Give me a noun? and wait
set Noun to answer
say (join Name (join "went to" Place))
say (join "They brought a" Noun)

Three variables

Name · Place · Noun — String

Кожна відповідь — у свою змінну.

join

join зʼєднує текст і змінну в один рядок.

Key idea · Space
␣

Spaces before and after the variables

✗ No spaces

join Name "went to"

Taraswent to

✓ A space before and after

join Name " went to "

Taras went to

Two words must not be joined together when they need a space between them.
💬
The prompt must be clear: Give me a noun? — the user enters one word. Зрозуміле запитання — і користувач вводить саме те, що треба грі.
Key idea · join inside join
🪆

One join inside another

One join

joins two pieces

join inside join

joins three pieces — two variables in the same line of text

зовнішній join · всередині — ще один join

Criteria · Критерії
🎯

A good Mad Libs game

1The game runs as expected.
2All prompts are clear to the user.
3The final text is clear, with a space between each word.
4The project plan is followed.

Why do we need clear criteria before we start?

Скажи вголос, потім клацни.

Criteria show the requirements of the task.

We can check that we have met all the requirements — so we know when the program is complete.

Критерії кажуть, що саме треба зробити, і коли робота закінчена.

Key idea · Project plan
📋

The project plan: a checklist

A project plan lists each task. When a task is complete, you tick it. Так програміст іде крок за кроком і нічого не пропускає.
1 · initialise the code — початок: start
2 · welcome the player
3 · ask three questions — the answers are single words
4 · save each answer in a separate variable with a clear name
5 · use say and join to display the Mad Libs text
6 · test the program
