When one flowchart is not enough

1 · Many programs are too complex for a single flowchart.  переклад? Багато програм надто складні для однієї блок-схеми.
2 · The main algorithm will link to another algorithm.  переклад? Головний алгоритм посилається на інший алгоритм.
3 · The other algorithm is a different part of the problem.  переклад? Інший алгоритм — це окрема частина задачі.
4 · This part is known as a sub-routine or procedure.  переклад? Ця частина називається підпрограмою, або процедурою.
5 · A sub-routine can often be used in different algorithms.  переклад? Підпрограму часто можна використати в різних алгоритмах.

The name at the start, Return at the end

1 · In the sub-routine, Start is replaced by Square, the name of the sub-routine.  переклад? У підпрограмі замість Start стоїть Square — назва підпрограми.
2 · Stop is replaced by Return at the end.  переклад? Замість Stop у кінці стоїть Return.
3 · Return means a return to the main algorithm.  переклад? Return означає повернення до головного алгоритму.
4 · The triangle is drawn in the main algorithm.  переклад? Трикутник малюється в головному алгоритмі.
5 · The outline of a house with a pitched roof is a square and a triangle.  переклад? Контур будиночка з гострим дахом — це квадрат і трикутник.

Why use a sub-routine?

1 · A sub-routine can be used many times in the same program.  переклад? Підпрограму можна використати багато разів в одній програмі.
2 · The code is only written once. This saves time and computer memory.  переклад? Код пишуть лише один раз. Це економить час і памʼять компʼютера.
3 · Other programmers can use the sub-routine in different parts of the program.  переклад? Інші програмісти можуть використати підпрограму в інших частинах програми.
4 · They can use it in completely different programs.  переклад? Вони можуть використати її в зовсім інших програмах.
