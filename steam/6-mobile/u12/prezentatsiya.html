Торкнувся — персонаж тікає навмання

when ImageSprite1.Touched x y do
set global baly to get global baly + 1
set Label1.Text to join "Бали: " …
call ImageSprite1.MoveTo x random integer from 0 to 220 y random integer from 0 to 220
Кожен дотик — нові X і Y. Персонажа вже не впіймаєш на тому самому місці.
Чому 220? Полотно 300, персонаж 80: 300 − 80 = 220 — щоб не виліз за край.
У кожному гнізді — свій random: X і Y випадають окремо, один від одного.
