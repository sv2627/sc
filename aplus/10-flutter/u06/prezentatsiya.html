Навіщо

Два списки розʼїжджаються

main.dart
var nazvy = ['Minecraft', 'Terraria', 'Portal']; var ciny = [650, 250, 500]; // Minecraft розпродано — прибрали nazvy.removeAt(0); // ... а ціну прибрати забули print('${nazvy[0]}: ${ciny[0]}'); // Terraria: 650 — чужа ціна!
Назва в одному списку, ціна в іншому — вони тримаються разом лише номером. Один removeAt — і все поїхало
Запис — один Map, де лежить усе про одну гру: назва, жанр, ціна
База даних — список таких записів. Прибрав запис — прибрав гру цілком, нічого не розʼїхалось

Запис · Map<String, dynamic>

Одна гра — один Map

main.dart
Map<String, dynamic> gra = { 'nazva': 'Minecraft', // String 'zhanr': 'sandbox', // String 'cina': 650, // int 'reytyng': 4.8, // double }; print(gra['nazva']); // Minecraft print(gra['cina'] + 50); // 700 gra['cina'] = 599; // змінили поле
Ключі — назви полів, завжди рядки. Значення — різних типів: текст, ціле, дробове
dynamic — «значення може бути будь-якого типу». Без нього в один Map не покласти і 'Minecraft', і 650
Усе інше — як на уроці 5: gra['kliuch'] читає, gra['kliuch'] = ... міняє або дописує

Показати весь каталог

main.dart
// for-in: потрібен лише запис for (var g in katalog) { print('${g['nazva']} - ${g['cina']} grn'); } // Minecraft - 650 grn // Terraria - 250 grn ... // for(i): потрібен ще й номер for (int i = 0; i < katalog.length; i++) { var g = katalog[i]; print('${i + 1}. ${g['nazva']} (${g['zhanr']})'); } // 1. Minecraft (sandbox) ...
g — це один запис, цілий Map. var тут можна: Dart бере тип зі списку
Усередині ${ } можна писати ті самі одинарні лапки: '${g['nazva']}' — це правильний Dart

Редагувати базу · 4 дії

Додати, змінити, прибрати запис

main.dart
// 1. додати запис — цілий Map katalog.add({ 'nazva': 'FIFA', 'zhanr': 'sport', 'cina': 1800, }); // 2. змінити одне поле katalog[0]['cina'] = 599; // 3. прибрати за номером katalog.removeAt(1); // 4. прибрати за умовою katalog.removeWhere((g) => g['nazva'] == 'FIFA');
add — той самий, що в уроці 5. Тільки тепер кладемо не слово, а цілий Map у фігурних дужках
Поле міняється так само, як у Map, — просто спершу номер запису
removeWhere прибирає всі записи, для яких умова — true. Умова — коротка функція зі стрілкою з уроку 4

Пошук за ключем · ще 3 способи

Той самий пошук одним рядком

main.dart
// чи є хоч один такий? → true / false print(katalog.any((g) => g['nazva'] == 'Portal')); // true // під яким номером? → -1, якщо немає print(katalog.indexWhere((g) => g['nazva'] == 'Doom')); // -1 // дай сам запис var p = katalog.firstWhere((g) => g['nazva'] == 'FIFA'); print(p['cina']); // 1800 katalog.firstWhere((g) => g['nazva'] == 'Doom'); // ПАДІННЯ: Bad state: No element
У всіх трьох — та сама умова зі стрілкою. Різниця лише в тому, що повертають
any — так/ні · indexWhere — номер · firstWhere — запис
firstWhere без збігу падає. Не впевнений, що є, — спершу any

Фільтр · where

Відібрати всі записи за умовою

main.dart
// katalog: Minecraft 650 · Terraria 250 · // Portal 500 · Stardew 350 · FIFA 1800 var deshevi = katalog .where((g) => g['cina'] < 500) .toList(); print(deshevi.length); // 2 // лише назви, одним рядком print(deshevi.map((g) => g['nazva']).join(', ')); // Terraria, Stardew int skilky = katalog .where((g) => g['zhanr'] == 'sandbox') .length; // 2
where лишає всі записи, для яких умова — true. Сам каталог не чіпає (на відміну від removeWhere)
Повертає ще не список — потрібне .toList(), як у reversed
map перетворює кожен запис на щось інше — тут на назву. join склеює, як в уроці 5

Сума, середня, найдорожча

main.dart
int suma = 0; for (var g in katalog) { suma += g['cina'] as int; } print(suma); // 3550 double serednia = suma / katalog.length; print(serednia); // 710.0 var top = katalog[0]; for (var g in katalog) { if (g['cina'] > top['cina']) top = g; } print(top['nazva']); // FIFA

Гра дня

main.dart
import 'dart:math'; // для Random // 1. перетасувати весь каталог katalog.shuffle(); print('Gra dnia: ${katalog.first['nazva']}'); // три різні випадкові — перші три після shuffle var tri = katalog.sublist(0, 3); print(tri.map((g) => g['nazva']).join(', ')); // 2. випадковий номер — порядок не міняється int i = Random().nextInt(katalog.length); print(katalog[i]['nazva']);
shuffle, як і sort, міняє сам список. Старий порядок пропадає
sublist(0, 3) — записи з номерами 0, 1, 2. Після shuffle це три випадкові без повторів
Random — з уроку 3. nextInt(n) дає від 0 до n-1 — якраз усі номери списку. import — першим рядком файлу

1. Скільки коштують усі ігри одного жанру разом

Пастки

На чому спотикаються всі

1 Тип каталогу — повністю. var katalog = [...] Dart прочитає не як dynamic, і g['cina'] < 500 не скомпілюється
2 Спершу номер, потім ключ. katalog['nazva'] — помилка: у списку ключів немає. Правильно katalog[0]['nazva']
3 as int у сумі. suma += g['cina']; не компілюється — значення з dynamic треба назвати числом
4 where — ще не список. Без .toList() не працює [0]
5 firstWhere без збігу падає. Спершу any — або пошук циклом із прапорцем
6 Помилка в ключі мовчить. g['cena'] замість g['cina'] — це null, а не повідомлення про помилку
