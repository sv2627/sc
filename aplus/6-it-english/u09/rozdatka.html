Following a flowchart of a journey

Keep this

journey · path

Forward 1 Step · Turn Right 90° · Turn Left 90°. 90° is the same as a right angle. Forward steps can be combined: Forward 3 Steps.

pen · count-controlled loop

Pen down — an instruction to draw. Count-controlled loop — the steps are repeated a set number of times. The output — what the pen draws.

Count

A variable. It stores an integer. It is used in the decision block: Is Count < 4? Set Count = 0 — start at 0. Change Count by 1 — add 1.
