Read aloud · 8.2 Data types · с. 202

Data can be of different types

1
Data in programs can be of different types. For example, it could be numeric or text.

переклад — клацни

Дані в програмах можуть бути різних типів. Наприклад, числові або текстові.
2
You will need to tell your program what type of data you want it to store.

переклад — клацни

Вам доведеться сказати програмі, який тип даних ви хочете, щоб вона зберігала.
3
Some programming languages need you to declare what type of data your variable will store when you first use it.

переклад — клацни

Деякі мови програмування вимагають оголосити, який тип даних зберігатиме змінна, коли ви вперше її використовуєте.
4
In some programming languages you need to swap data between types, for example, Python will only output string (text) data, so if you try and output a number without turning it into a string it will produce an error.

переклад — клацни

У деяких мовах треба переводити дані з одного типу в інший; наприклад, Python виводить лише рядкові (текстові) дані, тож якщо спробувати вивести число, не перетворивши його на рядок, буде помилка.

Code · Storing different data types · с. 202–203

A string, an integer, a real number, a Boolean

Pseudocode
Storing a string in a variable: Colour ← "red" Storing an integer in a constant: CONSTANT Value ← 10 Storing a real number in a variable: Price ← 22.4 Storing a Boolean in a variable: Flag ← TRUE
VB.NET
Dim colour As String = "red" Const value As Integer = 10 Dim price As Single = 22.4 Dim flag As Boolean = True
Python
colour = "red" value = 10 price = 22.4 flag = True
Java
public static void main(String args[]){ String colour = "red"; final Integer value = 10; Double price = 22.4; Boolean flag = true; }

⭐ Де у VB.NET і Java видно тип даних? А в Python? — клацни.

VB.NET: after As — String, Integer, Single, Boolean. Java: before the identifier — String, Integer, Double, Boolean. Python: the type is not written.

Read aloud · Converting between data types · с. 203–204

Casting: one data type → another data type

1
You might need to turn one data type into another data type. This is not required as part of the specification, but when you are programming in your chosen language you might have to do it for your program to work. This is called casting.

переклад — клацни

Іноді треба перетворити один тип даних на інший. Специфікація цього не вимагає, але коли програмуєте обраною мовою, це може знадобитися, щоб програма працювала. Це називають приведенням типів (casting).
2
You can do this by using the name of the data type you want the data to become. casting: converting data from one data type to another data type.

переклад — клацни

Для цього пишуть назву типу даних, яким дані мають стати. casting: перетворення даних з одного типу в інший.
Example 1 · Convert a string to an integer
Number ← int("123") VB.NET number = Convert.ToInt16("123") Python number = int("123") Java Integer number = Integer.parseInt("123");
Example 2 · Convert a number to a string
Value ← string(22.4) VB.NET value = Convert.ToString(22.4) Python value = str(22.4) Java String value = Double.toString(22.4);

VB.NET у книжці ще має рядок Dim number As Integer / Dim value As String; Java — усередині main(String args[]){ … }.
