Key words · с. 10

Analogue vs digital · Чому саме 0 і 1

analogue data

a continuous stream of data that is processed by humans.

Аналогові дані — неперервний потік. Усе, що ми бачимо, чуємо, відчуваємо й нюхаємо.

digital data

discrete data that only uses the values 0 and 1.

Цифрові дані — дискретні, лише два значення. Це і є binary data.

The components that process data in a computer are made up of very small logic gates. These gates cannot process analogue data, they can only process digital data. This data is stored in registers.
💡Ось відповідь на перший рядок чек-листа: дані треба перевести в binary, бо logic gate фізично вміє тільки «є струм / нема струму».
🔟
Number systems

Denary · base-10

In our daily lives we mostly use a denary number system. This is called a base-10 number system and uses the digits 0–9. The units in a denary number system are ones, tens, hundreds and thousands. Each time the unit increases by the power of 10.
For example, the denary number 123 has… — розряди ростуть справа наліво, кожен у 10 разів

Number systems

Binary · base-2

Computers use a binary number system. This is called a base-2 number system and uses the digits 0 and 1. The units in a binary number system increase by the power of 2.
8 bits = 1 byte. 4-bit число має 4 значення 1 або 0; 8-bit — 8. Бувають і 16-bit.

Key word · с. 9

Hexadecimal · base-16

hexadecimal: a base-16 number system that uses the values 0–9 and characters A–F.

Що каже книжка

Hexadecimal is also a number system. Humans can use hexadecimal, but computers cannot process it. Like denary numbers, hexadecimal numbers also need to be converted to binary to be processed by a computer.

Навіщо воно

4 біти = рівно один символ hex. Тому 8 бітів = 2 символи, а 16 бітів = 4.

Замість 11001001 пишемо C9. Коротше, і помилку видно оком.

🔤The reason for using the symbols A–F for the denary numbers 10–15 is so only one symbol is needed for the denary number in hexadecimal.
🔢

⚠️A, B, C, D, E, F — це цифри, а не літери. C означає 12, F означає 15. Одна клітинка — одне значення від 0 до 15, більше туди не влізе.
Тепер зрозуміло, чому #ff7fa0 — це три пари: ff = 255 червоного, 7f = 127 зеленого, a0 = 160 синього.

Find the mistake · Знайди помилку

Три учні здали роботу. У кожного рівно одна помилка. Знайди її й скажи англійською, у чому вона.

A · 5E → binary

Написав: 0101 1100

клікніть

Друга пара. E = 14 = 1110, а не 1100 (це 12, тобто C). Правильно: 0101 1110.

B · 200 → binary

Написав: 11000100

клікніть

Це 128+64+4 = 196, не 200. Пропущено розряд 8. Правильно: 11001000.

C · hex A

Написав: A = 11

клікніть

A = 10. Рахунок починається з нуля: 0–9 це десять цифр, тож наступна, A, — це 10, а не 11.

💬
Формулювання англійською: «The second nibble is wrong» · «The unit 8 is missing» · «Counting starts at zero». Помилку мало знайти — її треба вміти назвати.

Benefits for a programmer

The benefits of using hexadecimal rather than binary for a programmer are:

  • Hexadecimal is a shorter way of representing binary, so it takes up less space on the computer screen or piece of paper.
  • Hexadecimal is easier for a programmer to read, write and understand.
  • Hexadecimal is easier to debug and locate errors in data.

analogue data: a continuous stream of data that is processed by humans.
digital data: discrete data that only uses the values 0 and 1.
