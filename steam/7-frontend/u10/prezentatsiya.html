HTML не змінився ні на символ. CSS — Cascading Style Sheets, таблиця стилів: мова, якою описують вигляд — кольори, шрифти, рамки, розміри.

Де пишуть CSS

Три місця — обираємо окремий файл

1 · В атрибуті

<h1 style="color: red;">

тільки один елемент. Для 10 заголовків — 10 разів

2 · У тезі <style>

<head> <style> h1 { color: red; } </style> </head>

одна сторінка. Друга — своя копія

3 · Окремий файл ✓

<link rel="stylesheet" href="style.css">

усі сторінки сайту. Змінив раз — змінилось скрізь

У проєкті «Оформлений сайт» — тільки окремий файл style.css. Перші два місця побачиш у чужому коді через F12

<meta charset="UTF-8"> <title>Світ котів</title> <link rel="stylesheet" href="style.css">

link — звʼязок · rel="stylesheet" — «це таблиця стилів» · href — де файл. Тег без пари, як img

Як записати колір

Назва · шістнадцятковий код · rgb

redназва англійською — близько 140 готових
#ff0000шістнадцятковий код — будь-який із 16 мільйонів
rgb(255, 0, 0)те саме — звичайними числами 0–255
#ff0000
червонийзеленийсиній
Три пари знаків: скільки червоного, зеленого, синього. 00 — нічого, ff — найбільше

Знаки: 0 1 2 … 9 a b c d e f — шістнадцять, тому система шістнадцяткова. Малі й великі букви — однаково

Знайди помилку

Чому правило не працює?

h1 { color = red; }

Подумай, потім клацни

між властивістю й значенням — двокрапка

p { colour: blue; }

Подумай, потім клацни

CSS знає тільки color — без u

body { color: 22313f; }

Подумай, потім клацни

без # браузер не впізнає код кольору

h2 { color: red background-color: gold; }

Подумай, потім клацни

немає ; після red — не діють обидві

<h1> { color: navy; }

Подумай, потім клацни

у CSS селектор — без < >: h1

<link> є в index.html, а photos.html — без кольорів

Подумай, потім клацни

<link> потрібен у кожній сторінці

Крок 3 з 4 Палітра з паспорта — у style.css8 хвилин
Приклад — стиль «спокійний»
/* фон і текст усієї сторінки */ body { background-color: #f5f7fa; color: #22313f; } /* акцент */ h1 { color: #2e86de; } h2 { color: #2e86de; } footer { background-color: #2e86de; color: #f5f7fa; }
Тепер самостійно — кольори зі свого паспорта
  • body: фон і колір тексту
  • h1 і h2: колір акценту
  • footer: фон — акцент, текст — колір фону. Читається?
  • Над кожним правилом — коментар /* … */: що воно фарбує
  • ⭐⭐ Посилання меню погано видно? Правило для a
  • ⭐⭐⭐ Фон для header — і перевір, що меню читається
