Project plan and test plan

Довідка

Project plan

A project plan identifies: the inputs, outputs and processes · the tasks · which person will do each task · the timescales · the order to do tasks.

Why test a program?

To make sure it produces the expected outputs for a range of inputs and does not crash. Input a range of data, record each test and its result.

Test plan · columns

Test number · Description — what we test · Input data · Expected result — what it should output · Actual result — what it outputs
