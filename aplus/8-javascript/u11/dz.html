Функція sum уже готова. Місця, які треба дописати, позначені ДОПИШИ ТУТ. У кожному — один рядок.

  1. Встав заготовку. Зараз у консолі: Середній бал: undefined, Найнижча: 9, Нижче 7: 0.
  2. ДОПИШИ ТУТ 1: у функції average поверни суму, поділену на кількість оцінок — return sum(arr) / arr.length;. Має стати Середній бал: 8.
  3. ДОПИШИ ТУТ 2: у циклі функції min запамʼятай меншу оцінку — if (arr[i] < m) m = arr[i];. Має стати Найнижча: 1.
  4. ДОПИШИ ТУТ 3: у циклі функції countLow порахуй оцінки нижче 7 — if (arr[i] < 7) n++;. Має стати Нижче 7: 2.
