Practice 3 · correct Find the error5 хвилин

У кожній схемі одна помилка. Спершу прочитай вимогу. У зошит: номер і як виправити. Потім біля дошки — виправлена схема, по одній на учня.

1. Take two numbers and multiply them.
INPUT number1 → INPUT number2 → result = number1 + number2 → OUTPUT result
2. Take three numbers, add them together and output the result.
INPUT number1, number2, number3 → sum = number1 + number2 + number3 → OUTPUT total
3. Your name, age and favourite colour as input; output a message with all three.
INPUT name → INPUT age → OUTPUT "Hello", name, age, colour
4. If the number is less than 0, Minus runs. If it is 0 or more, Positive runs.
IF number < 0: true → Positive · false → Minus

Перевірка

Спершу зошит і дошка, потім клацни.

1 не той оператор:
result = number1 * number2

2 імена не збігаються:
OUTPUT sum

3 бракує фігури:
INPUT colour перед OUTPUT

4 не та підпрограма:
true → Minus · false → Positive

2. Має вивести Goodbye · Hello.
main: START → Run Me First → Run Me Second → STOP
3. value більше за 20 → Higher, інакше → Lower.
IF value > 20: true → Higher · false → Low
A the incorrect sub-routine is called
B the wrong identifier (name)
C sub-routines in the wrong order

Перевірка

1 A · 2 C · 3 B

2 Run Me Second → Run Me First

3 Low → Lower

Words in use

follow Follow the flowchart and identify the output. Follow and discuss each flowchart.
predict Predict the output of each one. Predict the outcome of flowcharts that use selection.
to edit Edit the flowchart to meet the new requirement. Show the flowchart before and after.
to correct Find the error and agree the change that is needed. The colour is not taken as an input, so this is an error.
description Create a flowchart for the description. Check the flowchart against the description.
checklist Use the requirements checklist. Is the flowchart structurally correct?
