Крок 1 Меню на головній4 хвилини
Приклад — index.html
<header> <h1>Світ котів</h1> <nav> <a href="index.html">Головна</a> <a href="photos.html">Фото</a> </nav> </header>
Тепер самостійно
  • VS Code → File → Open Folder… → папка pr1 з уроку 7
  • Відкрий index.html. У nav — «Головна» на index.html
  • Додай посилання на другу сторінку твоєї теми. Ім'я файлу — латиницею: games.html, photos.html…
  • Посилання на чужі сайти — лишай, вони не заважають
  • ⭐⭐ Ще пункт меню — для третьої сторінки
  • ⭐⭐⭐ Між пунктами меню — знак |
⚡ Швидше схожий рядок — Alt+Shift+↓ Ctrl+S → F5
Крок 2 Друга сторінка — копією5 хвилин
Приклад — разом
1. index.html → Ctrl+A → Ctrl+C 2. New File → photos.html → Ctrl+V 3. <title>Фото</title> 4. header і footer — НЕ чіпаємо 5. у main стираємо все, пишемо: <main> <section> <h2>Фото котів</h2> </section> </main>
Тепер самостійно
  • Скопіюй index.html у новий файл — ім'я точно таке, як у меню
  • У <title> — назва другої сторінки
  • Шапку й підвал не чіпай — вони однакові на всіх сторінках
  • У main — новий section з h2
  • Ctrl+S. На вкладці браузера — нова назва?
  • ⭐⭐ Так само — третя сторінка для третього пункту меню
⚡ Швидше виділи рядки в main → Delete у href="" — ім'я файлу з підказки
Крок 3 Своя середина другої сторінки6 хвилин
Приклад — у section
<h2>Фото котів</h2> <p>Це мій <strong>Барсик</strong>.</p> <img src="img/barsyk.jpg" alt="Сірий кіт на дивані" width="300"> <ul> <li>Спить</li> <li>Їсть</li> </ul>
Тепер самостійно — розширюй приклад
  • Абзац про твою тему, одне слово — strong
  • Дві картинки з папки img: у кожної src, alt, width
  • Список ul або ol на три пункти
  • Ctrl+S → F5. Обидві картинки видно?
  • ⭐⭐ Другий section з h2 і article
  • ⭐⭐⭐ Картинка — посилання на головну
⚡ Швидше у src="" VS Code сам підказує файли картинка → правий клац → «Зберегти зображення як…» → img
Крок 4 Меню туди й назад4 хвилини
Приклад — перевіряємо клацанням
index.html → клац «Фото» photos.html → клац «Головна» index.html ✓ F12 → Elements: body → header, main, footer
Тепер самостійно
  • Збережи всі файли: на вкладках VS Code немає кружечка ●
  • Головна → друга сторінка → головна — тільки клацаючи
  • Меню на обох сторінках однакове: ті самі пункти, той самий порядок
  • F12 на другій сторінці: у body — header, main, footer?
  • ⭐⭐ Обійди всі три сторінки по колу, тільки через меню
  • ⭐⭐⭐ У footer кожної сторінки — ще одне меню в nav
⚡ Швидше браузер: Alt+← — назад не відкривається? Ім'я в href і ім'я файлу — літера в літеру

Перевір себе

3 Меню на обох сторінках однакове
4 Клацаючи меню, можна дійти туди й назад
5 Картинки видно, у кожної є alt
6 F12: у body — header, main, footer
