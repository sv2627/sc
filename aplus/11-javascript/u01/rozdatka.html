Старт: що лишилося з 8 класу

Розриву немає: ви писали JS торік. Цей рік — не «що таке змінна», а «як це пишуть зараз».

Робоча папка

js-11/
  index.html
  script.js
  styles.css

У VS Code відкривати папку, а не файл: File → Open Folder → js-11. Live Server стартує від кореня відкритої папки.

Назви — латиницею, малими, без пробілів.

Каркас index.html

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
</head>
<body>
<h1>GameStore</h1>
<script src="script.js">
</script>
</body>
</html>

Два правила запуску

  • Скрипт — у кінці body: браузер читає зверху вниз, тож із <head> він спрацює до появи <h1> — і querySelector дасть null.
  • Відкривати тільки через Live Server (http://localhost:5500), не подвійним кліком: на file:// згодом не запрацюють ES-модулі й fetch.

Git: три команди + найчастіший затик

git init
git add .
git commit -m "page skeleton"

init — раз на проєкт, add і commit — щоразу. У повідомленні — що зроблено, а не які файли змінено.
