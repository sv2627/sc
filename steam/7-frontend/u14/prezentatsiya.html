Одиниці розміру

px · % · em · rem · vw · vh

ЗаписВід чого рахуєтьсяПриклад
pxточка екрана — завжди однаковоborder: 2px
%від ширини батька — блоку, в якому лежитьwidth: 50%
emвід розміру шрифту цього елемента: 1em = його font-sizepadding: 0.5em
remвід шрифту сторінки — звичайно 16px: 2rem = 32pxfont-size: 2rem
vw1% ширини вікна браузера: 100vw — уся ширинаfont-size: 5vw
vh1% висоти вікна: 100vh — уся висотаheight: 50vh

Число й одиниця — впритул: 50%, не 50 %. Дробове — через крапку: 1.5rem. Лише нуль можна без одиниці: 0

Ширина і висота · уся родина

width · height · max-width · min-width

widthширина точно. width: 300px — і на телефоні 300, навіть якщо не влазить
max-widthширина не більша за. Вікно широке — 900, вузьке — скільки є місця ✓
min-widthширина не менша за — кнопка не стискається в смужку
heightвисота. Зазвичай не задаємо: блок сам росте під текст
max-heightвисота не більша за · min-height — не менша за
style.css
/* головна частина */ main { max-width: 900px; }
Для сторінки — max-width, не width: на вузькому екрані блок стиснеться сам

По центру

Текст — text-align. Блок — margin: 0 auto

Текст усередині блоку

h1 { text-align: center; }

Рухає рядки тексту всередині блоку. Сам блок стоїть де стояв

Сам блок на сторінці

main { max-width: 900px; margin: 0 auto; }

0 — зверху й знизу · auto — ліво й право порівну, скільки лишилось

margin: 0 auto працює, лише коли блок вужчий за батька. Без max-width чи width лишку немає — нічого ділити
