Головне слово року

Адаптивність

Адаптивний сайт — це сайт, який сам підлаштовується під ширину екрана: на телефоні картки стають одна під одною, меню — стовпчиком, текст лишається читабельним.

❌ Як НЕ треба

Зробити три різні сайти: один для комп'ютера, один для планшета, один для телефона. Три папки, три style.css, три рази правити кожну кому.

✅ Як треба

Один сайт, один style.css — і кілька правил, які кажуть: «якщо екран вузький, розстав блоки інакше».

🔑Запам'ятай фразу: один сайт, який працює на всіх ширинах — а не три різні сайти.

Що шукаємо

Три типові поломки

1. Прокрутка вбік

Сторінка їздить ліворуч-праворуч. Внизу з'явилася горизонтальна смуга прокрутки. Частина контенту заїхала за край екрана.

2. Дрібний текст

Щоб прочитати, треба розсунути пальцями. Літери менші за нігтик — читати неможливо.

3. Картинка вилазить

Фото ширше за екран: видно тільки ліву частину, права поїхала кудись убік разом зі сторінкою.

Ці три є в усіх без винятку сайтах із 6 класу. Не тому, що хтось погано вчився, — а тому, що про телефон торік ніхто й не думав.
Поломка 1

Звідки береться прокрутка

style.css
/* так написано з 6 класу */
.container {
  width: 900px;   /* ← ось воно */
}

/* Екран телефона — 360 px.
   Блок ширший за екран на 540 px
   → браузер додає прокрутку вбік. */
🔍Правило на весь рік: горизонтальна прокрутка = десь стоїть фіксована ширина в пікселях. Шукай width у px.
Поломки 2 і 3

Як знайти винний елемент

1
У DevTools вкладка Elements — там увесь HTML сторінки
2
Наведи мишею на рядок коду — на сторінці підсвітиться саме цей блок
3
Біля підсвітки браузер пише розмір: div.container 900 × 420
4
Перше число більше за 360 → винний знайдено. Дивись його CSS у панелі Styles
💡Для дрібного тексту — вкладка Computed: там видно справжній font-size у пікселях.
