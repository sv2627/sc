Стартовий код — сторінка «Код уроку», два блоки «Лічильник лайків». Відкрий codepen.io: блок «панель HTML» — у панель HTML, блок «панель JS» — у панель JS.

Праворуч — три кнопки і напис ❤ 0. Поки кнопки нічого не роблять. Місця, які треба дописати, позначені ДОПИШИ.

  1. ДОПИШИ 1. В обробнику кнопки ❤ два рядки: count++; і out.textContent = `❤ ${count}`; (у зворотних лапках). Перевір: 5 кліків — ❤ 5.
  2. ДОПИШИ 2. Обробник кнопки «Скинути» — за зразком першого: reset.addEventListener('click', () => { … });, усередині count = 0; і той самий рядок з textContent. Перевір: після «Скинути» — ❤ 0, а наступний клік по ❤ дає ❤ 1.
  3. ДОПИШИ 3. Обробник кнопки «Тема»: усередині document.body.classList.toggle('dark');. Перевір: один клік — сторінка темна, ще один — світла.

Що надіслати: увесь код із панелі JS, першим рядком — коментар із прізвищем та імʼям, наприклад // Коваль Олена.
