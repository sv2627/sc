AND, OR, NOT in code · Логіка в коді

Reference

Boolean operators

AND — both conditions must be true.

OR — one or both conditions can be true.

NOT — reverses the condition: true becomes false.

true = 1 · false = 0

Python

if first < 20 and second < 20:
  print("Both less than 20")
else:
  print("No")

The code after if and else: is indented.

Remember

A conditional statement: the condition; the code to run if true; the code to run if not true.

and, or — lower case, a condition on either side. not — before a condition: not(answer == 100)

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
