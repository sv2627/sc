Обгортка: не ширше — і посередині

Широкий монітор без обгортки
Капучино — кава з молоком і пінкою, яку ми готуємо з ранку до вечора щодня, крім неділі.
З обгорткою .container
Капучино — кава з молоком і пінкою, яку ми готуємо щодня.
Обгортка · style.css
.container { max-width: 1000px; /* не ширше */ margin: 0 auto; /* посередині */ padding: 0 16px; /* не до краю телефона */ }
📱
Без padding на телефоні текст прилипає до краю екрана.

Ескіз з уроку 14 — поруч із ноутбуком

Крок 1 Папка й файли проєкту4 хвилини
Приклад
zerno-site/ ├── index.html ├── css/ │ └── style.css └── img/
Тепер самостійно
  • Нова папка — назва твого сайту латиницею: kino-site, zoo-site…
  • VS Code → File → Open Folder… → ця папка
  • Файл index.html: каркас документа, lang="uk", title — назва сайту
  • Папки css і img, файл css/style.css, у head — link на нього
  • ⭐⭐ У style.css першим рядком — * { box-sizing: border-box; }
Крок 2 П'ять частин за ескізом8 хвилин
Приклад · у body

Тепер самостійно
  • Шапка: назва в h1 і меню з 3 посиланнями
  • У main — три section з id: перший екран, каталог, форма
  • У кожному розділі — свій h2 і абзац тексту з ескізу
  • Підвал: контакти й «© 2026»
  • ⭐⭐ Пункти меню ведуть на id розділів
  • ⭐⭐⭐ На першому екрані — посилання-кнопка на розділ форми

Приклад

Тепер самостійно
  • Усередині шапки, кожного розділу й підвалу — div class="container"

  • Шапці й підвалу — свій фон і колір тексту

Крок 4 «Рентген»: побач усі коробки4 хвилини
Приклад · тимчасово, в кінець style.css
* { outline: 1px solid red; }

outline — обвідка, що не змінює розмір коробки

Тепер самостійно
  • Додай рядок і подивись на сторінку: які коробки на всю ширину?
  • Знайди рядкові: посилання меню, strong
  • У гаслі першого екрана одне слово — у span class="accent", інший колір
  • Вимкни рентген: Ctrl+/ на цьому рядку
  • ⭐⭐ Посиланню-кнопці — display: inline-block і padding: 10px 20px
