Міні-проєкт I «Текстовий квест»

Довідка

Розвилка

prompt + if; відповідь — рядок '1'

if усередині if — друге питання

останній else — кінцівка «усе інше»

Ввід

Скасувати → null — перевіряти першим

' Так '.trim().toLowerCase() → 'так'

c === 'так' || c === 'т'

Стан

let gold = 10; — не const

gold += 5; · gold -= 2;

`Золото: ${gold}`

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

1 · Пройди квест за кодом

const c1 = prompt('1 — печера, 2 — річка');
if (c1 === '1') {
  const c2 = prompt('1 — факел, 2 — наосліп');
  if (c2 === '1') { alert('Скарб!'); }
  else { alert('Ти впав у яму. КІНЕЦЬ'); }
} else if (c1 === '2') {
  alert('Човен довіз до села. КІНЕЦЬ');
} else { alert('Ти пішов додому. КІНЕЦЬ'); }

Що покаже останній alert?

2 · Порахуй золото

let gold = 10;
const c1 = prompt('1 — меч, 2 — щит');
if (c1 === '1') { gold -= 7; }
else if (c1 === '2') { gold += 5; }
const c2 = prompt('1 — таверна, 2 — ліс');
if (c2 === '1') { gold -= 2; }
alert(`Золото: ${gold}`);
