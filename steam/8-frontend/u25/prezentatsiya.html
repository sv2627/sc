Адаптивний сайт: десять пунктів

1. На 360 немає прокрутки вбік
2. Текст читається без збільшення пальцями
3. Кнопки й посилання — під палець: великі, не злипаються
4. Фото не вилазять, у картках однакові
5. У кожного фото є alt
6. Меню видно й воно працює на телефоні
7. Форма: підписи, required, поля не вилазять
8. Обидві сторінки: та сама шапка, меню туди й назад
9. Перехід із меню — заголовок розділу не під шапкою
10. У кожної сторінки свій title

Телефон

Пальцем, а не мишею

44pxкнопка чи посилання не нижчі за 44px — палець товстіший за курсор
gapміж пунктами меню — відстань, щоб не влучити в сусідній
:hoverна телефоні наведення немає: важливе не ховати «під мишу»
16pxтекст у полях форми не менший — інакше телефон сам збільшує сторінку
.btn { padding: 12px 20px; } nav { gap: 20px; flex-wrap: wrap; } .order-form input { font-size: 16px; }
малапід палець

Для всіх

Сайт, який можна «почути»

altпрограма читає вголос, що на фото. Без alt — лише «зображення»
label forпрограма каже, що вписати в поле
h1 → h2 → h3заголовки по порядку: за ними незрячий «гортає» сторінку
контрастсвітлий текст на світлому фоні не прочитає ніхто
Не так
<img src="img/1.jpg">
Так
<img src="img/late.jpg" alt="Лате у високій склянці">
💡
Фото лише для краси — alt="": програма його пропустить.

Крок 2 · ⭐ Прибрати прокрутку вбік6 хвилин
Приклад · знайшли винного
/* було */ .promo { width: 800px; } /* стало */ .promo { max-width: 800px; }
Тепер самостійно
  • 360 → F12 → Elements: наводь на теги, шукай той, що за правим краєм
  • Звір із таблицею причин — що з неї твоє?
  • Виправ, Ctrl+S, F5, перевір ще раз
  • Прокрутки немає — пункт 1 став ✓
  • Далі — наступний ✗ з чек-листа

Тепер самостійно

  • Менша — більший padding
  • Пункти меню на 360 не злипаються — gap
  • Поля форми — font-size: 16px
  • ⭐⭐⭐ Кнопки в картках на телефоні — на всю ширину картки

Крок 5 · ⭐⭐⭐ Шапка не ховає розділ4 хвилини
Приклад
section { scroll-margin-top: 80px; }

Клацнули пункт меню — браузер зупиняє розділ на 80px нижче верху вікна, і закріплена шапка не закриває заголовок.

Тепер самостійно
  • Клацни пункт меню: заголовок розділу ховається під шапкою?
  • F12: яка висота шапки? Це твоє число
  • section { scroll-margin-top: … } — висота шапки
  • На телефоні шапка вища — інше число в медіа-запиті
