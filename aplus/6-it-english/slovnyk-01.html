3 · Questions and answers · Питання й базові відповіді

1. What is a sequence?
Steps in a precise order. A computer runs the code in that order.
2. What is a logic error?
The program still runs, but it does not do what the programmer expects.
3. Why is a logic error hard to find?
The program does not stop and there is no red message. Only a person who knows what should happen can see it.
4. Which two blocks make the sprites speak in turn?
broadcast and when I receive — not wait blocks.
5. What does broadcast do?
It sends a message to all the other sprites.
6. What does when I receive do?
The sprite waits for the message. It does nothing until it receives it.
7. Both sprites start from the green flag. What happens?
They speak at the same time, so there is no joke.
8. What are our three criteria for the joke?
broadcast and when I receive are used, not wait · the joke is properly sequenced · there is sufficient time to read the text.
9. What is a construct?
The common building blocks of our programs, which are used to undertake a range of tasks.
10. Name five constructs in English.
variables · conditionals (selection) · arithmetic and comparison operators · loops (iteration) · interaction.
11. What is a variable used for?
To store information in the computer’s memory.
12. Which construct is each block? repeat 10 · when I receive · set name to · ( ) > ( )
loops (iteration) · interaction · variables · arithmetic and comparison operators.
13. Why use the correct vocabulary?
Two reasons: you can explain your program to others, and it is easier to move to other programming languages.
