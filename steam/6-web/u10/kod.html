Приклад із кроку 3 · стиль «нічний»

Звір зі своїм після уроку. Твої кольори — зі свого стилю: обери один із чотирьох нижче

style.css 
/* Стиль: нічний. Тло: midnightblue. Текст: white. Акцент: gold */

/* уся сторінка: тло і колір тексту */
body {
  background-color: midnightblue;
  color: white;
}

/* заголовки розділів: тло — акцент, літери — темні, щоб читалось */
h2 {
  background-color: gold;
  color: midnightblue;
}

Чотири стилі (тло · текст · акцент): нічний — midnightblue · white · gold; спокійний — white · navy · skyblue; яскравий — ivory · darkred · orange; природний — honeydew · darkgreen · yellowgreen
