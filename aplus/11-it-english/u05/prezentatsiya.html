Bubble sort · с. 161

Пара за парою

1«A bubble sort takes the first 2 values; value 1 and 2, and compares them. If they are the wrong way around it swaps them.»
2«It then puts these back and takes values 2 and 3 and compares them. If they are the wrong way around it swaps them.»
3«This repeats until it has worked all the way through the list once.»
4«It then starts again with the first two values.»
«It is called a bubble sort because it acts like a bubble moving across all the elements to the end, then starting from the beginning.»
🛑
When to stop · с. 161

There are two ways to tell the algorithm when to stop

1 · XElements − 1 times

«10 elements — the algorithm runs 9 times. 100 elements — it runs 99 times.»

«This is the easiest way to program it, but it is not efficient. All elements might be in the correct order to begin with, but it is still going to run through the same number of times.»

2 · no changes

«Either the algorithm has run through the list XElements - 1 times, or it has run through the list, checking all of the elements, and it has not made any changes.»

Activity 7.6 Bubble sort with playing cards7 хвилин

«Get a set of playing cards. Select 10 random cards and place them face down on the table in a row. Perform a bubble sort to put the cards in ascending numerical order.» — с. 162

1Turn over the first two cards.
2If the 1st is larger than the 2nd, swap them. Otherwise, do nothing.
3Turn the cards back over.
4Turn over the 2nd and 3rd cards.
5Repeat step 2.
6Repeat turning over the cards and swapping until you have been through all 10 cards once.
7Did you make any swaps? If so, start again from step 1. If not, stop because the cards should be in order.

Question 20 · с. 167

Explain the difference in efficiency between the two different bubble sort algorithms.

Дві умови зупинки — потім клацни.

Version 1 always runs length − 1 passes, even if the data is already in order. Version 2 stops after a pass with no changes → fewer passes and comparisons → more efficient.

° У книжці цей рядок надруковано обірвано: «NumberPasses ENDWHILE».
