3 · Phrases · Фрази, які ми казали на уроці

  • What does the algorithm do? What are the key features? What programming techniques are used? Три питання до будь-якого чужого алгоритму.
  • The algorithm was wrong because… Алгоритм був неправильний, тому що… (наш зразок речення)
  • The counter starts at the start value. Лічильник починається з початкового значення.
  • The loop increments the counter each time. Цикл щоразу збільшує лічильник на одиницю.
  • The loop repeats end − start times. Цикл повторюється «кінцеве мінус початкове» разів.
  • A count-controlled loop runs a set number of times. Цикл із лічильником виконується задану кількість разів.
  • One iteration is one pass through the loop. Одна ітерація — один прохід циклу.
  • I can predict the outcome before I follow the algorithm. Я вмію передбачити результат до того, як пройду алгоритм.
  • A string stores one or more characters, a character stores exactly one. Найкоротше формулювання різниці між string і character.

4 · Questions and answers · Питання й базові відповіді

1. What does this algorithm do? result = number1 + number2, then print(result)
It takes two numbers from the user, adds them and outputs the sum.
2. What are the key features of an algorithm?
inputs · decisions · output.
3. What programming techniques are used?
sequence · selection · iteration.
4. Why are brackets needed in (a + b + c) / 3?
Without them the division happens first, so only c is divided. That is a logic error — the program runs and the answer is wrong.
5. What is repetition in a computer program?
A piece of code that is run more than once.
6. What is a count-controlled loop?
Code that runs a set number of times.
7. When can it be useful?
When something has to happen a set number of times.
8. What are its key features?
A counter with a starting value, an end value and an increment.
9. for count in range(0, 10) — what is the output and how many lines?
0 to 9, ten lines. The end value itself is not printed.
10. What values can a binary number take?
1 and 0.
11. In what format is data stored in a computer?
Binary.
12. Why do computers use binary?
They use logic gates that are either open or closed.
13. What sort of data can be stored using binary?
Any and every sort of data.
14. What is a nibble?
Four bits — half a byte.
15. Why are units such as kilobytes used instead of just bits and bytes?
It is easier for a person to say small numbers of large units than thousands and millions of small ones.
16. How do you convert between units?
From a larger unit to a smaller one — × 1000. From a smaller one to a larger — ÷ 1000.
17. What can be stored in a string?
Lowercase letters, uppercase letters, numbers and symbols. "2026" is also a string.
18. Explain the difference between a string and a character.
A string stores one or more characters. A character stores exactly one.
19. Why does a separate character type exist?
It saves memory space: a string reserves memory with a margin, a character has a fixed memory size. Not all languages have it — Python has only string.
20. Why do programs use different data types?
To stop invalid data being entered · so that numbers can be used in calculations · to limit what is accepted · to save memory.
