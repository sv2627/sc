Підказка 1 · удар

hit: удар із розкидом

class Fighter · метод
void hit(Fighter other) { int damage = attack + Random().nextInt(6); other.hp = other.hp - damage; if (other.hp < 0) other.hp = 0; print('$name hits ${other.name} for $damage. ${other.name}: ${other.hp} hp'); }
damage — локальна змінна методу: сила бійця плюс від 0 до 5
У лозі — $damage, а не $attack. Інакше лог показує не той удар
hp не йде в мінус: після удару підрізаємо до 0

Підказка 2 · бій

fight: бій до переможця

main.dart
Fighter fight(Fighter a, Fighter b) { int round = 0; while (a.isAlive() && b.isAlive()) { round++; print('--- Round $round ---'); a.hit(b); if (b.isAlive()) b.hit(a); } Fighter winner = a.isAlive() ? a : b; print('Winner: ${winner.name} in $round rounds, ${winner.hp} hp left'); return winner; }
Функція повертає переможця — цілий обʼєкт. Турніру це знадобиться
&& — бʼються, поки живі обидва
if (b.isAlive()) — мертвий у відповідь не бʼє

main

Рівень ⭐⭐⭐ · крит і лікування

Удар ×2 і одне лікування за бій

class Fighter · додати
int potions = 1; // поле; і в restore(): potions = 1; // у hit, після рядка з damage: if (Random().nextInt(5) == 0) { damage = damage * 2; print('CRIT!'); } void heal() { hp = hp + 20; if (hp > maxHp) hp = maxHp; potions--; print('$name heals. $name: $hp hp'); } void turn(Fighter other) { if (hp < maxHp ~/ 3 && potions > 0) { heal(); } else { hit(other); } }
nextInt(5) == 0 — одне число з пʼяти, шанс 20 %
turn — хід: лікується, якщо hp менше третини і є зілля, інакше бʼє
У fight заміни a.hit(b) на a.turn(b), а b.hit(a) на b.turn(a)

Ще вісім доробок

1. Нічия: бій довший за 20 раундів зупиняється (break), у лозі Draw
2. Захист: поле defence зменшує кожен отриманий удар, але не нижче 1
3. Олімпійська система: shuffle, два півфінали, фінал між переможцями
4. Серія: двоє бʼються, поки хтось не виграє 3 бої
5. Лог у список: кожен рядок — add у List<String>, після бою — лише останні три
6. Середня кількість раундів за турнір — double
7. Смужка здоровʼя в лозі: Bohdan: ##### (52 hp)
8. 2 на 2: у кожній команді бʼється перший живий (firstWhere)

Пастки

Найчастіші проблеми

1У лозі $attack замість $damage — лог бреше, бо удар із розкидом інший
2Без restore() — другий бій переможець починає з тим hp, що лишилось
3j = 0 замість j = i + 1 — кожна пара бʼється двічі, а боєць — сам із собою
4fight без return — переможця не записати в таблицю
5update для нового ключа падає. Спершу всім 0 у таблиці
6|| замість && — бій не закінчується, вкладка DartPad зависає
