Many languages, the same fundamentals

Read aloud · Programming languages · с. 197–198

A FOR loop: output the numbers 1 to 10

For example, a FOR loop (a type of count-controlled loop that you will learn about later in the chapter) that will output the numbers 1 to 10. In pseudocode (a generic non-language specific language) this could be:

Pseudocode
FOR Count ← 1 TO 10 OUTPUT(Count) NEXT Count
VB.NET
FOR count = 1 to 10 Console.writeline(count) NEXT count
Java
for(count = 1; count < 11; count++){ System.out.println(count); }
5
These all do the same functions, and they all follow the same principles. They start with the word ‘for’. They have a variable (count). They set the starting value and they say when to stop.

переклад — клацни

Усі вони роблять те саме й дотримуються тих самих принципів. Починаються зі слова «for». Мають змінну (count). Задають початкове значення й кажуть, коли зупинитися.
6
So once you can do a for loop in VB.NET, you should just be able to search for how to do it in Python and just change a couple of the words.

переклад — клацни

Тож коли вмієш написати цикл for у VB.NET, досить пошукати, як це робиться в Python, і змінити кілька слів.

Key words · с. 198 · читаємо й перекладаємо

variable · constant · identifier

1
variable: a named memory location that can store data. The data can change whilst a program is running.

переклад — клацни

змінна: іменована комірка памʼяті, яка може зберігати дані. Дані можуть змінюватися, поки програма працює.
2
constant: a named memory location that can store data. The data cannot change whilst a program is running.

переклад — клацни

константа: іменована комірка памʼяті, яка може зберігати дані. Дані не можуть змінюватися, поки програма працює.
3
identifier: a name given to a variable, constant, data structure (e.g. array) or subroutine.

переклад — клацни

ідентифікатор: імʼя, дане змінній, константі, структурі даних (наприклад, масиву) чи підпрограмі.
variable і constant відрізняються одним словом: can / cannot.

1
Variables and constants have one difference. In a variable, you can change the data while the program is running. For example, putting the number 30 into memory location number1, the memory would then look like this.

переклад — клацни

Змінні й константи мають одну відмінність. У змінній дані можна змінювати, поки програма працює. Наприклад, якщо покласти число 30 у комірку number1, памʼять виглядатиме так.

Read aloud · Using constants · с. 201

CONSTANT Colour ← "yellow"

1
Before you use a constant in your program you need to give it a value. This is an assignment statement the same as a variable. (No examples are given for Python as it does not have in-built constants.)

переклад — клацни

Перш ніж використати константу, треба дати їй значення. Це інструкція присвоєння, як і для змінної. (Прикладів для Python немає: у ньому немає вбудованих констант.)
2
Using the key word constant makes it clear that this value cannot then be changed.

переклад — клацни

Ключове слово constant чітко показує, що це значення потім не можна змінити.
3
You get data out of a constant the same way as a variable, by using its identifier.

переклад — клацни

Дані з константи беруть так само, як зі змінної, — через її ідентифікатор.
Pseudocode
CONSTANT Colour ← "yellow" OUTPUT(Colour)
VB.NET
Const colour As String = "yellow" Console.Writeline(colour)
Java
public static void main(String args[]){ final String colour = "yellow"; System.out.println(colour); }
