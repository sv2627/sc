Data types: Character, String, Integer

Keep this

variable

a data structure that stores data while a program is running. Like a small whiteboard: the name at the top, the data below. The data can be rubbed out and replaced.

Three data types

Character — individual letters: A, B or C
String — letters, words or text: Olena
Integer — whole numbers: 10

One variable, many algorithms

The same variable can be used in a number of algorithms: the user name — for the password, for the last log-in, for the final score.
