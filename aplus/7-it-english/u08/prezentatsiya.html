What is a pattern?

Один читає рядок англійською — наступний перекладає. Клацни на рядок — переклад.

1
What is a pattern? A repeating sequence of data, values, text, images or signs.
Що таке pattern? Послідовність даних, значень, тексту, зображень або знаків, яка повторюється.
2
How do you recognise a pattern in numbers? Look at the numbers and see if the same sequence of numbers occurs more than once.
Як знайти повтор у числах? Подивись, чи та сама послідовність чисел трапляється більше ніж один раз.
3
In text? Look at the text and see if the same words or letters appear multiple times in the same order.
У тексті? Подивись, чи ті самі слова або літери зʼявляються багато разів у тому самому порядку.
4
In an image? Look at an image and see if the same colours, shapes, pixels appear in a sequence.
На зображенні? Подивись, чи ті самі кольори, фігури, пікселі йдуть послідовністю.

Sub-routines and patterns

Один читає рядок англійською — наступний перекладає. Клацни на рядок — переклад.

1
What is a sub-routine? An independent or separate algorithm, that has a name, and can be called from other parts of an algorithm.
Що таке підпрограма? Незалежний, окремий алгоритм, який має імʼя і який можна викликати з інших частин алгоритму.
2
When are sub-routines used? When the same series of steps might need to run more than once.
Коли використовують підпрограми? Коли ті самі кроки, можливо, треба виконати більше ніж один раз.
3
Why are sub-routines helpful? Instead of writing the same steps multiple times, you can write them once and then call them multiple times.
Чим корисні підпрограми? Замість писати ті самі кроки багато разів, їх пишуть один раз і викликають багато разів.
4
Is there a link between sub-routines and patterns? Yes. The repetition first needs to be identified using pattern recognition.
Чи є звʼязок між підпрограмами й повторами? Так. Спершу повтор треба знайти — це pattern recognition.

What does the word ‘select’ mean?

Один читає рядок англійською — наступний перекладає. Клацни на рядок — переклад.

1
The word ‘select’ relates to the choice of one or more options, or outcomes.
Слово «select» стосується вибору одного чи кількох варіантів, або результатів.
2
The words ‘IF’, ‘THEN’ and ‘ELSE’ are commands that give choice of one or more options or outcomes.
Слова IF, THEN і ELSE — це команди, які дають вибір одного чи кількох варіантів або результатів.
3
Therefore they require a selection to be made.
Тому вони вимагають зробити вибір (selection).

Patterns

repetition → sub-routine

Choices

IF, THEN, ELSE → selection

Selection in a flowchart

1
A diamond-shaped box is used.
Використовують фігуру-ромб.
2
The diamond has two data flow arrows coming from it, labelled ‘true’, or ‘yes’, and ‘false’, or ‘no’.
З ромба виходять дві стрілки, підписані «true» або «yes» і «false» або «no».
3
The word ‘IF’ starts the question. The word ‘IS’ can also be used: IS number1 > number2?
Питання починається словом IF. Можна й словом IS.
4
The question (condition) must have a true or false result only — there can only be two options, not three or four.
Питання (умова) має лише відповідь true або false — тільки два варіанти, не три й не чотири.
5
If the question is true, the true data flow is followed. This is the ‘IF’ and ‘THEN’.
Якщо питання true, ідемо стрілкою true. Це IF і THEN.
6
If the question is false, the false data flow is followed. This is the ‘ELSE’.
Якщо питання false, ідемо стрілкою false. Це ELSE.

Key idea · Constructs

Sequence or selection?

Select and use appropriate constructs in algorithms written as flowcharts — sequence and selection. — обери потрібну конструкцію.

sequence

steps one after another · input, process, output

INPUT → process → OUTPUT

selection

a question in a diamond · two options: true or false

IF … THEN … ELSE …

🪜
Start with sequence flowcharts, and gradually increase the complexity to selection.

Words in use

Читаємо по черзі: картка — один учень читає, наступний перекладає.

pattern A pattern is a repeating sequence of data. Identify the pattern, which is the repeated elements.
pattern recognition The repetition needs to be identified using pattern recognition. Pattern recognition shows where sub-routines are appropriate.
sub-routine Put the repeated elements in a sub-routine. Call it from the main algorithm.
sequence Create flowcharts that use sequence and selection. Start with sequence flowcharts.
selection A selection must be in a diamond. A selection must only have true or false as answers.
choice ‘Select’ relates to the choice of one or more options. IF, THEN and ELSE give choice of options or outcomes.
