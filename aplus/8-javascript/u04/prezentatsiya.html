Тип 2

ReferenceError — такої змінної немає

script.js · зламано навмисно
console.log('старт'); const name = 'Марія'; alert(nmae); // ReferenceError: nmae is not defined
Три причини: одруківка · забув оголосити · звернувся раніше, ніж оголосив

Не те саме, що SyntaxError

Файл почав виконуватись. Усе, що було до цього рядка, уже спрацювало — «старт» у консолі є.

Зупинка — рівно на рядку з помилкою. Усе, що нижче, не виконалось.

Тип 3

TypeError — з цим значенням так не можна

script.js · зламано навмисно
const price = 499; price = 399; // TypeError: Assignment to // constant variable const name = prompt('Ім\'я:'); console.log(name.length); // натиснули Скасувати // TypeError: Cannot read // properties of null

Що не так у кожному?

Поясни обидва, потім клацни.

Перший: const не можна переприсвоїти. Змінна, яка змінюється, — це let

Другий: Скасувати дає null — «навмисно порожньо». У порожнечі немає нічого, зокрема довжини

Другий зустрічатиметься найчастіше. Від нього рятує перевірка raw === null з уроку 3.

Проти логічних помилок — інструменти, які показують, що насправді лежить у змінних: console.log, breakpoint і debugger. Усі три — сьогодні.

Інструмент 1

console.log — не для виводу, а для перевірки

script.js
const raw = prompt('Вік:'); console.log('raw =', raw, typeof raw); // raw = 12 string const age = Number(raw); console.log('age =', age, typeof age); // age = 12 number
Плюсом — бреше
console.log('age = ' + age); // age = 12 — рядок чи число? не видно
Комою — правда
console.log('age =', age); // рядок і число консоль показує по-різному
Назва змінної — у тексті, щоб знати, чий це рядок
typeof — половина бід саме про тип
У console.log — кома, не плюс
📍
Метод

Чотири місця для console.log

1 Одразу після prompt — що прийшло
2 Після Number() — чи перетворилось
3 У кожній гілці if — яка спрацювала
4 Перед результатом — чи збігається з очікуваним
script.js
const raw = prompt('Вік:'); console.log('1 raw =', raw); const age = Number(raw); console.log('2 age =', age); let price; if (age < 18) { console.log('3 гілка: дитячий'); price = 80; } else { console.log('3 гілка: дорослий'); price = 150; } console.log('4 price =', price);

Знайди

Помилки немає. Але порожнє поле дає «Малюк»

script.js · зламано навмисно
const age = prompt('Вік:'); if (age < 6) { alert('Малюк'); } else if (age < 18) { alert('Дитячий'); } else { alert('Дорослий'); } // натиснули OK з порожнім полем

Чому людина без віку стала малюком?

Знайди причину, потім клацни.

Порожнє поле дає порожній рядок ''.

< сам перетворює рядок на число, а Number('') — це 0. Перевіряється 0 < 6 → true.

Жодної помилки в консолі. Видно тільки так: console.log('age =', age, typeof age) — порожні лапки й слово string.

Лікується перевіркою вводу з уроку 3: if (raw === '').

Приклад — чотири точки перевірки

Тепер самостійно
  • Відкрити свій «Квиток у кіно» з уроку 3. Немає — набрати код зі слайда 12
  • Поставити console.log у всі чотири місця
  • Прогнати на віках 3, 12, 30, 70 — по консолі назвати гілку, не дивлячись на вікно
  • Навмисно прибрати Number(). Що змінилось у логах? А ціна? Повернути
  • ⭐⭐ Скасувати й порожнє OK — що показують логи кожного разу? Чим відрізняються?
  • ⭐⭐⭐ Показати вік у логах і плюсом, і комою. Де видно, що це рядок? Потім прибрати всі логи

Інструмент 2

breakpoint — зупинити програму посеред роботи

console.log показує окремі точки. Breakpoint дає більше: програма стає на паузу, і видно ВСІ змінні одразу — а далі можна йти по одному рядку.

1 F12 → вкладка Sources → зліва вибрати script.js
2 Клацнути по номеру рядка — з'явиться синя мітка
3 Оновити сторінку (F5). Виконання зупиниться саме там, рядок підсвітиться
👁️
Що видно на паузі

Права панель і дві клавіші

Scope — усі змінні, які зараз існують, і що в кожній. Нічого не треба логувати
Навести мишею на змінну в коді — спливе її значення

Дві клавіші

↷ Step over F10 — виконати один рядок і знову стати

▶ Resume F8 — бігти далі до наступної мітки

▸ Мітка не спрацювала — поставили після завантаження. Оновити сторінку
▸ Мітка зникла після оновлення — Chrome іноді губить її. Поставити ще раз
▸ Сторінка «зависла» — вона на паузі. F8
▸ Прибрати мітку — клацнути по ній ще раз. У файлі її немає

Три рядки — три різні типи

Назви тип кожної й полагодь

Нове в коді

+= — додати до того, що вже є

довго
let score = 0; score = score + 1; score = score + 1; // 2
коротко — те саме
let score = 0; score += 1; score += 1; // 2
score += 1 — «збільш score на 1»
Так само -= і *=. З рядком += доклеює текст
Тільки let. З const — TypeError
🧠
= означає не «дорівнює», а «поклади праве в ліве». Спершу рахується правий бік, потім результат іде в змінну.

Задача уроку

Вікторина на три питання

script.js
let score = 0; const a1 = prompt('Столиця України?'); if (a1 === 'Київ') { score += 1; } const a2 = Number(prompt('5 × 6 = ?')); if (a2 === 30) { score += 1; } // третє питання так само alert(`Ваш результат: ${score} з 3`);
Усе вже знайоме: prompt, Number(), if, шаблонний рядок. Нове тільки +=
Три питання — три окремі блоки. Коротше можна циклом, але цикли — у листопаді
Числова відповідь — через Number(). Текстова — рядком, і тут чатує пастка
🪤
Пастка вікторини

«київ» — це не «Київ»

консоль
'київ' === 'Київ' // false 'Київ ' === 'Київ' // false — пробіл! 'КИЇВ' === 'Київ' // false ' КИЇВ '.trim().toLowerCase() // 'київ'
=== порівнює рядки посимвольно. Велика й маленька літера — різні символи
.toLowerCase() — усе маленькими літерами
.trim() — прибрати пробіли з країв
Разом: a1.trim().toLowerCase() === 'київ' — порівнюємо з маленькими
💀
Скасувати → a1 дорівнює null → null.trim() → TypeError. Той самий, що на слайді 7.
🤔
Знайди

Вікторина дає 0 балів завжди. Чому?

script.js · зламано навмисно
let score = 0; const a1 = prompt('2 + 2 = ?'); if (a1 === 4) { score += 1; } alert(`Результат: ${score}`); // ввели 4, а балів 0

Помилки в консолі немає. Де біда?

Знайди сам, потім клацни.

prompt повертає рядок '4', а порівнюємо з числом 4. '4' === 4 → false.

Два способи полагодити:

if (Number(a1) === 4) — перетворити

if (a1 === '4') — порівняти з рядком

Як знайти самому: console.log('a1 =', a1, typeof a1) → a1 = 4 string. Слово string і є відповідь.
