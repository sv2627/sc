7.8 Trace tables

Довідка · с. 179–183

Trace table

a structure to complete when walking through an algorithm manually, where the values that change are written in each row

Як заповнювати

Each variable has its own column + an OUTPUT column.

Read one line and perform that action. Don't jump ahead and guess.

Пам'ятай

When a variable has a new value, it is written below the previous one.

Outputs must match the code: The total is 10, not total = 10.
