label і for: підпис знає своє поле

index.html
<form class="order-form"> <label for="name">Ім'я</label> <input type="text" id="name" name="name"> <button type="submit">Замовити</button> </form>
Так
for="name" id="name"
Не так
for="name" id="imya"
forу підпису — те саме слово, що id поля
клікклацнув на підпис — курсор уже в полі. На телефоні це велика ціль для пальця
nameім'я, під яким значення поля піде на сервер
сіткаполя стовпчиком із проміжком: .order-form { display: grid; gap: 8px; }

Кружечки, галочки, список і великий текст

<label><input type="radio" name="size"> малий</label> <label><input type="radio" name="size"> великий</label> <label><input type="checkbox" name="togo"> з собою</label> <label for="drink">Напій</label> <select id="drink" name="drink"> <option>Капучино</option> <option>Лате</option> </select> <label for="note">Побажання</label> <textarea id="note" name="note" rows="3"></textarea>
radioоднаковий name — одна група: обираєш один
checkboxкожна галочка сама по собі: скільки завгодно

checkedкружечок чи галочка вже обрані з самого початку

Нове · без жодного рядка JavaScript

Перевірка: браузер не пускає помилку

<input type="text" id="name" placeholder="Олена" required> <input type="number" id="count" min="1" max="10"> <input type="text" id="phone" placeholder="0671234567" pattern="[0-9]{10}">
⚠️ Заповніть це поле.
АтрибутЩо робить
requiredполе обов'язкове: порожнім форма не піде
placeholderсіра підказка в порожньому полі — не значення
min · maxнайменше й найбільше число (для number, date)
patternзразок: [0-9]{10} — рівно десять цифр
type="email"без @ — не пропустить

Крок 1 · ⭐ Поля з підписами5 хвилин
Приклад
<form class="order-form"> <label for="name">Ім'я</label> <input type="text" id="name" name="name"> <label for="email">Пошта</label> <input type="email" id="email" name="email"> <button type="submit" class="btn">Замовити</button> </form>
.order-form { display: grid; gap: 8px; max-width: 420px; }
Тепер самостійно
  • У розділ «Замовити» свого сайту — form class="order-form"
  • Два поля: ім'я (text) і пошта (email), кожне з label
  • for підпису = id поля. Перевір: клац на підпис
  • Кнопка «Замовити» з класом btn
  • CSS: форма — сітка в один стовпчик, не ширша за 420px
  • ⭐⭐ Полям — рамка, padding, font-size: 16px
Крок 2 · ⭐ Вибір значень5 хвилин
Приклад
<label for="drink">Напій</label> <select id="drink" name="drink"> <option>Капучино</option> <option>Лате</option> </select> <label for="count">Скільки чашок</label> <input type="number" id="count" name="count"> <label for="day">Коли прийдеш</label> <input type="date" id="day" name="day"> <p>Розмір: <label><input type="radio" name="size"> малий</label> <label><input type="radio" name="size"> великий</label> </p> <label><input type="checkbox" name="togo"> з собою</label>
Тепер самостійно
  • Список select — три варіанти зі свого каталогу
  • Число (number) і дата (date) — з підписами
  • Два–три кружечки з однаковим name
  • Галочка checkbox
  • textarea «Побажання», rows="3"
  • ⭐⭐ Один кружечок обраний одразу — checked
Крок 3 · ⭐⭐ Перевірка4 хвилини
Приклад
<input type="text" id="name" name="name" placeholder="Олена" required> <input type="number" id="count" name="count" min="1" max="10" value="1"> <input type="text" id="phone" name="phone" placeholder="0671234567" pattern="[0-9]{10}">
⚠️ Значення має бути не більше 10.
Тепер самостійно
  • Ім'я і пошта — required. Натисни «Замовити» з порожніми
  • Кожному текстовому полю — placeholder із прикладом
  • Число — min="1" і max="10". Впиши 15 — що каже браузер?
  • Поле «Телефон» з pattern="[0-9]{10}". Впиши 9 цифр
  • ⭐⭐⭐ Друга форма «Вхід»: пошта і password, обидва required
