Коробкова модель

Кожен елемент — це коробка з чотирьох шарів

margin — зовнішній відступ
border — рамка
padding — внутрішній відступ
вміст
текст, картинка
вмістсам текст чи картинка
paddingвід вмісту до рамки. Фон елемента заходить сюди
borderрамка навколо padding
marginвід рамки до сусідів. Завжди прозорий
Коробки є в усіх: h1, p, section, article, a. Досі всі рамки були нульові — тому їх не було видно

margin

Зовнішній відступ — простір між коробками

style.css
.card { margin-bottom: 16px; } footer { margin-top: 30px; }
Форми запису — ті самі, що в padding: 1, 2, 3 або 4 числа, margin-top … margin-left
Барсик зловив мишу
margin-bottom 16px
Барсик у ветеринара
padding — усередині рамки, фон є. margin — ззовні, прозорий: видно фон батька

Прибрати відступ: margin: 0; — нуль можна без px
