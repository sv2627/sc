Два класи на одному елементі

katalog.html + style.css
<p class="price">450 грн</p> <p class="price sale">250 грн</p> .price { color: red; font-weight: bold; } .sale { background-color: yellow; }

450 грн

250 грн

Класи — через пробіл в одних лапках. Елемент отримує правила обох класів
Порядок не важливий: "price sale" = "sale price"
⚠️
class="price" class="sale" — два атрибути: браузер бере тільки перший
class="price, sale" — кома прилипає: price, — уже інше імʼя, ціна не червона
