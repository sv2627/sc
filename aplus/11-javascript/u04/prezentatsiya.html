Тип 1

SyntaxError — написано не за правилами мови

script.js · зламано навмисно
const name = prompt('Ім\'я:'; // не закрита дужка if (age > 18 { // не закрита дужка умови
Найважливіше: при SyntaxError не виконується жоден рядок файлу. Навіть ті, що вище
Ознака: сторінка «зовсім нічого не робить», хоча раніше працювала
Номер рядка може вказувати на наступний після справжньої помилки. Дивіться на рядок вище теж
🔤
Майже завжди причина одна з трьох: незакрита дужка, незакриті лапки, зайва або пропущена кома.
👻
Тип 2

ReferenceError — такої змінної немає

script.js · зламано навмисно
const name = 'Марія'; alert(nmae); // ReferenceError: nmae is not defined
Три причини: одруківка · забув оголосити · написав до оголошення

Головна відмінність від SyntaxError

Файл почав виконуватись. Усе, що було до цього рядка, уже спрацювало.

Тому в консолі поруч можуть бути результати попередніх console.log — це нормально й навіть корисно.

🧩
Тип 3

TypeError — значення не того типу

script.js · зламано навмисно
const age = 25; age.toUpperCase(); // TypeError: age.toUpperCase // is not a function const x = null; x.length; // TypeError: Cannot read // properties of null

Чому саме ці два приклади?

Подумай, потім клацни.

Перший: toUpperCase — це дія для рядків. У числа її немає

Другий: null — це «навмисно порожньо». У порожнечі немає нічого, зокрема довжини

Другий випадок ви зустрінете найчастіше: prompt + Скасувати дає null, і будь-яка дія з ним дає TypeError.

Ось навіщо була перевірка вводу на минулому уроці.

Тепер самостійно

Інструмент 1

console.log — не для виводу, а для перевірки

Ви користувались ним з першого уроку, щоб щось показати. Сьогодні його справжня робота: подивитись, що реально лежить у змінній у цю мить.

script.js
const raw = prompt('Вік:'); console.log('raw =', raw, typeof raw); const age = Number(raw); console.log('age =', age, typeof age);
Пишіть назву змінної в тексті. Інакше через п'ять рядків не зрозумієте, який log чий
Додавайте typeof. Половина ваших бід — саме про тип, а не про значення
🪤
Дрібниця, яка ламає все

Кома, а не плюс

Плюсом — бреше
console.log('age = ' + age); // age = 25 // а число це чи рядок — // не видно взагалі
Комою — правда
console.log('age =', age); // age = '25' ← рядок // age = 25 ← число // консоль показує різницю
➕
Плюс перетворює все на рядок — той самий плюс, що ламав вам арифметику на уроці 2. Тут він приховує саме те, що ви шукаєте. У console.log — завжди кома.
📍
Метод

Де ставити console.log

1 Одразу після кожного prompt — побачити, що прийшло
2 Після кожного Number() — переконатись, що перетворилось
3 Усередині кожної гілки if — побачити, яка спрацювала
4 Перед кінцевим результатом — звірити з тим, що очікували
🧹
Полагодили — приберіть їх. Купа console.log у робочому коді заважає наступного разу.
🤔
Знайди

Помилки немає. Але порожнє поле дає «Малюк»

script.js · зламано навмисно
const age = prompt('Вік:'); if (age < 6) { alert('Малюк'); } else if (age < 18) { alert('Дитячий'); } else { alert('Дорослий'); } // натиснули OK з порожнім полем

Чому людина без віку стала малюком?

Знайди причину, потім клацни.

Порожнє поле дає порожній рядок ''.

У порівнянні '' < 6 оператор < сам перетворює рядок на число. А Number('') — це 0.

Отже перевіряється 0 < 6 → true. Перша гілка спрацювала.

Жодної помилки в консолі. Знайти це можна тільки одним способом: console.log('age =', age, typeof age) — і побачити порожні лапки та слово string.

Лікується перевіркою вводу з минулого уроку: Number() плюс if (raw === '').

Практика 2 console.log як інструмент6 хвилин
Приклад — чотири точки перевірки
console.log('raw =', raw, typeof raw); console.log('age =', age, typeof age); console.log('гілка: дитячий'); console.log('price =', price);
Тепер самостійно
  • Узяти свій «Квиток у кіно» з минулого уроку
  • Поставити console.log у всі чотири місця зі слайда 13
  • Прогнати на віках 3, 12, 30, 70 — і простежити по консолі, яка гілка спрацювала
  • Прибрати Number() і знайти поломку по консолі, а не очима
  • ⭐⭐ Порівняти console.log('age = ' + age) і console.log('age =', age). Побачити різницю
  • ⭐⭐⭐ Прибрати всі console.log і переконатись, що код працює так само
⏯️
Інструмент 2

breakpoint — зупинити програму посеред роботи

console.log показує окремі точки. Breakpoint дає більше: програма зупиняється, і ви бачите ВСІ змінні одразу — і можете йти далі по одному рядку.

1 F12 → вкладка Sources → зліва вибрати script.js
2 Клацнути по номеру рядка — з'явиться синя мітка
3 Оновити сторінку. Виконання зупиниться саме там, рядок підсвітиться
👁️
Що видно на паузі

Права панель показує все

Scope — усі змінні, які зараз існують, і що в кожній. Не треба нічого логувати
Наведіть мишею на змінну прямо в коді — спливе її поточне значення
Сторінка на паузі не реагує ні на що. Це нормально, так і має бути

Три кнопки, яких вистачить

▶ Resume (F8) — бігти далі до наступного breakpoint

↷ Step over (F10) — виконати один рядок і знову стати. Оце головне

Прибрати мітку — клацнути по ній ще раз

⚖️
Коли що брати

console.log проти breakpoint

console.log

Швидко, нічого не треба відкривати. Видно історію: усі значення підряд, зокрема ті, що були давно

Беріть, коли: знаєте приблизно, де шукати, або треба подивитись, як значення змінювалось

breakpoint

Видно всі змінні одразу, без жодного рядка коду. Можна йти по одному кроку

Беріть, коли: не розумієте, куди взагалі йде виконання, або змінних багато

🤝
На практиці їх поєднують: console.log, щоб звузити місце, потім breakpoint — щоб розібратись у ньому детально.
🚧
Що станеться на уроці

Три дрібниці з breakpoint

▸ Мітка не спрацювала. Її поставили після завантаження сторінки — треба оновити, щоб код пішов заново
▸ Мітка зникла після оновлення. Chrome іноді її губить. Просто поставте ще раз
▸ Сторінка «зависла». Вона на паузі. Натисніть F8 — і все побіжить далі
🧯
Головне: breakpoint нічого не змінює у вашому коді. Це мітка в браузері, не в файлі. Закрили DevTools — усе працює як раніше.

Виправ

Три рядки — три різні типи

script.js · зламано навмисно
// 1 const a = Number(prompt('Число:'); // 2 alert('Вітаю, ' + user); // 3 const b = prompt('Ім\'я:'); alert(b.toUpperCase()); // натиснули Скасувати

Назви тип кожної

Розбери всі три, потім клацни.

1 · SyntaxError. Не закрита дужка Number(. Жоден рядок файлу не виконається

2 · ReferenceError. Змінної user ніде немає

3 · TypeError. Скасувати дало null, а в null немає toUpperCase

Порядок лагодження завжди такий самий: спершу синтаксис — поки він зламаний, решти помилок ви навіть не побачите.

Нове в коді

+= — додати до того, що вже є

довго
let score = 0; score = score + 1; score = score + 1;
коротко — те саме
let score = 0; score += 1; score += 1;
score += 1 читається «збільш score на 1». Так само працюють -=, *=
Обов'язково let, не const: значення змінюється
🧠
score = score + 1 у математиці — нонсенс. У програмуванні = означає не «дорівнює», а «поклади праве в ліве». Спершу рахується правий бік.

Пастка вікторини

«київ» — це не «Київ»

консоль
'київ' === 'Київ' // false 'Київ ' === 'Київ' // false — пробіл! 'КИЇВ' === 'Київ' // false
=== порівнює рядки посимвольно. Велика й маленька літера — різні символи
Рятує .toLowerCase() — зводить усе до маленьких: a1.toLowerCase() === 'київ'
І .trim() — прибирає пробіли з країв. Разом: a1.trim().toLowerCase()
💀
Обережно: якщо людина натисне Скасувати, a1 буде null — і null.toLowerCase() дасть TypeError. Ось де сьогоднішня тема зустрічається з учорашньою.

Знайди

Вікторина дає 0 балів завжди. Чому?

script.js · зламано навмисно
let score = 0; const a1 = prompt('2 + 2 = ?'); if (a1 === 4) { score += 1; } alert(`Результат: ${score}`); // ввели 4, а балів 0

Помилки в консолі немає. Де біда?

Знайди сам, потім клацни.

prompt повертає рядок '4'. А порівнюємо з числом 4.

'4' === 4 → false, бо === порівнює і значення, і тип.

Два способи полагодити:

if (Number(a1) === 4) — перетворити

if (a1 === '4') — порівняти з рядком

Як знайшли б це самі: console.log('a1 =', a1, typeof a1) → a1 = 4 string. Слово string і є відповідь.

Практика 4 Вікторина на три питання8 хвилин
Приклад — один блок, далі за аналогією
let score = 0; const a1 = prompt('Столиця України?'); if (a1.trim().toLowerCase() === 'київ') { score += 1; } // ще два питання так само alert(`Ваш результат: ${score} з 3`);
Тепер самостійно
  • Зробити три питання на свою тему. Одне має бути з числовою відповіддю
  • Числове питання — не забути Number()
  • Додати .trim().toLowerCase() до текстових відповідей
  • У кінці — оцінка словами: 3 бали «Відмінно», 2 «Добре», решта «Спробуй ще»
  • ⭐⭐ Показувати після кожного питання, чи відповідь правильна
  • ⭐⭐⭐ Захистити від Скасувати: щоб не було TypeError на null
