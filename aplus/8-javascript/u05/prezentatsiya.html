Три питання — одна відповідь

1 prompt — перше число. Людина вводить 7
2 prompt — знак дії: + - * /. Людина вводить *

Три рівні

Кожен наступний — це попередній плюс ще щось

⭐ Рахує. Два числа й знак через prompt, чотири дії + - * /, відповідь в alert шаблонним рядком
⭐⭐ Не ламається. + Скасувати, порожнє поле, не число, невідомий знак, ділення на нуль — на кожне своє повідомлення
⭐⭐⭐ Уміє більше. + дії % і **, другий режим — конвертер валют з округленням toFixed(2)

Два способи вибрати дію

if / else if чи switch — результат той самий

if / else if
let result; if (op === '+') { result = a + b; } else if (op === '-') { result = a - b; } else { result = 'невідомий знак'; }
switch
let result; switch (op) { case '+': result = a + b; break; case '-': result = a - b; break; default: result = 'невідомий знак'; }
Обирай будь-який. Обидва порівнюють op через ===
Забув break — виконається й наступний case
default = останній else: «жоден знак не підійшов»
Рівень ⭐ Калькулятор, що рахує13 хвилин
Приклад — одна дія з чотирьох
// Рівень ⭐ · Прізвище Імʼя const a = Number(prompt('Перше число:')); const op = prompt('Знак: + - * /'); const b = Number(prompt('Друге число:')); let result; if (op === '+') { result = a + b; } alert(`${a} ${op} ${b} = ${result}`);
Тепер самостійно
  • Набрати приклад, перевірити 2 + 3
  • Дописати -, *, / через else if або switch
  • Прогнати три тести ⭐ зі слайда 15
  • Прибрати Number() з першого рядка. Що стало з 2 + 3? Повернути
  • ⭐⭐ Ввести знак ^. Додати else або default: «Невідомий знак: ^»
  • ⭐⭐⭐ Переписати вибір дії другим способом: if ↔ switch. Тести мають дати те саме

Знайди

Ввели 2, *, 3 — а побачили «2 + 3 = 23»

script.js · зламано навмисно
let a = prompt('Перше:'); let op = prompt('Знак:'); let b = Number(prompt('Друге:')); let result; if (op = '+') { result = a + b; } else if (op === '*') { result = a * b; } alert(`${a} ${op} ${b} = ${result}`);

Дві помилки, жодного червоного рядка

Знайди обидві, потім клацни.

1. op = '+' — одне =. Знак перезаписано на плюс, умова завжди істинна. Тому в alert плюс, хоч ввели зірочку

2. a без Number() — '2' + 3 склеїлось у '23'

Як знайти самому: console.log('op =', op) до і після if. Змінилось — ось воно.

5,5 з комою — не число для JavaScript: Number('5,5') → NaN. Дробові — тільки через крапку: 5.5.

Підказка до ⭐⭐

Одна розвилка — перевірки згори

1 Скасували? raw1 === null || op === null || raw2 === null
2 Порожньо? raw1 === '' || raw2 === ''
3 Не число? isNaN(a) || isNaN(b)
4 На нуль? op === '/' && b === 0
5 Далі — чотири дії і останній else: невідомий знак
Спершу сирий ввід у raw1, raw2, потім Number() окремим рядком. Інакше Скасувати й порожнє поле не розрізнити: обидва стануть 0
isNaN(x) — нове: коротший брат Number.isNaN. Сам робить Number(): isNaN('abc') → true
Перевірки — вище за дії. Перша, що спрацювала, — єдина

Приклад — початок розвилки
const raw1 = prompt('Перше число:'); const op = prompt('Знак: + - * /'); const raw2 = prompt('Друге число:'); const a = Number(raw1); const b = Number(raw2); if (raw1 === null || op === null || raw2 === null) { alert('Скасовано'); } else if (op === '+') { alert(`${a} + ${b} = ${a + b}`); } // далі — інші дії
Тепер самостійно
  • Перейти на сирий ввід, як у прикладі. Тести ⭐ мають працювати як раніше
  • Додати «Поле порожнє», «Це не число», «На нуль ділити не можна» — по одній, щоразу тест
  • Останній else: «Невідомий знак: ^»
  • Поставити перевірку «не число» вище за «порожнє». Що тепер дає порожнє поле? Повернути
  • ⭐⭐ Дробові: 2.5 · * · 4 має дати 10
  • ⭐⭐⭐ Точне повідомлення: «Перше поле порожнє» або «Друге поле порожнє»

Діагностика

Шість бід калькулятора

2 + 2 = 22 — немає Number()
Завжди рахує плюсом — одне = в умові
= undefined — знак не збігся з жодною гілкою, else немає
Infinity — ділення на нуль не перевірено
Не число, хоча ввів число — дріб через кому або пробіл у полі
Сторінка мовчить зовсім — SyntaxError, відкрий консоль
🔦
Знак не збігається, хоча ввів правильний? console.log('[' + op + ']') — квадратні дужки покажуть зайвий пробіл.

Банк — доповни свій калькулятор

Парність. Після відповіді одним ? : дописати «парне» чи «непарне»
Відсоток. Режим 3: «скільки це p % від числа n». 20 % від 150 → 30
Середнє трьох. Режим 4: три числа → середнє з двома знаками
Зворотна валюта. Конвертер уміє і usd → гривні
Знак словами. Людина вводить плюс замість + — теж додає
Множення буквою. x і X теж множать. Згадай toLowerCase()
Ціле ділення. Знак //: 7 // 2 → 3. Підказка: (a - a % b) / b
Порівняння. Знак ?: «7 більше за 6», «6 менше за 7» або «рівні»
Усі вісім — тільки тим, що вже було. Циклів не треба
