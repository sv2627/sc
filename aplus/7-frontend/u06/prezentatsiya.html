Нагадування · урок 3

rem — для тексту й відступів, % — для ширини

pxremде
16px1remзвичайний текст
8px0.5remмалий відступ
24px1.5remh2, проміжок
32px2remh1
main { width: 80%; margin: 0 auto; } h1 { font-size: 2rem; }
1rem = розмір шрифта сторінки, зазвичай 16px
80% — від ширини батька. margin: 0 auto — по центру
