Що надіслати

Картинку блоків проєкту MoyaGra: у Blocks правий клік на порожньому місці → Download Blocks as Image. І відповіді на пункт 2 — текстом у коментарі до завдання.

1 · Персонаж тікає навмання

Що зробити: торкнувся персонажа — +1 бал, а персонаж стрибає у випадкове місце полотна.

Що має вийти: після кожного дотику бали ростуть, а персонаж щоразу в іншому місці і видно його повністю.

Де: у підкові when ImageSprite1.Touched блок MoveTo; у гнізда x і y — Built-in → Math → random integer from … to …, межі 0 і 220 (полотно 300 − персонаж 80).

set global baly toget global baly + 1
set Label1.Text tojoin"Бали: "get global baly
call ImageSprite1.MoveTo
x random integer from 0 to 220
y random integer from 0 to 220
