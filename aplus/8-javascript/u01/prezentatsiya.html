Друга половина уроку

Змінна — коробка з назвою

Python — ти це вже писав
price = 499 print(price)
JavaScript — те саме
let price = 499; console.log(price);
Різниця рівно у двох речах: спереду зʼявилося слово let, у кінці — крапка з комою. Сама ідея та сама.
🔒
Нове в коді

let і const

let — значення може змінитись

let score = 0; score = 10; // можна

const — значення назавжди

const shop = 'GameStore'; shop = 'Інший'; // помилка
📌
Правило на весь рік: починай із const. Заміни на let тільки тоді, коли справді треба буде змінити значення. Так менше випадкових помилок.
🏷️
Нове

Три типи, яких вистачить надовго

number

Як називати змінні

Так

  • ціна — не кирилицею
  • total price — без пробілів

Читаємо помилки

Три червоні написи

1
SyntaxError — помилка запису. Забув дужку, лапку або кому. Код не запустився взагалі
2
ReferenceError: x is not defined — такої змінної немає. Найчастіше — друкарська помилка в назві
3
NaN — не помилка, а результат. «Not a Number»: спробував порахувати з текстом
Читати треба завжди перший червоний рядок згори. Решта — часто наслідки того самого.
🧪
Ламаємо навмисне

Що виведе цей рядок?

script.js
const price = '499'; // у лапках! const count = 3; console.log(price * count); console.log(price + count);

Обидва рядки. Клац — перевіримо

Console1497
4993
Множення спрацювало: браузер сам перетворив '499' на число. А плюс — склеїв: '499' + 3 дало '4993'. Один тип даних, два різні результати.
