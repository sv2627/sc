Анатомія

З чого складається функція

main.dart
int suma(int a, int b) { return a + b; } void main() { int r = suma(2, 3); print(r); }
Console5
1. int — тип результату: що функція віддасть
2. suma — імʼя, з малої літери
3. (int a, int b) — параметри, кожен зі своїм типом
4. return — віддати результат і вийти
a, b — параметри (в оголошенні). 2, 3 — аргументи (у виклику)

Результат

void і return

main.dart
void pryvit(String imya) { print('Pryvit, $imya!'); } String riven(int bal) { if (bal >= 10) return 'vysokyi'; if (bal >= 7) return 'dostatnii'; return 'pochatkovyi'; }
void — «порожнеча»: функція щось робить, але нічого не віддає. return не потрібен
return одразу виходить з функції. Спрацював перший — решта рядків не виконується
⚠️ Функція з типом String мусить повернути рядок на кожному шляху. Забув останній return — програма не запуститься

Параметри · вид 1 з 3

Позиційні — порядок вирішує

main.dart
String opys(String nazva, int cina) { return '$nazva: $cina grn'; } opys('Minecraft', 600); // так opys(600, 'Minecraft'); // помилка: не ті типи opys('Minecraft'); // помилка: бракує аргументу
Аргументи стають у параметри по черзі: перший у перший, другий у другий
Усі позиційні — обовʼязкові. Скільки параметрів, стільки й аргументів
Переплутав порядок — Dart помітить за типами ще до запуску. Якщо типи однакові (int, int) — не помітить, і це найпідступніше
2️⃣
Параметри · вид 2 з 3

Необовʼязкові позиційні — у квадратних дужках

main.dart
String pryvit(String imya, [String slovo = 'Pryvit']) { return '$slovo, $imya!'; } print(pryvit('Olia')); print(pryvit('Olia', 'Hello'));
ConsolePryvit, Olia! Hello, Olia!
[ ] — «можна не передавати». Тоді береться значення за замовчуванням після =
Стоять у кінці, після обовʼязкових
Порядок і тут вирішує: другий аргумент завжди потрапляє в slovo

Параметри · вид 3 з 3

Іменовані — у фігурних дужках

main.dart
void lichy({required int kinec, int krok = 1}) { for (int i = 1; i <= kinec; i += krok) { print(i); } } lichy(kinec: 5); // 1 2 3 4 5 lichy(kinec: 9, krok: 4); // 1 5 9 lichy(krok: 4, kinec: 9); // те саме
У виклику пишемо імʼя: значення. Порядок не важливий
required — без цього аргументу програма не запуститься
int krok = 1 — можна не передавати, тоді буде 1
Так пишуть увесь Flutter: Text('Hi', style: …). Звикаємо зараз

Порівняння

Три види параметрів в одній таблиці

ВидОголошенняВикликОбовʼязковий?
позиційний(int a)f(2)так · порядок важливий
необовʼязковий позиційний(int a, [int b = 1])f(2) · f(2, 5)ні · є значення
іменований({required int a})f(a: 2)так · порядок будь-який
іменований зі значенням({int krok = 1})f() · f(krok: 3)ні · є значення
Поєднувати можна: спершу позиційні, потім або [ ], або { } — обидва в одній функції не можна.
Коли параметрів три й більше — беремо іменовані. kvytok(misto: 'Lviv', den: 5) читається без підказок.

Коротко

Стрілкова функція =>

main.dart
// довгий запис int kvadrat(int x) { return x * x; } // те саме одним рядком int kvadrat(int x) => x * x; bool parne(int n) => n % 2 == 0; String hi(String s) => 'Hi, $s!';
=> вираз — це скорочення для { return вираз; }
Беремо, коли вся функція — один вираз
⚠️ Після => не можна кілька команд чи if з блоком. Треба більше — повертаємось до фігурних дужок
Тернарний з уроку 3 тут до речі: => bal >= 7 ? 'tak' : 'ni';

⭐⭐⭐ Функція як значення

Функцію можна передати в іншу функцію

main.dart
int zastosuy(int x, int Function(int) f) { return f(x); } int kvadrat(int x) => x * x; void main() { print(zastosuy(5, kvadrat)); print(zastosuy(5, (n) => n * 2)); }
Console25 10
int Function(int) — тип «функція, що бере int і повертає int»
Передаємо імʼя без дужок: kvadrat, а не kvadrat()
(n) => n * 2 — функція без імені, написана просто на місці
На уроці 6 так фільтруватимемо списки: where((g) => …)
🪞
⭐⭐⭐ Рекурсія

Функція, що кличе сама себе

main.dart
int faktorial(int n) { if (n <= 1) return 1; // база return n * faktorial(n - 1); // крок } print(faktorial(5)); // 120
Як рахує5 * 4 * 3 * 2 * 1 = 120
База — коли зупинитись. Без неї функція кличе себе вічно, і програма падає
Крок — та сама задача, але менша: n - 1
Будь-яку рекурсію можна переписати циклом for. Цикл зазвичай швидший, рекурсія — коротша
🧱
Правила разом

Функції кличуть функції · змінні живуть усередині

так
int podvoity(int x) => x * 2; int rakhuy(int x) { int d = podvoity(x); return d + 1; } // rakhuy(4) → 9
помилка
void lichylnyk() { int rahunok = 0; rahunok++; } void main() { lichylnyk(); print(rahunok); // Undefined name }
Змінна, створена всередині функції, існує тільки там. Потрібне значення назовні — повертай його через return. Порядок оголошення не важливий: main може стояти й першою.

Тримати відкритим

Уся родина на одному екрані

з результатом int f(int a) { return a * 2; }
без результату void f(String s) { print(s); }
ранній вихід if (x < 0) return 0;
стрілкова int f(int x) => x * x;
позиційні f(int a, int b) → f(2, 3)
необовʼязковий f(int a, [int b = 1]) → f(2)
іменовані f({required int a}) → f(a: 2)
зі значенням f({int krok = 1}) → f()
тип-функція int Function(int) f
без імені (n) => n * 2
рекурсія if (n <= 1) return 1; ... f(n - 1)
рядок n разів '*' * n

Цей слайд лишається на дошці, поки ви працюєте. Те саме є в роздатці — у довідці вгорі.

Набір функцій

Приклад · так виглядає одна функція і її виклик
int perymetr(int a, int b) { return 2 * (a + b); } void main() { print('Perymetr: ${perymetr(3, 4)}'); }

Перевір себе

Клацни, коли всі три запрацюють.

plosha(3, 4) → 12.0 pryvit('Olia') → Pryvit, Olia! parne(7) → false parne(10) → true

⭐ Тепер самостійно · обовʼязково для всіх
  • double plosha(double a, double b) — площа прямокутника
  • String pryvit(String imya) — повертає 'Pryvit, Olia!'
  • bool parne(int n) — true, якщо число парне
  • У main виклич кожну щонайменше двічі з різними аргументами й виведи результат із підписом
  • Над кожною функцією — коментар //: що вона робить

Клацни, якщо застряг.

Клацни, якщо застряг.

Фібоначчі: fib(0) = 0, fib(1) = 1, далі fib(n - 1) + fib(n - 2). fib(10) → 55
