Відкрити на дошці

Презентація

22 слайдів, три практичні блоки й дві схеми. Стрілки ← → або Space — гортати, свайп — на дошці й планшеті, F — на весь екран, Ctrl+P — зберегти у PDF

 Роздрукувати учням

Роздатка · 1 сторінка A4

Довідка в один блок угорі, решта аркуша — шість завдань олівцем: схема з пропусками, дві команди по пам'яті, стани файлів, словник. Робиться без комп'ютера, зокрема в сховищі. Ctrl+P → «Зберегти як PDF», книжкова, фонову графіку не вмикати
На уроці
  • Відкрити стартовий комплект папкою — File → Open Folder…
  • Що таке репозиторій і що змінює кнопка Initialize Repository
  • Службова папка .git: де історія й чому туди не заходять
  • Практика 1 (7 хв) — створити репозиторій і перевірити трьома способами
  • Автор змін: git config --global user.name та user.email
  • Практика 2 (4 хв) — назвати себе, перевірити через --list
  • Панель Source Control і дві букви стану: U untracked, M modified
  • Практика 3 (8 хв) — змінити файл, створити новий, прочитати стан
  • Три збої першого уроку й чому всі три лікуються видаленням .git
Що взяти

Ноутбук потрібен — це перший урок за машинами. VS Code і Git уже стоять, встановлювати нічого не треба. Стартовий комплект видаю на уроці. Інтернет не потрібен: GitHub буде аж у грудні.

Чого сьогодні немає

Комітів не робимо. git add і git commit — це урок 3 за планом. Сьогодні тільки готуємо місце й учимося читати стан файлів.
