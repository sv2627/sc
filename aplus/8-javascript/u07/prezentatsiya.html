Виправ

Три біди, а червона — лише одна

script.js · зламано навмисно
let gold = 0; const raw = prompt('Ліворуч чи праворуч?'); let c = raw.trim().toLowerCase(); if (c === 'ліворуч') { gold + 10; alert('Скриня!'); } else if (c = 'праворуч') { alert('Пастка. КІНЕЦЬ'); } alert(`Золото: ${gold}`);

Ввели «ліворуч», «абв», Скасувати

Знайди всі три, потім клацни

1. gold + 10; рахує, але не зберігає — «Золото: 0». Треба gold += 10;

2. c = 'праворуч' — одне =: на «абв» теж «Пастка». Треба ===

3. Скасувати → TypeError: null не має trim. Спершу raw === null

Банк завдань — бери будь-яке

Імʼя героя. prompt('Як тебе звати?') на початку, імʼя — в кожній кінцівці
Рюкзак. let item = 'нічого'; гілки кладуть предмет. Наприкінці: «У рюкзаку: …»
Платна брама. Є 7 золота — gold -= 7 і далі, ні — «Бракує 3 золота»
Друга спроба. Не зрозумів відповідь — спитати ще один раз, потім кінцівка
Меню через switch. Перша розвилка — switch: case '1': case 'ліс': поруч
Загадка. Двері відчиняються, якщо відповідь на загадку правильна: trim і toLowerCase
Чесний підсумок. Наприкінці: «Розвилок пройдено: 3» — лічильник += 1 у кожній
Зламай сусідові. У копії його квесту — одна тиха помилка. Хай шукає з console.log
Усі вісім — тільки тим, що вже було. Циклів не треба
