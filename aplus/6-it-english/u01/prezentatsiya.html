Sequence
🔢

Computers work in a precise order

wake up
↓
get up
↓
get dressed
↓

a sequence · послідовність
Компʼютер виконує код у точному порядку. Цей порядок англійською називається sequence.
🧠
У житті теж повно послідовностей. Ця — ранок звичайного дня.
Predict · передбач
🔀

What if we swap two steps?

wake up
↓
get up
↓
go to school
↓
get dressed
the same steps, different order

Кроки ті самі. Змінився тільки порядок. Що буде?

Клац або пробіл — і перевіримо

To go to school before getting dressed would be an error in the sequence.
🏷️
Це те, що комп'ютерні науковці називають logic error — логічна помилка.
Predict · передбач
🪥

Cleaning your teeth

take the toothbrush
↓
start to brush
↓
add the toothpaste

Чи можна так почистити зуби?

Клац — перевіримо

Можна. Someone can still brush their teeth — but this will be far less effective if they did not add the toothpaste before they started to brush.
Key idea
⚠️

What is a logic error?

If the code contains a logic error, it may still run — but not as the programmer expects it to.

Помилка, яку видно одразу

Програма зупиняється. Червоне повідомлення. Зрозуміло, де шукати.

Logic error

Програма працює до кінця. Нічого не червоніє. Просто результат — не той, якого ти хотів.

🔍
Саме тому logic error шукати найважче: комп'ютер не скаржиться. Помилку бачить лише людина, яка знає, що мало вийти.

Scratch blocks
📡

broadcast and when I receive

broadcast

broadcast message1
broadcast message1 and wait

Спрайт розсилає повідомлення всім іншим.

when I receive

when I receive message1

Спрайт чекає повідомлення. Поки не отримав — не робить нічого.

These blocks send messages between sprites to trigger events.
How it works
🔗

The second sprite waits for the message

Sprite 1

when green flag clicked
say "Knock, knock." for 2 seconds
broadcast knock

Sprite 2

when I receive knock
say "Who's there?" for 2 seconds
broadcast answer
The second sprite will not perform an action, such as saying "Who's there?", until they have received a message from the first sprite.
Naming messages
🏷️

One sprite, two or more scripts

The name of the message in the broadcast and when I receive blocks can be altered to trigger different events in the code.
🧩
Кожен спрайт матиме два або більше окремих шматки коду, кожен починається з when I receive — а не один довгий скрипт.

Criteria
✅

What makes the program successful?

Are the broadcast and when I receive blocks used to sequence events, rather than wait blocks?
Is the joke properly sequenced?
Is there sufficient time to read the text when the character displays it to the screen?
Ці три питання — наші criteria. За ними ми перевірятимемо і свою роботу, і роботу сусіда.
