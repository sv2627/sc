Уся родина

П'ять значень position

ЗначенняЩо робитьДе трапляється
staticстоїть на своєму місці, як завжди. Так — у всіх тегівусе, що ти верстав досі
relativeзсувається від свого місця; місце лишається за нимкартка — «якір» для бейджа
absoluteвиходить з потоку й стає поверх; рахує від найближчого relativeбейдж «-30%», підпис на фото
fixedприбитий до вікна, не гортаєтьсякнопка «вгору», чат у кутку
stickyїде зі сторінкою, а потім прилипаєшапка, що не зникає
Координати top · right · bottom · left — відстань від краю. Для static вони не працюють

z-index

Хто над ким

A · 1 B · 3 C · 2
.a { position: absolute; z-index: 1; } .b { position: absolute; z-index: 3; } .c { position: absolute; z-index: 2; }
1Більше число — вище. Просто число, без px
2z-index однаковий або немає — вище той, хто нижче в HTML
3Працює тільки з position: relative, absolute, fixed, sticky

C має стати над B. Що змінити?

Скажи число — потім клацни.

Будь-яке число, більше за 3: .c { z-index: 4; }
