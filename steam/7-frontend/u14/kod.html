Немає папки pr1 або вона відстала? Збери її за три хвилини: нова папка, у ній три файли. Кнопка «Скопіювати» бере весь блок

pr1/ ├── index.html ├── photos.html ├── style.css └── img/ └── barsyk.jpg ← будь-яке своє фото з таким ім'ям

VS Code → File → Open Folder… → pr1 → у панелі Explorer кнопки New File і New Folder. Імена файлів — точно такі. Немає фото — на його місці буде видно опис з alt
