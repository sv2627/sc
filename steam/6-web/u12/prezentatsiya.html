Як працює клас

Одне правило — на багато елементів

Один клас — багато елементів

Клас fact у трьох абзаців — одне правило виділяє всі три. Змінив правило — змінились усі

Клас — на будь-якому тезі

<p class="fact">, <li class="fact">, <h2 class="fact"> — правило .fact діє на всіх

Клас сильніший за тег

Абзац-факт отримує обидва правила. Де вони сперечаються — перемагає клас: він точніше каже, кому

style.css → у браузері
p { color: navy; } .fact { color: darkred; }

Мене звати Оля. — navy від p

Факт: я вмію свистіти. — darkred від .fact

Уся родина селекторів

Імʼя класу, два класи, тег + клас

Так — що це
fact note menu new-photo
Не так
red big new photo Fact ≠ fact

Латиницею, малими літерами, без пробілів. Два слова — через дефіс. red — погано: завтра колір зміниться, а імʼя лишиться

СелекторКому
pусім абзацам сторінки
.factусім із класом fact — будь-який тег
p.factтільки абзацам із класом fact. Разом, без пробілу
два класи — через пробіл
<p class="fact new">…</p> .new { font-weight: bold; }

Отримує правила обох класів. Порядок не важливий

Довідник — лишається на дошці

Класи на одному екрані

У HTML

<p class="fact">

імʼя без крапки

У CSS

.fact { color: red; }

крапка + імʼя

Два класи

class="fact new"

через пробіл, в одних лапках

Тег + клас

p.fact { }

тільки абзаци з класом, разом

Хто сильніший

.fact > p

клас перемагає тег

Банк завдань

1. Ще два факти — на hobi.html. Правило не міняй
2. Клас fact — пункту списку li, який тобі найважливіший
3. У правило .note — text-align: right
4. Над кожним правилом класу — коментар: /* факти */, /* примітка */
5. ⭐⭐ li.fact — інший колір, ніж у абзаців-фактів
6. ⭐⭐ Клас menu для списку посилань на index.html: великі літери, 20px
7. ⭐⭐⭐ Три класи на одному: class="fact new big", .big — 24px
8. ⭐⭐⭐ Картинку — у папку img/, якщо ще не там. Виправ src
Усі вісім робляться тільки тим, що було на уроках 1–12.
