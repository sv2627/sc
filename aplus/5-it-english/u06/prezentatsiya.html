A quiz program

Програма-вікторина: що вона робить

1The program asks a question. — Програма ставить питання.
2The user types the answer. — Користувач вводить відповідь.
3The program compares it with the correct answer. — Порівнює з правильною.
4Correct → ‘Correct, well done!’ · Not correct → ‘Hard luck, try again’

Key idea · one correct answer

Програма знає тільки одну відповідь

In which country is Chicago?

USA · America · the United States of America

Три правильні відповіді людською мовою.

if <answer = USA> then say Correct, well done! else say Hard luck, try again

Користувач вводить America. Що скаже програма?

Спочатку відповідь, потім клацни.

‘Hard luck, try again’ — програма бачить лише точно таку саму відповідь, як у блоці. Тому для вікторини беремо питання з однією правильною відповіддю.
