Цикли: for, while, do…while

Довідка

for — скільки разів

for (let i = 1; i <= 5; i++)

старт · умова · крок

i++ +1 · i-- −1 · i += 2

while · do…while

while (умова) { … } — спершу перевірка

do { … } while (умова); — хоч раз

умова не змінюється — вічний цикл

Керування

break — вийти з циклу

continue — пропустити крок

sum += i — накопичити; let sum = 0 до циклу

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
