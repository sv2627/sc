font-family

Шрифт — і запасний

style.css
body { font-family: Verdana, sans-serif; } h1 { font-family: "Times New Roman", serif; }
Через кому — запасний: немає першого шрифту на компʼютері — браузер бере наступний
Назва з пробілом — у лапках: "Times New Roman", "Courier New"

Родина шрифтів — пишемо останньою:

serif — з «ніжками»Про мене · Аа Бб Вв

monospace — літери однакової шириниПро мене · Аа Бб Вв

text-align · line-height

Де стоїть текст і скільки повітря між рядками

text-align: left; — ліворуч, так само
Мій ранок
text-align: center; — по центру
Мій ранок
text-align: right; — праворуч
Мій ранок
text-align: justify; — по ширині
Обидва краї рівні: браузер розтягує пробіли між словами в кожному рядку, крім останнього.
line-height: 1;
Рядки майже торкаються. Довгий текст так читати важко.
line-height: 1.5;
Зручно: між рядками є повітря. Так пишуть у книжках.
line-height: 2;
Дуже просторо: рядки далеко один від одного.
Число без px: у скільки разів рядок вищий за літери. Дріб — через крапку: 1.5

Банк завдань

1. На сайті — не більше двох шрифтів: один для заголовків, один для тексту. Перевір свій
2. strong — колір акценту і font-size: 20px
3. Посилання a — великими літерами і жирні
4. Унизу сторінки — <h3>© 2026 Оля</h3>. Правило h3: 14px, normal, праворуч
5. ⭐⭐ Списку ul — italic і line-height: 2. Пункти розійшлися?
6. ⭐⭐ Абзац із <em>: правило em — line-through. Що бачиш?
7. ⭐⭐⭐ h2 — capitalize. Напиши заголовок малими: «мій улюблений ранок»
8. ⭐⭐⭐ Над кожним правилом — коментар: /* заголовки */, /* абзаци */
