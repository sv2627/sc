Довгий main: де тут що?

main.dart
void main() { List<Map<String, dynamic>> k = [ {'nazva': 'Minecraft', 'cina': 650}, {'nazva': 'Portal', 'cina': 500}, ]; print('=========='); for (var g in k) print('${g['nazva']} - ${g['cina']} grn'); print('=========='); int s = 0; for (var g in k) s += g['cina'] as int; print('Suma: $s'); k.add({'nazva': 'Stardew', 'cina': 350}); print('=========='); for (var g in k) print('${g['nazva']} - ${g['cina']} grn'); print('=========='); int s2 = 0; for (var g in k) s2 += g['cina'] as int; print('Suma: $s2'); }
Той самий шматок стоїть двічі. Знайди обидва — рядки з рамкою й рядки з сумою
Захочеш писати UAH замість grn — виправляти в двох місцях. Забув одне — програма бреше
Щоб зрозуміти, що робить програма, треба прочитати кожен рядок. У «Арені» рядків буде вдвічі більше

Розбір на функції · 5 кроків

Як різати програму

1 Знайди шматок, що повторюється або робить одну справу: показати каталог, порахувати суму, знайти гру
2 Назви дію дієсловом: pokazhy · suma · znaidy · attack. Назва каже, що робить, а не як
3 Що шматку треба ззовні — це параметри. Каталог, назва для пошуку, межа ціни
4 Рахує щось — тип результату і return. Лише показує або міняє — void
5 main стає змістом: 4–8 рядків викликів, які читаються як план — показати, порахувати, додати, показати
✂️
Та сама програма · після розбору

Функції зверху, зміст унизу

main.dart
void ramka() => print('=========='); void pokazhy(List<Map<String, dynamic>> k) { ramka(); for (var g in k) print('${g['nazva']} - ${g['cina']} grn'); ramka(); } int suma(List<Map<String, dynamic>> k) { int s = 0; for (var g in k) s += g['cina'] as int; return s; } void main() { // ... каталог k, як і був pokazhy(k); print('Suma: ${suma(k)}'); k.add({'nazva': 'Stardew', 'cina': 350}); pokazhy(k); print('Suma: ${suma(k)}'); }
main читається як план: показати, порахувати, додати, показати. Вивід — той самий, що до розбору
pokazhy лише друкує — void. suma рахує — int і return
print — у main, не всередині suma: число ще знадобиться для середньої

Приклад — і самостійно: розбери команду

Приклад · набираємо разом
void main() { List<Map<String, dynamic>> komanda = [ {'imia': 'Lytsar', 'hp': 100, 'ataka': 15}, {'imia': 'Mah', 'hp': 70, 'ataka': 25}, {'imia': 'Luchnyk', 'hp': 80, 'ataka': 20}, ]; for (var h in komanda) print('${h['imia']}: hp ${h['hp']}'); int suma = 0; for (var h in komanda) suma += h['hp'] as int; print('Razom hp: $suma'); var syl = komanda[0]; for (var h in komanda) { if (h['ataka'] > syl['ataka']) syl = h; } print('Naisylnishyi: ${syl['imia']}'); }
Тепер самостійно · той самий вивід
  • Вивід команди — у void pokazhy(k), у main лише виклик
  • int sumaHp(k) з return; друк лишається в main
  • naisylnishyi(k) повертає цілого героя — тип Map<String, dynamic>
  • Додай четвертого героя — чи довелось міняти щось, крім списку?
  • Зверни в помилку: прибери return s; у sumaHp, прочитай, поверни
  • ⭐⭐ List<String> slabki(k, int mezha) — імена з hp нижче межі
  • ⭐⭐⭐ String opys(h) => ... — рядок-опис; pokazhy друкує через нього

Картки-завдання: одна функція на картку

1 ⭐ String stan(int hp): більше 70 — 'bodryi', більше 30 — 'poranenyi', інакше 'ledve zhyvyi'. Перевір на 80, 50, 10

Цеглина 2 · удар

attack: функція, що міняє героя

main.dart
void attack(Map<String, dynamic> a, Map<String, dynamic> b) { b['hp'] = b['hp'] - a['ataka']; if (b['hp'] < 0) b['hp'] = 0; print('${a['imia']} bie ${b['imia']} na ${a['ataka']}. ${b['imia']}: ${b['hp']} hp'); } void main() { Map<String, dynamic> lytsar = {'imia': 'Lytsar', 'hp': 30, 'ataka': 12}; Map<String, dynamic> ork = {'imia': 'Ork', 'hp': 40, 'ataka': 9}; attack(lytsar, ork); print(ork['hp']); }
ВивідLytsar bie Ork na 12. Ork: 28 hp 28

Цеглина 3 · бій

Бʼються, поки живі обидва

main.dart · у main, після героїв
int raund = 0; while (lytsar['hp'] > 0 && ork['hp'] > 0) { raund++; print('--- Raund $raund ---'); attack(lytsar, ork); if (ork['hp'] > 0) attack(ork, lytsar); } var p = lytsar['hp'] > 0 ? lytsar : ork; print('Peremig ${p['imia']}!');
&& — цикл іде, поки живі обидва. Упав один — бій скінчився
if перед відповіддю — мертвий не бʼє. Інакше Ork з 0 hp ще раз ударить
? : з уроку 3: переможець — той, у кого лишилось hp. p — цілий герой
Чому не do-while? Він зробить раунд, навіть якщо хтось уже з 0 hp. while спершу перевіряє

import 'dart:math'; // першим рядком файлу void attack(Map<String, dynamic> a, Map<String, dynamic> b) { int udar = a['ataka'] + Random().nextInt(6); // +0..5 if (Random().nextInt(5) == 0) { // 1 з 5 udar = udar * 2; print('KRYT!'); } b['hp'] = b['hp'] - udar; if (b['hp'] < 0) b['hp'] = 0; print('${a['imia']} bie ${b['imia']} na $udar. ${b['imia']}: ${b['hp']} hp'); }

Розбір на функції · знову

Увесь бій — одна функція

main.dart
Map<String, dynamic> biy(Map<String, dynamic> a, Map<String, dynamic> b) { int raund = 0; while (a['hp'] > 0 && b['hp'] > 0) { raund++; print('--- Raund $raund ---'); attack(a, b); if (b['hp'] > 0) attack(b, a); } return a['hp'] > 0 ? a : b; } // у main — випадкова пара з чотирьох: heroi.shuffle(); var p = biy(heroi[0], heroi[1]); print('Peremig ${p['imia']}!');
biy повертає переможця — цілого героя. Що з ним робити, вирішує main
shuffle з уроку 6: після нього два перші — випадкова пара без повторів
Після бою hp не відновлюється: наступний бій переможець почне пораненим

Тримати відкритим

Функції й «Арена» на одному екрані

герой Map<String, dynamic> h = {'imia': 'X', 'hp': 30, 'ataka': 12};
команда List<Map<String, dynamic>> heroi = [h, {...}];
показує / міняє void pokazhy(List<Map<String, dynamic>> k) {...}
рахує int sumaHp(k) { ...; return s; }
коротка bool zhyvyi(h) => h['hp'] > 0;
за замовч. int zillia(int hp, {int syla = 20})
параметр int — копія · Map — той самий
удар b['hp'] = b['hp'] - a['ataka'];
не в мінус if (b['hp'] < 0) b['hp'] = 0;
бій while (a['hp'] > 0 && b['hp'] > 0) {...}
відповідь if (b['hp'] > 0) attack(b, a);
переможець var p = a['hp'] > 0 ? a : b;
розкид · шанс Random().nextInt(6) · nextInt(5) == 0
випадкова пара heroi.shuffle(); biy(heroi[0], heroi[1]);

Практика · далі

Кому мало

⭐⭐ Бій — функція biy(a, b), що повертає переможця. Випадкова пара через shuffle.
Смужка здоровʼя з картки 3 у лозі: Ork: ## (28 hp)
⭐⭐⭐ Крит — шанс 1 з 5, удар ×2, у лозі KRYT!
Особливість працює: 'shchyt' — отримує на 3 менше · 'liut' — +5 до удару, коли власне hp нижче 15 · своя третя
Серія до двох перемог: поле maxHp, перед кожним боєм h['hp'] = h['maxHp']; перемоги — у Map<String, int> через update(..., ifAbsent: ...)
Усе, що є в тебе в кінці уроку, — основа міні-проєкту на уроці 8: там турнір із чотирьох героїв і показ своєї «Арени»

Банк завдань · для тих, хто закінчив

Ще вісім задач до «Арени»

1. Картка героя одним рядком зі станом з картки 1: Ork: 12 hp (poranenyi)
2. Найслабший у команді — функція, що повертає героя з найменшим hp
3. Середнє hp команди — функція, що повертає double
4. Нічия: бій довший за 20 раундів зупиняється (break) і пише Nichyia
5. Зілля: один раз за бій, коли hp нижче 15, герой пʼє zillia замість удару
6. Скільки шкоди завдав кожен за бій — Map<String, int> shkoda
7. Лог у список: кожен рядок бою — add у List<String>, після бою виведи лише останні три (sublist)
8. 2 на 2: у кожній команді бʼється перший живий (firstWhere після any)
⚠️
Пастки

На чому спотикаються всі

1 Тип героя — повністю. З var h = {...} Dart виведе Map<String, Object>, і h['hp'] - 9 не скомпілюється
2 void і return s; — помилка. Рахує — пиши тип результату: int sumaHp(...)
3 Порахувала й викинула. sumaHp(k); без print чи змінної — на екрані нічого
4 int — копія. likuvaty(hp) не змінить hp у main. Map — той самий, його змінить
5 Мертвий бʼє у відповідь. Без if (b['hp'] > 0) перемагає не той
6 || замість &&. Бій не закінчується ніколи — вкладка DartPad зависає
