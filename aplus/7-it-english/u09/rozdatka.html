From blocks to text

Довідка

Block-based ≠ text-based

text-based program: there are no blocks, you have to type everything, you decide what fits where. block-based: you fit pieces of code together, you choose from a list.

print · input · " "

print("Hi") — output what is in the brackets.
name = input("Name?") — wait for the text a user enters; name is a variable.
speech marks " " — the exact text is used.

Rules for print

1. print in lowercase (case-sensitive)
2. message in speech marks
3. open ( and closed ) bracket
4. each print on a new line
