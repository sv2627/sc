Посилання у VS Code — швидко

<a → Enter після < — список тегів. Enter вибирає
пробіл → hr → Enter зʼявиться href="", курсор — у лапках
href=" → файл → Enter у лапках VS Code підказує файли папки. Без помилок в імені
> → </a> автозакриття: закривний тег VS Code допише сам
Ctrl + клац по імені файлу в href — VS Code відкриє цей файл
Alt + ← у браузері — назад на попередню сторінку
Alt + Shift + ↓ дублювати рядок — копія зʼявиться нижче
Ctrl + Z скасувати останню зміну
Ctrl + S → F5 зберегти в VS Code → оновити в браузері. Кружечок ● на вкладці = не збережено

Від англ. anchor — «якір». Парний: є і </a>. Не як img

Головне правило уроку

Два види адрес у href

Чужий сайт — повна адреса

href="https://uk.wikipedia.org"

Обовʼязково з https:// на початку. Найпростіше — скопіювати з адресного рядка браузера

Своя сторінка — імʼя файлу

href="sayty.html"

Як src для картинки: шлях від сторінки. Файл поруч — досить імені

⚠️
Без https:// браузер вважає uk.wikipedia.org файлом у вашій папці — і не знаходить його.
⚖️

Помилки

Чому посилання не працює

1 · Назва. href="sait.html", а файл — sayty.html
2 · Розширення. .htm замість .html
3 · Розташування. Файл не в папці сайту
💡
Ті самі три причини, що з картинкою на уроці 5
4 · Немає https:// у чужій адресі — браузер шукає файл у вашій папці
5 · Немає </a> — усе після посилання стає синім і клацається
6 · Немає href — текст не синій і не клацається

Тепер самостійно — у своєму сайті
  • Назва: у href="sayty.html" змінити одну літеру. Клац — що видно? Повернути
  • Розширення: .html → .htm. Клац — що видно? Повернути
  • https:// — прибрати з посилання на Вікіпедію. Клац — що видно? Повернути

Закінчив раніше?

Банк завдань

1. Унизу кожної сторінки — посилання «На головну»
2. Меню однакове на всіх сторінках: ті самі пункти, той самий порядок
3. На sayty.html — п'ять сайтів. Під списком абзац: який з них головний для тебе і чому
4. «Топ-3 сайти»: нумерований список <ol>, у кожному пункті — посилання
5. ⭐⭐ Кожна мініатюра в галереї — посилання на свою картинку з img
6. ⭐⭐ На index.html — привітання реченням, де назви сторінок самі є посиланнями
7. ⭐⭐⭐ Скільки посилань треба, щоб із кожної з 4 сторінок дійти до кожної одним клацом? Порахуй і перевір у себе
8. ⭐⭐⭐ Логотип: маленька картинка width="40" угорі кожної сторінки веде на головну
Усі вісім робляться тільки тим, що було сьогодні й раніше. Нічого нового шукати не треба.
