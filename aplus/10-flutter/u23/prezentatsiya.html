Перевір себе · зламай і полагодь

Що скаже редактор?

1 · Без функції

onPressed: _items.removeAt(i),

Що буде?

Помилка: The argument type 'String' can't be assigned to the parameter type 'VoidCallback?'. Обгорни: () { setState(() { _items.removeAt(i); }); }

2 · Поле в Row

Row(children: [TextField(…), ElevatedButton(…)])

Що буде?

Червоний екран: An InputDecorator, which is typically created by a TextField, cannot have an unbounded width. Поле — в Expanded

3 · Список у Column

Column(children: [Row(…), ListView.builder(…)])

Що буде?

Червоний екран: Vertical viewport was given unbounded height. Список — в Expanded

Ще вісім доробок

1. Нове — нагору: _items.insert(0, text) замість add
2. Додавати й клавішею Enter: у TextField — onSubmitted: (String v) => _add()
3. Без повторів: if (_items.contains(text)) return; і червоне Already in the list
4. Кнопка Clear all у шапці: actions: [IconButton(…)], усередині _items.clear()
5. Номер у колі ліворуч: CircleAvatar(child: Text('${i + 1}')) — після видалення номери самі зсуваються
6. Кнопка Add сіра, поки поле порожнє: onChanged поля + null за умовою (урок 21)
7. Зроблені — вниз: після галочки _tasks.remove(t); _tasks.add(t);
8. Кнопка Delete done: прибрати всі зроблені — _tasks.removeWhere((t) => t.done)
