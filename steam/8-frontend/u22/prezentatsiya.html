Нове · два підходи

max-width чи min-width: спершу телефон

Спершу комп'ютер · max-width

.cards { grid-template-columns: repeat(3, 1fr); } @media (max-width: 600px) { .cards { grid-template-columns: 1fr; } }

звичайні правила — для монітора, медіа-запит відміняє для телефона

Спершу телефон · min-width

.cards { grid-template-columns: 1fr; } @media (min-width: 600px) { .cards { grid-template-columns: repeat(2, 1fr); } } @media (min-width: 900px) { .cards { grid-template-columns: repeat(3, 1fr); } }

звичайні правила — для телефона, медіа-запити додають для ширших екранів

📱
Спершу телефон (mobile-first): з телефонів сайти відкривають найчастіше, а додавати простіше, ніж відміняти.
