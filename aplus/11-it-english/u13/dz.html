Table 8.1: Common data types (с. 202)

String — text: characters, numbers and symbols, inside speech marks: "hello", "123"

Integer — whole numbers: 23, 45656

Real, single, double — decimal numbers: 23.0, -20.49

Boolean — either true or false

Char — one character or symbol, inside speech marks: "h", "?"
