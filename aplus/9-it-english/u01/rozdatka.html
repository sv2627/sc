Дві пастки

a + b + c / 3 — ділення виконається раніше за додавання, поділиться тільки c.
Треба: (a + b + c) / 3
elseif — це псевдокод, не Python: у Python пишуть elif. Псевдокод бере від мови вигляд, але їй не підкоряється.

Correct · алгоритм не відповідає вимозі

Вимога: порахувати середню з трьох оцінок і вивести її.
mark1 = input("Enter mark 1")
mark2 = input("Enter mark 2")
mark3 = input("Enter mark 3")
average = mark1 + mark2 + mark3 / 3
print(average)
