Щоб рахувати бали, застосунок має памʼятати число і після кожного дотику додавати до нього 1. Памʼять для числа — це змінна.
baly0

baly1
→
baly2
→
baly3
Змінна — коробка з наліпкою. На наліпці — назва baly, усередині — число. Число можна взяти і замінити новим.

Нове · Blocks → Built-in → Variables

Три помаранчеві блоки

БлокЩо робить
initialize global baly to 0 створює змінну baly і кладе в неї перше число — 0
get global baly бере число зі змінної — щоб додати або показати
set global baly to кладе у змінну нове число. Старе зникає
🧰
Число 0, знаки + і − — у Built-in → Math, сині блоки. У Variables є ще initialize local … in — змінна всередині однієї підкови. Сьогодні не потрібна.
