One IF, three languages · Один IF, три мови

Reference

Pseudocode

IF number = 10 THEN
    OUTPUT "Yes"
ELSE
    OUTPUT "No"
ENDIF

Flowchart: the condition is in a diamond; two arrows — YES / NO.

Python

if number == 10:
  print("Yes")
else:
  print("No")

colon : after if and else · the indented line only runs if the condition is true.

Conditional operators

< less than · > greater than
== equal to · != not equal to (≠)
<= less than or equal to (≤)
>= greater than or equal to (≥)

Three component parts

the condition · the code to run if true · the code to run if not true

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
