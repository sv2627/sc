Нове · масив

Сто цін — сто змінних?

без масиву — змінна на кожну ціну
const price1 = 699; const price2 = 199; const price3 = 449; const price4 = 319; const sum = price1 + price2 + price3 + price4; // а якщо ігор 100?
з масивом — одне імʼя на всі
const prices = [699, 199, 449, 319]; let sum = 0; for (let i = 0; i < prices.length; i++) { sum += prices[i]; } // хоч 4 ціни, хоч 100
Масив (array) — впорядкований список значень під одним імʼям. Квадратні дужки [ ], між значеннями — коми
У Python це список: prices = [699, 199] — запис той самий

Масив цін → сума і середня ціна

js-8/masyvy/script.js
const prices = [699, 199, 449, 319]; let sum = 0; for (let i = 0; i < prices.length; i++) { sum += prices[i]; } const avg = sum / prices.length; console.log(`Разом: ${sum} грн`); console.log(`Середня: ${avg} грн`);
КонсольРазом: 1666 грн Середня: 416.5 грн
Накопичувач з уроку 8: let sum = 0 до циклу, sum += … у циклі
Середнє = сума ÷ length
Додай у масив ще ціну — цикл не змінюється, сума рахується сама

Виправ

Має бути середнє 10. Що не так?

script.js · зламано навмисно
const marks = [10, 8, 12]; let sum; for (let i = 1; i <= marks.length; i++) { sum += marks[i]; } console.log(sum / marks.length);
КонсольNaN

Три біди, червоного рядка немає

Знайди всі три, потім клацни

1. let sum; — без нуля: undefined + 8 = NaN («не число»). Треба let sum = 0;

2. i = 1 — перша оцінка пропущена. Старт з 0

3. i <= marks.length — читає marks[3], тобто undefined. Потрібно <

Полагоджене дає 10
