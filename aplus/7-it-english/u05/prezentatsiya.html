Питання для ромба — тільки true або false

Which number is larger, 2 or 3?

Можливі відповіді: 2 або 3. Це не true / false.

Is 2 > 3? → false

How many words did the user input?

Відповідь — будь-яке число. Не true / false.

Did the user enter more than one word?
Далі друге питання: Did the user enter more than two words?
✍️
rephrase — переписати так, щоб відповідей було рівно дві.
Practice 2 · тепер самостійно Rephrase: true or false only5 хвилин
1. Which number is larger, 99 or 32?
2. How old are you? (руки вгору — тим, кому менше 12)
3. What is your favourite colour? (встати — усім, крім purple)
4. When is your birthday? (плескати — з 1 May і пізніше)
5. How tall are you? (атракціон — від 140 см)
⭐ 1–3⭐⭐ 4–5 ⭐⭐⭐ до 1 — друге питання для рівних чисел

Перевірка

Спершу зошит, потім клацни.

1 · Is 99 > 32?

2 · Is age < 12?

3 · Is colour != "purple"?

4 · Is birthday >= 1 May?

5 · Is height >= 140?

⭐⭐⭐ · Is 99 == 32? або !=

Checklist

What makes an accurate flowchart?

Десять правил правильної схеми

Назви пʼять правил, потім клацни.

1 · It must always have a start and a stop
2 · All inputs and outputs must be in a parallelogram
3 · All processes must be in a rectangle
4 · A selection must only have true/yes or false/no as answers
5 · A selection must be in a diamond
6 · All boxes apart from selection: one arrow in, one arrow out
7 · Selection must have two arrows going out, labelled true/yes and false/no
8 · Every box must join to another box
9 · Data flows must have arrows to show which way to work
10 · Start and end with an oval, or a rectangle with curved corners

Practice 4 · тепер самостійно Create your own flowchart8 хвилин

Обери опис, намалюй схему в зошиті, перевір за чек-листом.

⭐ sequence

The algorithm should take three numbers as input, add them together and output the result.

Намалюй, потім клацни.

START → INPUT n1, n2, n3 → result = n1 + n2 + n3 → OUTPUT result → STOP

⭐⭐ selection

The minimum height for a fairground ride is 140. Compare the input height and output whether the user is allowed to use the ride, or not.

Намалюй, потім клацни.

START → INPUT height → ◇ height >= 140?
true → "You can ride"
false → "Too short" → STOP

⭐⭐⭐ two selections

Input the number of words. Did the user enter more than one word? A second selection asks: more than two words?

Намалюй, потім клацни.

◇ words > 1? false → "One word"
true → ◇ words > 2?
true → "More than two"
false → "Two words"

Words in use

description Give learners a description of what the flowchart should do. Check the flowchart against the description.
in the correct order Put the flowchart symbols in the correct order. Draw the data flows between them.
swap Two pairs form a group of four and swap their flowcharts. Tell them if they work, or if there are any errors.
rephrase Rephrase the statements so they only have a true or false answer. Which number is larger, 2 or 3? — Is 2 > 3?
checklist Use the requirements checklist. Make sure the flowchart is structurally correct.
accurate The requirements for drawing an accurate flowchart. A poster about creating an accurate flowchart.
