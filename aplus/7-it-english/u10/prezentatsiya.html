Three groups — three data types

1
One of the groups contains words.
Одна з груп містить слова.
2
One contains whole numbers. One contains decimal numbers.
Одна містить цілі числа. Одна містить десяткові дроби.

These three groups are String (text), Integer (whole numbers) and Real (decimal numbers).
Ці три групи — String (текст), Integer (цілі числа) і Real (десяткові дроби).

Types in a program

1
A programmer usually has to state what type of data a variable is going to store.
Програміст зазвичай має вказати, який тип даних зберігатиме змінна.
2
If a variable is going to store a name, it is going to be a String.
Якщо змінна зберігатиме імʼя, це буде String.
3
Python does not require this.
Python цього не вимагає.
4
Strings are surrounded by speech marks.
Рядки (String) беруть у лапки.
5
print(Value1) will output the content of Value1. print("Value1") will output the word "Value1".
print(Value1) виведе вміст змінної Value1. print("Value1") виведе слово «Value1».

What do we now know about data types?

1
You cannot divide an Integer by a String.
Не можна поділити Integer на String.
2
You cannot add a String to an Integer or Real.
Не можна додати String до Integer чи Real.
3
You can add, subtract, multiply and divide Integer and Real numbers.
Числа Integer і Real можна додавати, віднімати, множити й ділити.
4
You can multiply an Integer by a String and output that String a number of times.
Можна помножити Integer на String і вивести цей String кілька разів.
5
When you add two Strings they join together.
Коли додаєш два String, вони зʼєднуються.

Input is a String

1
When a user enters a value in Python, it is stored as a String.
Коли користувач вводить значення в Python, воно зберігається як String.
2
If you enter a number, it will not be stored as a number, unless you tell Python to do this.
Якщо ввести число, воно не збережеться як число, хіба що ти скажеш Python це зробити.
3
int stands for Integer.
int означає Integer.
4
A Real number in Python is known as a float.
Число Real у Python називають float.
5
The command for a String is str.
Команда для String — str.
Number = int(input("Enter a number"))

stored as an Integer

Number = float(input("Enter a number"))

stored as a Real number

Number = str(input("Enter a number"))

stored as a String
