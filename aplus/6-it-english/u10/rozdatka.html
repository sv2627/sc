Sub-routines: when one flowchart is not enough

Keep this

sub-routine · procedure

Many programs are too complex for a single flowchart. The main algorithm links to another algorithm — a sub-routine, or procedure.

the symbol · called

A rectangle with double sides. A set of instructions is called at this point. Called — the program begins using the sub-routine.

Return

In the sub-routine, Start is replaced by its name (Square), Stop is replaced by Return — a return to the main algorithm. The code is written once.
