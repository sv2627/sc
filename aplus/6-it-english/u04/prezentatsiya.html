Words in use

data · to store Programs need a structure to store data. The name will be letters, words or text.
variable This data structure is called a variable. The same variables can be used in a number of algorithms.
Character Individual letters are known as Characters. The answer is either A, B or C.
String Sequences of letters, words or text are known as Strings. Store the name in a String variable.
Integer Whole numbers are known as Integers. The score is represented by an integer.
score Start that score at 0. Increase the score by 1 each time.
user · to enter A username when logging on. Ask a user to enter their password.
data type There is a naming convention for different data types. The score will be a number.
