Strings in code

We change words entered into a computer to check what has been entered. The function len returns the length of the string. The function upper returns the string in upper case, and the function lower returns it in lower case. To find the longest word, we find the length of each word and then use an if statement to compare them.

Читаємо по реченню по черзі. Переклад — клацни.

Слова, введені в компʼютер, змінюємо, щоб перевірити, що ввели. Функція len повертає довжину рядка. Функція upper повертає рядок великими літерами, а функція lower — малими. Щоб знайти найдовше слово, знаходимо довжину кожного слова, а тоді порівнюємо їх інструкцією if.
