Проблема

Одна сторінка — екрани від 320 до 2560

Ваша сторінка виглядає добре на тому екрані, за яким ви її робили. На іншому — ні. І це не питання смаку: це питання того, у чому ви задали розміри.

320телефон, вузький
1366звичайний ноутбук
2560великий монітор
Сьогодні розберемо п'ять одиниць і навчимося обирати, яку де брати. Головний прийом уроку — тягнемо вікно мишею й дивимось, що рухається.
📏
Одиниця 1

px — абсолютна, ні від чого не залежить

.card { width: 600px; font-size: 18px; }
600 точок — завжди 600 точок. На телефоні, на моніторі, скрізь

У чому біда

Екран телефона — 360 точок завширшки. Блок на 600 у нього не влізе.

З'явиться горизонтальна прокрутка — і сторінка стане незручною. Це найпомітніша ознака «зробленого тільки під свій ноутбук» сайту

✅
Не поспішайте викидати

Де px доречний

Рамки

border: 1px solid — рамка має бути тонкою завжди, а не «пропорційно»

Заокруглення

border-radius: 8px — те саме. Це деталь оформлення, не розмір блока

Тіні й дрібні відступи

box-shadow, 2px там, де це чиста косметика

🎯
Правило: px — для дрібниць, які не мають розтягуватись. Для ширини блоків і розміру тексту — ні.
🧩
Одиниця 2

% — частка від батьківського блока

.card { width: 80%; }
«Вісімдесят відсотків від того блока, у якому я лежу»
Не від вікна! Це головне непорозуміння. Від батька — того елемента, усередині якого стоїть ваш
Якщо батько на всю ширину вікна — тоді так, вийде 80 % вікна. Але це окремий випадок, а не правило
Батько в <main> завширшки 600px → 80 % це 480px, хай який монітор
🪆
Що з цього випливає

Відсотки складаються ланцюжком

body ширина вікна 1000px └ main width: 80% → 800px └ .card width: 50% → 400px └ img width: 50% → 200px
Кожен наступний рахує від свого батька, а не від вікна
Тому width: 50% у різних місцях сторінки дає різну реальну ширину — і це нормально
🔍
Побачити реальний розмір: F12 → навести на елемент. Chrome покаже у пікселях, скільки вийшло.
🖥️
Тягнемо вікно

Той самий блок, два способи

width: 600px · вузьке вікно
поїхало за край · горизонтальна прокрутка
width: 80%
влізло, стиснулось разом із вікном
Перевірка, яку робимо весь урок: узяти вікно браузера за край і потягнути. Що рухається разом із вікном — те задано у відсотках. Що стоїть намертво — у пікселях.

Приклад — розбираємо разом
main { width: 80%; margin: 0 auto; } .card { width: 50%; }
Тепер самостійно
  • Набрати приклад у своїй сторінці з уроку 2. Потягнути вікно — переконатись, що рухається
  • Поставити main ширину 600px і знову потягнути. Записати різницю
  • Повернути відсотки. Додати max-width: 900px — подивитись, що змінилось на широкому вікні
  • Через F12 дізнатись, скільки це в пікселях зараз
  • ⭐⭐ Вкласти блок у блок і поставити обом width: 50%. Порахувати очікувану ширину внутрішнього, потім перевірити в F12
  • ⭐⭐⭐ Домогтися, щоб на вузькому вікні не з'являлась горизонтальна прокрутка

Друга половина проблеми

Ширину полагодили. А текст?

Блоки тепер дихають разом із вікном. Але font-size: 18px лишається 18 точками завжди — і на телефоні, і на великому моніторі.

Чому це погано

Людина зі слабким зором збільшує шрифт у налаштуваннях браузера. Розмір у px це просто ігнорує.

Сторінка лишається дрібною, і користуватись нею неможливо

Що потрібно

Одиниця, яка каже «у півтора раза більша за звичайний текст», а не «вісімнадцять точок».

Тоді збільшив базовий шрифт — виросло все разом

🔠
Одиниця 3

rem — від кореневого розміру шрифта

h1 { font-size: 2rem; } p { font-size: 1rem; } .small { font-size: 0.875rem; }
rem = root em, «від кореня». Корінь — це <html>
За замовчуванням у браузері 1rem = 16px. Це стандарт, не наша вигадка
Людина поставила у налаштуваннях 20px — усе, що в rem, виросло разом. Автоматично
Тому rem — стандарт для тексту. Не «краще», а саме стандарт
🧮
Переведення

Найчастіші значення

remу пікселях (при 1rem = 16px)для чого
0.875rem14pxдрібний текст, підписи
1rem16pxзвичайний абзац
1.25rem20pxпомітний текст, лід
1.5rem24pxпідзаголовок h3
2rem32pxзаголовок h1
➗
Рахується просто: потрібні пікселі ÷ 16. Треба 24px → 24 / 16 = 1.5rem.
⚠️
Одним слайдом

Чому rem, а не em

Є схожа одиниця — em. Вона рахує не від кореня, а від батька. І через це поводиться несподівано.

em — множиться
.a { font-size: 1.5em; } → 24px .b { font-size: 1.5em; } → 36px .c { font-size: 1.5em; } → 54px // вкладені один в одного — // кожен множить попередній
rem — не множиться
.a { font-size: 1.5rem; } → 24px .b { font-size: 1.5rem; } → 24px .c { font-size: 1.5rem; } → 24px // усі рахують від кореня, // вкладеність не впливає
Тому в цьому курсі беремо тільки rem. em існує, іноді корисний — але не зараз.
🪟
Одиниці 4 і 5

vw і vh — від самого вікна

vw — viewport width. 1vw = 1 % ширини вікна
vh — viewport height. 1vh = 1 % висоти вікна
Головна відмінність від %: рахують завжди від вікна, а не від батька. Вкладеність не має значення
.hero { height: 50vh; }
«Обкладинка заввишки на пів екрана» — і так буде на будь-якому пристрої
🤔
Передбач

Що станеться, коли потягнути вікно?

main { width: 80%; } .card { width: 300px; } .hero { height: 40vh; } h1 { font-size: 2rem; } .note { font-size: 14px; }

Що зміниться, а що ні?

Розбери всі п'ять, потім клацни.

main — міняється, іде за шириною вікна

.card — ні, стоїть намертво 300 точок

.hero — міняється при зміні ВИСОТИ вікна, не ширини

h1 — ні. Але виросте, якщо людина збільшить шрифт у налаштуваннях

.note — ні й ніколи. Навіть налаштування браузера його не змінять

Останній рядок і є причина, чому текст задають у rem, а не в px.

🚧
Пастка

100vw — не те саме, що ширина сторінки

100vw — це ширина вікна разом зі смугою прокрутки
Якщо сторінка довга й смуга є, блок на 100vw буде ширшим за видиму область приблизно на 15 точок
Результат — горизонтальна прокрутка на порожньому місці. Найзагадковіша біда початківця

Що робити

Для ширини на весь екран беріть width: 100%, а не 100vw.

vw лишаємо там, де він справді потрібен: коли треба прив'язатись саме до вікна, а не до батька.

vh такої проблеми не має — з ним працюємо спокійно

Закінчив раніше?

Банк завдань — бери будь-яке

Три обкладинки. Одна на 30vh, друга 50vh, третя 100vh. Порівняти відчуття
Типографічна шкала. Шість розмірів тексту в rem: 0.75 · 0.875 · 1 · 1.25 · 1.5 · 2
Полагодь чуже. Візьми сторінку сусіда й переведи всі px у правильні одиниці
Картки різної ширини. Три картки: 50 %, 30 %, 20 % — щоб разом було рівно 100 %
Мінімум і максимум. Додати блоку min-width і max-width, подивитись, як він поводиться
Полювання на прокрутку. Знайти на своїй сторінці все, що спричиняє горизонтальну прокрутку
Усі шість робляться тільки тим, що було сьогодні. Медіа-запити не потрібні — вони аж у січні
