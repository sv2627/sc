while

Ті самі три частини — у різних рядках

for
for (let i = 1; i <= 5; i++) { console.log(i); }
while — те саме
let i = 1; // старт — до циклу while (i <= 5) { // умова console.log(i); i++; // крок — у кінці тіла }
while — «поки». Поки умова true, тіло повторюється

Коли while

Скільки кроків — невідомо, відома лише межа

script.js · подвоюємо, поки не більше 1000
let n = 1; let steps = 0; while (n <= 1000) { n *= 2; // n = n * 2 steps++; } console.log(steps, n);
Консоль10 1024
for — «зроби 10 разів»
while — «роби, поки не перевалить за 1000». Скільки це кроків, ми дізнались лише в кінці
*= — родич += і -=

Небезпека

Нескінченний цикл вішає вкладку

i не змінюється
let i = 1; while (i <= 5) { console.log(i); } // 1 1 1 1 1 1 …
крок не в той бік
for (let i = 1; i <= 5; i--) { console.log(i); } // 1 0 -1 -2 …

do...while

Спершу зроби, потім перевір

script.js
let again; do { alert('Раунд гри…'); again = confirm('Зіграти ще раз?'); } while (again); alert('Дякую за гру!');
Тіло виконується хоча б один раз — перевірка стоїть унизу
confirm з уроку 7: OK → true, Скасувати → false
Раніше «ще раз» був location.reload(). Тепер гра не перезавантажує сторінку — і памʼятає рахунок
Після while (again) — крапка з комою

script.js · перше кратне 7 від 50

continue

Пропустити цей крок — і далі

script.js · 1…10 без кратних 3

Діагностика

Шість бід циклу

Вкладка зависла — крок не змінює лічильник або йде не в той бік. Shift + Esc

Assignment to constant variable — for (const i = 0; …; i++). Потрібен let
Вгадав, а гра питає далі — рядок порівнюється з числом. Number(prompt(…))
