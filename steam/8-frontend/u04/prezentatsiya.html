F12 на твоєму сайті

Знайти тег і поміняти

Знайти

Правий клац на заголовок → Перевірити (Inspect). Праворуч підсвічено <h1>

Текст

Подвійний клац на тексті в Elements → своє → Enter

Колір

Styles → element.style → color: red

⚠️
Ctrl+U тут майже порожній — сайт складає JavaScript. Справжні теги — у F12 → Elements. Оновиш сторінку — зміни зникнуть. Скрін: Win+Shift+S.

Папки проєкту

Кожен файл — на своєму місці

cats-site/
  ├── index.html
  ├── about.html
  ├── css/
  │    └── style.css
  └── images/
       ├── cat-main.jpg
       └── logo.png
index.html — головна. Сервер відкриває її першою, якщо файл не названо
Сторінки — в корені проєкту, поруч з index.html
Картинки — в images/, стилі — в css/
Одна папка = один сайт. Нічого з «Завантажень»

Передбач

Чому «Мій сайт.html» ламає посилання?

Що побачить браузер в адресі?

Подумай, потім клацни

%D0%9C%D1%96%D0%B9%20%D1%81%D0%B0%D0%B9%D1%82.html

Кирилиця стає кашею з %D0…, пробіл — %20. Одна літера не та — сторінку не знайдено

Cat.JPG і cat.jpg — це один файл?

Подумай, потім клацни

На твоєму Windows — так. На сервері в інтернеті — ні, це два різні файли. Тому вдома все працює, а опублікований сайт — без картинок

VS Code

Відкриваємо ПАПКУ, а не файл

Відкрив файл

Один файл, дерева немає. Не видно images/, шлях пишеш наосліп

Відкрив папку

Ліворуч — усе дерево проєкту. Нові файли створюються там, де треба

1 File → Open Folder (Файл → Відкрити папку)
2 Обрати папку проєкту → Select Folder
⌨️
VS Code · довідка

Від порожньої папки до сторінки

1Значок New File над деревом → index.html
2Набрати ! → Tab — готовий каркас
3Зберегти: Ctrl+S. Білий кружечок на вкладці = не збережено
4У браузер: перетягнути файл у Chrome або подвійний клац у провіднику
5File → Auto Save — зберігає саме. Лишається оновити сторінку F5

Emmet · вбудований у VS Code

Скорочення + Tab = теги

пишеш → Tab
! header header>nav section*3 main>section>h2
отримуєш
каркас сторінки <header></header> <header><nav></nav></header> три <section> поспіль <main><section><h2>…
> — усередину · *3 — три рази
Зроби зараз AI-сторінку — у свою папку15 хвилин
Приклад
1. папка cats-site → VS Code → File → Open Folder 2. New File → index.html → ! → Tab → Ctrl+S 3. сайт у Lovable: F12 → правий клац на <header> → Copy → Copy element 4. вставити всередину <body> → Ctrl+S → відкрити в Chrome
Тепер самостійно — стилів не буде, це нормально
  • Папка своєї теми, назва за правилами. Перенеси <header> і одну <section>
  • Зроби папку images/, збережи туди картинку з сайту, назва латиницею
  • Виправ src на images/назва.jpg — картинка має показатись
  • Постав <main> і <footer> руками, Emmet-ом
  • ⭐⭐ Заміни всі <div>, які можна, на семантичні
  • ⭐⭐⭐ about.html з тим самим <header> і посилання між сторінками
