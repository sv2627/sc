What do AND, OR and NOT mean?

1 · In the AND statement, both conditions must be true.°  переклад? В інструкції з AND обидві умови мають бути істинними.
2 · In the NOT statement, it reverses the condition.  переклад? В інструкції з NOT умова перевертається на протилежну.
3 · In the OR statement, either condition being true will result in a clap.  переклад? В інструкції з OR досить, щоб істинною була будь-яка з умов, — і буде оплеск.
4 · AND means both sides of the expression must be true.  переклад? AND означає: обидві частини виразу мають бути істинними.
5 · OR means one or both sides can be true.  переклад? OR означає: істинною може бути одна частина або обидві.

What do you do if one side of an AND expression is true and the other is false?

Англійською, потім клацни.

Nothing: the AND expression is false. Both sides must be true.

if and if else in Python

if
if condition: code to run if true
if else
if condition: code to run if true else: code to run if false
number = 10 if number == 10: print("Yes") else: print("No")

Що виведе?

Yes — 10 is equal to 10

first = 20 if first < 20: print("Less than 20") else: print("20 or more")

Що виведе?

20 or more — 20 is not less than 20

The indents are important

A
if x == 10: print("Hello")
B
if x == 10: print("Hello")

Which print will always run? Which one runs only if the condition is true?

Англійською, потім клацни.

A — the print is not in the if statement, so it will always run.°
B — it is indented, so it will only run if the if statement is true.

1 · The indents are important in Python.  переклад? У Python відступи важливі.
2 · Once you have typed the colon and pressed enter, the cursor should be auto-indented.°  переклад? Щойно ти набрав двокрапку й натиснув Enter, курсор сам стає з відступом.
3 · In Python, and and or are written in lower case and need to have a condition on either side.  переклад? У Python and і or пишуть малими літерами, і з кожного боку від них має бути умова.
4 · The Boolean operator not needs to be before a condition.  переклад? Логічний оператор not ставиться перед умовою.

Boolean operators in Python

operators.py
first = 10 second = 20 if first < 20 and second < 20: print("Both less than 20") if first < 20 or second < 20: print("At least one is less than 20") value = True if not value: print("False") else: print("True")

Lines 3–4: 10 < 20 and 20 < 20?

Що виведе?

Nothing: 20 < 20 is false, and AND needs both sides to be true.

Lines 5–6: with or?

Що виведе?

At least one is less than 20 — 10 < 20 is true, one side is enough.

Lines 8–12: not value?

Що виведе?

True — not True is False, so the code after else: runs.

⭐⭐ first = 25, second = 5. What will it output now?

Що виведе?

Only At least one is less than 20 (25 < 20 is false, 5 < 20 is true) · then True.
