Це не «ще одне вікно»

alert зупиняє виконання коду й саму сторінку: нічого не клікається, ніщо не малюється, таймери стоять

Навіщо він нам

Це найшвидший спосіб показати результат людині без жодного HTML. Нам він потрібен рівно доти, доки в III періоді ми не навчимося писати прямо в сторінку

Ідея однакова до рядка: спитати → перетворити на число → зібрати відповідь. Відрізняються тільки назви й лапки.

Головне про prompt

Він повертає значення

prompt не «записує кудись» те, що ввели. Він віддає результат — і цей результат треба кудись покласти, інакше він зникне безслідно.

Марно
prompt('Як тебе звати?'); alert('Вітаю!'); // спитали й викинули // відповідь
Правильно
const name = prompt('Як тебе звати?'); alert(name); // відповідь у змінній
🤔
Передбач

Що опиниться в змінній?

script.js
const a = prompt('Число:'); // ввели 7 const b = prompt('Число:'); // натиснули OK // з порожнім полем const c = prompt('Число:'); // натиснули Скасувати console.log(typeof a, typeof b, typeof c);

Три значення й три типи

Спробуй назвати, потім клацни.

a = '7' — рядок, не число

b = '' — порожній рядок

c = null — не рядок і не порожньо, а «людина відмовилась»

У консолі: string string object. Так, typeof null дає 'object' — це давня помилка мови, яку вже не виправлять.

Пастка номер один

prompt завжди повертає рядок

Навіть якщо людина ввела 25, у змінній лежить '25' — текст із двох символів. Не число. І арифметика з ним поводиться зовсім не так, як очікуєш.

консоль
const a = prompt('Перше число:'); // 2 const b = prompt('Друге число:'); // 3 console.log(a + b); // '23' ← а не 5 console.log(a * b); // 6 ← а тут раптом правильно
⚠️
Множення, ділення й віднімання самі перетворюють рядок на число — інакше вони не вміють. А плюс уміє ще й склеювати, тому обирає склеювання. Ламається завжди саме плюс.
🔢
Нове в коді

Number() — перетворити на число

script.js
const a = Number(prompt('Перше:')); const b = Number(prompt('Друге:')); console.log(a + b); // 5
Обгортаємо prompt одразу, у тому ж рядку. Так неможливо забути
Number('25') → 25
Number('3.5') → 3.5
Number('') → 0 — порожній рядок стає нулем!
Number('сім') → NaN
🚫
Коли не вдалося

NaN — «не число»

NaN означає Not a Number. Це не помилка й не збій: код спокійно виконується далі, просто з безглуздим значенням. Саме тому це небезпечно.

Заражає все навколо

NaN + 5 → NaN
NaN * 100 → NaN

Один зіпсований ввід — і весь подальший розрахунок безглуздий, а програма про це мовчить

Як побачити

Найпростіше — console.log одразу після Number().

Побачив NaN — знай: у полі було не число. Або людина натиснула Скасувати

🔮
Перевіряти ввід по-справжньому навчимося на наступному уроці — для цього потрібні умови. Сьогодні просто знаємо, звідки береться NaN.
🤔
Передбач

Чотири рядки в консолі

script.js
// у полі ввели: 10 const s = prompt('Число:'); const n = Number(s); console.log(s + 5); console.log(n + 5); console.log(s - 5); console.log(s === n);

Що виведе кожен рядок?

Порахуй усі чотири, потім клацни.

'105' — плюс склеїв рядок і число

15 — тут уже справжня арифметика

5 — мінус не вміє склеювати, тому сам перетворив рядок

false — '10' і 10 різного типу, а === порівнює і значення, і тип

Мораль: поки не викликав Number(), у тебе на руках текст — хай як він виглядає.

Що станеться на уроці

Chrome запропонує «блокувати діалоги»

Після кількох вікон поспіль браузер показує галочку «Заборонити цій сторінці створювати діалогові вікна». Хтось її поставить — і далі все «зламається».

▸ Ознака: prompt більше не з'являється, а в змінних одразу null
▸ Лікується закриттям вкладки й відкриттям сторінки наново. Оновлення (F5) не допомагає
▸ Тому в реальних сайтах prompt і не використовують: браузер має право його не показати
Це не помилка в твоєму коді. Але поводиться воно рівно так само, як помилка — тому вміти впізнавати треба.

Нове в коді

Шаблонний рядок і ${ }

Плюсами
alert('Вітаю, ' + name + '! Тобі ' + age + ' років.');
Шаблонним рядком
alert(`Вітаю, ${name}! Тобі ${age} років.`);
Замість звичайних лапок — зворотні: `. На клавіатурі це клавіша ліворуч від 1, у тому ж ряду
Усередині ${ } можна писати будь-який вираз, не тільки змінну: ${2026 - year} порахує на місці
⌨️
Три види лапок

І тільки одні вміють ${ }

'одинарні'

Звичайний рядок. ${name} усередині — це просто чотири символи, нічого не підставиться

"подвійні"

Те саме, що одинарні. Різниці немає жодної — у проєкті просто обирають одні й тримаються їх

`зворотні`

Шаблонний рядок. Розуміє ${ } і зберігає переходи рядка

🔍
Найчастіша помилка: написали ${ }, а лапки лишили звичайні. Помилки не буде — у вікні просто з'явиться сам текст ${name}. Це і є ознака.
📐

Виправ

Три рядки — три різні біди

script.js
const year = prompt('Рік:'); alert('Тобі ${2026 - year}'); alert(`Тобі ${2026 + year}`); alert(`Тобі {2026 - year}`);

Що покаже кожен alert?

Розбери всі три, потім клацни.

1. Тобі ${2026 - year} — лапки звичайні, підстановки не сталося

2. Тобі 20262010 — year досі рядок, плюс склеїв

3. Тобі {2026 - year} — загубився $

Спільне в усіх трьох: жодної помилки в консолі. Код працює, результат безглуздий.

Культура коду

Не питай те, що можеш порахувати

Погано
const year = prompt('Рік:'); const age = prompt('Вік:'); // два питання про одне // й те саме — і вони // можуть суперечити
Добре
const year = Number(prompt('Рік:')); const age = 2026 - year; // одне питання, // решта — розрахунок
Правило просте: кожне зайве питання — це ще одне місце, де людина може помилитися. Питай мінімум, рахуй решту.
