Метод — дія, що живе в класі

main.dart
class Fighter { String name; int hp; int attack; Fighter(this.name, this.hp, this.attack); bool isAlive() => hp > 0; String info() => '$name: hp $hp, attack $attack'; void hit(Fighter other) { other.hp = other.hp - attack; if (other.hp < 0) other.hp = 0; print('$name hits ${other.name} for $attack. ${other.name}: ${other.hp} hp'); } }
Усередині методу поля — просто за назвою: hp, attack, name. Це поля того бійця, чий метод викликали
other — інший боєць. Його поля — через крапку: other.hp
Виклик: a.hit(b); — читається як речення «a бʼє b». a.isAlive() — «a живий?»
