Рішення

Один файл + ланцюг історії

Найчастіше питання

Навіщо проміжний крок?

Ти правив сайт годину й зачепив п'ять файлів. Але завершена в них лише одна справа — нове меню. Решта ще в процесі.

💡
Ось навіщо середній крок: щоб у ланці історії була одна завершена справа, а не «все, що я встиг за годину». Тоді через місяць зрозуміло, що там відбулося.
🧭
Не плутати

Git — це не GitHub

Git

Програма на твоєму комп'ютері. Веде історію змін. Працює без інтернету. Безкоштовна.

Це блокнот, у якому записана вся історія.

GitHub

Сайт в інтернеті. Місце, куди цю історію можна відправити: щоб не загубити, показати іншим, працювати разом.

Це хмара, куди блокнот копіюється.

📌
Git можна використовувати без GitHub — і всю першу тему ми саме так і працюватимемо. GitHub без Git — не буває.
☁️
Як це працює

Твій комп'ютер ↔ GitHub

Історія живе у двох місцях одночасно. Синхронізують їх дві команди.

Показую на проєкторі · резерв

Як ці команди виглядають

Git не має вікна з кнопками. Це термінал — команди пишуть текстом. Виглядає суворо, але за рік їх набереться близько десяти.

Термінал
# 1 · обираю, що зберегти $ git add index.html style.css # 2 · зберігаю в історію з підписом $ git commit -m "Зробив нове меню" [main a3f7c21] Зробив нове меню # 3 · відправляю в хмару $ git push
🔗
Три команди — це рівно три стрілки зі схем, які ми щойно розібрали. Нічого нового тут немає.
📦
Матеріал курсу · резерв

Стартовий комплект

Щоб вести історію змін, потрібен проєкт, який змінюється. Я видам усім однаковий готовий сайт — далі кожен переробляє його під себе.

starter/
  ├── index.html головна
  ├── about.html про мене
  ├── works.html роботи
  ├── style.css оформлення
  └── img/
Три сторінки, зв'язані меню. Один файл оформлення.
Хто вже має власні HTML-файли — можна працювати з ними. Але комплект однаково візьми.
Ніхто нічого не «повинен був зробити раніше». Стартуємо всі з одного місця.
🔐
Організаційне · важливо

Три речі, без яких курс стане

1 · Пошта

Робоча адреса, до якої ти маєш доступ і пам'ятаєш пароль. На неї реєструється GitHub

2 · Акаунт GitHub

Створимо разом на уроці. Безкоштовно. Ім'я акаунта стане частиною адреси твого сайту

3 · Телефон

На нього приходить код підтвердження. Без нього акаунт у якийсь момент заблокується

⏰
Якщо чогось із цього немає — скажи мені зараз, а не в грудні. Зараз це вирішується спокійно. У грудні, коли треба публікувати сайт — уже ні.

Що ти вже знаєш

Розумієш

  • яку задачу розв'язує контроль версій
  • один файл + ланцюг історії замість купи копій
  • три стани: папка → підготовлено → історія
  • Git — програма, GitHub — сайт у хмарі

Наступного разу — за комп'ютерами

  • отримаєш стартовий комплект
  • відкриєш термінал
  • створиш свій перший репозиторій
  • зробиш перший коміт
На наступний урок: згадай пароль від своєї пошти й перевір, що вона відкривається. Це все. Домашнього завдання немає.
