How this course works · Як влаштований курс

Якою мовою ти пишеш

  • Терміни, псевдокод, код — англійською. Завжди. Вони не перекладаються.
  • Коротка відповідь за зразком — англійською. Зразок завжди на слайді, вигадувати речення не треба.
  • Розгорнуте пояснення — українською. Цього року. Я перевіряю, чи ти зрозумів, а не як ти володієш англійською.

Слова курсу

  • Key words — терміни юніта. Висять на стіні, входять у vocabulary check.
  • Command words — дієслова завдань: describe, explain, identify, compare. Від дієслова залежить, що саме від тебе хочуть.
  • Оцінки: поточна · практична · міні-проєкт. Кожна практична має рівні ⭐ / ⭐⭐ / ⭐⭐⭐ — рівень обираєш сам.
Помилка в терміні — виправляється завжди. Граматична помилка поза терміном не оцінюється й не знижує бал. Тому писати й говорити англійською тут безпечно.

1. Що робить підпрограма PrintCertificate і в який момент її викликають? Чому її винесли окремо, а не вписали в схему?

Check yourself · Звіряємось

1 · Підпрограма

клікни, щоб показати відповідь

Це окремий іменований шматок алгоритму. Головна схема тільки викликає його (CALL) і не повторює його кроки в собі. Викликається, коли mark >= 60.

2 · Вхід 60

клікни, щоб показати відповідь

Умова 60 >= 60 істинна, отже гілка YES: викликається PrintCertificate, далі END. Пастка тут одна — знак >= включає саме число 60.

3 · Розгалуження

клікни, щоб показати відповідь

Ромб — decision. З нього виходять рівно дві гілки: YES і NO. Англійською сама конструкція зветься conditional statement.

Якщо ви прочитали схему — ви вже вмієте головне. Логіка вам знайома з коду, новим був тільки вигляд. Сьогодні додаємо ще один спосіб записати ту саму думку.
Новий інструмент
🛠️

New tool: pseudocode · Псевдокод

Що це

Запис алгоритму словами, але за жорсткою структурою: один крок — один рядок, ключові слова великими літерами, вкладене — з відступом.

Мета одна: щоб інша людина зрозуміла алгоритм однозначно — ще до того, як обрано мову програмування.

Чим воно НЕ є

  • Не мова програмування.
  • Не запускається — жоден комп'ютер його не виконає.
  • Не має єдиного стандарту: немає «офіційно правильного» варіанта, є домовленість класу.
  • Не коментарі до коду: коментар пояснює готовий код, псевдокод пишеться до коду.
🔀
Ви вже пишете у трьох мовах: Python, JavaScript, C#. Псевдокод — це те, чим ці три мови домовляються між собою, і те, що Cambridge просить у роботах.
Один алгоритм, три записи · 1 з 3
💬

In plain words · Звичайними словами

Спитай в учня, скільки балів він набрав за тест. Максимум у нас 50. Порахуй, скільки це у відсотках. Якщо вийшло 60 відсотків або більше — скажи, що склав, а якщо ні — скажи, що не склав.

Що з цим не так

  • Де початок і де кінець? Текст просто починається і просто обривається.
  • «Порахуй, скільки це у відсотках» — як саме? Формули немає.
  • «Максимум у нас 50» — це крок алгоритму чи побічна репліка? З тексту не видно.
  • Кроки злиті в речення — їх навіть не порахувати.

As pseudocode · Псевдокодом

exam-result.txt · pseudocode
BEGIN SET maximum TO 50 INPUT score SET percent TO score / maximum * 100 IF percent >= 60 THEN OUTPUT 'Passed' ELSE OUTPUT 'Not passed' ENDIF END
👀
Нові слова сьогодні: BEGIN, END, INPUT, OUTPUT, SET _ TO _. Конструкцію IF … ENDIF сьогодні тільки читаємо — розберемо на уроці 3.

Four requirements · Чотири вимоги

short
коротко: без зайвих слів, один крок — один рядок. Порушення: «Спочатку, будь ласка, обережно спитай в учня його бали».
clear
зрозуміло: слова, які всі читають однаково. Порушення: do the check — яку саме перевірку?
precise
точно: жодного кроку, який можна виконати двома різними способами. Порушення: calculate the result — за якою формулою?
start and end
clearly shown
початок і кінець позначені явно: BEGIN … END. Порушення: запис, що починається одразу з INPUT і просто обривається.
📌
Це чек-лист усього року: за цими чотирма словами прийматимуться всі роботи з алгоритмів. Випиши їх у зошит англійською просто зараз.

A complete algorithm · Приклад цілком

tickets.txt
BEGIN SET priceOfTicket TO 120 INPUT numberOfTickets SET total TO numberOfTickets * priceOfTicket OUTPUT 'Tickets: ' OUTPUT numberOfTickets OUTPUT 'Total to pay: ' OUTPUT total END
1. Скільки заплатить той, хто взяв 3 квитки? Пройди рядок за рядком.
2. Який рядок доведеться змінити, якщо ціна стане 150?
3. Чи можна тут щось видалити так, щоб алгоритм лишився зрозумілим?
🔗
Питання 2 — це вже місток до уроку 4: constant, значення, яке живе в одному місці.

Change one line · Зміни один рядок

Спершу передбач уголос, потім перевір. Той самий алгоритм про квитки — міняємо в ньому рівно одну річ.

1 · Ціна стає 150

SET priceOfTicket TO 150

Що виведе алгоритм для 3 квитків?

клікніть, щоб перевірити

450. Змінився один рядок — змінився весь результат. Це і є причина, чому таке число тримають в одному місці.

2 · Замість * пишемо +

SET total TO numberOfTickets + priceOfTicket

Що виведе для 3 квитків по 120?

клікніть, щоб перевірити

123. Алгоритм не зламався й не поскаржився — він слухняно порахував дурницю. Комп'ютер не знає, що ти мав на увазі.

🎯
Друга помилка страшніша за першу: програма не падає, вона просто дає неправильну відповідь. Англійською це logic error — на відміну від syntax error, який видно одразу.

практика 1 Rewrite it as pseudocode · Перепиши псевдокодом
«Запитай у покупця суму замовлення. Доставка коштує 60 гривень. Але якщо замовлення на 500 гривень і більше — доставка безкоштовна. Порахуй, скільки платити разом, і скажи покупцеві.»
⭐
Переписав псевдокодом, є BEGIN і END.
⭐⭐
Плюс кожен крок окремим рядком, без «і потім»; використані INPUT, SET _ TO _, OUTPUT.
⭐⭐⭐
Плюс перевірив запис за чотирма вимогами і підписав збоку, яку з них ледь не порушив і чому.

практика 3 The largest of three · Найбільше з трьох
Напиши свій алгоритм. Спершу на папері, потім набери в текстовому редакторі — простому, без підсвітки. Сьогодні ⭐ достатньо — це перший урок.
⭐
Найбільше з двох чисел. Є BEGIN, INPUT, OUTPUT, END і одна умова.
⭐⭐
Найбільше з трьох чисел.
⭐⭐⭐

🤔
