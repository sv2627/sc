Нове правило

grid-column: span 2 — займи дві колонки

<div class="card wide">Картка 1</div> .gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } .wide { grid-column: span 2; }
1 · wide23 45
display: grid — батькові. span — самій картці. Це правило про одну дитину, не про всю сітку
span — «простягнутися». span 2 — на дві колонки, span 3 — на три
Решта карток самі посуваються далі — нічого їм писати не треба

Як сітка рахує

Лінії сітки та їхні номери

Колонок три — ліній чотири. Ліній завжди на одну більше
Рахуємо з 1, не з 0. Лінія 1 — лівий край сітки
З кінця — від'ємні номери. Остання лінія — завжди -1, скільки б колонок не було
Рядки мають свої лінії — так само, згори вниз
🎯
Точно на місце

grid-column: 1 / 3 — від лінії до лінії

.a { grid-column: 1 / 3; } /* лінії 1 → 3 */ .b { grid-column: 2 / 4; } /* лінії 2 → 4 */ .c { grid-row: 1 / 3; } /* рядки 1 → 3 */
Перше число — звідки, друге — докуди. Між ними — скісна риска /, не мінус
span 2 каже скільки. 1 / 3 каже звідки й докуди
a · 1 / 3· ·b · 2 / 4

a — ліворуч, b — праворуч, обидві на дві колонки

🔗
Можна змішати: grid-column: 2 / span 2 — «почни з лінії 2 і займи дві колонки»

grid-template-areas — карта з імен

body { display: grid; grid-template-columns: 200px 1fr; grid-template-areas: "header header" "aside main" "footer footer"; } header { grid-area: header; } aside { grid-area: aside; } main { grid-area: main; } footer { grid-area: footer; }
Кожні лапки — один рядок сітки. Слів у лапках стільки, скільки колонок
Ім'я повторюється — ділянка розтягується: "header header" — шапка на дві колонки
grid-area каже тегу, яке ім'я з карти — його
Інспектор: F12 → вкладка Layout → увімкнути показ імен ділянок — Chrome підпише кожну
