Ключове

Розриву немає

Ви писали JavaScript торік. Змінні, умови, цикли, функції, масиви, DOM, події — це не «колись у 8 класі», це минулий навчальний рік. Тому I період — не «з нуля», а «як це пишуть зараз».
так писали
var game = 'Hades II'; var price = 499; console.log('Gra: ' + game + ', tsina: ' + price);
так пишуть
const game = 'Hades II'; const price = 499; console.log(`Gra: ${game}, tsina: ${price}`);
💡Той самий результат. Різниця — у звичках, які читає й перевіряє будь-який сучасний проєкт.

Чому саме там

Скрипт — в кінці <body>

Браузер читає документ зверху вниз. Якщо <script> стоїть у <head>, то на момент його виконання <h1> ще не існує — і querySelector('h1') поверне null.

Скрипт угорі

Код виконався → елементів ще немає → null → «Cannot read properties of null». Класика, яку ви бачили торік.

Скрипт унизу

Уся розмітка вже прочитана → елементи існують → код працює. Це і є наш варіант.

🎓Є й другий шлях: лишити скрипт у <head>, але з атрибутом defer — «завантаж зараз, виконай після розмітки». У листопаді, з модулями, defer увімкнеться сам.

Тизер II періоду

Що саме ламається на file://

ES-модулі

import / export з file:// просто не завантажаться. Браузер відмовить із помилкою про CORS.

fetch

Запит до API з file:// блокується. Ніякого «Завантаження…» — одразу помилка в консолі.

Причина одна: у file:// немає походження (origin). Браузеру нема з чим порівнювати — і він забороняє все підозріле.
📅Сьогодні ви цієї різниці не помітите. У листопаді помітите дуже. Тому звичку «завжди через Live Server» ставимо зараз, поки вона нічого не коштує.
