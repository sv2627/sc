Гривні → долари · ≈ 10 хвилин · CodePen

Стартовий код — сторінка «Код уроку», два блоки «Гривні → долари». Відкрий codepen.io: блок «панель HTML» — у панель HTML, блок «панель JS» — у панель JS.

Праворуч — поле «Гривні» і напис —. Кнопки немає: рахує подія input — на кожну цифру. Місця, які треба дописати, позначені ДОПИШИ.

  1. ДОПИШИ 1. Прочитай поле і зроби з рядка число: const uah = Number(field.value);
  2. ДОПИШИ 2. Якщо поле порожнє: out.textContent = 'Введи суму';
  3. ДОПИШИ 3. Інакше — результат: out.textContent = `${uah} грн = ${(uah / 42).toFixed(2)} $`; (у зворотних лапках). Перевір: вводиш 420 — одразу 420 грн = 10.00 $; стерла поле — Введи суму.

Що надіслати: увесь код із панелі JS, першим рядком — коментар із прізвищем та імʼям, наприклад // Коваль Олена.
