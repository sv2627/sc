What each part means

print("Hello world!") name = input("What is your name?") print("Hello ", name)
1
What does the program do? It outputs ‘Hello world!’, asks a user to enter their name, then says ‘Hello’ and the name.
Що робить програма? Виводить «Hello world!», просить користувача ввести імʼя, потім каже «Hello» та імʼя.
2
What does ‘print’ mean? It is the instruction to output what is in the brackets.
Що означає print? Це команда вивести те, що в дужках.
3
What does ‘input’ mean? It is the instruction to wait for the text a user enters.
Що означає input? Це команда чекати на текст, який вводить користувач.
4
Why is some text in speech marks? Speech marks show that the exact text will be used.
Чому частина тексту в лапках? Лапки показують, що буде використано саме цей текст.
5
What is the purpose of ‘name’? It is a variable to store the name the user inputs.
Для чого name? Це змінна, щоб зберегти імʼя, яке вводить користувач.

What is the difference?

What is the difference between a text-based program and a block-based program?

1
There are no blocks. You have to type everything.
Блоків немає. Усе треба набирати.
2
You cannot fit pieces of code together. You have to decide what fits where.
Не можна скласти шматки коду разом. Треба самому вирішити, що куди йде.
3
There is no list of code that you can choose from.
Немає списку коду, з якого можна вибрати.
4
There is no visual display for images or text.
Немає вікна, де показано зображення чи текст.

Where is a text-based program written?

1
Python is a text-based programming language. Other text-based languages include VB.NET and Java.
Python — текстова мова програмування. Інші текстові мови — VB.NET і Java.
2
A program is written in an IDE. An IDE is an Integrated Development Environment.
Програму пишуть в IDE. IDE — інтегроване середовище розробки.
3
At this stage the program is in console mode, which is purely text input and output.
На цьому етапі програма в режимі консолі — лише текст на вході й на виході.
4
To run the program in IDLE, you press F5, or Run → Run Module.
Щоб запустити програму в IDLE, натискають F5 або Run → Run Module.

What we know about output

1
There is a ‘print’ command word.
Є командне слово print.
2
‘print’ is written in lowercase.
print пишуть малими літерами.
3
The output message is in speech marks.
Повідомлення для виведення — у лапках.
4
After ‘print’ there is an open bracket.
Після print — відкрита дужка.
5
At the end of the message there is a closed bracket.
Наприкінці повідомлення — закрита дужка.
6
Each print statement is on a new line.
Кожна команда print — з нового рядка.
print("Hi") print("Bye")
🔡
case-sensitive — print і Print — різні слова.
