Boolean · Тип із двох значень

Reference

Data types

Integer stores whole numbers: 100

Real stores decimal numbers: 22.50

String stores characters (letters, symbols, numbers that cannot be used mathematically): Purple

Boolean can only be one of two values: True or False

Python

age = int(input("Enter your age"))
price = float(input("Price"))
name = input("Enter your name")

input() stores all data as a string. True / False — case sensitive.

Remember

The result from 10 > 5 is a Boolean: True. true = 1 · false = 0.

If the number is never used in a calculation, it is a string: 001182738.

Flag: true — positive (occurred, valid, correct) · false — negative.

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
