Міні-проєкт II: три питання

1 · Межа

if (_index < films.length - 1) { _index++; }

Навіщо - 1?

Клацни — відповідь.

Останній номер — length - 1. Без нього ▶ робить зайвий крок і RangeError

2 · class чи Map

Фільм із назвою, роком і тривалістю — і лайки за назвою

Що з них class, що Map?

Фільм — сутність, class Film. Лайки — словник «назва → кількість», Map<String, int>

3 · Що виведе

Map<String, int> likes = {'Up': 2}; print(likes['Soul'] ?? 0);

Клацни — відповідь.

0

Ключа Soul немає — null, ?? 0 дає 0

Хто вчора не встиг показати — показ зараз. Цей самий код сьогодні переїде в проєкт

Створити проєкт: два способи

Термінал

flutter create --platforms web first_app cd first_app code .

--platforms web — тільки веб, без папок Android та iOS. code . — відкрити цю папку у VS Code

Меню VS Code

Ctrl + Shift + P → Flutter: New Project → Application → папка → назва → Enter

VS Code сам відкриє новий проєкт у вікні

Назва проєкту — малі латинські літери, цифри й _: first_app. Не можна First-App, 2app, class

Крок 2

Запуск у Chrome

1Унизу праворуч у VS Code — пристрій. Клацни → Chrome (web-javascript)
2Відкрий lib/main.dart → F5 або меню Run → Start Debugging
3Відкриється окреме вікно Chrome з лічильником. Перший запуск — 1–3 хвилини
4Зверху зʼявиться панель: ⚡ hot reload · 🔄 hot restart · ⏹ стоп
або в терміналі, у папці проєкту
flutter run -d chrome
Поки працюєr — hot reload R — hot restart q — зупинити
Запустилось — не тисни F5 вдруге: зміни бачимо через hot reload
⚡
Головне сьогодні

Hot reload і hot restart

⚡ Hot reload🔄 Hot restart
ЯкCtrl + S у VS Code · r у терміналікнопка 🔄 · Ctrl + Shift + F5 · R
Що робитьпідставляє новий код і перемальовуєзапускає застосунок наново
Стан (_counter)лишається — було 5, лишилось 5з нуля — знову 0
Швидкістьсекундакілька секунд
Колизмінив вигляд: текст, колір, віджетзмінив main(), початкове значення поля, весь файл
Hot reload не перезапускає main() і не рахує наново int _counter = 0 — для цього hot restart
✍️

Ще вісім доробок

1. Створи другий проєкт через меню Flutter: New Project — порівняй папки: що зайве?
2. Спробуй flutter create First-App — прочитай, яку назву пропонує Flutter
3. Запусти з термінала flutter run -d chrome; зроби r, R, q
4. У шаблоні: кругла кнопка — Icons.favorite, підказка tooltip: 'Like'
5. Число — displayLarge замість headlineMedium: hot reload чи restart?
6. У pubspec.yaml знайди версію Dart і назву. Чи збігається назва з папкою?
7. Зсунь у pubspec.yaml рядок sdk: flutter лівіше, збережи — прочитай помилку, поверни
8. Зітри всі англійські коментарі шаблону — лишився тільки код. Чи змінився застосунок?

Найчастіші проблеми

1'flutter' is not recognized — Flutter не в PATH. Закрий і відкрий VS Code; не допомогло — до вчителя
2is not a valid Dart package name — назва з великими літерами або -. Тільки first_app
3No pubspec.yaml file found — команда не в папці проєкту. Спершу cd first_app
4Відкрита не та папка — батьківська замість first_app: F5 не знає, що запускати. File → Open Folder → саме first_app
5Пристрій не Chrome — у правому нижньому куті вибери Chrome, не Web Server і не Windows
6«Зміни не видно» — змінив main() або початкове значення поля: потрібен 🔄 hot restart, а не Ctrl + S
