Три питання — одна відповідь

1 prompt — перше число. Людина вводить 7
2 prompt — знак дії: + - * /. Людина вводить *
3 prompt — друге число. Людина вводить 6
4 alert — відповідь: 7 * 6 = 42

Три рівні

Калькулятор, який не ламається

Що зробила людинаЩо має побачити
натиснула Скасувати на будь-якому питанні«Скасовано» — і далі нічого не питаємо
лишила поле порожнім«Поле порожнє»
ввела не число: abc, 5,5«Це не число»
ввела невідомий знак: ^, x«Невідомий знак: ^»
ділить на нуль«На нуль ділити не можна» — а не Infinity
💡
5,5 з комою — не число для JavaScript: Number('5,5') → NaN. Дробові — тільки через крапку.

Підказка до ⭐⭐

Порядок перевірок — від вужчої

1 Скасували? raw === null
2 Порожньо? raw === ''
3 Не число? Number.isNaN(a)
4 Ділимо на нуль? op === '/' && b === 0
5 Інакше — рахуємо за знаком
Спершу зберегти сирий ввід у raw, потім Number(raw). Інакше Скасувати й порожнє поле не розрізнити: обидва стануть 0
Два числа й знак — три prompt. Кожне число можна перевіряти одразу після його prompt
isNaN(x) — коротший брат Number.isNaN: сам робить Number(). Для вже перетвореного числа — однакові

toFixed(2)округлити до 2 знаків(10 / 3).toFixed(2)'3.33'

toFixed повертає рядок! Лапки в результаті — не одруківка. Округлюй тільки для показу, в останньому рядку
Навіщо: 0.1 + 0.2 дає 0.30000000000000004. Це не баг JavaScript — так комп'ютер зберігає дроби

const USD = 41.5; // курс умовний const EUR = 48.5; const mode = prompt('1 — калькулятор, 2 — валюта'); if (mode === '1') { // твій калькулятор } else if (mode === '2') { // гривні → usd або eur } else { alert('Немає такого режиму'); }

Весь калькулятор ⭐⭐ переїжджає всередину першої гілки. Відступи — щоб бачити, де яка дужка

Знайди

Ввели 2, *, 3 — а побачили «2 + 3 = 23»

script.js · зламано навмисно
let a = prompt('Перше:'); let op = prompt('Знак:'); let b = Number(prompt('Друге:')); let result; if (op = '+') { result = a + b; } else if (op === '*') { result = a * b; } alert(`${a} ${op} ${b} = ${result}`);

Три біди, жодного червоного рядка

Знайди всі три, потім клацни.

1. op = '+' — одне =. Знак перезаписано на плюс, умова завжди істинна. Тому в alert плюс, хоч ввели зірочку

2. a без Number() — '2' + 3 склеїлось у '23'

3. Немає else — на невідомий знак буде = undefined

Як знайти самому: console.log('op =', op) до і після if. Змінилось — ось воно.

Діагностика

Шість бід калькулятора

2 + 2 = 22 — немає Number()
Завжди рахує плюсом — одне = в умові
= undefined — знак не збігся з жодною гілкою, else немає
Infinity — ділення на нуль не перевірено
Не число, хоча ввів число — дріб через кому або пробіл у полі
Сторінка мовчить зовсім — SyntaxError, відкрий консоль
🔦
Знак не збігається, хоча ввів правильний? console.log('[' + op + ']') — квадратні дужки покажуть зайвий пробіл.

Банк — доповни свій калькулятор

Відсоток. Ще один режим: «скільки це p % від числа n»
Парність. Після відповіді одним ? : дописати «парне» чи «непарне»
Середнє трьох. Ще один режим: три числа → середнє з двома знаками
Зворотна валюта. Конвертер уміє і usd → гривні
Знак словами. Людина може ввести плюс замість + — теж працює
Ціле ділення. Знак // — частка без остачі: 7 // 2 → 3. Згадай %
Усі шість — тільки тим, що вже було. Циклів і функцій не треба
