What is a project plan?

Спершу — відповідай: What do you find in a project plan? Потім читаємо по черзі; клацни на рядок — переклад.

1
A project plan identifies the inputs, outputs and processes.
План проєкту визначає входи, виходи й процеси.
2
It identifies the tasks to be completed.
Він визначає завдання, які треба виконати.
3
It identifies which person will do each task.
Він визначає, яка людина виконає кожне завдання.
4
It identifies the timescales for tasks.
Він визначає терміни для завдань.
5
It identifies the order to do tasks.
Він визначає порядок, у якому виконувати завдання.

Why do you need to test a program?

Питання — спершу відповідай сам, потім читаємо відповідь.

1
Why do you need to test a program that you have written?
To make sure it produces the expected outputs for a range of inputs and so that it does not crash. — Щоб переконатися, що вона дає очікуваний результат на різних вхідних даних і не «падає».
2
How should you test the program?
Input a range of data and see if it gives the expected result. — Ввести різні дані й подивитися, чи дає вона очікуваний результат.
3
How should you record the results of your tests?
Write each test and its results. — Записати кожен тест і його результати.

What is a test plan?

1
A test plan is a table that identifies the different tests that need to be carried out.
План тестування — це таблиця, яка визначає різні тести, які треба провести.
2
It contains the part of the program being tested, the data being input,
Він містить частину програми, яку перевіряють, дані, які вводять,
3
the expected result and the actual result.
очікуваний результат і справжній результат.
4
Someone else can then easily check that all possibilities have been tested.
Тоді будь-хто інший легко перевірить, що протестовано всі можливості.
