Крок 1 · ⭐ Друга сторінка7 хвилин
Приклад · pro-nas.html
<main> <section id="team"> <div class="container"> <h2>Про нас</h2> <p>Варимо каву з 2020 року.</p> </div> </section> </main>
Тепер самостійно
  • VS Code → новий файл у папці проєкту: pro-nas.html (або своя назва)
  • Скопіюй з index.html усе від <!DOCTYPE html> до кінця header і підвал
  • У title — назва цієї сторінки
  • Між шапкою і підвалом — main з одним розділом
  • Відкрий у Chrome: шапка й підвал такі самі, як на головній?
Крок 2 · ⭐ Меню між сторінками5 хвилин
Приклад · однаково в обох файлах
<a href="index.html"><h1>Зерно</h1></a> <nav> <a href="index.html#drinks">Напої</a> <a href="pro-nas.html">Про нас</a> <a href="index.html#order">Замовити</a> </nav>
Тепер самостійно
  • У меню обох сторінок — пункт на другу сторінку
  • На другій сторінці пункти головної: index.html#…
  • Пройди всі пункти з обох сторінок — жоден не веде в нікуди?
  • ⭐⭐ Назва сайту в шапці веде на головну
  • ⭐⭐ Підвал — ті самі посилання
Крок 3 · ⭐⭐ Розділи другої сторінки7 хвилин
Приклад · команда сіткою
<div class="team"> <article class="card"> <img src="img/olena.jpg" alt="Бариста Олена"> <h3>Олена</h3><p>бариста</p> </article> … </div>
.team { display: grid; grid-template-columns: repeat(auto-fit, minmax(180px, 1fr)); gap: 20px; }
Тепер самостійно
  • Два–три розділи на другій сторінці — за своєю ідеєю
  • Один розділ — сіткою, як каталог
  • Класи card, btn з головної працюють і тут — CSS той самий
  • Розділам по черзі — клас alt для фону
  • ⭐⭐⭐ Розділ із 200px 1fr: ліворуч фото, праворуч текст
Крок 4 · ⭐⭐ Дірки в проєкті6 хвилин
Приклад · коментар угорі style.css
/* Карта проєкту ✓ 1 шапка з меню ✓ 2 каталог сіткою ✗ 3 форма — немає required ✓ 4 ефекти ✗ 5 телефон — прокрутка вбік ✓ 6 друга сторінка */
Тепер самостійно
  • Пройди карту проєкту: кожна частина — ✓ чи ✗
  • Обери один ✗ і доробляй — презентація потрібного уроку на сторінці курсу
  • Готово — наступний ✗
  • Усе ✓? Переходь до кроку 5 і банку
