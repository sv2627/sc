let і const

let score = 0;      // можна змінити
score = 10;
const shop = 'A+';  // назавжди
shop = 'B';         // помилка

Правило: починай із const, заміни на let, лише коли треба міняти.

Три типи

number499   4.5   -3
string'Hades II'   '499'
booleantrue   false

Пастка: 2 + 3 → 5, але '2' + 3 → '23'. Якщо хоч з одного боку рядок — плюс склеює, а не рахує.

Червоне в консолі

  • SyntaxError — помилка запису: дужка, лапка, кома
  • ReferenceError — такої змінної немає
  • NaN — не помилка, а результат: рахував із текстом

Читати перший червоний рядок згори: праворуч у ньому файл і номер рядка.
