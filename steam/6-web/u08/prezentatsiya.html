Приклад
New File → hobi.html <title>Мої захоплення</title> … <h1>Мої захоплення</h1>
Тепер самостійно
  • ⭐ VS Code → та сама папка сайту, де pro-mene.html
  • ⭐ New File → hobi.html — імʼя латиницею, з .html
  • ⭐ Каркас — копією з pro-mene.html, у <body> стерти старе. Або руками — за довідником
  • ⭐ У <title> і в <h1> — «Мої захоплення». Ctrl+S
  • ⭐⭐ Набери каркас руками, не дивлячись на дошку
  • ⭐⭐⭐ Під <body> — коментар «Моя друга сторінка»
Клавіші Ctrl+A, Ctrl+C → Ctrl+V каркас Ctrl+S → F5
Крок 2 з 5 Заголовок, текст, список5 хвилин
Приклад
<p>Найбільше я люблю <strong>футбол</strong>.</p> <ul> <li>футбол</li> </ul>
Тепер самостійно
  • ⭐ Під <h1> — абзац: що ти любиш робити найбільше
  • ⭐ Одне слово в абзаці — <strong>
  • ⭐ Список <ul>: три твої захоплення. Новий пункт — Alt+Shift+↓
  • ⭐ Ctrl+S → F5: є крапки перед пунктами?
  • ⭐⭐ Заголовок <h2> «Як я почав» і список <ol> із трьох кроків
  • ⭐⭐⭐ Між розділами — риска <hr>, одне слово — <em>

Тепер самостійно
  • ⭐ Картинка про твоє захоплення: у браузері правий клац → «Зберегти зображення як…» → папка img, імʼя латиницею

  • ⭐⭐ Немає картинки? Перевір три причини: назва, розширення, розташування
  • ⭐⭐ Друга картинка, width="150"
Клавіші src=" → img/ → файл → Enter
