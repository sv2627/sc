≈ 10 хвилин. Робимо на сайті codepen.io (або у VS Code вдома). У CodePen два поля: HTML і CSS — рядок <link> там не потрібен.

Код для копіювання

Сторінка «Код уроку», блоки 1 і 2. Натисни «Скопіювати» біля блоку 1 — встав у поле HTML. Те саме з блоком 2 — у поле CSS.

Завдання

  1. ДОПИШИ ТУТ 1: правило для класу price — колір red і жирний (font-weight: bold). Має вийти: обидві ціни червоні й жирні. Як на кроці 1 уроку: .price { color: red; } — з крапкою перед іменем.
  2. ДОПИШИ ТУТ 2: правило для класу note — колір gray і похилий (font-style: italic). Має вийти: «Компот — безкоштовно.» сіре й похиле. Як на кроці 2.
  3. ⭐⭐⭐ ДОПИШИ ТУТ 3: правило для класу sale — фон yellow (background-color). Має вийти: ціна вареників червона на жовтому — у неї два класи, price і sale. Як на кроці 3.

Що надіслати

Весь код з поля CSS (виділити — Ctrl+A, скопіювати — Ctrl+C) — у Google Classroom · 6 клас. Поле HTML не змінюй: класи там уже стоять.
