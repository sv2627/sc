7.7 Validation

Довідка · с. 172–176

Validation

the checking of data to make sure it is reasonable and within set bounds

Range check

data is between the minimum and maximum

Length check

the number of characters is within a set limit

Type check

data is the correct data type: integer · real · string · Boolean

Presence check

data has been entered (NULL, "")

Format check · check digit

a specific order, e.g. __/__/____ · a calculated digit, input with the numbers
