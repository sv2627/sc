What is a sub-routine?

A set of commands that is given an identifier and can be called from anywhere in an algorithm.

Write it once — use it multiple times.

Call it in a flowchart

In pseudocode

subroutine addition()
  ...
endsubroutine

addition()    # call it

To call a sub-routine, use its identifier.
