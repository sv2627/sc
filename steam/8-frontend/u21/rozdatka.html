Довідка

Стани

:hover — миша над елементом

:focus — поле в роботі

:active — мить натискання

Плавно і transform

.btn { transition: transform 0.3s; }

scale(1.1) · translateY(-5px)

rotate(15deg)

Шапка не зникає

header { position: sticky;

  top: 0; z-index: 10; }

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

2 · Що зробить рядок

3 · Намалюй, що буде при наведенніквадрат 20 × 20 мм

.a:hover {
  transform: rotate(45deg);
}
.b:hover {
  transform: scale(1.5);
}
.c:hover {
  transform: translateY(-10mm);
}

4 · Знайди помилку

.btn { transition: transform 0.3; }
a : hover { color: red; }
header { position: sticky; }
/* шапка не прилипає */

5 · Допиши CSS кнопки

Плавно темнішає і більшає при наведенні, «втискається» при натисканні:

.btn {
  __________: background-color 0.3s,
              transform 0.3s;
}
.btn:______ {
  background-color: darkgreen;
  transform: ________(1.1);
}
.btn:______ {
  transform: scale(0.9);
}
