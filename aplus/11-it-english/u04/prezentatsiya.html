Key words · с. 159

Три означення з книжки

search algorithm
a series of steps that searches for a specific value in a set of data
sorting algorithm
a series of steps that will rearrange a set of data into an order, e.g. ascending numerical data
linear search
a search algorithm that visits each item of data in turn to check whether it is the data being looked for
🔎
7.7 Common algorithms · с. 159

Search і sort — навіщо

search algorithm

«checks a set of data to identify whether a specific value exists in the data, or not.» Приклад — linear search

sorting algorithm

«takes a set of data and rearranges it to be in a specific order, e.g. in ascending alphabetical order.» Приклад — bubble sort

Один за одним, з першого

Activity 7.5 Ace of Spades5 хвилин

«Get a set of playing cards. Select 10 random cards and place them face down on the table in a row. Perform a linear search to see if the Ace of Spades is in the set.» — с. 159

1Turn over the first card.
2Is it the Ace of Spades?
3If it is, then stop searching, you’ve found it.
4If it isn’t, turn over the next card. Repeat from 2.

Example 1 · с. 160

Search this set of data for the number 4

5394 218

Скільки порівнянь? Що скаже алгоритм після кожного?

Спершу англійською вголос — потім клацни.

Compare the first number (5) with the search value (4). They are not the same.
Compare the second number (3) with 4. They are not the same.
Compare the third number (9) with 4. They are not the same.
Compare the fourth number (4) with 4. They are the same. It has been found.

4 порівняння. Решту (2, 1, 8) не перевіряємо.

❔
Example 2 · с. 160

Search this set of data for the character "#"

"a""v""!"

Чим закінчиться пошук?

Подумай, потім клацни.

Compare the "a" with "#". They are not the same.
Compare the "v" with "#". They are not the same.
Compare the "!" with "#". They are not the same.
There are no more values, so "#" is not found.

Стоп № 2: перевірили останнє — і тільки тепер можна сказати not found.

Searching an array

Data1568

Search the array for the number 6

Запитання для кожного індексу — потім клацни.

Algorithm · с. 160

Linear search у псевдокоді

с. 160 · «This can now be written as an algorithm»
FOR ArrayIndex = 0 to LENGTH(Array) -1 //loop through each element //check if the current index is the data searched for IF DataArray[ArrayIndex] = SearchValue THEN //if it is, output the index where it is found OUTPUT "Found at " & ArrayIndex ELSE //if it not found, increment arrayIndex to check the next value ArrayIndex ← ArrayIndex + 1 ENDIF NEXT ArrayIndex
🔍
В одному алгоритмі книжки — і =, і ←. Обидва валідні (с. 155). Логіка: порівняти → вивести або перейти до наступного.
⏱️
Efficient · с. 161

Знайшли — зупинись

«This algorithm is inefficient because if it finds the search value then it still continues searching.»
Корисно лише тоді, коли треба знати, чи значення трапляється більше ніж раз.
Коментар у різних мовах: # // /* ' — у псевдокоді годиться будь-який (TIP, с. 161).
с. 161 · more efficient · коментарі скорочено
Found ← FALSE ArrayIndex ← 0 WHILE Found = FALSE AND ArrayIndex < LENGTH(Array) DO IF DataArray[ArrayIndex] = SearchValue THEN OUTPUT "Found at " & ArrayIndex //set found to be true to stop the while loop running again Found ← TRUE ELSE ArrayIndex ← ArrayIndex + 1 ENDIF ENDWHILE
