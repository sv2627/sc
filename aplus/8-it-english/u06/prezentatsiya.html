↓
INPUT age
↓
age >= 18 ?
YES

NO

Перепиши цю схему псевдокодом у зошит. Будь-яким записом з уроку 3.

Check · two notations

Спершу напиши, потім клацни.

INPUT age if age >= 18: OUTPUT "Adult" else: OUTPUT "Child"
BEGIN INPUT age IF age >= 18 THEN OUTPUT "Adult" ELSE OUTPUT "Child" ENDIF END

Обидва записи правильні. Перевір: ромб → if, гілки YES і NO → два блоки з відступом.
