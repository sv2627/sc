Передбач · відповідь у коментар CSS

Що буде з картками?

Контейнер .cards завширшки 700px, кожна .card — width: 200px

1.cards { display: flex; gap: 20px; }
Три картки. Скільки в рядку?
2.cards { display: flex; gap: 20px; }
Шість карток. Що станеться з їхньою шириною?
3.cards { display: flex; gap: 20px; flex-wrap: wrap; }
Шість карток. Скільки в першому рядку?
4.card { display: flex; }
Рядка для .cards немає. Картки стануть у рядок?
5.cards { display: flex; align-items: flex-start; }
Тексту в картках різна кількість. Висота однакова?
6.cards { display: flex; flex-wrap: wrap; justify-content: center; }
Чотири картки, у рядок влазять три. Де четверта?
