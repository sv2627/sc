Що зробить рядок?

padding: 20px;

Клацни після відповіді

Відступ усередині — 20px з усіх боків

Клацни після відповіді

Зверху й знизу 10px, з боків 30px

margin-bottom: 25px;

Клацни після відповіді

Відстань 25px лише знизу, поза рамкою

border-top: 4px dotted red;

Клацни після відповіді

Рамка лише зверху: 4px, крапками, червона

border-radius: 12px;

Клацни після відповіді

Заокруглені кути

box-shadow: 0 4px 10px gray;

Що означає кожне число?

0 убік · 4px униз · 10px розмиття · колір

Передбач

Яка ширина на екрані?

width: 200px; padding: 25px; border: 5px solid;

Порахуй, потім клацни

260px = 200 + 25 + 25 + 5 + 5

width: 200px; padding: 25px; border: 5px solid; box-sizing: border-box;

А тепер?

200px. Відступ і рамка — всередині цих 200

width: 400px; padding: 10px 30px; border: 1px solid;

Обережно з padding

462px = 400 + 30 + 30 + 1 + 1. Боки — це 30, а не 10

width: 300px; padding: 20px; margin: 30px;

А margin рахуємо?

340px = 300 + 20 + 20. margin — поза коробкою, у ширину не входить

Ширина й центр

Екран телефона — 400px. Картка має width: 600px

Що побачимо?

Картка вилізе за екран — з'явиться прокрутка вбік

Той самий екран, але max-width: 600px

А тепер?

Картка стиснеться до 400px. max-width — «не ширше», а не «рівно»

Як поставити main посередині?

Два рядки

max-width: 800px; і margin: 0 auto;

Фото ширше за картку й вилазить. Що допоможе?

Клацни після відповіді

img { max-width: 100%; } — не ширше за свою коробку

Крок 1 Основа: box-sizing і центр4 хвилини
Приклад · на початок style.css
* { box-sizing: border-box; } main { max-width: 800px; margin: 0 auto; }
Тепер самостійно
  • Правило для * — першим рядком файлу
  • main — не ширше 800px і посередині
  • Звуж вікно Chrome — прокрутки вбік немає?
  • Шапці й підвалу — padding: 20px
  • ⭐⭐ F12 → Computed для main: яка ширина на твоєму екрані?
  • ⭐⭐⭐ main — ще padding: 0 15px. Ctrl+Shift+M — текст на телефоні не прилипає до краю?

Крок 2 Картки: відступ, рамка, кути, тінь6 хвилин
Приклад
.card { padding: 20px; border: 2px solid #1b5e20; border-radius: 12px; box-shadow: 0 4px 10px gray; }
Тепер самостійно
  • Усім карткам: відступ усередині, рамка, кути, тінь — свої числа й колір
  • Підбери відступ у F12 стрілками ↑ ↓, потім перепиши в файл
  • Картці з класом hot — товща рамка, 4px
  • Картці з класом new — рамка пунктиром: dashed
  • ⭐⭐ Різний padding зверху й збоку: padding: 10px 25px
  • ⭐⭐⭐ Тінь сильніша: 0 8px 20px. Порівняй із 0 2px 4px — яка краща?
Крок 3 Відстані між картками й розділами5 хвилин
Приклад
.card { margin-bottom: 20px; } section { padding: 20px 0; } h2 { border-bottom: 3px solid #1b5e20; padding-bottom: 5px; }
Тепер самостійно
  • Між картками — відстань: margin-bottom
  • Кожному розділу — відступи зверху й знизу
  • Під кожним h2 — лінія й невеликий відступ до неї
  • F12 → наведи на картку: де margin, а де padding?
  • ⭐⭐ Цитаті чи примітці — border-left і padding-left
  • ⭐⭐⭐ Абзацам одного розділу — max-width: 600px. Читати легше?
Крок 4 Розміри й фото5 хвилин
Приклад
img { max-width: 100%; border-radius: 12px; } #avatar { width: 150px; height: 150px; border-radius: 50%; } header { min-height: 40vh; }
Тепер самостійно
  • Фото не вилазять за картки й розділи: max-width: 100%
  • Фото — заокруглені кути
  • Одному фото — id="avatar": 150 на 150, коло, рамка
  • Шапка — не нижче за 40vh. Звуж і розтягни вікно
  • ⭐⭐ Одній картці — max-width: 400px і margin: 0 auto
  • ⭐⭐⭐ width: 900px на картці — що на вузькому вікні? Заміни на max-width, порівняй
