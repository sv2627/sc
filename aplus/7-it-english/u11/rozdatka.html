Variables and arithmetic

Довідка

Variable

A variable stores data. It has a name — identifier.
MyName = "Jamelia"
MyAge = 12
The value can change.

Reserved words

print, input — command words: not a name for a variable.
print("Hello", MyName) — the comma joins text with a variable → Hello Jamelia

Operators · brackets

+ add · - subtract
* multiply · / divide
Brackets first:
(1 + 2) * 2 → 6
1 + (2 * 2) → 5

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
