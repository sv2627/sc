Чому правило не працює?

h1 { color = red; }

Подумай, потім клацни

Між властивістю й значенням — двокрапка: color: red;

p { colour: blue; }

Подумай, потім клацни

Британське написання. CSS знає тільки color. VS Code підкреслить хвилькою

h2 { color: red font-size: 30px; }

Подумай, потім клацни

Немає ; після red — зламались обидві властивості

body { color: navy;

Подумай, потім клацни

Немає } — браузер вважає, що всі наступні правила ще всередині body

Селектори · сьогодні три

Кому саме правило

p { … }тег — усі <p> на сторінці
h1, h2, h3 { … }група через кому — одне правило на кілька тегів
nav a { … }вкладений через пробіл — тільки <a>, що всередині <nav>
footer p { … }тільки абзаци в підвалі, решта не змінюються
📌
Кома й пробіл — різні речі: nav, a — меню і всі посилання; nav a — лише посилання в меню. Класи й id — урок 8.

Передбач

Два правила сперечаються. Хто переможе?

h1 { color: blue; } h1 { color: green; }

Якого кольору h1?

Зелений. Однакові селектори — перемагає нижчий у файлі

nav a { color: white; } a { color: blue; }

Якого кольору меню?

Біле. nav a точніший, ніж просто a — він перемагає, хоч і вище

body { color: navy; }

Якого кольору p, h2 і a?

p і h2 — navy: колір успадковується. Посилання — ні, у них свій колір від браузера

Вирівнювання, інтервал, підкреслення

text-align: center;left · center · right · justify
line-height: 1.6;міжрядковий інтервал: 1.6 від розміру літер. Текст дихає
text-decoration: none;прибрати підкреслення з посилань у меню

Приклад
body { font-family: Arial, sans-serif; line-height: 1.6; } h1 { font-size: 40px; text-align: center; } nav a { color: white; text-decoration: none; font-weight: bold; }
Тепер самостійно
  • Шрифт і line-height для всієї сторінки — в body
  • h1 більший і по центру, h2 — свій розмір
  • Меню: без підкреслення, жирне, колір із палітри
  • Підвал: дрібніше й курсивом — footer p
  • ⭐⭐ Google-шрифт із кирилицею для заголовків

Закінчив раніше?

Банк завдань — бери будь-яке

Важливе. strong — колір акценту, em — інший відтінок
Три рівні. h1, h2, h3 — три розміри, щоб ієрархію видно було здалеку
Темна тема. Поміняй місцями фон і текст у body. Що ще довелось змінити?
Друга сторінка. link:css в about.html — вона одразу така сама
Списки. li з більшим інтервалом, ol — жирні пункти
Коментарі. /* шапка */, /* меню */ над групами правил — Ctrl+/
Emmet-марафон. Правило для footer тільки скороченнями: bgc, c, ta:c, fz14
Палітра сусіда. Повернись до сусіда: вгадай три його кольори й перевір у F12
