Стартовий код — сторінка «Код уроку», блок «Три функції · допиши три return». Натисни «Скопіювати», відкрий codepen.io, встав у панель JS. Результат — кнопка Console унизу.

Місця, які треба дописати, позначені ДОПИШИ ТУТ. У кожному — один рядок із return.

  1. Встав заготовку. Зараз у консолі всюди undefined: функції рахують, але нічого не повертають.
  2. ДОПИШИ ТУТ 1: у функції square поверни квадрат числа — return n * n;. Має стати square(7) = 49.
  3. ДОПИШИ ТУТ 2: у функції isCheap поверни, чи ціна менша за 300 — return price < 300;. Має вийти 199 дешева? true і 699 дешева? false.
  4. ДОПИШИ ТУТ 3: у функції total після циклу поверни суму — return sum;. Має вийти Разом: 1666 грн.

Що надіслати: увесь код із панелі JS, першим рядком — коментар із прізвищем, і чотири рядки консолі.
