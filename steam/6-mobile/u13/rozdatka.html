Таймер. Дії, що повторюються

Довідка

Компонент

Clock — таймер, Sensors. Невидимий

TimerInterval — як часто, у мс

1000 мс = 1 секунда

Увімкнути / вимкнути

TimerEnabled — працює чи ні

true — так, увімкнено

false — ні, вимкнено

Блоки

when Clock1.Timer — щоразу, як минув інтервал

set Clock1.TimerEnabled to

set ImageSprite1.X to X + 10

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
