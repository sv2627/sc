Нове · стани

:hover, :focus, :active — коли спрацьовує правило

.btn { background-color: #d9822b; } .btn:hover { background-color: #b5651d; } input:focus { outline: 3px solid #d9822b; } .btn:active { background-color: #8d4a12; }
Наведи на мене
:hoverмиша над елементом. На телефоні миші немає — там наведення не буває
:focusполе в роботі: клацнули в нього або дійшли клавішею Tab
:activeу ту мить, коли кнопку натиснули
✍️
Двокрапка — впритул до селектора: .btn:hover, без пробілу.
🎞️
Нове

transition — плавно, а не стрибком

без transition — наведи
Стрибком
transition: background-color 0.3s, transform 0.3s; — наведи
Плавно
.btn { transition: background-color 0.3s; } .btn:hover { background-color: #b5651d; }
щояку властивість вести плавно: background-color, transform, color… Кілька — через кому
скількичас у секундах: 0.3s. Без s не працює
комузвичайному стану .btn, не :hover — тоді плавно і туди, і назад
alltransition: all 0.3s — плавно все, що зміниться
🔄
Нове

transform — збільшити, зсунути, повернути

звичайно

scale(1.3)

translateY(-12px)

rotate(20deg)

ЗначенняЩо робить
scale(1.1)у 1,1 раза більше · scale(0.9) — менше
translateX(10px) · translateY(-5px)зсув праворуч · вгору (мінус — угору). translate(10px, -5px) — обидва
rotate(15deg)поворот за годинниковою стрілкою, deg — градуси
scale(1.1) rotate(5deg)кілька разом — через пробіл в одному transform
💡
Сусіди не посуваються: transform лише малює елемент інакше.

Передбач · відповідь у коментар CSS

Що станеться?

1.btn:hover { background-color: red; }
Колір зміниться плавно чи стрибком?
2.btn:hover { background-color: red; transition: 0.5s; }
Навели — плавно. А коли мишу прибрали?
3.card:hover { transform: scale(2); }
Картка 200px. Яка ширина на екрані? Сусіди посунуться?
4.card:hover { transform: translateY(-10px); }
Картка поїде вгору чи вниз?
5header { position: sticky; }
Прокрутили вниз. Шапка прилипне?
6.logo:hover { transform: rotate(360deg); }
Без transition. Що побачимо?

Крок 1 · ⭐ Кнопка5 хвилин
Приклад · style.css
.btn { transition: background-color 0.3s, transform 0.3s; } .btn:hover { background-color: #b5651d; transform: scale(1.05); } .btn:active { transform: scale(0.95); }
Замовити
Тепер самостійно
  • .btn:hover — темніший колір твоєї кнопки
  • Звичайному .btn — transition на 0.3s
  • У :hover — ще й scale(1.05)
  • :active — кнопка «втискається»: scale(0.95)
  • ⭐⭐ Спробуй 1s і 0.1s — що приємніше?
Крок 2 · ⭐ Картки піднімаються5 хвилин
Приклад
.card { transition: transform 0.3s, box-shadow 0.3s; } .card:hover { transform: translateY(-5px); box-shadow: 0 6px 14px rgba(0, 0, 0, 0.2); }
Капучинонаведи на мене
Тепер самостійно
  • Наведення на картку каталогу: вгору на 5px
  • Тінь у :hover — ніби картка злетіла
  • transition — для transform і box-shadow, через кому
  • ⭐⭐ Головній картці — scale(1.03) замість зсуву
  • ⭐⭐⭐ Наведення на картку змінює колір рамки — ще одна властивість у transition
Крок 3 · ⭐⭐ Поле форми в роботі4 хвилини
Приклад
.order-form input:focus, .order-form select:focus, .order-form textarea:focus { outline: 3px solid #d9822b; }
Тепер самостійно
  • Полям форми в стані :focus — товстий контур твого кольору
  • Три селектори через кому — одне правило
  • Пройди форму клавішею Tab: видно, де ти?
  • ⭐⭐⭐ Поле в роботі ще й світліше: background-color у :focus
⌨️
Контур не прибирати зовсім: без нього не видно, де курсор.
Крок 4 · ⭐⭐ Шапка, що не зникає4 хвилини
Приклад
header { position: sticky; top: 0; z-index: 10; }
Тепер самостійно
  • Шапці — position: sticky і top: 0
  • Прокрути сторінку: шапка лишається вгорі?
  • Наведи на картку під шапкою: картка налазить на шапку? Додай z-index: 10
  • Клацни пункт меню: розділ видно повністю?
  • ⭐⭐⭐ Шапка з тінню знизу: box-shadow
Крок 5 · ⭐⭐⭐ Меню й іконки4 хвилини
Приклад
nav a { transition: color 0.3s; } nav a:hover { color: white; } .feature span { transition: transform 0.4s; } .feature span:hover { transform: rotate(20deg); }
☕🥐📶
Тепер самостійно
  • Пункти меню при наведенні — інший колір, плавно
  • Іконки «Чому ми» повертаються при наведенні
  • Підвал: посилання підкреслюються лише при наведенні — text-decoration
  • Не працює transform на span у рядку тексту? Йому потрібен display: inline-block

Чому не працює · 3 хвилини

Шість помилок — виправ у коментарі CSS

1Хотіли плавно і туди, і назад
.btn:hover { transition: background-color 0.3s; background-color: #b5651d; }
2Хотіли колір при наведенні
.btn : hover { background-color: #b5651d; }
3Хотіли плавно
.btn { transition: transform 0.3; }
4Хотіли шапку, що не зникає
header { position: sticky; }
5Хотіли і збільшити, і повернути
.card:hover { transform: scale(1.1); transform: rotate(5deg); }
6Хотіли, щоб картка піднялась
.card:hover { transform: translateX(-5px); }
