Що на екрані?

У списку games — вісім ігор, перша Stardew Valley

1 · Скільки рядків

ListView.builder( itemCount: 3, itemBuilder: (c, i) => Text(games[i].title), )

Клацни — відповідь.

3 рядки: перші три гри. itemCount вирішує, скільки, а не довжина списку

2 · Номер для людини

itemBuilder: (c, i) => Text('${i + 1}. ${games[i].title}'),

Що в першому рядку?

Клацни — відповідь.

1. Stardew Valley — i починається з 0, людям показуємо i + 1

3 · Забагато

ListView.builder( itemCount: 10, itemBuilder: (c, i) => Text(games[i].title), )

Клацни — відповідь.

8 рядків, на девʼятому — червоний екран RangeError (length): Invalid value: Not in inclusive range 0..7: 8. Пиши games.length

Перевір себе · зламай і полагодь

Що скаже Flutter?

1 · Список у Column

Column(children: [Text('Games'), ListView.builder(…)])

Що буде?

Червоний екран: Vertical viewport was given unbounded height. Обгорни список в Expanded — він займе все вільне місце

2 · Рядок замість віджета

ListTile(title: 'Celeste')

Що буде?

Помилка ще до запуску: The argument type 'String' can't be assigned to the parameter type 'Widget?'. Пиши title: Text('Celeste')

3 · Забули return

itemBuilder: (c, i) { Text(games[i].title); }

Що буде?

Жовте попередження This function has a nullable return type of 'Widget?', but ends without returning a value. Екран порожній. Допиши return

Банк завдань · для тих, хто закінчив

Ще вісім доробок

1. Лінія між рядками: ListView.separated і separatorBuilder: (c, i) => const Divider()
2. Ліворуч іконка за жанром: Sandbox — Icons.landscape, решта — Icons.sports_esports
3. Стрічка вбік: scrollDirection: Axis.horizontal, кожна картка — SizedBox(width: 200)
4. Дві колонки: GridView.count(crossAxisCount: 2, …) з тими самими картками
5. Над списком — підсумок 8 games · 144.92 USD: сума циклом, toStringAsFixed(2), список в Expanded
6. ⭐⭐⭐ ще раз натиснули вибрану гру — вибір знімається: _selected = _selected == i ? null : i
7. Праворуч сердечко IconButton замість ціни; ціна — у subtitle поруч із жанром
8. Свої дані: 8 обʼєктів своєї теми з міні-проєкту II — у той самий ListView.builder
