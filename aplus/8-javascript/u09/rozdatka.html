Довідка

const a = [10, 20, 30];

індекс з 0: a[0] — перший

a.length — скільки; останній a[a.length - 1]

Змінити

a[1] = 99; — замінити

a.push(x) — додати в кінець

a.pop() — забрати останній

за межею — undefined

Перебрати

for (let i = 0; i < a.length; i++)
