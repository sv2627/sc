Технологія Flexbox. Меню сайту

Довідка

Контейнер

display: flex — пишемо батькові, діти стають у рядок

gap: 20px — відстань між дітьми

flex-wrap: wrap — переносити

Уздовж осі

flex-direction: row · column · row-reverse · column-reverse

justify-content: flex-start · center · flex-end · space-between · space-around · space-evenly

Поперек осі

align-items: stretch · flex-start · center · flex-end · baseline

У column осі міняються: justify-content — згори вниз

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

1 · Кому писати display: flex?

<div class="container">
  <h1>Кіно</h1>
  <nav>
    <a href="#films">Фільми</a>
    <a href="#prices">Ціни</a>
  </nav>
</div>

назва й меню по краях →

2 · Що робить властивість

flex-direction
justify-content
align-items
gap
flex-wrap

3 · Намалюй три квадрати 1 2 3 у рамціконтейнер з display: flex

justify-content: center

justify-content: space-between

justify-content: flex-end

flex-direction: row-reverse

4 · Знайди помилку

Хотіли меню посередині:

nav { justify-content: center; }

Хотіли відстань 20px:

nav { display: flex; gap: 20; }

5 · Допиши CSS

Назва ліворуч, меню праворуч, на одній висоті:

  display: ________;
  justify-content: _____________;
  align-items: ________;
}

Перший екран: стовпчиком і посередині:

#hero .container {
  display: flex;
  flex-direction: ________;
  justify-content: ________;
  align-items: ________;
}
