Завдання практичної

З чого складається твоя сторінка

<header> <h1> — назва сторінки
<nav> 2–3 посилання
<main> один на сторінку
<section> <h2> + абзац <p>
<section> <h2> + список <ul> або <ol>
<section> <h2> + картинка <img> з alt
<footer> © 2026 і посилання на сайт про твою тему

Передбач

Що дасть скорочення після Tab?

nav>a*3

Подумай, потім клацни

<nav> <a href=""></a> ×3 </nav>

header>h1+nav

Подумай, потім клацни

<header> <h1></h1> <nav></nav> </header>

ol>li*3

Подумай, потім клацни

<ol> <li></li> ×3 </ol>

main>section*2

Подумай, потім клацни

<main> <section></section> ×2 </main>

p>lorem5

Подумай, потім клацни

<p>Lorem ipsum dolor sit amet.</p>

h2+p+p

Подумай, потім клацни

<h2></h2> <p></p> <p></p>

Крок 1 Папка й каркас4 хвилини
Приклад
папка football-page → VS Code → File → Open Folder New File → index.html → ! Tab <html lang="en"> → lang="uk" <title>Футбол — моя гра</title>
Тепер самостійно
  • Папка своєї теми: латиниця, малі літери, дефіс
  • index.html → ! + Tab
  • lang="en" заміни на lang="uk"
  • У <title> — назва твоєї сторінки. Ctrl+S, відкрий у Chrome: що на вкладці?
  • ⭐⭐ Одразу створи поруч папку images/
  • ⭐⭐⭐ Увімкни File → Auto Save — білого кружечка більше не буде
Крок 2 Семантичний скелет одним рядком5 хвилин
Приклад · усередині <body>
header+nav+main+footer Tab у <header>: h1 Tab → Футбол — моя гра у <nav>: a*3 Tab → три посилання
Тепер самостійно
  • Скелет одним рядком — у свій <body>
  • <h1> з назвою сторінки — у <header>
  • У <nav> — a*3, поки просто тексти: Головна · …
  • У <footer> — p + Tab: © 2026 і назва сторінки
  • ⭐⭐ Перенеси <nav> усередину <header>: курсор на рядок → Alt+↑
  • ⭐⭐⭐ Меню списком, як на уроці 3: nav>ul>li*3>a
⚡
Набрав <h1> — </h1> з'явився сам. Закривальні теги руками не пишемо.

Якщо Emmet мовчить

Tab ставить пробіли замість тегів — чому?

Файл не .html

Новий файл без назви Emmet не розуміє. Збережи як index.html. Праворуч унизу має бути HTML

Пробіл у скороченні

header + nav — ні. header+nav — так. Emmet бачить тільки до першого пробілу

Курсор не в кінці

Tab тиснемо одразу після останньої літери скорочення

Вискочив список підказок

Обери рядок зі значком 🔧 Emmet Abbreviation — Enter

Клавіші, які економлять хвилини

Одну секцію написав — решту копіюєш

1Виділи мишею рядки від <section> до </section>
2Alt+Shift+↓ — під нею така сама секція
3Міняєш лише текст. Двічі — три секції
4Секція заважає? Ctrl+/ — вона в коментарі, у браузері зникла. Ще раз — повернулась
Крок 3 Секції: заголовки, текст, списки9 хвилин
Приклад · усередині <main>
section>h2+p>lorem10 Tab → розділ, у p — 10 слів-заглушок Alt+Shift+↓ двічі → три секції ul>li*3 Tab → список
Тепер самостійно
  • Три <section>, у кожній свій <h2>
  • lorem заміни своїм текстом — 2–3 речення про тему
  • В одній секції — <ul> на 4 пункти, в іншій — <ol> (топ-3, кроки)
  • Виділи головне слово <strong>. Ctrl+S → F5
  • ⭐⭐ Секція з трьома <article>: article*3>h3+p
  • ⭐⭐⭐ <aside> «Цікавий факт» після <main>
Крок 4 Картинка зі своєї папки5 хвилин
Приклад
знайти фото → «Зберегти як» → images/ball.jpg img Tab → <img src="images/ball.jpg" alt="М'яч на траві" width="400">
Тепер самостійно
  • Одна картинка до теми → images/, назва латиницею
  • img + Tab у третю секцію: src, alt, width
  • alt описує, що на фото, а не «картинка»
  • Зламай: прибери images/ з src → F5. Що видно? Поверни Ctrl+Z
  • ⭐⭐ Друга картинка в іншій секції
  • ⭐⭐⭐ Картинка-посилання: <img> усередині <a>
⚡
У src="" набери images/ — VS Code сам покаже файли з папки. Стрілка й Enter.
Крок 5 Посилання5 хвилин
Приклад
<nav> <a href="index.html">Головна</a> <footer> <a href="https://uk.wikipedia.org/wiki/Футбол" target="_blank">Вікіпедія</a>
Тепер самостійно
  • У <nav>: перше посилання — index.html, «Головна»
  • Друге — на сайт про твою тему, у новій вкладці
  • У <footer> — посилання на Вікіпедію про тему
  • Клацни кожне в Chrome. Жодне не веде «в нікуди»
  • ⭐⭐ Прибери з <nav> зайві порожні <a> — Ctrl+Shift+K видаляє рядок
  • ⭐⭐⭐ about.html з тими ж header і footer, посилання туди й назад

Передбач

У цьому коді п'ять помилок. Знайди

index.html
<header> <h1>Мій кіт</h1> </header> <main> <section> <h2>Хто він <img src="Мій кіт.jpg"> </section> </main> <main> <li>спить</li> </main> <footer><a href="about.html>Про нас</a></footer>

Відповідь

Спершу знайди сам, потім клацни

  • <h2> не закритий
  • img без alt
  • назва файлу кирилицею з пробілом і не в images/
  • два <main> — має бути один
  • <li> без <ul>; у href немає закривальних лапок
Фініш Перевір у F123 хвилини
1F12 → Elements → згорни всі трикутники в <body>. Видно header · main · footer?
2Розгорни <main>: три section, у кожній h2?
3Картинка показується, а не значок-«зламка»?
4Кожне посилання клацається й веде туди, куди написано?
5Повернись до сусіда: знайди в його F12 один тег, якого немає в тебе

Закінчив раніше?

Банк завдань — бери будь-яке

Топ-5. Нумерований список «Мій топ-5» з ol>li*5
Вкладений список. У пункті списку — ще один <ul>, як на уроці 2
Три картки. section>h2+article*3>h3+p+img — одним рядком
Цитата дня. Секція з <em>-цитатою й автором
Коментарі. Над кожною секцією Ctrl+/: що в ній
Друга сторінка. gallery.html з трьома картинками й меню
Без миші. Дві нові секції тільки клавіатурою: Emmet, Alt+Shift+↓, Alt+↑
Порожній style.css. Папка css/ і файл у ній — чекає на урок 7
