Крок 1 Відкрий свій сайт і пройди його5 хвилин
Приклад — разом
VS Code → File → Open Folder… → папка pr1 Chrome → Ctrl+O → pr1/index.html Головна → Фото → Головна ✓
Тепер самостійно
  • Відкрий папку pr1 у VS Code, головну — у Chrome
  • Пройди усі сторінки, тільки клацаючи меню, — туди й назад
  • Усі картинки видно? На кожній вкладці — своя назва?
  • Не відкривається — звір ім'я в href з ім'ям файлу
  • ⭐⭐ F12 → Elements: у body — header, main, footer?
  • ⭐⭐⭐ Немає папки pr1? Слайд «Починаєш заново» — через два
⚡ Швидше Ctrl+S → F5 браузер назад — Alt+←
Крок 2 Лад у розмітці — до оформлення7 хвилин
Приклад — так зручно оформлювати
<main> <section> <h2>Новини</h2> <article> <h3>Барсик зловив мишу</h3> <p>Сьогодні вранці…</p> </article> </section> </main>
Тепер самостійно
  • Кожен розділ — section, і в ньому свій h2
  • Новина, пост, картка — article з h3
  • На кожній сторінці — один h1, у шапці
  • У кожної картинки — alt
  • ⭐⭐ Головній — ще один розділ: «Про мене» або «Цікаві факти»
  • ⭐⭐⭐ Над кожним section — коментар <!-- -->: що в цьому розділі
⚡ Швидше схожий блок — виділи й Alt+Shift+↓ коментар — Ctrl+/
Крок 3 Паспорт стилю — у index.html6 хвилин
Приклад — у head, під title

Тепер самостійно
  • Обери стиль і три кольори з палітри — або свої
