Три способи перемикати картинку

when Button1.TouchDown do
set Image1.Picture to " dog.png "
when Button1.TouchUp do
set Image1.Picture to " cat.png "
Click — натиснув і відпустив: одна кнопка — одна картинка
TouchDown + TouchUp — пес, поки тримаєш. Відпустив — знову кіт. Як «лампочка» з уроку 4
LongClick — секретна картинка на довге натискання

Закінчив раніше?

Банк завдань — бери будь-яке

Світлофор. Три кнопки — червоне, жовте, зелене світло: три картинки
Настрій. Кнопки «😊» і «😢» міняють картинку і пишуть повідомлення
Секрет. LongClick — секретна картинка і ShowAlert «Ти знайшов секрет!»
Говорун. Картинка змінюється, а TextToSpeech вимовляє, хто на ній
Правила. ShowMessageDialog при запуску: як користуватись застосунком
Кнопки-картинки. Кнопки самі з картинками: Button1.Image — як на уроці 5
Ховайка. Одна кнопка ховає картинку, друга показує: Visible false / true
⭐⭐⭐ Перевертень. set Image1.RotationAngle to 180 — картинка догори дриґом, 0 — назад
🧰
Усі вісім робляться тільки тим, що було сьогодні й раніше.

Якщо щось пішло не так

Пʼять бід сьогоднішнього уроку

Картинка не змінюється — назва в блоці не збігається з файлом у Media
Картинка на пів екрана — Width і Height у pixels
Немає блоку set Image1.Picture — шукаєш у шухляді кнопки, а він у шухляді Image1
Не встиг прочитати повідомлення — NotifierLength = Long або ShowMessageDialog
Текст вікна порожній — текст у гнізді title, а треба в message
🔤
Назви файлів — латиницею, без пробілів: dog.png, а не Мій пес.png.
🔤
