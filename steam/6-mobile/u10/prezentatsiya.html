MoveTo — стрибок у точку

when ImageSprite1.Touched x y do
call ImageSprite1.MoveTo x 200 y 150
MoveTo переносить персонажа одразу в точку X 200, Y 150. Числа — сині блоки з Math.
БлокЩо робить
call ImageSprite1.MoveToміняє X і Y разом
set ImageSprite1.X toміняє лише X — рух уліво-вправо
set ImageSprite1.Y toміняє лише Y — рух угору-вниз
🧭
Усі три — у шухляді ImageSprite1 в Blocks.

⭐⭐⭐ Для тих, хто встиг

Щоразу в інше місце

when ImageSprite1.Touched x y do
call ImageSprite1.MoveTo x random integer from 0 to 220 y random integer from 0 to 220
random integer from 0 to 220 — синій блок з Math. Щоразу дає інше ціле число від 0 до 220 — як кубик.
Чому 220? Полотно 300, персонаж 80: 300 − 80 = 220 — щоб не виліз за край.
🗓️
Випадкові числа докладно — 1 грудня. Сьогодні досить цього блоку.
