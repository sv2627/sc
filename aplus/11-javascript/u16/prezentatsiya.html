Що бачить JavaScript

DOM — дерево елементів сторінки

Браузер читає HTML і будує дерево обʼєктів. JavaScript працює з деревом, а не з файлом
Вхід у дерево — обʼєкт document. Усе, що на сторінці, — його гілки
🛠️

3Подвійний клік по тексту — змінити. F5 — і все як було: змінилось дерево, а не файл

Читати і писати

textContent — текст елемента

Console або script.js
const t = document.querySelector('#title'); console.log(t.textContent); // Магазин t.textContent = 'GameStore'; // тепер GameStore t.textContent += ' · знижки'; // GameStore · знижки
Знайдене — у const: шукаємо один раз, змінюємо скільки завгодно
Читати — як змінну. Писати — через =, дописати — через +=
Шаблонний рядок працює й тут: `Ігор: ${n}`

З тегами

innerHTML — вміст разом з тегами

textContent — теги як текст
el.textContent = 'Minecraft — <b>649 грн</b>';

Minecraft — <b>649 грн</b>

innerHTML — теги працюють
el.innerHTML = 'Minecraft — <b>649 грн</b>';

Minecraft — 649 грн

Просто текст — textContent. Потрібні теги — innerHTML
Текст, який ввела людина (prompt), — тільки textContent: інакше чужі теги стануть частиною сторінки

Зі скрипта

<script> — останнім рядком у body

index.html
<body> <h1 id="title">Магазин</h1> <p id="today">Дата</p> … <script src="script.js"></script> </body>
Браузер читає HTML згори вниз і виконує скрипт там, де його зустрів
Скрипт у кінці body — на цей момент усі елементи вже є в дереві
Скрипт у head — body ще не прочитано, querySelector → null
Зміни зі скрипта не зникають після F5: скрипт виконується щоразу заново

Знайди всі три, потім клацни

3. 'game' без крапки — тегу game немає, null і TypeError

Дата і час

new Date() — зараз

script.js · 11 листопада 2026, 16:15
const d = new Date(); d.getDate() // 11 — число місяця d.getMonth() // 10 — листопад! місяці з 0 d.getFullYear() // 2026 d.getHours() // 16 d.getDay() // 3 — середа, 0 — неділя
getMonth(): січень — 0, грудень — 11. Людині — getMonth() + 1
Дата — з годинника компʼютера: завтра скрипт покаже вже 12
Методи з дужками () — як trim() у рядка
