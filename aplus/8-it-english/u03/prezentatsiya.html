Key question 1
🔀

What is selection?

selection an instruction within an algorithm where a decision is made about whether to run a piece of code or not
Українською — розгалуження. Алгоритм доходить до розвилки й вирішує, куди йти
Без нього алгоритм — пряма лінія: кожен крок виконується завжди і рівно раз
Key question 2
❓

How is selection usually written?

Схема відповідає так: as a question, or a comparison, that results in true or false.

As a question

Is the answer correct?

Відповідь може бути тільки так або ні

As a comparison

Value1 >= Value2

Результат теж тільки true або false

⚖️
Третього не буває. Якщо на питання можна відповісти «ну, залежить» — це ще не умова для алгоритму.
Key question 3
🔑

The key words: IF, THEN, ELSE

IF далі йде умова — те, що перевіряємо
THEN далі йде код, який виконається, якщо умова істинна
ELSE далі йде код, який виконається, якщо умова хибна
🌍
Ці три слова однакові в усіх мовах програмування. Вивчили раз — упізнаєте скрізь.

Notation 1
📊

The flowchart: a diamond with two arrows

START
↓
INPUT age
↓
age >= 18 ?
YES · true
OUTPUT "Adult"
NO · false
OUTPUT "Child"
Ромб — і тільки він — означає selection. Усередині ромба завжди питання
Із ромба виходять дві стрілки: yes і no. Куди йти — залежить від того, істинна умова чи хибна
Далі гілки сходяться назад. Алгоритм має один кінець, а не два

Notation 2
⌨️

The same thing as pseudocode

if condition: Code to run if true else: Code to run if false
Це псевдокод у стилі Python — саме такий у Stage 8
Після умови — двокрапка :. Вона обов'язкова
else теж має двокрапку: else:
🧭
Той самий алгоритм, що на схемі, — просто інший notation. Ромб стає рядком if, стрілки YES і NO стають двома блоками під ним.
The rule that decides everything
📐

Indentation — відступ показує, що куди належить

if mark > 50: OUTPUT "Pass" OUTPUT "Well done" else: OUTPUT "Try again" OUTPUT "The end"
Усе, що з відступом після if condition:, виконується тільки якщо умова істинна
else: стоїть на одному рівні з if, не з відступом
OUTPUT "The end" — без відступу, отже виконається завжди, хай яка гілка спрацювала
Example 1
🔢

Which of two numbers is bigger?

Input Value1 Input Value2 if Value1 >= Value2: OUTPUT Value1 else: OUTPUT Value2
Алгоритм виводить більше з двох чисел
Спробуйте: Value1 = 7, Value2 = 3 → виведе 7
А якщо обидва однакові? 5 >= 5 дає true — виведе Value1
📖
Цей приклад узято зі схеми дослівно. Так само дослівно він може трапитись у завданні.
Example 2
🎨

Purple or green?

Colour = INPUT("Do you prefer purple or green?") if Colour == "purple": OUTPUT "Purple is the best" else: OUTPUT "Purple is better than green"
Тут порівнюємо не числа, а текст. Тому "purple" у лапках
Зверніть увагу: ==, а не =. Обидва варіанти прийнятні в псевдокоді, але тут стоїть подвійний
😏
Прочитайте обидві гілки уважно. Хай яку відповідь дасть людина — алгоритм усе одно скаже, що purple кращий. Це і є «follow the algorithm»: побачити, що він робить насправді, а не що ви очікували.
The three parts
🧩

Every conditional statement has three parts

1 · the condition

Value1 >= Value2

Те, що перевіряємо. Дає true або false

2 · if true

OUTPUT Value1

Код, який виконається, коли умова істинна

3 · if false

OUTPUT Value2

Код, який виконається, коли умова хибна

🔎
У будь-якому алгоритмі — і на схемі, і в псевдокоді — ви маєте вміти показати пальцем усі три частини. Це і є завдання 2.

Important
✍️

There is no single correct pseudocode

Той самий алгоритм можна записати по-різному — і всі записи будуть правильні. Схема наводить ще два способи:

IF condition THEN Code to run if true ELSE Code to run if false ENDIF
If (condition) Then Code to run if true Else Code to run if false endif
🧭
Що спільне в усіх трьох: умова, код на true, код на false. Форма різна — суть та сама. Саме тому вміти follow важливіше, ніж завчити один запис.
