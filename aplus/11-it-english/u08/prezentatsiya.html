What is a trace table?

1
A trace table is a structure to help you follow an algorithm, for example, to find an error, or to work out what the algorithm does.

переклад — клацни

Трасувальна таблиця — це структура, яка допомагає пройти алгоритм, наприклад, щоб знайти помилку або зрозуміти, що алгоритм робить.
2
Each statement in an algorithm is run manually, and the values that are written to variables are written in the table in the order the changes are made.

переклад — клацни

Кожну інструкцію алгоритму виконують вручну, а значення, які записуються у змінні, пишуть у таблицю в тому порядку, в якому вони змінюються.
3
Each column in the table is designated to one variable. There can also be a column for any outputs to be written in.

переклад — клацни

Кожен стовпець таблиці відведено одній змінній. Може бути й стовпець, куди записують усе, що виводиться.
4
User prompts are also entered in the trace table, these can be entered in a separate column or as an output (because they will be output).

переклад — клацни

Підказки для користувача теж записують у трасувальну таблицю — в окремий стовпець або як вивід (бо їх буде виведено).
5
Specific inputs can be given to test different parts of the algorithm.

переклад — клацни

Можна дати конкретні вхідні дані, щоб перевірити різні частини алгоритму.

Trace table with loops

1
When you are following an algorithm that includes a loop (iteration), some of the code will be repeated.

переклад — клацни

Коли ви йдете за алгоритмом, у якому є цикл (повторення), частина коду повторюватиметься.
2
To follow the code run one line at a time as before, and when you get to the end of the loop, go back to the start of the loop.

переклад — клацни

Щоб іти за кодом, виконуйте по одному рядку, як і раніше, а коли дійдете до кінця циклу — поверніться на початок циклу.
3
Start by creating the trace table with each of the variables and the output.

переклад — клацни

Почніть зі створення трасувальної таблиці з усіма змінними та виводом.
4
When a variable has a new value, it is written below the previous one.

переклад — клацни

Коли змінна отримує нове значення, його пишуть під попереднім.

True or false? · с. 179–183

Це правда?

Прочитай речення вголос і скажи T (true — так, правда) або F (false — ні, неправда).

1 · Each variable has its own column in the trace table.
2 · You can jump ahead and guess what the algorithm will do.
3 · When a variable has a new value, it is written below the previous one.
4 · A trace table has no column for outputs.
5 · At the end of the loop, you go back to the start of the loop.
6 · 'total = 10' is a correct output for Skills Focus 7.4.

Відповідь

Спершу вголос — потім клацни.

1 T · 2 F — read one line at a time · 3 T · 4 F — there can be an output column · 5 T · 6 F — correct is 'The total is 10'
