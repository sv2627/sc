Key words (с. 198)

variable: a named memory location that can store data. The data can change whilst a program is running.

constant: a named memory location that can store data. The data cannot change whilst a program is running.

Код до завдання 2 (с. 199–200)

Псевдокод:

Number ← 10
Colour ← "red"
Price ← 22.2

A

public static void main(String args[]){
    Integer number = 10;
    String colour = "red";
    Double price = 22.2;
}

B

Dim number As Integer
Dim colour As String
Dim price As Single
number = 10
colour = "red"
price = 22.2

C

number = 10
colour = "red"
price = 22.2
