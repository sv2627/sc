Що надіслати

  • Картинку блоків проєкту Lichylnyk: у Blocks правий клік на порожньому місці → Download Blocks as Image. Прикріпи PNG до завдання в Classroom.
  • Одне число — відповідь на пункт 2, текстом у коментарі до завдання.

1 · Кнопка «+10»

Що зробити: у Designer — нова кнопка Button10 з написом «+10».

Що має вийти: на екрані 0 → натиснув «+10» → 10 → натиснув «+1» → 11.

Де: Blocks → шухляда Button10 → when Button10.Click, у неї — два блоки нижче. Як у Button1, тільки 10 замість 1. Число й «+» — у Built-in → Math.

when Button10.Click do
set global score to get global score + 10
set Label1.Text to get global score

2 · Яке число в кінці?

На старті на екрані 0. Натиснули Button1 тричі, потім ButtonReset, потім Button1 ще двічі. Яке число в Label1 у кінці? Напиши одне число.

Увага: тут Button1 додає 2, а не 1 — програма нижче, у своєму проєкті її збирати не треба.

initialize global score to 0
when Button1.Click do
set global score to get global score + 2
set Label1.Text to get global score
when ButtonReset.Click do
set global score to 0
set Label1.Text to get global score

Немає проєкту з уроку?

Створи новий проєкт Lichylnyk (Projects → Start new project) і збери за 3 хвилини:

Designer: Label1 — Text 0, FontSize 40 · Button1 — Text «+1» · ButtonReset — Text «Скинути».

Blocks: змінна — окремо, поза підковою (Built-in → Variables, клац по name → score):

initialize global score to 0
when Button1.Click do
set global score to get global score + 1
set Label1.Text to get global score
when ButtonReset.Click do
set global score to 0
set Label1.Text to get global score
