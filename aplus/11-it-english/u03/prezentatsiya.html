Key words · с. 167–171

Пʼять означень із книжки

totalling
statements in a program that add together a set of data to produce the total
counting
statements in a program that record how many of something there are
minimum
the smallest item in a set of data
maximum
the largest item in a set of data
average
the mean of a set of values, the total divided by the quantity

Головна думка

Пʼять алгоритмів — один шаблон

1 Initialise — завести змінну й дати їй стартове значення
2 Loop — пройти по всіх даних: FOR по масиву або WHILE по вводу
3 Update — на кожному кроці змінити змінну за своїм правилом
4 Output — вивести результат після циклу, не всередині
Різниця між пʼятьма алгоритмами — тільки в кроках 1 і 3. Цикл і вивід у всіх однакові.

Totalling · с. 167

Приклад із книжки

Totalling is adding a group of values together to give a total.

A person buys items at a supermarket. The items cost: $0.50 · $1.00 · $1.00 · $15.50 · $21.30
The total is 0.5 + 1 + 1 + 15.5 + 21.3 = $39.30

Initialise

Total ← 0 — змінна для суми

Update

Total ← Total + Value — додати значення до того, що вже є

⌨️
Totalling · Example 1

Сума десяти введених значень

с. 167 · Example 1
Total ← 0 //Initialise the total variable to 0 FOR X ← 0 TO 9 Total ← Total + INPUT("Enter a value") //Add the input to the total NEXT X OUTPUT Total
0 TO 9 — це десять проходів, не девʼять
Ініціалізація до циклу. Усередині вона обнуляла б суму щоразу
OUTPUT — після NEXT. Інакше друкує проміжні суми
🗄️
Totalling · Example 2

Сума значень масиву

с. 167 · Example 2
TotalValue ← 0 //Initialise the total variable to 0 FOR Count ← 0 TO LENGTH(DataArray) − 1 TotalValue ← TotalValue + DataArray[Count] //Add the input to the total NEXT Count OUTPUT Total
🔍
Придивіться до останнього рядка: у книжці там OUTPUT Total, хоча змінна називається TotalValue. Знайдіть таке в себе — на іспиті це коштує бала.

Counting · с. 168

Скільки чогось є

Counting is working out how many of something there are — наприклад, скільки пальців на руці або скільки речей ви купили.

Initialise

CountItems ← 0

Update

Count ← Count + 1 — завжди на одиницю, хоч би яке було значення

Ось уся різниця з totalling: там додаємо значення, тут — одиницю.
📊
Counting · Example 2

Два лічильники одночасно

с. 168–169 · below 10 and above 20
CountBelow10 ← 0 //initialise both counters to 0 CountAbove20 ← 0 FOR X ← 0 TO LENGTH(NumberArray) //loop through each array element //if the number is less than 10 IF NumberArray[x] < 10 THEN CountBelow10 ← CountBelow10 + 1 //increment the counter //if the number is greater than 20 ELSEIF NumberArray[x] > 20 THEN CountAbove20 ← CountAbove20 + 1 //increment the counter ENDIF NEXT X

Question 21 · с. 172

Explain the difference between totalling and counting

Сформулюйте самі

Одне-два речення англійською, потім клацни.

Totalling adds the value of each item to a running total: Total ← Total + Value

Counting adds 1 each time, no matter what the value is: Count ← Count + 1

Один набір даних — різні відповіді. Для 5, 5, 5 сума 15, а лічильник 3.

Minimum · с. 169–170

Найменше значення

с. 170 · Example 1
Minimum ← 9999 //initialise minimum to large value Number ← 1 WHILE Number >= 1 DO //loop until the user enters 0 Number ← INPUT("Enter a number or 0 to stop") IF Number < Minimum THEN Minimum ← Number ENDIF ENDWHILE
Три кроки з книжки:
initialise a minimum variable to be a large value, beyond those that will be entered
compare each value: IF Number < Minimum
if it is — it replaces the minimum value
⬆️
Maximum · с. 170–171

Найбільше — дзеркально

с. 171 · Example 2
Maximum ← −1 // initialise the maximum value to a small number FOR X ← 0 TO LENGTH(NumberArray) //check if the number entered is larger than the current maximum IF NumberArray[X] > Maximum THEN Maximum ← NumberArray[X] //if true store the value in maximum ENDIF NEXT X

Minimum

старт — велике число · знак <

Maximum

старт — мале число · знак >

Question 22 · с. 172

Пастка ініціалізації

«A program allows numbers to be entered between 20 and 200, and finds the smallest and largest entered. Identify appropriate values to initialise the variables Smallest and Largest.»

Що поставити?

Свої числа — і поясни чому. Потім клацни.

Smallest — щось більше за 200, наприклад 201 або 9999: інакше перше ж введене число не замінить його

Largest — щось менше за 20, наприклад 19 або 0

Правило з Summary книжки: minimum ініціалізують великим значенням, maximum — малим. Навпаки — і алгоритм поверне стартове число.

Average · с. 171

Середнє — це total і count разом

«The average here is referring to the mean. This is the total of all the values added together, then divided by how many numbers there are.»

To do this you need to use the count and total from earlier. The average is then calculated with the formula Total / Count
🧮
Тому середнє ніколи не рахують окремо: це два вже знайомі алгоритми, які працюють в одному циклі.
🔎
Перевір книжку

Приклад із с. 171

if the data is 1, 3, 5, 8, 4, 2, 6, 9,
the average = (1+3+5+8+4+4+6+9) / 8 = 40 / 8 = 5

Порахуйте суму самі. Збіглося?

Додайте вісім чисел із переліку. Потім клацни.

У переліку шосте число — 2, а у формулі на його місці 4.

За переліком: 1+3+5+8+4+2+6+9 = 38, отже 38 / 8 = 4.75.

Це одруківка в книжці. Метод правильний, число ні. На іспиті рахують за вашими даними — тож перевіряйте арифметику завжди, навіть за підручником.

⌨️
Average · Example 1

Total і count в одному циклі

с. 171 · Example 1
Count ← 0 //initialise the count to 0 Total ← 0 //initialise the total to 0 Number ← 1 WHILE Number >= 1 DO //loop until the user enters 0 Number ← INPUT("Enter a number or 0 to stop") Total ← Total + Number //add the number entered to the total Count ← Count + 1 //add 1 to the count ENDWHILE
👀
Зверніть увагу: у книжці немає рядка з діленням і немає OUTPUT. Допишіть їх самі — і подумайте, де саме вони мають стояти.
