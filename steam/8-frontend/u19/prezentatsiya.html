Вимоги до каталогу

⭐Етапи 1–2. Розділ каталогу з h2 і id, меню веде на нього · не менше шести карток · сітка з трьох колонок через repeat і fr, проміжок gap · у картці назва, опис, ціна й кнопка; ціна ліворуч, кнопка праворуч

Етап 1 · ⭐ Розділ і сітка7 хвилин
Приклад
<section id="drinks"> <div class="container"> <h2>Напої</h2> <div class="cards"> <article class="card">…</article> … </div> </div> </section>
.cards { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }
Тепер самостійно
  • Розділ каталогу: section з id, усередині h2
  • Пункт меню в шапці веде на цей id: href="#…"
  • Обгортка .cards — сітка з трьох колонок, gap
  • Не менше шести карток, у картки — жодного width
  • ⭐⭐ F12 → кнопка grid: колонки рівні?
Етап 2 · ⭐ Картка7 хвилин
Приклад
<article class="card"> <h3>Капучино</h3> <p>Кава з молоком і пінкою</p> <div class="card-foot"> <span class="price">55 грн</span> <a class="btn" href="#order">Замовити</a> </div> </article>
.card-foot { display: flex; justify-content: space-between; align-items: center; }
Тепер самостійно
  • У кожній картці: h3 — назва, p — опис
  • Низ картки .card-foot: ціна ліворуч, кнопка праворуч
  • Картці — рамка, круглі кути, padding, білий фон
  • Ціна — span class="price", жирна й кольорова
  • ⭐⭐ Тексти карток — свої, не з прикладу
  • ⭐⭐⭐ Емодзі або фото з папки img угорі картки, width: 100%

Етап 4 · ⭐⭐ Рядок фільтрів4 хвилини
Приклад
<div class="filters"> <a class="btn" href="#drinks">Усі</a> <a class="btn" href="#drinks">Кава</a> <a class="btn" href="#drinks">Випічка</a> </div>
.filters { display: flex; flex-wrap: wrap; gap: 10px; margin-bottom: 20px; }
Тепер самостійно
  • Над .cards — div class="filters" з трьома–чотирма кнопками

  • Між фільтрами й сіткою — margin-bottom
  • Фільтри поки не фільтрують — це вигляд. Фільтрувати вміє JavaScript
  • ⭐⭐⭐ Фільтри посередині: justify-content: center

Flexbox: діти в рядок або в стовпчик

Властивість · батьковіЗначення і що робить
display: flexдіти стають у рядок. Пишемо батькові, не дитині
flex-directionrow — рядок · column — стовпчик · row-reverse · column-reverse
justify-contentуздовж осі: flex-start · center · flex-end · space-between · space-around · space-evenly
align-itemsпоперек осі: stretch — однакова висота · flex-start · center · flex-end · baseline
gapвідстань між дітьми: gap: 20px
flex-wrapnowrap — стискаються · wrap — переносяться на новий рядок
шапка: space-between + center

Grid: рядки і колонки разом

Що пишемоЩо робить
display: gridдіти стають у комірки сітки. Пишемо батькові
grid-template-columnsколонки: 200px 200px — дві по 200px
grid-template-rowsвисота рядків: 100px auto
frчастка вільного місця: 2fr 1fr — перша вдвічі ширша
repeat(3, 1fr)те саме, що 1fr 1fr 1fr
gapпроміжки; row-gap — між рядками, column-gap — між колонками
grid-column: span 2картка на дві колонки. Пишемо дитині
grid-row: span 2картка на два рядки
grid-column: 1 / -1на всю ширину: від першої лінії до останньої
1 / -1span 23456
.cards { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }
