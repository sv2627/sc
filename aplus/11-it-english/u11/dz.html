Self-evaluation checklist (с. 195)

  1. identify the stages in the program development life cycle.
  2. use decomposition to split a system into sub-systems.
  3. create structure diagrams, flowcharts and pseudocode algorithms.
  4. explain how a bubble sort and linear search works.
  5. describe and produce algorithms that include finding the maximum, minimum and average values.
  6. understand the need for validation and verification and write programs that make use of each.
  7. identify appropriate test data for an algorithm.
  8. complete a trace table for an algorithm.
  9. check a program for errors and amend the program.
  10. explain the purpose of an algorithm.

Завдання · ≈ 10 хвилин

  1. Exam-style question 3 (с. 192). Дай відповідь англійською, два речення: Describe the purpose of decomposition. [2]
  2. Self-evaluation checklist (вище): для кожного з 10 рядків напиши номер і оцінку 1 (Needs more work), 2 (Getting there) або 3 (Confident to move on).
  3. Translate (переклади українською): define · identify · describe · show (that).
