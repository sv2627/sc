class · .note

Клас: імʼя в HTML — крапка в CSS

index.html
<h3>Барсик зловив мишу</h3> <p class="note">10 листопада</p> <p>Сьогодні вранці на кухні.</p>
style.css
.note { font-size: 14px; font-style: italic; }
class="note"атрибут у HTML — як href чи alt. Імʼя — без крапки
.noteселектор класу: крапка + імʼя — «усі, у кого клас note»
noteімʼя придумуєш сам. В обох файлах — літера в літеру
<p>абзац без класу правило .note не чіпає
🧩
Як працює клас

Багато елементів, кілька класів, хто сильніший

Один клас — багато

Клас card у двох новин — одне правило на обидві. Змінив правило — змінились усі. Клас можна дати будь-якому тегу

Кілька класів

class="card important"

через пробіл, в одних лапках. Елемент отримує правила обох класів

Хто сильніший

Правила сперечаються — перемагає клас, а не тег: він точніше каже, кому. Однакова сила — перемагає нижче правило

Так — що це за річ

card — картка · note — примітка · important — важливе · два слова — дефіс: main-news

Не так

red — завтра стане зеленим · main news — пробіл ділить на два класи · Card і card — різні

id · #novyny

Ідентифікатор — один елемент на сторінці

index.html і style.css
<section id="novyny"> <h2>Новини</h2> </section> #novyny { background-color: #eaf2fb; }
класid
у HTMLclass="card"id="novyny"
у CSS.card#novyny
скільки на сторінціскільки завгодноодин — унікальний
на елементікілька через пробілодне імʼя
хто сильнішийсильніший за тегсильніший за клас
Оформлення — здебільшого класами. id — щоб знайти одне місце сторінки: до нього веде посилання
⚓
Якір · href="#novyny"

Посилання до розділу сторінки

href="#novyny"на цій сторінці — до елемента з id="novyny". Сторінка «стрибає»
href="index.html#novyny"з іншої сторінки: файл, потім # і id
href="#top"«Нагору» — до шапки з id="top"
index.html · меню на розділи
<header id="top"> … <a href="#kit">Мій кіт</a> <a href="#novyny">Новини</a> <section id="kit"> … <section id="novyny"> …
У href — з решіткою, в id — без. Як клас: крапка в CSS, а в HTML без неї
