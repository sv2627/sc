Домашнє завдання · 10 хвилин

Сайт codepen.io → новий Pen. Там два поля: HTML і CSS — рядок <link> не потрібен, CodePen підключає CSS сам.

1 · Скопіюй код

Верхній блок — у поле HTML, нижній — у поле CSS.

поле HTML
<h1>Кафе «Пончик»</h1>
<p>Найсмачніші пончики в місті.</p>
<p>Відкрито щодня з 8:00.</p>
поле CSS
body {
  background-color: lightblue;
}

/* ДОПИШИ ТУТ 1: h1 — колір тексту darkred */

/* ДОПИШИ ТУТ 2: p — колір тексту navy, тло lightyellow */

Що має вийти: тло всієї сторінки — блакитне.

2 · ДОПИШИ ТУТ 1 — заголовок

Що зробити: під коментарем «ДОПИШИ ТУТ 1» — правило для h1, властивість color, значення darkred. Як правило для body вище: селектор, фігурні дужки, двокрапка, крапка з комою.

Що має вийти: заголовок «Кафе «Пончик»» — темно-червоний.

3 · ДОПИШИ ТУТ 2 — абзаци

Що зробити: правило для p з двома властивостями: color — navy, background-color — lightyellow. Крапка з комою — після кожного значення.

Що має вийти: обидва абзаци — темно-сині літери на світло-жовтих смугах.

Що надіслати

Натисни Save у CodePen і надішли посилання на свій Pen з адресного рядка. Робив у VS Code — надішли код із поля CSS текстом.
