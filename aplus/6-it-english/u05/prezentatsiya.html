Key idea · Prototype
🧪

What is a prototype?

A small section of code that is used to test part of a program is known as a prototype.

Why?

Programmers use prototypes to make sure that sections of their code work before they build it into their program.

Спершу перевіряють маленький шматок — потім ставлять його у велику програму.

Not only in code

A prototype is an early example of a product — a device or a piece of software.

Ранній пробний зразок. Його показують іншим і отримують відгук — feedback.

Words in use

prototype · section of code A small section of code that is used to test part of a program. A prototype is an early example of a product.
to test · to work Test these to check that they work. It can then be tested in isolation.
user interface · prompt Build a user interface for the user name. A prompt invites a user to enter their name.
to set · score Set the player's score to 0 at the start of the game. The data in the score variable is changing.
event · to increase · to decrease Increase the score using one event. Decrease it by using another event.
negative score · starting score A negative score can result from one negative event. The starting score should be set higher, for example 10.
answer One point is added for a correct answer in a quiz. Set User name to answer.
problem · solution Discuss the problems. Seek solutions from the class.
