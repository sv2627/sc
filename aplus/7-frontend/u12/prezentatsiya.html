Банк завдань — бери будь-яке

Секція одразу. <option selected>Minecraft</option> — що видно спочатку?
Підказка в тексті. <textarea placeholder="Улюблені ігри"> — як у input
Не тягни. textarea { resize: none; } — спробуй потягнути кут поля
Скільки букв. <textarea maxlength="100"> — впиши довгий текст
Червоне, поки порожнє. input:invalid { border-color: #af3b41; } — коли рамка стає звичайною?
Скинути все. Обери інший рівень, натисни «Очистити». Котрий кружечок обраний тепер?
