Range check · Приклад · с. 173

Between the minimum and maximum

«A range check assesses whether data is within one or two bounds. For example, an age must be between 0 and 100. A date must be before today's date.»
Example 1 · using selection
Number ← INPUT("Enter a number between 1 and 10") IF Number < 1 OR Number > 10 THEN OUTPUT("Invalid") ELSE OUTPUT("Valid") ENDIF
Example 2 · using a loop
Number ← INPUT("Enter a number between 1 and 10") WHILE Number < 1 OR Number > 10 DO OUTPUT("Invalid please try again") Number ← INPUT() ENDWHILE

Example 2 «will continually ask for a value to be input until the number is valid».

Length check · Приклад · с. 173

The number of characters

«A length check will check the number of characters that are present. … the length of "hello world" is 11, the space is also a character.»
с. 173 · «8 will be output»
TheData ← "123 ABC!" OUTPUT(LENGTH(TheData))

«The following are all valid»

theData.length() · LENGTH(theData)
LEN(theData) · theData.len

«A length check can be programmed using selection or iteration.» Так само range check — IF або WHILE.
Тепер самостійно Length check · с. 173–1743 хвилини
Example 1 · using selection
Data ← INPUT() IF LENGTH(Data) < 10 THEN OUTPUT("Invalid") ELSE OUTPUT("Valid") ENDIF
Example 2 · using iteration
Data ← INPUT() WHILE LENGTH(Data) < 10 DO OUTPUT("Invalid, please try again") Data ← INPUT() ENDWHILE

Presence check · с. 175

Some data has been entered

«A presence check makes sure that some data has been entered. Programming languages can make use of the value null, or for a string value an empty string represented by "".»
Example 1 · «outputs Invalid if there is no data entered»
INPUT Data IF Data = NULL THEN //check if the data entered is null OUTPUT("Invalid") ENDIF
Example 2 · «while there is no data entered»
INPUT Data WHILE Data = "" DO //loop while there is nothing in data OUTPUT("Invalid please try again") INPUT Data ENDWHILE
📅
Format check · Приклад · с. 175–176

Entered in a specific way

«…a date must be: __/__/____, where each space is a number — a format check makes sure the data is entered this way.»
«SUBSTRING(String, x, y) starts at character x in the string, and returns y number of characters.»

Перший символ — позиція 0.

Example 2 · using a loop · с. 176
INPUT Date //loop while the data is not in the correct format WHILE (SUBSTRING(Date, 0, 2).IsNumeric = FALSE OR //2 numbers SUBSTRING(Date, 2, 1) <> "/" OR // 1st slash SUBSTRING(Date, 3, 2).IsNumeric = FALSE OR //2 numbers SUBSTRING(Date, 5, 1) <> "/" OR //2nd slash SUBSTRING(Date, 6, 4).IsNumeric = FALSE) DO // 4 numbers, year OUTPUT("Invalid") INPUT Date ENDWHILE OUTPUT("Valid")

Check digit · с. 176

Calculated from a set of numbers

check digit
a type of error detection method that is used for data entry. A calculation is performed on the data entered to create a value. Check digit values are compared to see if the data entered is correct.
«A check digit is calculated from a set of numbers, and is input with the numbers. When the data has been input, the calculation is performed on the data again and the result is compared with the final number (the check digit).»
1Example: 5 digit number input — «4 digits used to calculate 5th check digit»
2«check if the calculated check digit is the same as the last digit» → "Correct data entry" або "Incorrect data entry"
