7.9 Finding the purpose of an algorithm

Довідка · с. 184–186

Purpose — призначення

A trace table can help you work out the purpose. Repeat with a different set of data until you can identify the pattern.

Describe — описати

Do more than repeat the line of code. Not: ‘it is a for loop from y is 0 to x.’

Description — приклад

The algorithm takes a number from the user, and then outputs all of the numbers from 0 to the number input.
