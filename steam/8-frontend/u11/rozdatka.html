Структура сторінки. Блочні та рядкові елементи

Довідка

Блочний

З нового рядка, на всю ширину

Слухає width, height, усі відступи

header main section p h1 div

Рядковий

У рядку, як слово; ширина за текстом

Не слухає width, height, відступ зверху-знизу

a span strong em

display

block · inline · inline-block · none

div — група, span — слово

Обгортка: max-width + margin: 0 auto

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

3 · Спрацює чи ні?

Напиши Так або Ні.

p { width: 200px; }
span { width: 200px; }
a { margin-top: 30px; }
a { padding: 0 20px; }
