Chapter 8 · 8.2 Data types

Table 8.1: Common data types · Key words · с. 202–204

data type — the characteristics of a piece of data. Common data types are string, integer, real and Boolean.

string — any characters including letters, numbers and/or symbols: "hello" "123"

integer — whole numbers: 23 -300

real, single, double — decimal numbers: 1.2 -20.49

Boolean — true or false: TRUE FALSE

char — a single character: "h" "?"

String and char: always inside speech marks, either ' ' or " ".

casting — converting data from one data type to another data type.

Casting · с. 203–204

Pseudocode: Number ← int("123")
Value ← string(22.4)

Python: int("123") · str(22.4)

Java: Integer.parseInt("123")
