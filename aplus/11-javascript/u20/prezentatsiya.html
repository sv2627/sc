Головна пастка

value — завжди рядок. Навіть у type="number"

без Number — склеює
// у полях a і b ввели 5 і 3 a.value + b.value // '53' typeof a.value // 'string'
Number() — рахує
Number(a.value) + Number(b.value) // 8 const money = Number(uah.value); money / 48
type="number" лише не дає набрати літери і показує стрілочки. Що повертає value — однаково рядок

Запис'42''12.5''12.5грн''''abc'

Три біди

Знайди всі три, потім клацни

1. textContent поля — порожньо, і прочитано до вводу. Треба Number(uah.value) у функції

2. money + 50 з рядком — склеїть. Спершу Number

3. RATES.code — undefined, результат NaN. Треба RATES[code]
