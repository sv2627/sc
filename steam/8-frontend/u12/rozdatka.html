Практика: класи, id, якорі

Довідка

Клас

HTML: class="card"

CSS: .card { … } — з крапкою

Два класи — через пробіл: class="card hot"

На скількох завгодно елементах

id

HTML: id="top"

CSS: #top { … } — з решіткою

Один елемент на сторінку

Сила: #id > .клас > тег; рівні — нижчий

Меню на розділи

href="#music" ↔ id="music"

Літера в літеру, без пробілів

«Нагору ↑» — href="#top", шапці id="top"

scroll-behavior: smooth — плавно

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

1 · Клас чи id? Впиши

однакові картки товарів
шапка, на яку веде «Нагору ↑»
усі примітки дрібним шрифтом
розділ «Контакти», на який веде меню

2 · Скільки класів?

class="big card"
