Зроби свою гру

Ти вже вмієш HTML і CSS. Гру пишуть третьою мовою — JavaScript, і її ми вчитимемо у 8 класі. Але чекати рік нецікаво, тому JavaScript уже написаний за тебе. Твоя робота — зібрати сторінку і сказати грі, якою вона має бути.

Чесно кажучи

Це не «ти зробив гру з нуля» — це «ти скористався чужим кодом і зробив із нього своє». Саме так працює справжня розробка: ніхто не пише все сам. Але й списати тут нічого: сторінка, кольори, картинка і правила — твої, і двох однакових ігор у класі бути не повинно.

З чого почати

Почни звідси · сім завдань

📄 Шаблон

Порожня заготовка: каркас уже працює, але виглядає ніяк. У коментарях — сім завдань, які роблять із нього твою сторінку. Збережи собі й міняй по одному.
Якщо застряг

📘 Готові приклади

Нижче — дві повністю зроблені гри. Подивись, як там написано те, що в тебе не виходить, і зроби так само у своєму файлі.

Як підключити

1
Створи папку для гри й поклади в неї файл gra.js — забери його за цим посиланням (правою кнопкою → «Зберегти як…»).
2
Поруч зроби свій index.html — звичайний, з <head>, <body> і своїм CSS.
3
Постав у <body> порожній блок — саме туди приїде гра:
<div id="game"></div>
4
Наприкінці <body> підключи рушій і опиши гру:
<script src="gra.js"></script> <script> Game.snake({ field: 20, snakeColor: '#00e676' }); </script>
5
Відкрий сторінку через Live Server — і грай.
Головна пастка

<script src="gra.js"> має стояти раніше, ніж рядок із Game.snake(…). Інакше браузер спершу почує слово Game, якого ще не знає, і в консолі (F12) буде Game is not defined. Правило просте: спочатку підключи, потім користуйся.

Чому назви англійською

Game, snake, speed, score — не примха. Рівно так називаються речі в справжніх бібліотеках, і саме ці слова ти побачиш у JavaScript у 8 класі. Українською тут тільки коментарі — пояснення для тебе, які браузер не читає.

Дві готові гри

Приклад · відкрий і подивись код

🐍 Змійка

Класика. Керується стрілками, їсть яблука, росте. Міняєш розмір поля, швидкість, кольори й саму їжу — вона може бути будь-яким емодзі.

 Приклад · відкрий і подивись код

🧩 Пазл

П'ятнашки з твоєї картинки: фото, малюнок, скрін улюбленої гри. Плитки — звичайні блоки в CSS Grid, тому стилі до них ти пишеш сам.

В обох іграх є ще одне налаштування — mount: id блока, куди ставити гру. За замовчуванням 'game', і міняти його треба тільки якщо робиш дві гри на одній сторінці.

Стилі пазла — твої

Рушій дає плиткам класи .puzzle, .tile, .empty і .number. Твій CSS сильніший за стилі рушія, тому можеш міняти все: gap (шви між плитками), border-radius, колір фону, тінь, transition. Це та сама сітка, що на уроці 4 — display: grid уже стоїть.

/* шви товщі, плитки круглі, номери прибрано */ .puzzle { gap: 8px; background: crimson; } .puzzle .tile { border-radius: 50%; } .puzzle .number { display: none; }

Три рівні

⭐ базовий

Узяти шаблон, пройти всі сім завдань у коментарях: своя назва, свої кольори, рамка, табло, правила і хоча б три змінені налаштування гри. Гра запускається, у неї можна грати.

⭐⭐ середній

Своя сторінка навколо гри: шапка з назвою, правила, табло рахунку, кнопка. Пазл — зі своєї картинки. Сторінка виглядає як зроблена, а не як шаблон: свої шрифти, фон, відступи.

⭐⭐⭐ високий

Обидві гри на одній сторінці з перемиканням (тут і знадобиться mount), або третя власна гра з цеглинок нижче. Плюс адаптив: на телефоні грати так само зручно, як на ноутбуку.

Цеглинки для своєї гри ⭐⭐⭐

Коли щось не працює

Перше, що робиш завжди: F12 → вкладка Console. Біла сторінка без помилки — рідкість; майже завжди помилка там є.

Одне правило

Кома, дужка й лапка мають бути на місці. Пропущена кома між налаштуваннями ламає всю гру, а не одне налаштування. Копіюй шаблон і міняй значення, не чіпаючи розділові знаки, — і майже все працюватиме з першого разу.
