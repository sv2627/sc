Список Map'ів як база даних

Довідка

Запис і каталог

k[0]['nazva'] — номер, потім ключ

k[0]['cina'] = 99 — змінити

k.add({...}) · k.removeAt(0)

k.removeWhere((g) => ...)

Шукати й відбирати

any → true / false

indexWhere → номер або -1

firstWhere → запис

where(...).toList() → усі збіги

map((g) => g['nazva']) → назви

Рахувати й пастки

s += g['cina'] as int;

s / k.length → завжди double

shuffle() міняє сам список

немає поля → null, номера → падіння

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

Каталог для завдань 1–5:

List<Map<String, dynamic>> k = [
  {'nazva': 'Mario', 'zhanr': 'platformer', 'cina': 1200},
  {'nazva': 'Sonic', 'zhanr': 'platformer', 'cina': 300},
  {'nazva': 'Zelda', 'zhanr': 'adventure', 'cina': 1500},
];
