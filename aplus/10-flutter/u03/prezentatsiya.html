switch — коли варіантів багато

main.dart
String den = 'сб'; switch (den) { case 'сб': print('Вихідний'); break; case 'нд': print('Вихідний'); break; default: print('Робочий день'); }
Порівнює одне значення з переліком варіантів
default — «усі інші випадки». Як else
У Dart break обовʼязковий. Забудеш — програма не запуститься, а не «провалиться далі», як у C++
🤔
Передбач

Що виведе цей код?

main.dart
int n = 7; if (n > 3) { print('A'); } if (n > 5) { print('B'); } else { print('C'); }

Відповідь

Спочатку скажи сам, потім клацни.

A, потім B

Тут два окремі if, а не один ланцюжок. Перший спрацював і завершився. Другий почався заново

Якби другий був else if — вивелось би тільки A.

int x = 100; do { print('Виконалось із x = $x'); x++; } while (x < 5);

Керування циклом

break виходить · continue пропускає

break
for (int i = 1; i <= 100; i++) { if (i == 7) { print('Знайшов на кроці $i'); break; } }
ConsoleЗнайшов на кроці 7
continue
for (int i = 1; i <= 6; i++) { if (i % 2 == 0) continue; print(i); }
Console1 3 5
break — «досить, виходимо з циклу зовсім». continue — «цей крок пропускаємо, беремо наступний». А % — остача від ділення: i % 2 == 0 означає «парне».
📋

Вгадай число

Приклад · продовжуємо файл зі слайда 20
int sproby = 0; for (int i = 1; i <= 100; i++) { sproby++; if (i == secret) { print('Вгадав: $i за $sproby спроб'); break; } }
Тепер самостійно · тут працює все з довідника
  • Запусти пʼять разів і запиши кількість спроб у роздатку
  • Розшир діапазон до 1000 — як зміниться середня кількість?
  • Перепиши перебір через while
  • ⭐⭐ Додай вивід «Гаряче», коли до числа лишилось менше 10
  • ⭐⭐⭐ Хай програма грає десять партій підряд і виводить середню кількість спроб
⚡
⭐⭐⭐ Швидший спосіб

Поділ навпіл

main.dart
int low = 1, high = 100, sproby = 0; while (low <= high) { int mid = (low + high) ~/ 2; sproby++; if (mid == secret) { print('Вгадав за $sproby спроб'); break; } if (mid < secret) { low = mid + 1; } else { high = mid - 1; } }
~/ — цілочисельне ділення. Звичайне / у Dart завжди дає double
Щоразу відкидаємо половину діапазону
Перебір: у середньому ~50 спроб. Поділ навпіл: не більше 7
🗃️
Закінчив раніше?

Банк завдань

1. Вивести числа від 10 до 1 у зворотному порядку
2. Порахувати суму всіх чисел від 1 до 100 одним циклом
3. Вивести тільки ті числа з 1–50, що діляться на 3 — через continue
4. switch по місяцю: сказати, скільки в ньому днів
5. Меню на do-while: показати три пункти, повторювати, поки не обрано «вихід»
6. Знайти найбільше з набору [12, 7, 45, 3, 28] через for-in
7. ⭐⭐ Порахувати, скільки чисел від 1 до 200 діляться і на 3, і на 5
8. ⭐⭐⭐ Вивести перші 10 чисел Фібоначчі (кожне — сума двох попередніх)
Усі вісім робляться тільки тим, що є в довіднику на слайді 18. Нічого нового шукати не треба.
