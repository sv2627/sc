Клас чи id?

class="card"на скількох завгодно елементах
class="card hot"два класи — через пробіл
id="top"одне ім'я на всю сторінку
href="#top"посилання на елемент з id="top"

Що пишемо в CSS перед назвою класу?

Клацни після відповіді

Крапку: .card { … }

А перед id?

Клацни після відповіді

Решітку: #top { … }

Три однакові картки. Клас чи id?

Клацни після відповіді

Клас. id — лише для одного елемента

Згадуємо · урок 8

Що тут не так із класом?

<p class="big card">

Скільки тут класів?

Два: big і card. Усе гаразд

<p class=".card">

Подумай, потім клацни

Крапка — лише в CSS. У HTML: class="card"

<p class="Card">

а в CSS: .card

Подумай, потім клацни

Велика й мала літера — різні. Правило не діє

<p class="my card">

хотіли один клас «my card»

Подумай, потім клацни

Пробіл ділить на два класи. Один клас: my-card

Крок 1 Один клас — багато елементів4 хвилини
Приклад
<article class="card"><h3>Марс</h3><p>Червона планета</p></article> .card { background-color: #e8f5e9; padding: 15px; margin-bottom: 15px; }
Тепер самостійно
  • Кожній картці (article) — class="card"
  • Одне правило .card: фон, відступ, рамка
  • Ще одна картка: Alt+Shift+↓, міняєш лише текст. Оформлення вже є?
  • Зміни фон у .card — змінились усі картки одразу?
  • ⭐⭐ Клас note для приміток: дрібніше, іншим кольором. Дай його двом абзацам
  • ⭐⭐⭐ F12 → Elements: клацни картку й знайди в Styles правило .card
Крок 2 Два класи: спільне й різне5 хвилин
Приклад
<article class="card hot"><h3>Сатурн</h3><p>Має кільця</p></article> .hot { border: 3px solid red; font-weight: bold; }
Тепер самостійно
  • Найкращій картці — другий клас hot: своя рамка, жирний текст
  • Іншій картці — клас new: свій фон
  • Одна картка з трьома класами: card hot new. Що вийшло?
  • Клас hot на абзаці поза карткою — що з оформлення взялось?
  • ⭐⭐ Ще один клас на свій смак і дай його двом різним тегам
  • ⭐⭐⭐ .hot і .new задають різний колір тексту. Хто переможе? Поміняй правила місцями у файлі
Крок 3 id на розділах, меню веде на них5 хвилин
Приклад
<a href="#planets">Планети</a> <section id="planets"> … </section> html { scroll-behavior: smooth; }
Тепер самостійно
  • Кожному розділу section — свій id, латиницею, без пробілів
  • Кожен пункт меню веде на свій розділ: href="#…"
  • Клацни кожен пункт — сторінка стрибає куди треба?
  • Плавна прокрутка — одним рядком для html
  • ⭐⭐ Новий розділ «Контакти» з id="contacts" і пункт меню на нього
  • ⭐⭐⭐ Посилання з тексту абзацу: «Детальніше — у розділі Факти»
⚡
Сторінка коротка — стрибка не видно. Звуж вікно Chrome або додай текст
Крок 4 «Нагору ↑» і стиль для одного4 хвилини
Приклад
<header id="top"> … </header> <footer><a href="#top">Нагору ↑</a></footer> #top { background-color: #1b5e20; color: white; }
Тепер самостійно
  • Шапці — id="top", у підвалі — посилання «Нагору ↑»
  • Правило #top: свій фон і світлий текст
  • Першому абзацу сторінки — id="intro": більший шрифт, курсив
  • Прокрути донизу й клацни «Нагору ↑» — працює?
  • ⭐⭐ «Нагору ↑» ще й у кінці кожного розділу
  • ⭐⭐⭐ Абзацу дай клас і id. У CSS: p, клас і id — три різні кольори. Передбач, потім F12 → Styles: що закреслене?
Крок 5 Меню як на картинці4 хвилини
Приклад · HTML уже є
<nav> <a href="#planets" class="active">Планети</a> <a href="#facts">Факти</a> <a href="#top">Нагору ↑</a> </nav>
має вийти так
ПланетиФактиНагору ↑
Тепер самостійно · CSS пишеш сам
  • Усі пункти меню: зелений текст, без підкреслення
  • Відступ усередині: 6px 14px
  • Пункт із класом active: зелений фон, білий текст, кути 20px
  • ⭐⭐ Перенеси class="active" на «Факти» — підсвітка переїхала?

Зробив? Клацни — звір

nav a { color: #1b5e20; text-decoration: none; padding: 6px 14px; } .active { background-color: #1b5e20; color: white; border-radius: 20px; }
