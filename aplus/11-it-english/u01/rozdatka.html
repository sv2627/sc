Life cycle · decomposition · flowcharts

Усе на цьому аркуші — з Coursebook, с. 145–154.

Key wordsс. 145–149

program development
life cycle		 a series of structure step / activities that are followed to produce a system
analysis the first stage … that involves investigating the problem
decomposition taking a system and splitting it into smaller sub-systems
design the second stage … algorithms created ready for implementation
structure diagram a hierarchical diagram that shows the decomposition of a system
flowchart a diagrammatic representation of an algorithm
Етапи циклу: analysis → design → coding → testing.

1 · Draw a structure diagramQuestions 2–4, с. 149

  1. A program asks the user to enter two numbers. The program then adds the numbers together and outputs the total.
  2. A satellite navigation system needs to ask the user to input their destination. It then finds the route to the destination and outputs the instructions to the user.
  3. A login system asks the user to enter their username and password. It checks these are valid and either outputs that they are correct, or incorrect and prompts to re-enter.
