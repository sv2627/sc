What is a data type in programming?

Відповідь вголос, потім клацни.

Data that is put into categories, so the program knows what is expected.

What data types do you already know?

Відповідь вголос, потім клацни.

Integer, Real and String.

What is the difference between an Integer and a Real number?

Відповідь вголос, потім клацни.

An Integer is a whole number, a Real number is a decimal number.

What is a string?

Відповідь вголос, потім клацни.

One or more characters that can include letters, symbols and numbers that are not used in mathematics calculations, such as telephone numbers or credit card numbers.

Boolean: only one of two values

A Boolean data type is true or false, because it can only be one of two values.

‘10 is less than 11’

10 < 11 → True

The result is true. The result is a Boolean.

What else in programming only has two values?

4 · An ID number with leading 0s will need to be stored as a string.°  переклад? Номер (ID) з нулями попереду треба зберігати як рядок.

Boolean data as a flag

A flag is used to indicate if something has occurred, or is valid or correct.°

If the flag is true

then it is positive, meaning that it has occurred, it is valid or it is correct.

Переклад вголос, потім клацни.

тоді він позитивний: це сталося, це допустимо або це правильно.

If the flag is false

it is negative, meaning that it has not occurred, it is not valid or it is incorrect.

Переклад вголос, потім клацни.

він негативний: це не сталося, це недопустимо або це неправильно.
