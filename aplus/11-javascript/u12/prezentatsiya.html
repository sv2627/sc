Вікторина на три питання

const questions = ['Столиця України?', 'Скільки буде 7 * 8?', 'Мова цього курсу?']; const answers = ['київ', '56', 'javascript']; function clean(text) { return text.trim().toLowerCase(); } function isRight(input, correct) { return clean(input) === correct; } let score = 0; for (let i = 0; i < questions.length; i++) { const input = prompt(questions[i]); if (isRight(input, answers[i])) score++; } alert(`Правильно: ${score} з ${questions.length}`);

Тепер самостійно
  • Набери вікторину з прикладу й пройди її двічі: усе правильно і все неправильно
  • Заміни питання своїми — пʼять на одну тему. Відповіді — малими літерами
  • Після кожної відповіді — alert: «Правильно!» або «Ні. Відповідь: …» з answers[i]
  • ⭐⭐ Натисни «Скасувати» — прочитай помилку в консолі. Полагодь: if (input === null) break; перед перевіркою
  • ⭐⭐ grade(score, total) з кількома return: усе правильно — «Відмінно», не менше половини — «Непогано», інакше «Спробуй ще». Додай у фінальний alert

Виправ

Усе правильно — а пише 0 з 3. Що не так?

script.js · зламано навмисно
// questions і answers — як у прикладі function isRight(input, correct) { input.trim().toLowerCase() === correct; } const score = 0; for (let i = 0; i <= questions.length; i++) { const input = prompt(questions[i]); if (isRight(input, answers[i])) score++; } alert(`Правильно: ${score} з ${questions.length}`);
Що бачить гравецьтри питання → четверте вікно без питання → «Правильно: 0 з 3»

Три біди — і поки жодної червоної

Знайди всі три, потім клацни

1. i <= questions.length — зайве коло, questions[3] — undefined. Треба <

2. У isRight немає return — завжди undefined, тому 0

3. const score — щойно полагодиш 2, зʼявиться TypeError: Assignment to constant variable. Треба let

Закінчив раніше?

Банк завдань — бери будь-яке

Помилки списком. Масив mistakes: неправильне питання — push. У кінці — join(', ')
Друга спроба. Неправильно — спитати те саме ще один раз
Підказка. Ввели ? — показати першу літеру: answers[i][0], і спитати знову
Бали за складність. Масив points = [1, 2, 3, …] і score += points[i]
Відсоток. «Правильно 60%» — score / total * 100 і toFixed(0)
Бліц. Одне випадкове питання — рецепт Math.floor(Math.random() * N)
Слово «бал». plural(score) з практики 1 у фінальному alert
Хто грає. Спершу prompt('Імʼя?'), у кінці — «Оля, правильно: 4 з 5»
