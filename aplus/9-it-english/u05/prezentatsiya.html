Warm-up

A program for a whole school

A program needs to store the first and last names of all of the learners in a school.

How many variables will you need to store this data?

Порахуй для школи на 300 учнів, потім клацни.

It depends on the school. A school with 300 learners will need 2 variables for each learner — one for first name, one for last name.

300 × 2 = 600 variables in total

Think · pairs

600 variables

What problems does this many variables cause?

Назви хоча б дві проблеми, потім клацни.

1 Defining each variable individually will take time.
2 Remembering the identifiers will be difficult.
3 Each variable will need to be hard-coded.

Definition

What is an array?

An array stores multiple items of data under one identifier.

Lots of data can be stored without needing a variable for each item.

Зразок

Спершу своє, потім клацни.

An array stores multiple items of data under one identifier. It allows lots of data to be stored without needing a variable for each item. Each item has an index: Colours[1] is Blue.
