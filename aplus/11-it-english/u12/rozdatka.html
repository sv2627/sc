Chapter 8 · 8.1 Programming concepts: variables and constants

Key words · с. 198–199

variable — a named memory location that can store data. The data can change whilst a program is running.

constant — a named memory location that can store data. The data cannot change whilst a program is running.

identifier — a name given to a variable, constant, data structure (e.g. array) or subroutine.

assignment — a type of programming statement that stores data in a variable or constant.

The left hand side of the equals sign is the identifier. The right hand side is the value.

Assignment · constant · с. 199–201

Pseudocode: Number ← 10
CONSTANT Colour ← "yellow"

VB.NET: number = 10
Const colour As String = "yellow"

Python: number = 10 · no constants

Java: Integer number = 10;
final String colour = "yellow";
