Головна думка

Свій віджет — це клас: описуємо картку один раз, дані передаємо через конструктор. Сутність (Game) — дані, віджет (GameCard) — як їх показати. Пастки: виклик без обовʼязкового параметра · без імен параметрів · const над полем · нема return у build.
