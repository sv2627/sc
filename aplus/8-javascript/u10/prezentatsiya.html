return

Показати — чи віддати результат

console.log — лише показує
function squareLog(n) { console.log(n * n); } const a = squareLog(5); // 25 на екрані console.log(a + 1); // NaN
return — віддає значення
function square(n) { return n * n; } const b = square(5); console.log(b + 1); // 26 console.log(square(3)); // 9
return віддає результат туди, де функцію викликали: square(5) стає 25
З результатом можна далі рахувати, класти в змінну, порівнювати. У Python — той самий return
🛑
true / false · кілька return

return одразу виходить із функції

script.js
function isEven(n) { return n % 2 === 0; } console.log(isEven(4)); // true console.log(isEven(7)); // false function check(age) { if (age < 12) { return 'рано'; } return 'можна'; } console.log(check(9)); // рано console.log(check(14)); // можна
Після return рядки функції не виконуються — тому 'можна' для 9 не дійде
Повертати можна true / false — зручно в if (isEven(n))
Немає return — функція повертає undefined

Виправ

Має бути «Разом: 1347 грн». Що не так?

script.js · зламано навмисно
function total(prices) { for (let i = 0; i <= prices.length; i++) { let sum = 0; sum += prices[i]; } console.log(sum); } const cart = [699, 199, 449]; console.log(`Разом: ${total(cart)} грн`);
КонсольUncaught ReferenceError: sum is not defined

Три біди

Знайди всі три, потім клацни

1. let sum = 0; у циклі — щоразу знову нуль, а за } циклу змінної вже немає. Перенести до циклу

2. i <= prices.length — читає prices[3], тобто undefined, сума стане NaN. Потрібно <

3. console.log(sum) замість return sum; — без нього в рядку буде «Разом: undefined грн»

Полагоджене дає Разом: 1347 грн
