Count-controlled loops

Iteration is code that repeats multiple times. A count-controlled loop runs a set number of times. It has a variable, its start value and its end value. In a flowchart, the variable is declared before the loop and the start value is given before the loop. Selection is used to check the variable value. The value is incremented within the loop. In Python, 101 is used to output the numbers 1 to 100, because this is where the loop stops.

Читаємо по реченню по черзі. Переклад — клацни.

Ітерація — це код, який повторюється багато разів. Цикл із лічильником виконується задану кількість разів. Він має змінну, її початкове значення і її кінцеве значення. У блок-схемі змінну оголошують до циклу, і початкове значення задають до циклу. Розгалуження перевіряє значення змінної. Значення збільшують усередині циклу. У Python, щоб вивести числа від 1 до 100, пишуть 101, бо на ньому цикл зупиняється.
