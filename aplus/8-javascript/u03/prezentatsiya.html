prompt дає рядок — і що з того?

консоль
// у полі ввели 7 const s = prompt('Число:'); console.log(s === 7); console.log(s > 3); console.log(Number(s) === 7); console.log(10 >= 10); console.log(2 < 5 < 1);

П'ять рядків — п'ять відповідей

Назви всі п'ять, потім клацни.

1. false — рядок '7' і число 7

2. true — > сам перетворив рядок

3. true — тепер обидва числа

4. true — «або дорівнює»

5. false! Рахується зліва направо: 2 < 5 → true, далі true < 1 → 1 < 1 → false

Number() — одразу в рядку з prompt. А подвійні нерівності пишуться інакше — слайд 14.

Виправ

Тут дві гілки мертві

script.js
if (age < 60) { price = 150; } else if (age < 18) { price = 80; } else if (age < 6) { price = 0; } else { price = 100; }

Які гілки не спрацюють ніколи і чому?

Знайди сам, потім клацни.

Мертві — друга й третя.

Будь-який вік, менший за 18, менший і за 60. Перша гілка забирає його собі — до другої черга не доходить ніколи. Так само з третьою.

Насправді працюють лише дві ціни: до 60 → 150 ₴, решта → 100 ₴.

Лікується перестановкою: найвужча умова — першою. Червоного рядка в консолі не було.

Передбач

Хто пройде на атракціон?

script.js
if (height >= 140 && age >= 12) { alert('Можна'); } else { alert('Не можна'); } // А · зріст 150, вік 10 // Б · зріст 130, вік 15 // В · зріст 160, вік 12 // Г · зріст 140, вік 12

Хто з чотирьох пройде?

Розбери всіх чотирьох, потім клацни.

А — ні. Зріст так, вік ні

Б — ні. Вік так, зріст ні

В — так. Обидві умови

Г — так. Рівно на межі, а >= — «або дорівнює»

А якби стояло ||? Тоді пройшли б усі четверо: кожен має хоча б одне «так».

Тернарний оператор ? :

if … else — п'ять рядків
let kind; if (age >= 18) { kind = 'дорослий'; } else { kind = 'дитячий'; }
? : — один рядок, те саме

Читається: умова? — тоді це, інакше — те
Дає значення, яке кладемо у змінну або в ${ }
Тільки для двох варіантів. Три й більше — else if

Нове в коді

switch — одна змінна, багато точних значень

script.js
const day = prompt('День: пн, вт … нд'); switch (day) { case 'сб': case 'нд': alert('Вихідний'); break; case 'пт': alert('Майже вихідний'); break; default: alert('Робочий день'); }
case — одне значення. Порівнює строго, як ===: число з prompt — через Number()
break — «вийти». Забули — код провалюється в наступний case
default — те саме, що else: «усе інше»
Два case поспіль без break між ними — це «або»
🚫
switch не вміє діапазонів. «Квиток у кіно» (до 6, 6–17…) — тільки else if.

Обіцяне на уроці 2

Перевіряємо ввід

script.js
const raw = prompt('Вік:'); const age = Number(raw); if (raw === null) { alert('Ви скасували'); } else if (raw === '') { alert('Поле порожнє'); } else if (Number.isNaN(age)) { alert('Це не число'); } else { alert(`Вік: ${age}`); }
raw — те, що ввели, ще рядком. age — уже число. Перевіряємо обидва
Порядок: Скасувати → порожньо → не число → усе гаразд. Той самий принцип «від вужчого»
age === NaN — не працює: NaN не дорівнює навіть сам собі. Тільки Number.isNaN()

Виправ

Чотири рядки — чотири різні біди

script.js
let age = prompt('Вік:'); if (age === 18) { … } if (age = 18) { … } if (18 <= age <= 22) { … } if (age >= 18); { … }

Що не так у кожному?

Розбери всі чотири, потім клацни.

1. Немає Number() — '18' === 18, завжди false

2. Одне = — це присвоєння. Умова завжди істинна, а age ще й зіпсовано

3. Подвійна нерівність — треба age >= 18 && age <= 22

4. ; після дужки — тіло if порожнє, блок виконається завжди

Спільне в усіх чотирьох: жодного червоного рядка в консолі.

Закінчив раніше?

Банк завдань — бери будь-яке

Оцінка за балами. 0–59 «незадовільно», 60–74 «задовільно», 75–89 «добре», 90–100 «відмінно»
Найбільше з трьох. Спитати три числа й назвати найбільше. Тільки умови й &&
Пароль. Прийняти, тільки якщо довжина .length не менша за 8
Пора року. Номер місяця 1–12 → пора року. Число поза межами — повідомлення
День тижня. switch: число 1–7 → назва дня. Не забути Number()
Світлофор. switch: «червоний», «жовтий», «зелений» → що робити пішоходу
Знак і парність. Додатне, від'ємне чи нуль — через else if; парне чи ні — одним ? :
Високосний рік. Ділиться на 4, але не на 100, або ділиться на 400. Одна умова з && і ||
Усі вісім робляться тільки тим, що було сьогодні й раніше
