Головне поняття

Змінна — це підписана коробка

main.dart
void main() { String name = 'Марія'; int age = 16; print(name); print(age); }
Спочатку тип, потім імʼя, потім значення
Крапка з комою в кінці — обовʼязково, як і на минулому уроці
Імена — латиницею, з малої літери, без пробілів: name, myAge
✍️
Культура коду

Як називати змінні

так не вартоint a = 16; String s = 'Рівне'; double x1 = 1.72; bool f = true;
такint age = 16; String city = 'Рівне'; double height = 1.72; bool likesTea = true;
Імʼя має відповідати на питання «що тут лежить?» — без заглядання вище
Два слова — друге з великої: myAge, likesTea. Це стиль Dart, і його дотримуються всі
📅
Перевірка проста: чи зрозумієш ти цей код через місяць? Через місяць у нас буде проєкт на три екрани, і це вже не жарт.

Головна відмінність від JavaScript

Тип не міняється

JavaScript — можнаlet x = 16; x = 'шістнадцять'; // працює
Dart — не можнаint x = 16; x = 'шістнадцять'; // помилка ще до запуску
У Dart тип обирається один раз і лишається назавжди
Помилку видно до запуску — редактор підкреслює червоним одразу
🛡️
Це не незручність, а страховка: більшість помилок ловиться в редакторі, а не в застосунку на телефоні користувача.

⭐ У DartPad оголосити чотири змінні про себе — по одній кожного типу — і вивести кожну окремим print
⭐⭐ Спробувати записати в int текст. Прочитати, що саме написав редактор

Помилки Dart читаються англійською й доволі зрозуміло. A value of type 'String' can't be assigned to a variable of type 'int' — тут сказано все.
🔀
Три способи оголосити

var · final · const

var

Тип вгадується зі значення. Змінювати можна

var age = 16; — це той самий int

final

Значення задається один раз і більше не міняється

final name = 'Марія';

const

Те саме, але значення відоме ще до запуску програми

const pi = 3.14;

Правило на весь курс: починай із final. Міняй на var, тільки коли значення справді має мінятися.
🤔
Передбач

Який рядок не запуститься?

main.dart
var score = 10; score = 20; final city = 'Рівне'; city = 'Київ'; var mark = 5; mark = 'пʼять';

Два рядки з трьох груп

Знайди обидва, потім клацни.

1. city = 'Київ'; — final міняти не можна

2. mark = 'пʼять'; — var mark = 5 зробило його int назавжди

Головне з другого: var не означає «будь-який тип». Він означає «тип вгадай сам» — і вгадується він один раз.

🧵
Нове в коді

Вставити значення прямо в текст

незручноprint('Мене звати ' + name + ', мені ' + age.toString());
по-дартівськиprint('Мене звати $name, мені $age');
Знак $ перед імʼям змінної — і Dart сам підставить значення
Ніяких плюсів і ніякого toString()
🔤
Це називається string interpolation — інтерполяція рядка. Слово знадобиться, коли шукатимеш відповідь англійською.
🧮
Нове в коді

А якщо треба порахувати?

main.dart
final age = 16; final height = 1.72; print('Через 10 років мені буде ${age + 10}'); print('Мій зріст — ${height * 100} см');
$name — просто змінна
${...} — вираз: усередині фігурних дужок можна рахувати
Правило просте: сама змінна — $, будь-що складніше — ${ }.

Знайди помилки

Тут їх три

main.dart
void main() { string name = 'Марія'; final age = 16 age = 17; print('Мені $age'); }

Назви всі три

Знайди, потім клацни.

1. string з малої літери — треба String

2. Немає крапки з комою після = 16

3. final не можна змінювати — рядок age = 17; зайвий

Прикмета: помилка про крапку з комою вкаже на наступний рядок. Дивитись треба вище.
