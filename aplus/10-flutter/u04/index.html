Головна думка

Функції ви вже писали в Python і JS. Нове в Dart — тип перед іменем і типи параметрів, а ще іменовані параметри { }, на яких тримається весь Flutter. Пʼять пасток уроку: print — не return · функція з типом мусить повернути значення на кожному шляху · void-функцію не можна вивести через print · іменований параметр кличемо з іменем · змінна, створена у функції, назовні не видна.

Чого тут немає

List і Map — це урок 5, тому в прикладах тільки числа й рядки. Знак ? у int? (null-safety) — пізніше: сьогодні іменований параметр завжди або required, або зі значенням за замовчуванням. Класи й методи — II період.
