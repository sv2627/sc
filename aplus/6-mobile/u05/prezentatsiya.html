Невидимий компонент не займає місця на екрані телефона. Його не видно — але він працює: грає звук, вібрує, говорить.

Де взяти: Palette → Media → Sound, перетягнути на екран
Він «падає» під телефон, у рядок Non-visible components
У дереві Components він є, як і кнопка — і в Blocks у нього теж є своя шухляда

Завантаження звуку

Три кроки до першого звуку

1 Palette → Media → Sound — перетягнути на екран
2 Клацнути Sound1 → Properties → Source → Upload File… → вибрати .mp3 → OK
3 Blocks → шухляда Sound1 → фіолетовий блок в підкову кнопки
when Button1.Click do
call Sound1.Play
Фіолетовий блок call — команда компоненту: «зроби!». Жовтий — коли, зелений — встанови, фіолетовий — зроби
🗣️
Файлу ще немає? Media → TextToSpeech, у підкову call TextToSpeech1.Speak message + текст — телефон заговорить без жодного файлу.

Вібрація

Телефон тремтить за командою

when Button1.Click do
call Sound1.Vibrate millisecs 500

Вібрацію дає той самий Sound1 — окремого компонента не треба. Число — з Built-in → Math.

millisecsСкільки вібрує
100коротке «дзь»
500пів секунди
1000одна секунда
3000три секунди — як дзвінок
⏱️
1000 мілісекунд = 1 секунда. Вібрацію відчуває тільки справжній телефон: в емуляторі й на комп'ютері її немає.
🎵
Другий компонент звуку

Player — для довгої музики

when Button2.Click do
call Player1.Start
when Button3.Click do
call Player1.Stop
Palette → Media → Player — теж невидимий, файл теж у Source
У Player не Play, а Start. Кнопка «▶» — Start, кнопка «■» — Stop
Галочка Loop у Properties — музика грає по колу, доки не натиснуть Stop
⚖️
Sound — короткий звук на кнопку: «мяу», клік, дзвоник. Player — довга пісня або фон, яку треба вмикати й вимикати.
📚

Спершу сам, потім перевір

Запиши три відповіді в зошит. Клацніть, щоб перевірити.

а) Той самий «мяу». Звук залежить від Source компонента, а не від кнопки

б) Приблизно двічі: поки не минуло пів секунди після звуку, нові натискання пропускаються

в) Пісня починається спочатку — і так по колу, доки не буде call Player1.Stop

Якщо щось пішло не так

П'ять бід сьогоднішнього уроку

Тиша, а блоки правильні — на телефоні вимкнений звук або гучність медіа на нулі
Тиша, телефон гучний — Source порожній, або фіолетовий блок не в підкові
Не вібрує — це емулятор або планшет без вібромотора
Швидко тисну — грає не щоразу — так працює MinimumInterval. Зменшити його
Музика не вимикається — у кнопці «■» стоїть Sound1.Stop, а грає Player1
⚠️
Дві кнопки грають одне й те саме? Обидві викликають Sound1. Друга має бути Sound2.
