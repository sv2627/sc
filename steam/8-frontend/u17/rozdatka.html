Практика Flexbox: шапка й картки

Довідка

Картки в рядок

.cards { display: flex;

  gap: 20px; flex-wrap: wrap; }

.card { width: 220px; }

Низ картки

.card-foot { display: flex;

  justify-content: space-between;

  align-items: center; }

Пам'ятай

display: flex — батькові, width — дитині

wrap — не влазять, ідуть на новий рядок

stretch — однакова висота в рядку

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

1 · Що зробить рядок

flex-wrap: wrap;
justify-content: space-around;
align-items: flex-start;
flex-direction: column;
gap: 30px;
