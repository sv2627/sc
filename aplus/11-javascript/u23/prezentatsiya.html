Крок 1 · showQuestion(i)

Текст питання — і по кнопці на кожен варіант

script.js
function showQuestion(i) { const q = questions[i]; questionEl.textContent = q.question; optionsEl.innerHTML = ''; // старі кнопки геть for (const opt of q.options) { const btn = document.createElement('button'); btn.textContent = opt; optionsEl.append(btn); } } showQuestion(0);
i — номер питання. Одна функція покаже будь-яке з пʼяти
Цикл і createElement — як картки на уроці 18
Варіант '<a>' — через textContent: лишиться текстом, а не стане посиланням
Практика 1 Питання на сторінці7 хвилин
Приклад
const q = questions[0]; questionEl.textContent = q.question;
Тепер самостійно
  • Набери приклад — на сторінці перше питання?
  • Допиши цикл: по кнопці на кожен варіант — три кнопки
  • Загорни все у function showQuestion(i) і виклич showQuestion(0)
  • Виклич showQuestion(2) — кнопка <a> видна текстом? Поверни 0
  • Прибери рядок optionsEl.innerHTML = '' і виклич функцію двічі — скільки кнопок? Поверни
  • ⭐⭐ Над питанням — «Питання 1 з 5»: `${i + 1} з ${questions.length}`

Крок 2 · обробник у циклі

Кожна кнопка знає, яку відповідь вона несе

script.js · усередині циклу, перед append
// над функцією: let score = 0; btn.addEventListener('click', () => { if (opt === q.answer) { score++; msg.textContent = 'Правильно!'; } else { msg.textContent = `Ні. Правильно: ${q.answer}`; } scoreEl.textContent = `Бали: ${score}`; });
Обробник — усередині циклу: у ньому opt саме цієї кнопки (як картка на уроці 19)
