CSS — Cascading Style Sheets — таблиця стилів: мова, якою описують вигляд сторінки

🔗
Два файли

Один рядок у <head>

moy-sayt/
  ├── pro-mene.html  ← що на сторінці
  └── style.css      ← як виглядає
Шлях — як у картинки: від сторінки. Файли лежать поруч — тому просто style.css
pro-mene.html · усередині <head>
<meta charset="UTF-8"> <title>Про мене</title> <link rel="stylesheet" href="style.css">
🔤
link — звʼязок · stylesheet — таблиця стилів. Тег без пари, як img

CSS можна написати й усередині сторінки — у тезі <style>. Але тоді на кожній сторінці — своя копія. Окремий файл — один на всі

🔬
Правило CSS

Кому · що · яким

style.css
h1 { color: darkred; }
h1селектор — кому: усім <h1> сторінки
colorвластивість — що міняємо
darkredзначення — яким
:двокрапка — між властивістю й значенням
;крапка з комою — після кожного значення
{ }усе для h1 — у фігурних дужках

Чому правило не працює?

h1 { color = red; }

Подумай, потім клацни

між властивістю й значенням — двокрапка: color: red;

p { colour: blue; }

Подумай, потім клацни

CSS знає тільки color — без u

body { color: navy;

Подумай, потім клацни

немає } — наступні правила теж ламаються

h2 { color: red
background-color: gold; }

Подумай, потім клацни

немає ; після red — не працюють обидві

p { color: dark red; }

Подумай, потім клацни

Банк завдань

1. Правило для a: посилання — кольором акценту. Читається?
2. Тло для h1 — і світлий колір літер
3. Над кожним правилом — коментар, наприклад /* уся сторінка */
4. Курсор на правило h2 → Ctrl+/ → F5. І ще раз
5. ⭐⭐ Інший стиль із чотирьох — лише заміною трьох кольорів у style.css
6. ⭐⭐ Два правила для h1: спершу red, нижче green. Хто переміг?
7. ⭐⭐⭐ Тло для strong — як маркер. Яке слово стало виділеним?
8. ⭐⭐⭐ Підказка VS Code: набери color: — і обери колір зі списку
Усі вісім робляться тільки тим, що було на уроках 1–10.
