Практика. Коробкова модель

Довідка

Коробка

Ззовні всередину: margin → border → padding → вміст

Ширина = width + 2×padding + 2×border

box-sizing: border-box — ширина = width

Скорочення

padding: 10px 20px — верх-низ · боки

border: 3px solid red — товщина · вид · колір

border-top, margin-bottom — один бік

Розміри й вигляд

max-width + margin: 0 auto — центр

border-radius: 50% — коло

box-shadow: 0 4px 10px gray — тінь

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
