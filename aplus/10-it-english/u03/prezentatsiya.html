KEY WORDS · с. 21–24

Слова цього підрозділу

character set — it contains all the characters that are in that character set and the binary value that is assigned to each character · с. 21
pixel — a very small dot of colour that is displayed with many others to create an image · с. 21
resolution — the dimensions of an image · с. 22
metadata — additional data that is stored with an image that can provide information such as the dimensions of the image and the time and date the image was taken · с. 22
colour depth — the number of bits that are used to create each colour in an image · с. 23
sound sampling — a little piece of sound that is recorded at regular time intervals · с. 23
sample rate — the number of samples recorded each second · с. 24
sample resolution — the number of bits that are used to record each sound sample · с. 24

Converting text to binary · с. 21

The tool is called a character set

Комп'ютер не «здогадується», яка буква перед ним. Він користується таблицею відповідностей: кожному символу заздалегідь призначено двійкове число.

Two main types

ASCII та Unicode. Так дослівно в книзі: «There are two main types of character set that a computer can use, ASCII and Unicode»

Що в таблиці

Усі символи набору — і двійкове значення кожного. Нічого більше

🅰️
ASCII · с. 21

8 bits — 256 characters

ASCII кодує символи 8-бітними двійковими числами
Отже, різних символів може бути 256 — книга уточнює діапазон: 0 to 255
«This is fine for certain languages, but some languages have an alphabet that requires more than 256 characters»
0100 0001

8 bits = 1 character in ASCII

Чому саме 256: 28 = 256. Це те саме, що ви рахували в підрозділі 1.1
🌍
Unicode · с. 21

16 bits — approximately 65 000

Саме тому Unicode was invented: 256 символів не вистачає світові.

Character setBits per characterHow many characters
ASCII8256 · 0 to 255

Книга, с. 21: «This means that many more characters can be developed in different alphabets and also symbols such as emojis can also be used.»
🇺🇦
Українська абетка, китайські ієрогліфи й емодзі існують у тексті саме завдяки Unicode. В ASCII для них просто немає місця.

Дві величини керують розміром файлу

Resolution ↑

«If the resolution is increased, the image will be created using more pixels, so more data will need to be stored»

Colour depth ↑

«each pixel will need more data to display a greater range of colours so more data will need to be stored»

«Both will result in a larger file size for the image.» — с. 23

Converting sound to binary · с. 23

sound sampling

Книга, с. 23: «Sound is made up of sound waves. When sound is recorded, this is done at set time intervals. This process is known as sound sampling.»

sound sampling — a little piece of sound that is recorded at regular time intervals
📏
Звук неперервний — записати його весь неможливо. Тому комп'ютер вимірює значення через рівні проміжки (time intervals) і запам'ятовує лише ці виміри.

What has been lost — and why?

Спробуй сформулювати, потім клацни.

Дослівно, с. 24: «This is because the number of samples taken is too far apart, so vital data in between time samples has been lost.»

Між сусідніми вимірами хвиля рухалась — але цього ніхто не записав. Комп'ютер просто з'єднує виміри прямими лініями.

Висновок книги: «more samples need to be taken each second to improve the accuracy of the recorded sound».

⏱️
с. 24

sample rate — скільки вимірів за секунду

sample rate — the number of samples recorded each second
Вимірюється в герцах. «1 hertz is equal to 1 sample per second»
44.1 kHz (kilohertz) — «this would require 44 100 samples to be taken each second». Це поширена частота

Ціна точності

Книга, с. 24: «That is a lot of data!»

«If the sample rate is increased, the amount of data required for the recording is increased. This increases the size of the file that stores the sound.»

Той самий обмін, що з картинками: більше якості — більший файл

🎚️
с. 24–25

sample resolution — скільки бітів на один вимір

sample resolution — the number of bits that are used to record each sound sample
«A common sample resolution is 16-bit.» — с. 24–25
«The higher the sample resolution, the greater the variations in amplitude that can be stored for each sample.»
«This means that aspects such as the loudness of the sound can be recorded more accurately.»
«This will also increase the amount of data … This increases the size of the file that stores the sound.»
🔀
Не плутати два поняття. sample rate — як часто вимірюємо. sample resolution — наскільки точно записуємо кожен вимір. Обидва збільшують файл, але по-різному.
