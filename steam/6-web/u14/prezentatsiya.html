width · height

Ширина і висота блока

без width — уся ширина
width: 300px;
width: 50%;
height: 70px;
pxточна ширина в пікселях %частина від ширини того, що навколо: 50% — половина heightвисота. Для тексту — рідко: довгий текст вилізе за край
style.css
h2 { width: 300px; } img { width: 200px; }
Картинці досить width — висоту браузер підбере сам, без розтягування

Чому не по центру?

немає одиниці: 300px

body { margin: 0 auto; }

Подумай, потім клацни

немає ширини: додай max-width: 800px

body { max-width: 800px;
margin: auto 0; }

Подумай, потім клацни

переплутано: спершу верх-низ — 0 auto

h2 { width: 300px;
text-align: center; }

Подумай, потім клацни

text-align рухає текст, а смугу — margin: 0 auto

img { border-radius: 50 %; }

Подумай, потім клацни

пробіл: 50%

Подумай, потім клацни

літери переплутані: width

Розміри й центрування на одному екрані

Ширина · висота

width: 300px; width: 50%; height: 80px;

px — точно, % — частина

Не ширше

max-width: 800px;

на вузькому — скільки є

Блок по центру

max-width: 800px; margin: 0 auto;

спершу ширина, потім auto

Текст по центру

text-align: center;

текст у смузі, не сама смуга

Круглі кути

border-radius: 12px; border-radius: 50%; border-radius: 0 12px 12px 0;

усі · коло · з лівого верхнього

Один кут

border-top-left-radius: 30px;

top-right · bottom-right · bottom-left
