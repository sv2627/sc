Банк завдань · для тих, хто закінчив

Ще вісім доробок

1. На останньому обʼєкті — напис Last, на першому — First
2. ▶ по колу через %: після останнього — знову перший
3. Кнопка Icons.shuffle: випадковий обʼєкт, Random().nextInt(…) з dart:math
4. Рядок Max: — обʼєкт із найбільшим числовим полем, циклом
5. Кнопка «скинути лайки»: _likes.clear() у setState
6. Liked: 3 of 5 — скільки обʼєктів мають хоч один лайк: _likes.length
7. Колір назви: зелений, коли метод так/ні дає true — TextStyle(color: …)
8. Фільтр показує в шапці стан: Long only або All

Пастки

Найчастіші проблеми

1Конструктор без const при const List — isn't a const constructor. Додай const перед конструктором
2Перейменував клас не скрізь — Undefined class 'Book': лишився в List<Book> або Book b = …
3Text(f.year) — число замість рядка. Треба Text('${f.year}')
4Межа _index < films.length без - 1 — один зайвий крок і RangeError
5Фільтр без _index = 0 — номер більший за новий список, червоний екран
6Кирилиця в назві поля — final String назва; не компілюється: класи й поля тільки латиницею, кирилиця — лише всередині '…'
