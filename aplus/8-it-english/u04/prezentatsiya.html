Key question
❓

What does the word constant mean?

Think first · Спершу подумай

Спробуй сам, потім клацни.

constant something that stays the same and cannot change

Українською — константа, стала величина: щось, що лишається тим самим і не може змінитися.

Example
🎮

A computer game with points

1 A player has a set number of points at the start — на старті гравець має певну кількість очок
2 They lose one of these points each time they are successfully attacked by another player — щоразу, коли його вдало атакують, він втрачає одне очко
3 The game ends when all the points have been lost — гра закінчується, коли всі очки втрачено
Talk in pairs · 2 хв
🤝

Which values do not change?

The gameset number of points at the start lose one point when attacked the game ends when all points are lost

Three values · Три значення

Обговоріть у парах, потім клацни.

1 the number of points that the player starts with

2 the number of points that they lose each time they are successfully attacked

3 the number of points that indicates that the game ends — 0 points

Definition
💾

A constant in programming

constant a space in memory that stores a value that cannot be changed while the program is running
Українською — місце в памʼяті, де зберігається значення, яке не можна змінити, поки програма працює
Приклад: програма з константою, яка завжди встановлює на старті гри 3 очки — initialise the points to 3
Purpose
🎯

Why do we use constants?

1 · No accidental changes

They prevent accidental changes — for example, incorrectly adding extra points for a player at the start of the game

Випадково змінити константу не вийде

2 · Change it once

Points lost per attack must now be 2? Change the constant only once — not every time the code for a successful attack occurs

Змінив в одному місці — змінилось скрізь

✅
This reduces the risk of human error in the coding and saves time. — менше людських помилок, менше часу
Important
⚖️

does not change ≠ cannot change

variable

A value can be stored in a variable and stay the same through the whole program

Але змінити його можна — отже, це не константа

constant

It can only be changed if:

1 the program is stopped

2 the source code is altered

3 the program is run again

Find the constant
🔎

Which value is the same every time?

OUTPUT 1 * 12 OUTPUT 2 * 12 OUTPUT 3 * 12 OUTPUT 4 * 12 OUTPUT 5 * 12
OUTPUT 1 * 12 means OUTPUT 1 multiplied by 12

The constant is…

Спробуй сам, потім клацни.

12 — it is the same for all five outputs, so 12 is the constant

Change it once
✏️

One line changes — the whole algorithm follows

Constant multiplier = 12 OUTPUT 1 * multiplier OUTPUT 2 * multiplier OUTPUT 3 * multiplier OUTPUT 4 * multiplier OUTPUT 5 * multiplier
Constant multiplier = 5 OUTPUT 1 * multiplier OUTPUT 2 * multiplier OUTPUT 3 * multiplier OUTPUT 4 * multiplier OUTPUT 5 * multiplier
🧭
Змінився тільки перший рядок. Пʼять рядків OUTPUT — ті самі, а значення multiplier оновилось у кожному.

What is a constant?

Відповідь англійською, потім клацни.

Why use a constant instead of a variable?

Відповідь англійською, потім клацни.

To avoid accidental changes.

To allow you to change the value once so it updates it everywhere that it is used.
