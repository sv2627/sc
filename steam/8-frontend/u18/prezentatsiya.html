grid-template-columns — скільки колонок і яких

style.css
.cards { display: grid; grid-template-columns: 150px 150px 150px; gap: 10px; } /* у .cards — шість карток */
Скільки значень через пробіл — стільки колонок. Три значення — три колонки по 150px.
123456

Рядків ніхто не задавав: колонки скінчились — сітка сама почала новий рядок. Картки 4–6 стали під 1–3.
