Картка з уроку 18: три питання

1 · Column чи Row

Іконка ліворуч, праворуч від неї — назва, під назвою жанр. Що з чого?

Клацни — відповідь.

Row: іконка + Column. У Column — назва і жанр, CrossAxisAlignment.start

2 · padding чи margin

Текст прилип до рамки картки. Що збільшити?

Клацни — відповідь.

padding — відступ від рамки до вмісту. margin — від рамки до сусідніх карток

3 · Що не так

Container( color: Colors.white, decoration: BoxDecoration( border: Border.all(), ), child: Text('Celeste'), )

Клацни — відповідь.

Cannot provide both a color and a decoration. Колір — у BoxDecoration(color: …)

Запуститься чи помилка?

Конструктор — як на слайді 5: {super.key, required this.title, required this.price}

1 · Без ціни

Клацни — відповідь.

Помилка: The named parameter 'price' is required, but there's no corresponding argument.

2 · Без імен

Клацни — відповідь.

Помилка: Too many positional arguments: 0 expected, but 2 found. Параметри іменовані — пиши title:, price:

3 · Інший порядок

Клацни — відповідь.

Запуститься: картка Terraria, 9.99 USD. Порядок іменованих не важливий

Перевір себе · зламай і полагодь

Що скаже редактор?

1 · Без final

У GameCard прибери final перед String title

Що буде?

Помилка: Can't define a const constructor for a class with non-final fields. І жовте must_be_immutable: віджет має бути незмінним — поверни final

2 · Без return

У build зітри слово return перед Container

Що буде?

Помилка: The body might complete normally, causing 'null' to be returned… build мусить повернути віджет

3 · const з полем

const Row(children: [ … Text(title) … ])

Що буде?

Помилка: Arguments of a constant creation must be constant expressions. title відомий лише під час роботи — const прибери
