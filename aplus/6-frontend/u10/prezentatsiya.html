font-family

Шрифт — і запасний

style.css
body { font-family: Verdana, sans-serif; } h1 { font-family: "Times New Roman", serif; }
Через кому — запасний шрифт: якщо першого немає на компʼютері, браузер бере наступний
Назва з пробілом — у лапках: "Times New Roman", "Courier New"
Родина — пишемо останньоюЯк виглядає
serifз «ніжками» — Аа Бб
sans-serifбез «ніжок» — Аа Бб
monospaceоднакова ширина — Аа Бб
Шрифти, що є майже скрізь: Arial, Verdana, Tahoma, Georgia, Times New Roman, Courier New

text-align

Де стоїть текст у рядку

text-align: left;Ліворуч — так за замовчуванням. Рядки починаються рівно.
text-align: center;По центру — для заголовків і коротких підписів.
text-align: right;Праворуч — для дати, підпису чи ціни.
text-align: justify;По ширині — обидва краї рівні, браузер розтягує пробіли між словами.
Вирівнювання — усередині своєї смуги. Смуга h1 чи p — на всю ширину сторінки, тому center ставить текст посередині сторінки
Крок 3 з 4 Жирність і вирівнювання6 хвилин
Приклад
h1 { … text-align: center; } h2 { … font-weight: normal; text-align: center; }
Тепер самостійно
  • h1 і h2 — по центру. Ctrl+S → F5
  • h2 — normal. Став тоншим?
  • Пункти li — жирні: bold
  • Абзаци p — праворуч. Що з обома абзацами? Обери, як краще: left чи center
  • ⭐⭐ Абзаци — похилі: font-style: italic
  • ⭐⭐⭐ Допиши в перший абзац три довгі речення. left → justify: що сталося з правим краєм?
Порядок не важливий у фігурних дужках властивості можна писати в будь-якому порядку — головне ; після кожної
↕️
line-height

Відстань між рядками

line-height: 1;Рядки майже торкаються. Довгий текст так читати важко, очі губляться.
line-height: 1.5;Зручно: між рядками є повітря. Так пишуть у книжках і на сайтах.
line-height: 2;Дуже просторо: рядки далеко один від одного.
Число без px — у скільки разів рядок вищий за літери. 1.5 — у півтора рази
Дробове число — через крапку: 1.5, не 1,5
