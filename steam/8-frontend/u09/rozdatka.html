Запис

4 числа: верх · право · низ · ліво

Ширина = width + 2×padding + 2×border

border-box — ширина = width

Одиниці й центр

% — від ширини батька

rem — від шрифту сторінки (16px)

vw / vh — 1% ширини / висоти вікна

Центр: max-width + margin: 0 auto
