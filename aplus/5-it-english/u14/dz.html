1. Переклади слова

Напиши українською, що означає кожне слово.

quiz — …  ·  correct — …  ·  plan — …

Приклад відповіді: «1. quiz — …, correct — …, plan — …»

2. Що скаже програма?

Ось програма-вікторина з уроку:

ask In which country is Mumbai? and wait if answer = India then say Well done! else say Bad luck

Що скаже програма, якщо користувач написав India? А якщо Japan? Напиши обидві відповіді англійською.

answer — те, що написав користувач  ·  = порівнює відповідь з India  ·  Bad luck — «Не пощастило»

3. План своєї вікторини

Придумай одне питання для вікторини на свою тему. Напиши англійською:

Question: ...? Correct answer: ...

Обери питання, у якого одна правильна відповідь. Програма приймає лише ту відповідь, яку в неї записали. Приклад з уроку: In which country is Mumbai? — India.
