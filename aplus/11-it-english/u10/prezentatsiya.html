Finding errors in a program and correcting the errors

1
To find an error in an algorithm you need to know the purpose of the algorithm.

переклад — клацни

Щоб знайти помилку в алгоритмі, треба знати його призначення.
2
You can then test the algorithm with different data, completing trace tables if needed, to find out what the algorithm actually does.

переклад — клацни

Потім можна перевірити алгоритм на різних даних, заповнюючи трасувальні таблиці, якщо треба, щоб зʼясувати, що алгоритм робить насправді.
3
Once you know the difference between what it does and should do, you can start to identify the errors and the changes you need to make.

переклад — клацни

Коли ви знаєте різницю між тим, що він робить, і тим, що має робити, можна шукати помилки й зміни, які треба внести.

Two methods

1
Computer programmers will come across errors all the time.

переклад — клацни

Програмісти постійно натраплятимуть на помилки.
2
These could be ones that they have made, or that they are testing or fixing for other people.

переклад — клацни

Це можуть бути їхні власні помилки або ті, які вони тестують чи виправляють для інших людей.
3
Many of them will use the two methods used here; using a trace table, and dry running by reading the code.

переклад — клацни

Багато хто з них використовує два методи з цього розділу: трасувальну таблицю й ручний прогін через читання коду.

Features within the Integrated Development Environment (IDE) allow the programmer to see the values of variables and the outputs at each stage, without having to trace them manually.

переклад — клацни

Можливості середовища розробки (IDE) дозволяють програмістові бачити значення змінних і виведення на кожному кроці, не трасуючи їх вручну.

Split the description into requirements

«take 3 numbers as input, and output the largest value and the average value»
01 Total ← 0 02 Largest ← 999 03 FOR X ← 0 TO 2 04 INPUT Data 05 IF Data < 999 THEN 06 Large ← Data 07 ENDIF 08 Total ← Total + Data 09 NEXT X 10 OUTPUT Largest 11 Average ← Total / 3 12 OUTPUT Average

⭐ Three sections

«Re-read the description» — розбий на 3 частини вголос, потім клацни.

1 Take 3 numbers as input. · 2 Output the largest value. · 3 Output the average value.

⭐⭐ Five requirements

«The two outputs need to be calculated before being output» — яких двох вимог бракує?

  1. Take 3 numbers as input.
  2. Calculate the largest value.
  3. Output the largest value.
  4. Calculate the average value.
  5. Output the average value.
