Позначка в HTML — правило в CSS

index.html
<section>…</section> <section class="hot">…</section> <section>…</section>
style.css
.hot { background-color: gold; }
class="hot"у HTML — без крапки
.hotу CSS — з крапкою попереду
hot = hotназва — літера в літеру

Закінчив раніше?

Банк завдань — бери будь-яке

Три види карток. Класи sale, new, top — у кожного свій фон
Важливий абзац. Клас important: жирний текст і свій фон
Підпис фото. Абзац під картинкою з класом caption: дрібно, курсивом, по центру
Три класи разом. class="card hot new" — що вийшло?
Чий колір сильніший. Дай абзацу і клас, і id з різними кольорами. Перевір, хто переміг
Меню на всіх сторінках. У about.html — те саме меню, посилання ведуть на розділи index.html
Коментарі. /* картки */, /* розділи */ над групами правил — Ctrl+/
Сусід. Повернись до сусіда: клацни кожен пункт його меню. Усі ведуть куди треба?
