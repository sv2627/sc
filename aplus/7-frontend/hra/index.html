Зроби свою гру

Ти вже вмієш HTML і CSS. Гру пишуть третьою мовою — JavaScript, і її ми вчитимемо у 8 класі. Але чекати рік нецікаво, тому JavaScript уже написаний за тебе. Твоя робота — зібрати сторінку і сказати грі, якою вона має бути.

Чесно кажучи

Це не «ти зробив гру з нуля» — це «ти скористався чужим кодом і зробив із нього своє». Саме так працює справжня розробка: ніхто не пише все сам. Але й списати тут нічого: сторінка, кольори, картинка і правила — твої, і двох однакових ігор у класі бути не повинно.

Як підключити

1
Створи папку для гри й поклади в неї файл gra.js — забери його за цим посиланням (правою кнопкою → «Зберегти як…»).
2
Поруч зроби свій index.html — звичайний, з <head>, <body> і своїм CSS.
3
Постав у <body> порожній блок — саме туди приїде гра:
<div id="gra"></div>
4
Наприкінці <body> підключи рушій і опиши гру:
<script src="gra.js"></script> <script> Гра.змійка({ поле: 20, кольорЗмійки: '#00e676' }); </script>
5
Відкрий сторінку через Live Server — і грай.
Головна пастка

<script src="gra.js"> має стояти раніше, ніж рядок із Гра.змійка(…). Інакше браузер спершу почує слово «Гра», якого ще не знає, і в консолі (F12) буде Гра is not defined. Правило просте: спочатку підключи, потім користуйся.

Дві готові гри

Шаблон · відкрий і збережи собі

🐍 Змійка

Класика. Керується стрілками, їсть яблука, росте. Міняєш розмір поля, швидкість, кольори й саме яблуко — воно може бути будь-яким емодзі.

 Шаблон · відкрий і збережи собі

🧩 Пазл

П'ятнашки з твоєї картинки: фото, малюнок, скрін улюбленої гри. Плитки — звичайні блоки в CSS Grid, тому стилі до них ти пишеш сам.

Стилі пазла — твої

Рушій дає плиткам класи .пазл, .плитка, .порожня і .номер. Твій CSS сильніший за стилі рушія, тому можеш міняти все: gap (шви між плитками), border-radius, колір фону, тінь, transition. Це та сама сітка, що на уроці 4 — display: grid уже стоїть.

/* шви товщі, плитки круглі, номери прибрано */ .пазл { gap: 8px; background: crimson; } .пазл .плитка { border-radius: 50%; } .пазл .номер { display: none; }

Три рівні

⭐ базовий

Взяти один шаблон, змінити заголовок, кольори і хоча б три налаштування. Гра запускається, у неї можна грати.

⭐⭐ середній

Своя сторінка навколо гри: шапка з назвою, правила, табло рахунку, кнопка. Пазл — зі своєї картинки. Сторінка виглядає як зроблена, а не як шаблон: свої шрифти, фон, відступи.

⭐⭐⭐ високий

Обидві гри на одній сторінці з перемиканням, або третя власна гра з цеглинок нижче. Плюс адаптив: на телефоні грати так само зручно, як на ноутбуку.

Коли щось не працює

Перше, що робиш завжди: F12 → вкладка Console. Біла сторінка без помилки — рідкість; майже завжди помилка там є.

Одне правило

Кома, дужка й лапка мають бути на місці. Пропущена кома між налаштуваннями ламає всю гру, а не одне налаштування. Копіюй шаблон і міняй значення, не чіпаючи розділові знаки, — і майже все працюватиме з першого разу.
