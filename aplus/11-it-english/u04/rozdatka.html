Linear search

a search algorithm that visits each item of data in turn to check whether it is the data being looked for

Два стопи

1 · the same → found

2 · checked the last value → not found

index починається з 0

Efficient

Found ← FALSE

WHILE Found = FALSE AND

 ArrayIndex < LENGTH(Array)

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
