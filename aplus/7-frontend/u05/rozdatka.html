Grid: fr, repeat, span

Довідка

Батькові — сітка

display: grid;

grid-template-columns: repeat(3, 1fr);

gap: 20px;

Картці — місце

grid-column: span 2; — на 2 колонки

grid-row: span 2; — на 2 рядки

grid-column: 3; — у колонку 3

Лінії

Ліній = колонок + 1, рахуємо з 1

1 / 3 — від лінії 1 до лінії 3

1 / -1 — на всю ширину

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

1 · Намалюй сітку за кодомпронумеруй картки

/* repeat(3, 1fr); 6 карток */
/* картка 1: */ grid-column: span 2;
/* repeat(3, 1fr); 7 карток */
/* картка 1: */ grid-column: span 2;
               grid-row: span 2;

4 · Знайди помилкущо не так і як треба

.gallery { display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-column: span 2; } /* не працює */
.title { grid-column: 0 / 3; }
/* мав бути на всі 3 колонки */
.wide { grid-column: 1 - 3; }

5 · Знайди діркупостав × у порожню
