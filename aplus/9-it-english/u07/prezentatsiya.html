Practice 3 Celsius to Fahrenheit5 хвилин
Problem: take a number between −10 and 40 from the user as a temperature in Celsius and convert it to Fahrenheit: multiply by 1.8, then add 32.
algorithm · pseudocode
Temperature = input("Enter the temperature in celsius") Fahrenheit = Temperature + 32 * 1.8 print(Temperature + " in celsius is " + Temperature + " in fahrenheit")

⭐ Temperature = 10. Що виведе?

Клацни після зошита.

10 in celsius is 10 in fahrenheit

⭐⭐ Fahrenheit = ?

Множення — першим. Клацни.

32 * 1.8 = 57.6 → 10 + 57.6 = 67.6. Має бути 50.

⭐⭐⭐ What does this algorithm do instead?

Одне речення. Клацни.

Adds 57.6 — and outputs the Celsius temperature twice.

🔧
Correct

Two lines need changing

was
Temperature = input("Enter the temperature in celsius") Fahrenheit = Temperature + 32 * 1.8 print(Temperature + " in celsius is " + Temperature + " in fahrenheit")

Line 2 · the calculation

Запиши правильний рядок. Клацни.

Fahrenheit = Temperature * 1.8 + 32

Line 3 · the output

Запиши правильний рядок. Клацни.

print(Temperature + " in celsius is " + Fahrenheit + " in fahrenheit")
Now: 10 → 50. Output: 10 in celsius is 50 in fahrenheit

Алгоритми з уроків 1 і 2. Для кожного запиши в зошит Yes або No. Якщо No — число, на якому видно помилку.

⭐ A · Multiply the two numbers

result = number1 + number2 print(result)

Клацни.

No. 3 і 4 → 7, а має бути 12.

⭐ B · Output the numbers 0 to 9

for count in range(0, 10): print(count)

Клацни.

Yes. 0, 1, 2 … 9

⭐⭐ C · Output "Valid" only when the number is greater than 0

if(value > 10): print("Valid")

Клацни.

No. 5 > 0, але нічого не виводиться.

⭐⭐⭐ D · "Valid" when the number is from 10 to 1000

if(value >= 10): print("Valid")

Клацни.

No. 2000 → "Valid". Треба and value <= 1000.

Practice 5 Two algorithms, one problem5 хвилин
Problem: take 3 numbers as input, add them together and output the result.
algorithm 1
number1 = input("Enter a number") number2 = input("Enter a number") number3 = input("Enter a number") value1 = number1 + number2 total = number3 + value1 print(total)
algorithm 2
number1 = input("Enter a number") number2 = input("Enter a number") number3 = input("Enter a number") print(number1 + number2 + number2)

⭐ Input 1, 2, 3. Outputs?

Клацни після зошита.

Algorithm 1 → 6 · Algorithm 2 → 5

⭐⭐ Which one meets the requirements?

Клацни.

Only algorithm 1. Algorithm 2 adds number2 twice.

⭐⭐⭐ Correct algorithm 2

Один рядок. Клацни.

print(number1 + number2 + number3)

Algorithm 2 is more … because … Клацни.

Algorithm 2 is more efficient: fewer lines of code — smaller file size; fewer variables — less memory usage.
