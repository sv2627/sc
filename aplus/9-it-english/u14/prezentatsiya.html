What is a sub-routine?

Explain your understanding of the term ‘sub-routine’. Then add to the answer of your classmate.

Спершу кілька відповідей класу — тоді клацаємо.

1
A sub-routine is a self-contained program that can be called from other programs.
переклад
Підпрограма — самостійна програма, яку можна викликати з інших програм.
2
Sub-routines can be used multiple times in an algorithm.
переклад
Підпрограми можна використати багато разів в одному алгоритмі.
3
Sub-routines can be used across different algorithms.
переклад
Підпрограми можна використати в різних алгоритмах.

Why was it easier to write Action 1 instead of ‘clap 3 times, jump twice, clap 3 times’ each time?

Read aloud · word bank

A sub-routine is…

1
A sub-routine is a set of commands that is given an identifier and can be called from anywhere in an algorithm.
переклад
Підпрограма — набір команд, якому дали ідентифікатор і який можна викликати з будь-якого місця алгоритму.
2
You do not need to write the same code every time it is used.
переклад
Не треба писати той самий код щоразу, коли він потрібен.
3
Each small program only has to be written once, but can be used many times within a larger program.
переклад
Кожну маленьку програму пишуть лише раз, а використовують багато разів у більшій програмі.

A sub-routine in pseudocode

the sub-routine
subroutine addition() firstNumber = input("Enter the first number") secondNumber = input("Enter the second number") result = firstNumber + secondNumber print(firstNumber, " + ", secondNumber, " = ", result) endsubroutine
the program that calls it
answer = input("Do you want to add two numbers together?") if(answer == "yes"): addition() else: print("Program exiting")

How do you call a sub-routine?

Відповідай повним реченням. Клацни — зразок відповіді.

1
What is a sub-routine?
зразок
A sub-routine is a section of code with a name that can be called from another program.
2
How do you call a sub-routine in a flowchart or pseudocode?
зразок
You call a sub-routine by its identifier.
3
Why do we use sub-routines?
зразок
We use sub-routines because we do not need to write the same code every time it is used.
⭐
How many times can you call one sub-routine?
зразок
You can call one sub-routine multiple times, from anywhere in an algorithm.
