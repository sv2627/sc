Відповіді надіслати на платформі — повідомленням учителю

≈ 10 хвилин. Робимо на сайті codepen.io (або у VS Code вдома). У CodePen два поля: HTML і CSS — рядок <link> там не потрібен.

Код для копіювання

У поле HTML:

<h1>Кафе «Пончик»</h1>
<p>Найсмачніші пончики в місті.</p>
<p>Відкрито щодня з 8:00.</p>

У поле CSS:

body {
  background-color: lightblue;
}

/* ДОПИШИ ТУТ 1: h1 — колір тексту darkred */

/* ДОПИШИ ТУТ 2: p — колір тексту navy, фон lightyellow */

Завдання

  1. Скопіюй код вище: верхній — у поле HTML, нижній — у поле CSS. Фон сторінки стане блакитним.
  2. ДОПИШИ ТУТ 1: правило для h1, колір тексту darkred. Має вийти: заголовок темно-червоний. Як на кроці 3 уроку, наприклад: h2 { color: white; }.
  3. ДОПИШИ ТУТ 2: правило для p, колір тексту navy і фон lightyellow. Має вийти: обидва абзаци — сині літери на жовтому, заголовок — без жовтого фону. Надішли код з поля CSS.
