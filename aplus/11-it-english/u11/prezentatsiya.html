Summary: from life cycle to bubble sort

1
Programs are developed by following a program development life cycle. The program development life cycle is made up of; analysis, design, coding and testing.

переклад — клацни

Програми розробляють за життєвим циклом розробки програми. Він складається з аналізу, проєктування, кодування й тестування.
2
In the analysis stage the problem is identified and decomposed. In the design stage the algorithms are planned.

переклад — клацни

На етапі аналізу задачу визначають і розкладають на частини. На етапі проєктування планують алгоритми.
3
In the coding stage the program is written. In the testing stage the program is tested.

переклад — клацни

На етапі кодування програму пишуть. На етапі тестування програму перевіряють.
4
Decomposition is the splitting of a system into sub-systems. Decomposition can be shown using a structure diagram.

переклад — клацни

Декомпозиція — це поділ системи на підсистеми. Її можна показати структурною діаграмою.
5
Algorithms can be planned using flowcharts and pseudocode.

переклад — клацни

Алгоритми можна планувати блок-схемами й псевдокодом.
6
A linear search checks each item of data in turn. A bubble sort compares the items in pairs repeatedly.

переклад — клацни

Лінійний пошук перевіряє кожен елемент даних по черзі. Сортування бульбашкою багаторазово порівнює елементи парами.

Summary: from totalling to trace tables

7
Totalling is adding together the values. Counting is adding 1 to the count for each item.

переклад — клацни

Підсумовування — це додавання значень. Підрахунок — це додавання 1 до лічильника за кожен елемент.
8
To find the minimum value, a variable needs to be initialised with a large value. To find the maximum value, a variable needs to be initialised with a small value.

переклад — клацни

Для мінімуму змінній задають велике початкове значення. Для максимуму — мале.
9
Validation is checking data entered is reasonable and within bounds. Validation checks include; range check, length check, type check, presence check, format check and check digit.

переклад — клацни

Валідація — перевірка, що введені дані розумні й у допустимих межах. Перевірки: діапазону, довжини, типу, наявності, формату й контрольна цифра.
10
Verification checks that data has been input accurately. Verification checks include visual check and double entry check.

переклад — клацни

Верифікація перевіряє, що дані введено точно. Перевірки: візуальна й подвійне введення.
11
Four types of test data are normal, abnormal, extreme and boundary.

переклад — клацни

Чотири види тестових даних: нормальні, некоректні, крайні й граничні.
12
A trace table is used to dry run an algorithm. It can be used to find the purpose of an algorithm and to find errors in the algorithm.

переклад — клацни

Трасувальна таблиця — для ручного прогону алгоритму: з нею знаходять призначення алгоритму й помилки в ньому.

A computer game

A computer game allows a user to load a saved game or to start a new game. The game then loads the puzzle for that level.
