Два види елементів

Блочні й рядкові

Блочний

<h2> Заголовок
<p> Абзац
<section> Розділ
  • починає новий рядок
  • займає всю ширину батька
  • слухає width, height, усі відступи

Рядковий

Текст абзацу, а в ньому <a> посилання і <strong> жирне слово — усе в одному рядку
  • стоїть у рядку, як слово
  • ширина — за вмістом
  • width, height і відступи зверху-знизу не діють

Рядковий елемент

Що на нього не діє

Не спрацює
nav a { width: 150px; height: 60px; margin-top: 20px; }

Ширина — за текстом, висота та сама, зверху відступу немає

Спрацює
nav a { margin: 0 10px; color: white; background-color: #1b5e20; }

Відступи з боків, колір і фон — працюють

🎯
Тому margin: 0 auto не ставить посилання по центру: воно не блок. Як це виправити — через слайд
🤔

Властивість display

Будь-який елемент можна переробити

display: block;стане блоком: з нового рядка, на всю ширину, слухає width і відступи
display: inline;стане рядком: стоїть серед тексту, розмірів не слухає
display: inline-block;у рядку, але як блок: слухає width, height і всі відступи
display: none;зникає зі сторінки й місця не займає
display: flex;урок 12

disp → Enter — після двокрапки VS Code покаже всі значення списком

Приклад
nav a { display: inline-block; padding: 8px 16px; margin: 4px; border-radius: 8px; } img { display: block; margin: 0 auto; }
Тепер самостійно
  • Меню: посилання — inline-block, відступ усередині, фон, кути
  • Вимкни рядок display через Ctrl+/: що сталося з кнопками? Поверни
  • Картинку — по центру: display: block + margin: 0 auto
  • У картку — посилання <a class="more">Детальніше</a>: inline-block, рамка, відступи
  • ⭐⭐ Сховай одну секцію: display: none. Що сталося з її місцем? Поверни
  • ⭐⭐⭐ Список ul — в один рядок: li { display: inline-block; }. Куди поділись крапки?
⚡
Не певен, що вийшло? F12 → наведи на кнопку меню: тепер підсвічується вся кнопка з відступами

<span>рядкова коробка: виділити шматок тексту

<div class="container"> h1 + nav

<section> <h2> + <article>

<div class="container"> © 2026
