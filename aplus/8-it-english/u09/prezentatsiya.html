The same algorithm, written three ways

1 · Flowchart

number = 10 ?
YES · true
OUTPUT "Yes"
NO · false
OUTPUT "No"

2 · Pseudocode

IF number = 10 THEN OUTPUT "Yes" ELSE OUTPUT "No" ENDIF

3 · Python

if number == 10: print("Yes") else: print("No")

What is the same?

Вголос, потім клацни.

the condition · the code to run if true · the code to run if false

What is new in Python?

Вголос, потім клацни.

lower case if else · colon : · indentation · == · no THEN, no ENDIF

The indents are important in Python

indent.py
if x == 10: print("Hello") print("Bye")
1 · The indents are important in Python.  переклад? Відступи в Python важливі.
2 · print("Hello") is indented, so it will only run if the if statement is true.  переклад? Цей рядок з відступом, тому виконається лише тоді, коли умова if — true.
3 · print("Bye") is not in the if statement, so it will always run.°  переклад? Цей рядок не всередині if, тому виконається завжди.
