Read aloud · answer in English

Arrays in code

Python does not have an inbuilt array data structure. Instead it uses lists. To access data in an array, we write the array name, followed by square brackets with the index inside. The first element is in index 0. We can output the value, or store it in a variable to perform a calculation. We can use a count-controlled loop to output each of the array items in turn.

Читаємо по реченню по черзі. Переклад — клацни.

У Python немає вбудованої структури «масив». Замість неї — списки. Щоб отримати дані з масиву, пишемо імʼя масиву, а за ним квадратні дужки з індексом. Перший елемент — в індексі 0. Значення можна вивести або зберегти у змінну, щоб із ним рахувати. Цикл із лічильником виводить усі елементи масиву по черзі.
