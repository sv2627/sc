Key words · с. 177

Two forms of verification

visual check
comparing the data entered with the original side-by-side
«A visual check is where you compare the data entered to the original. For example, reading each line from a paper copy and checking it is identical on the computer.»
double entry check
two different people enter the same data which are then compared
«A double entry check is where the same data is entered twice, usually by different people. The computer will then check whether there are any differences in what they each entered.»
