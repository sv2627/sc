Key idea · procedure = sub-routine
📦

procedure · sub-routine

procedure
процедура
sub-routine
підпрограма — те саме слово іншими словами

A procedure is a small section of a program that performs a specific task in a specific way. Procedures can be used many times in a program and can be re-used in other programs.

Прочитай уголос і переклади, потім клацни.

Процедура — це невеликий шматок програми, який виконує певне завдання певним способом. Процедуру можна використати в програмі багато разів і ще раз — в інших програмах.

The prototype for the user name is now called as a procedure: enter user name. to call — викликати.

Evaluation: how well does it work?

1Does the program follow the project plan?
2Does the program function as expected?
3Is the program easy to use?
4Can the program be improved?

This final, vital stage in the design of any product is known as ‘evaluation’.

Прочитай і переклади, потім клацни.

Цей останній і дуже важливий етап створення будь-якого продукту називається «оцінювання».
