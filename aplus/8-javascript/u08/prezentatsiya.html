Приклад · while

Гра «Вгадай число» — рівень ⭐

js-8/tsykly/script.js
// випадкове ціле від 1 до 100 const secret = Math.floor(Math.random() * 100) + 1; let guess = Number(prompt('Вгадай число від 1 до 100')); while (guess !== secret) { const hint = guess < secret ? 'Більше!' : 'Менше!'; guess = Number(prompt(`${hint} Ще раз`)); } alert(`Вгадав! Це ${secret}`);
Перший рядок — готовий рецепт: ціле випадкове число від 1 до 100. Як він працює — потім
Цикл крутиться, поки не вгадав: !== — «не дорівнює»
Перевірити швидше — підглянь: console.log(secret);
Практика 2 Вгадай число на while9 хвилин
Приклад — лічильник спроб
let tries = 1; … while (guess !== secret) { … tries++; } alert(`Вгадав! Спроб: ${tries}`);
Тепер самостійно
  • Набери гру й вгадай число. Підглядати можна
  • Число від 1 до 10: заміни 100 на 10 у двох місцях
  • Заміни !== на === — що каже гра з першої спроби? Поверни
  • Натисни Скасувати — яку підказку дає гра і чому? (Number(null) — це 0)
  • ⭐⭐ Лічильник спроб, як у прикладі: «Вгадав! Спроб: 5»
  • ⭐⭐⭐ Не більше 7 спроб: guess !== secret && tries < 7; після циклу — перемога або «Спроби скінчились»

Виправ

Сума від 1 до 5 — а тут три біди

script.js · зламано навмисно
for (let i = 1; i <= 5; i--) { let sum = 0; sum + i; } console.log(`Сума: ${sum}`);
⚠️
Не запускай, поки не виправиш, — вкладка зависне

Знайди всі три

Спершу вголос, потім клацни

1. i-- — i іде вниз, завжди <= 5: вічний цикл. Треба i++

2. let sum = 0 всередині — щоразу нуль, а після } її не видно: ReferenceError. Перенести до циклу

3. sum + i; рахує, але не зберігає. Треба sum += i; → Сума: 15
