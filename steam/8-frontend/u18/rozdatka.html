Технологія CSS Grid

Довідка

Сітка — батькові

.cards { display: grid;

  grid-template-columns:

    repeat(3, 1fr); gap: 20px; }

Картці

grid-column: span 2; — на дві колонки

grid-column: 1 / -1; — на всю ширину

grid-row: span 2; — на два рядки

Пам'ятай

Скільки значень — стільки колонок

fr — частка місця, що лишилось після gap і px

Три колонки — чотири лінії

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

1 · Що зробить рядок

grid-template-columns: 1fr 1fr;
grid-template-columns: 100px 1fr;
gap: 10px 30px;
grid-column: span 3;
grid-template-rows: 50px 100px;

2 · Намалюй сітку

.box { display: grid;
  grid-template-columns: repeat(4, 1fr); }
.big { grid-column: span 2; }
