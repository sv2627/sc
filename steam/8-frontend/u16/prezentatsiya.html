Головна вісь: у row — зліва направо, у column — згори вниз. Перше значення в кожному рядку — те, що діє без нього.

Що побачимо?

У контейнері — три дитини: <i>1</i> <i>2</i> <i>3</i>

1display: flex; justify-content: flex-end;
Де стоять 1, 2, 3?
2display: flex; flex-direction: column;
Рядок чи стовпчик?
3display: flex; flex-direction: row-reverse;
Яке число зліва?
4display: flex; justify-content: space-between;
Де 1, а де 3?
5display: flex; flex-direction: column; justify-content: center; height: 300px;
Посередині по вертикалі чи по горизонталі?
6justify-content: center;
Рядка display: flex немає. Що зміниться?

Закінчив раніше?

Банк завдань — бери будь-яке

Кнопка в меню. Останнє посилання шапки — class="btn": фон, padding, круглі кути
Меню списком. nav → ul з li. display: flex — для ul, плюс list-style: none і padding: 0
Чому ми. Новий розділ: три div з емодзі й підписом — в рядок, space-around
Дзеркало. row-reverse для обгортки шапки: назва праворуч, меню ліворуч
Підвал у колонки. Три стовпчики: адреса, меню, соцмережі — space-between
Справжній сайт. Будь-який сайт → F12 → знайди позначку flex біля тегу. Що це за частина сторінки?
