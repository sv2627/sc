Check yourself · Звіряємось

1 · Скільки разів

клікни

П'ять. range(1, 6) дає 1, 2, 3, 4, 5 — верхня межа не входить.

2 · Що надрукує

клікни

15. Це 1+2+3+4+5. Змінна total накопичує суму — вона й є counter у широкому сенсі.

3 · Якщо змінити межі

клікни

range(1, 5) → чотири проходи, сума 10. range(0, 6) → шість проходів, сума все одно 15: нуль нічого не додає.

Помилка «на одиницю» — off-by-one error — найчастіша помилка в циклах узагалі. Ми повернемось до неї на уроці 2, там вона головна тема.
Новий інструмент

New tool: pseudocode · Псевдокод

Що це

Запис алгоритму словами, але за жорсткою структурою: один крок — один рядок, ключові слова великими літерами, вкладене — з відступом.

Мета: щоб інша людина зрозуміла алгоритм однозначно — ще до того, як обрано мову програмування.

Чим воно НЕ є

  • Не мова програмування.
  • Не запускається — жоден комп'ютер його не виконає.
  • Не має єдиного стандарту: є домовленість класу.
  • Не коментарі до коду: псевдокод пишеться до коду.
🔀
Ви вже пишете щонайменше двома мовами: Python і Swift. Псевдокод — це те, чим ці мови домовляються між собою, і саме його Cambridge просить у роботах.

Same idea, new notation · Та сама думка, новий запис

Python · те, що ви знаєте
total = 0 for i in range(1, 6): total = total + i print(total)
pseudocode · те, що просить Cambridge
BEGIN SET total TO 0 FOR i ← 1 TO 5 SET total TO total + i NEXT i OUTPUT total END
⚠️
Одна пастка одразу. У Python range(1, 6) — це 1…5, верхня межа не входить. У псевдокоді FOR i ← 1 TO 5 — це теж 1…5, але тут межа входить. Різні мови, різна домовленість. Дивись на число, не на звичку.

Three forms of loop · Три форми циклу

ФормаКоли перевіряється умоваСкільки разів виконається тілоКоли брати
FOR … TO … NEXTкількість відома напередрівно стільки, скільки в заголовку«зроби 10 разів»
WHILE … ENDWHILEперед тіломможе жодного разу«роби, доки виконується умова»
REPEAT … UNTILпісля тілащонайменше один раз«зроби, а тоді перевір»
Уся різниця між WHILE і REPEAT — у моменті перевірки. Це не стилістика: від цього залежить, чи виконається тіло хоч раз. Це найчастіше питання рамки по цій темі.

2️⃣

WHILE … ENDWHILE · Перевірка перед тілом

while-loop.txt
BEGIN INPUT password WHILE password ≠ 'open' DO OUTPUT 'Wrong. Try again.' INPUT password ENDWHILE OUTPUT 'Welcome' END

Ключова властивість

Якщо користувач одразу ввів 'open' — тіло циклу не виконається жодного разу. І це правильно: навіщо казати «Wrong», якщо пароль вірний.

🔤
condition-controlled loop — цикл, керований умовою. Протилежність до count-controlled.
форма 3 / 3
3️⃣

REPEAT … UNTIL · Перевірка після тіла

repeat-loop.txt
BEGIN REPEAT OUTPUT 'Enter the password' INPUT password UNTIL password = 'open' OUTPUT 'Welcome' END

Ключова властивість

Питання ставиться щонайменше один раз — навіть якщо пароль уже відомий. Інакше нема чого перевіряти.

Питання класу

Той самий пароль — і WHILE, і REPEAT. Який запис чесніший для цієї задачі?

клікни після обговорення

REPEAT. Спитати пароль треба у будь-якому разі — тож перевірка після тіла точно описує задачу, а WHILE вимагає зайвого INPUT до циклу.

Move the bounds · Зсунь межі

Спершу скажи відповідь уголос, потім перевіряй. Той самий цикл, що на слайді 12: FOR i ← 1 TO 4, сума 10.

1 · FOR i ← 0 TO 4

Скільки iterations? Яка сума?

клікніть, щоб перевірити

П'ять проходів, сума 10. Проходів стало більше, результат той самий — нуль нічого не додав. Кількість ітерацій і результат — різні речі.

2 · FOR i ← 4 TO 1

Що станеться?

клікніть, щоб перевірити

Нуль проходів. Лічильник росте, а стартове значення вже більше за кінцеве — тіло не виконається жодного разу, на виході 0. Програма не впала і нічого не сказала.

🎯
Другий випадок страшніший: помилки не видно. Англійською це logic error — на відміну від syntax error, який ловиться одразу.

Find the infinite loop · Знайди нескінченний цикл

someone-elses.txt · чужий запис
BEGIN SET count TO 1 WHILE count < 10 DO OUTPUT count ENDWHILE END

Що тут не так?

спершу скажіть у парі, тоді клікніть

Ніхто не змінює count. Умова count < 10 істинна назавжди — це infinite loop. Виправлення: додати SET count TO count + 1 усередині циклу.

👑
Правило на весь рік: у WHILE і REPEAT завжди питай — що саме в тілі змінює умову? Немає відповіді — цикл нескінченний.
