Розвилка в коді

Одна розвилка = один prompt + if

script.js
const c1 = prompt('1 — у печеру, 2 — до річки'); if (c1 === '1') { alert('Усередині темно й холодно.'); } else if (c1 === '2') { alert('Річка вивела тебе до села. КІНЕЦЬ'); } else { alert('Такої дороги немає. КІНЕЦЬ'); }
Кожен варіант — своя гілка. Номер варіанта = номер стрілки на папері
'1' — у лапках: prompt дає рядок
else ловить усе інше: 3, «так», порожнє поле

Як гравцеві відповідати

Цифрою чи словом?

цифрою — беремо в квест
const c1 = prompt('1 — ліс, 2 — гори'); if (c1 === '1') { … }

Одруківки майже неможливі. Порівняння — з рядком '1'

словом — тільки для загадки ⭐⭐⭐
const a = prompt('Хто ходить без ніг?'); if (a.trim().toLowerCase() === 'час') { … }

Регістр, пробіли — і null.trim() на Скасувати

💀
Скасувати дає null. null.trim() → TypeError, гра падає. Тому спершу перевір a === null — як у калькуляторі.
🚪
Чужа відповідь і Скасувати

Кожен вихід — теж частина історії

script.js
const c1 = prompt('1 — ліворуч, 2 — праворуч'); if (c1 === null) { alert('Гру перервано.'); } else if (c1 === '1') { alert('Ліворуч — старий колодязь.'); } else if (c1 === '2') { alert('Праворуч — сторожова вежа.'); } else { alert('Ти вагався, і дракон прокинувся. КІНЕЦЬ'); }
null — першим. Порядок перевірок той самий, що в калькуляторі
else — не «помилка вводу», а ще одна кінцівка. Нехай гравець дізнається, що сталося
Без else на відповідь 7 гра просто мовчить. Людина не розуміє, що кінець

Вкладена розвилка

Друге питання — всередині гілки

script.js
const c1 = prompt('1 — зайти, 2 — піти до річки'); if (c1 === '1') { const c2 = prompt('Темно. 1 — факел, 2 — наосліп'); if (c2 === '1') { alert('Факел освітив скриню. ПЕРЕМОГА'); } else { alert('Ти впав у яму. КІНЕЦЬ'); } } else { alert('Річка вивела до села. КІНЕЦЬ'); }
c2 питаємо всередині if (c1 === '1'). Хто пішов до річки, цього питання не побачить
Гілка дерева = пара { }. Розвилка в розвилці — дужки в дужках
Кожен рівень — ще 2 пробіли відступу. По відступах видно, де яка гілка

Ще один запис розвилки

switch — коли варіантів багато

script.js
const c1 = prompt('1 — ліс, 2 — гори, 3 — море'); switch (c1) { case '1': alert('Ліс густий і тихий.'); break; case '2': alert('У горах холодний вітер.'); break; case '3': alert('Хвилі накривають берег.'); break; default: alert('Ти лишився вдома. КІНЕЦЬ'); }
switch (c1) порівнює через ===: '1' так само в лапках
case — один варіант, default — те саме, що else
break — «на цьому все». Без нього виконання провалюється в наступний case
Лише для точних збігів. <=, && — тільки if

Довідник — на дошці, поки пишемо

Усі розвилки на одному екрані

розвилка

const c = prompt('1 — …, 2 — …');
if (c === '1') { … }
else if (c === '2') { … }
else { … }

вкладена

if (c1 === '1') {
  const c2 = prompt('…');
  if (c2 === '1') { … }
}

switch

switch (c) {
  case '1': …; break;
  case '2': …; break;
  default: …
}

Скасувати і чуже

if (c === null) { … }
// першим!
else { … } // решта

стан

let health = 3; // вгорі
health -= 1;
gold += 5;
hasKey = true;

кінцівка за станом

if (health <= 0) { … }
else { … }

секрет

if (hasKey && gold >= 5)
if (a || b)

вибрати значення

const w = health > 1
  ? 'бадьорий'
  : 'слабкий';

вивести стан

alert(`Здоровʼя: ${health}`);

Стан

Змінна, що йде за гравцем через усю гру

script.js
let health = 3; // здоровʼя на старті const c1 = prompt('1 — вбрід, 2 — шукати міст'); if (c1 === '1') { health -= 1; alert(`Вода крижана. Здоровʼя: ${health}`); } else { alert('Міст знайшовся за годину.'); }
Оголошуємо на самому початку, вгорі файлу — до першої розвилки
let, не const: значення змінюється
health -= 1 — «зменш на 1». Родич score += 1 з уроку 4
Показуємо стан у `…${health}`. У таких лапках апостроф у «здоровʼя» не заважає
🏁
Кінцівка за станом

Одна перевірка — і кінцівок стало три

script.js · кінець файлу
// ... розвилки, кожна може забрати здоровʼя if (health <= 0) { alert('Сили скінчились. КІНЕЦЬ'); } else if (health === 3) { alert('Жодної подряпини! ПЕРЕМОГА'); } else { alert(`Ти дійшов. Здоровʼя: ${health}. ПЕРЕМОГА`); }
Та сама дорога — різний фінал, залежно від того, скільки здоровʼя лишилось
Порядок — від вужчої умови: <= 0, потім === 3, решта — else
<= 0, а не === 0: удар на 2 при здоровʼї 1 дасть -1
⛔
Стан посеред гри

Здоровʼя скінчилось — далі не питаємо

script.js
health -= 2; if (health <= 0) { alert('Сили скінчились. КІНЕЦЬ'); } else { const c3 = prompt('1 — відпочити, 2 — йти далі'); // гра триває тільки тут, усередині else }
Зупинити гру «на півдорозі» можна тільки так: наступна розвилка стоїть всередині else
Правило: після кожного health -= …, що може вбити, — перевірка
Інакше гравець з -1 здоровʼя спокійно піде далі й навіть переможе

Стан ⭐⭐⭐

Золото, ключ і прихована кінцівка

script.js
let gold = 0; let hasKey = false; // у гілці зі скринею gold += 5; // у гілці зі сторожем hasKey = true; if (hasKey && gold >= 5) { alert('Таємні двері! ПРИХОВАНА КІНЦІВКА'); }
Стан буває не тільки числом: true / false — «має ключ чи ні»
&& — треба і те, і те. || — досить одного. Це урок 3
Прихована кінцівка — та, до якої доходить лише уважний гравець. Про неї не пишуть у варіантах

Коротка розвилка

Тернарний оператор ? :

через if — шість рядків
let mood; if (health > 1) { mood = 'бадьорий'; } else { mood = 'слабкий'; }
через ? : — один
const mood = health > 1 ? 'бадьорий' : 'слабкий';

умова ? якщо так : якщо ні

Тільки щоб вибрати значення: слово, число, рядок
Не для дій. Нові prompt і розвилки — лише через if

Приклад — стан від початку до кінця
let health = 3; // ... у гілці, що шкодить: health -= 1; // ... у самому кінці гри: if (health <= 0) { alert('Сили скінчились. КІНЕЦЬ'); } else { alert(`ПЕРЕМОГА. Здоровʼя: ${health}`); }
Тепер самостійно — у свій квест
  • Вгорі файлу — let health = 3 (або золото)
  • У дві гілки, що шкодять, — health -= 1 і здоровʼя в alert
  • У кінці — кінцівка за станом: <= 0 поразка, інакше перемога
  • Заміни let на const — прочитай TypeError, поверни
  • ⭐⭐ Перевірка одразу після втрати: на нулі гра далі не питає
  • ⭐⭐⭐ Ключ або золото + прихована кінцівка з &&; настрій героя через ? :

Виправ

Що не введи — «Міст цілий». Чому?

script.js · зламано навмисно
const health = 3; let c1 = prompt('1 — вбрід, 2 — міст'); if (c1 === 1) { health -= 1; alert('Холодно!'); } else if (c1 = '2') { alert('Міст цілий.'); }

Три біди, червоного рядка немає

Знайди всі три, потім клацни

1. c1 === 1 — число, а prompt дав рядок. Ця гілка не спрацює ніколи

2. c1 = '2' — одне =. Це присвоєння, умова завжди істинна

3. const health — полагодиш першу біду, і health -= 1 дасть TypeError. Потрібен let

Діагностика

Шість бід квесту

Завжди else — порівняння з числом 1 замість '1' або пробіл у відповіді
Завжди та сама гілка — одне = в умові
Сторінка мовчить, missing ) after argument list — апостроф у 'здоров'я' закрив рядок. Бери `…`
Unexpected end of input — не вистачає }
Assignment to constant variable — const замість let для стану
Питання не в тій гілці — prompt стоїть за межами потрібних { }
🔦
Гілка не та? console.log('[' + c1 + ']', typeof c1) одразу після prompt покаже і пробіл, і тип.
