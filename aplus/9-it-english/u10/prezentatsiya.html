The syntax of a count-controlled loop

syntax · Python
for variable in range(startvalue, endvalue + 1): code
for — keyword variable — count, x startvalue — the first number endvalue + 1 — where the loop stops : — colon code — indented
1
This is the syntax for programming count-controlled loops in a text-based programming language.
переклад
Це синтаксис запису циклів із лічильником у текстовій мові програмування.
2
In Python, the end value is endvalue + 1, because this is where the loop stops.
переклад
У Python кінцеве значення — endvalue + 1, бо на ньому цикл зупиняється.
3
The code inside the loop is indented. The line ends with a colon.
переклад
Код усередині циклу записано з відступом. Рядок закінчується двокрапкою.

Program

Клацни після листочка.

total = 0 for count in range(0, 10): number = float(input("Enter a number")) total = total + number print(total)

⭐⭐ Which lines are before the loop, inside the loop and after the loop?

total = 0 is before the loop. The input and total = total + number are inside the loop. print(total) is after the loop.

Practice 6 Did it work first time? · one error in each5 хвилин

Кожна програма — задача «20 items», в кожній одна помилка. Знайди рядок і скажи: The error is … It should be …

A
total = 0 for count in range(0, 19): cost = float(input("Enter the cost")) total = total + cost print(total, total / 20)
?

The loop runs 19 times, not 20. It should be range(0, 20).

B
for count in range(0, 20): total = 0 cost = float(input("Enter the cost")) total = total + cost print(total, total / 20)
?

total = 0 is inside the loop, so the total is reset every time. It should be before the loop.

C
total = 0 for count in range(0, 20): cost = input("Enter the cost") total = total + cost print(total, total / 20)
?

input gives a string, so total + cost is an error. It should be float(input(…)).

D
total = 0 for count in range(0, 20): cost = float(input("Enter the cost")) total = total + cost print(total, total / 20)
?

print is indented, so it is inside the loop and outputs 20 times. It should be after the loop.

⭐⭐⭐ An algorithm asks the user how many numbers they want to enter, then loops this number of times, taking a number from the user each time, before it calculates and outputs the average.

Переклади умову вголос. Тоді — програма на листочку.

Підказка: кінцеве значення в range може бути змінною.

Program

Клацни після листочка.

howMany = int(input("How many numbers?")) total = 0 for count in range(0, howMany): number = float(input("Enter a number")) total = total + number print(total / howMany)

The loop runs howMany times — the user decides how many.
