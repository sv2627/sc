Урок · старт · для всіх, у кого немає папки gamestore

У VS Code: нова папка gamestore, у ній два файли — index.html і style.css. Скопіюй у кожен свій блок, Ctrl+S, відкрий index.html у Chrome.

gamestore/index.html — старт 
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>GameStore</title>
  <link rel="stylesheet" href="style.css">   <!-- підключає оформлення -->
</head>
<body>
  <h1>GameStore</h1>
  <p>Магазин настільних ігор. Працюємо щодня з 10:00 до 19:00.</p>

  <h2>Наші ігри</h2>
  <ul>
    <li>Шахи</li>
    <li>Монополія</li>
    <li>Уно</li>
  </ul>

  <h2>Контакти</h2>
  <p>Київ, вулиця Ігрова, 7.</p>
</body>
</html>

3 · gamestore/style.css — після уроку 
/* уся сторінка: фон, шрифт і розмір для всього тексту */
body {
  background-color: lightyellow;
  font-family: Verdana, sans-serif;   /* через кому — запасний шрифт */
}

/* головний заголовок */
h1 {
  color: darkblue;
  font-family: Georgia, serif;        /* свій шрифт — сильніший за body */
  font-size: 48px;                    /* px — впритул до числа */
  text-align: center;                 /* left · center · right · justify */
}

/* підзаголовки */
h2 {
  color: white;
  background-color: darkgreen;
  font-size: 28px;
  font-weight: normal;                /* заголовки жирні самі; normal — тонше */
  text-align: center;
}

/* абзаци */
p {
  color: brown;
  font-size: 18px;
  line-height: 1.5;                   /* без px, з крапкою */
}

/* пункти списку */
li {
  font-size: 20px;
  font-weight: bold;
}
