Навіщо

А чому не просто <br>?

index.html
<p>- хліб<br> - молоко<br> - сир</p>

- хліб
- молоко
- сир

Виглядає як список. Але для браузера це один абзац із рисками
Програма, що читає сторінку вголос, не скаже «список, три пункти». Вона прочитає «мінус хліб»
Справжній список браузер знає: сам ставить крапки чи номери й сам їх перераховує

Нове

<ul> — маркований список

index.html
<ul> <li>хліб</li> <li>молоко</li> <li>сир</li> </ul>
  • хліб
  • молоко
  • сир
ul — unordered list, «невпорядкований список». Обгортка — одна на весь список
li — list item, «пункт». Кожен пункт — свій <li>
Відступ пробілами в коді — для людей, щоб бачити, хто в кого вкладений. Браузер його не помічає
🔢
Нове

<ol> — нумерований список

index.html
<ol> <li>Налити молоко</li> <li>Додати какао</li> <li>Розмішати</li> </ol>
  1. Налити молоко
  2. Додати какао
  3. Розмішати
ol — ordered list, «впорядкований список». Пункти ті самі — <li>
Номери не пишемо руками. Вставили пункт посередині — браузер сам усе перерахує

Як вибрати

Переставили пункти — і зміст зламався? Тоді ol. Нічого не сталось — ul

Вкладений список — список у пункті

index.html

  • Фрукти
    • яблука
    • груші
  • Овочі
Внутрішній список пишеться всередині <li> — після назви пункту, але до </li>
Браузер сам зсуне його праворуч і змінить маркер: ● стає ○
Можна вкладати ul в ol і навпаки. І навіть у три рівні
Де буває: зміст книжки, план, меню з підменю
📍
Головне правило уроку

Куди ставити внутрішній список

Правильно — всередині li
<li>Фрукти <ul> <li>яблука</li> </ul> </li>
Неправильно — поза li
<li>Фрукти</li> <ul> <li>яблука</li> </ul>
🧦
Те саме правило вкладеності з уроку 3. <li>Фрукти відкрився раніше за внутрішній <ul> — значить, закривається пізніше, після </ul>.

Третій вид

<dl> — список «термін — пояснення»

index.html
<dl> <dt>HTML</dt> <dd>мова, якою пишуть сторінки</dd> <dt>браузер</dt> <dd>програма, що їх показує</dd> </dl>
HTML
мова, якою пишуть сторінки
браузер
програма, що їх показує
dl — description list, список описів. Обгортка на весь список
dt — term, термін. dd — description, пояснення. Ідуть парами
Ні крапок, ні номерів. Пояснення браузер зсуває праворуч
Де буває: словник, «питання — відповідь», характеристики телефона в магазині

Рецепт ⭐⭐⭐

Нумерація по-іншому

index.html
<ol type="A"> A, B, C <ol type="a"> a, b, c <ol type="I"> I, II, III <ol start="5"> 5, 6, 7 <ol reversed> 3, 2, 1
Слово всередині тега — як src і href з бонусу уроку 3. Пишеться в відкривному тегу, у закривному — ніколи
type="A" — варіанти відповіді в тесті. reversed — топ-10 з кінця до першого місця
Як це називається і що ще так можна — урок 5

Знайди помилку

Тут їх дві

kakao.html
<h2>Какао</h2> <ol> <li>Налити молоко</li> Додати какао <li>Розмішати</li> <ol> <p>Смачного!</p>

Знайди обидві й скажи, що буде видно

Спершу сам. Клацніть, щоб перевірити.

1. «Додати какао» — без <li>. Рядок буде без номера, а «Розмішати» стане пунктом 2

2. В останньому рядку списку <ol> замість </ol> — загубилась коса риска. Список не закрився, «Смачного!» зсунеться праворуч

Браузер знову мовчить. Помилку видно тільки очима — на сторінці.

Закінчив раніше?

Банк завдань

1. Список «Що взяти в похід» — вісім пунктів
2. Топ-5 улюблених пісень — нумерований
3. Рецепт: кроки — ol, у першому кроці вкладений список продуктів
4. Зміст книжки: три розділи, у кожному два підрозділи
5. ⭐⭐ Список покупок у три рівні: магазин → відділ → товар
6. ⭐⭐ dl «Мої ігри»: назва — про що вона, одним реченням
7. ⭐⭐⭐ Тест на три питання з варіантами type="a", питання починаються з start="4"
8. ⭐⭐⭐ «Карта мого сайту»: вкладений список усіх файлів і папок, які в тебе є
Усі вісім робляться тільки тим, що було сьогодні й раніше. Нічого нового шукати не треба.

nested — вкладений

term — термін. dt
