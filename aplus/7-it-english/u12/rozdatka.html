Two kinds of error

Довідка

Syntax error

The code does not match Python's code rules. The program does not run.
INPUT → input · output → print
no speech marks " " · no comma , · no bracket )

Logic error

The program runs, but it does not do what it is supposed to.
Total = Number1 + Number1
→ Total = Number1 + Number2

Debug · one-by-one

Look at each line of code. Check: the words · the operators · the variables · the speech marks. There might be several errors.
