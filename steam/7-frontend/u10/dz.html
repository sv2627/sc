≈ 10 хвилин. Робимо на сайті codepen.io → новий Pen. Потрібні поля HTML і CSS. Рядок <link> у CodePen не потрібен — поле CSS підключене саме.

Код для копіювання

У поле HTML: 

<header>
  <h1>Світ котів</h1>
</header>
<main>
  <section>
    <h2>Мій кіт</h2>
    <p>Мій кіт <strong>Барсик</strong> спить 16 годин на добу.</p>
  </section>
</main>
<footer>
  <p>© 2026 Світ котів</p>
</footer>

У поле CSS: 

body {
  background-color: #f5f7fa;
  color: #22313f;
}

/* ДОПИШИ ТУТ 1: h2 — колір тексту #2e86de */

/* ДОПИШИ ТУТ 2: footer — фон #22313f, колір тексту #ffffff */

Не копіюється кнопкою? Виділи код пальцем або мишею і скопіюй.

Завдання

  1. Скопіюй обидва блоки у свої поля. Має вийти: фон сторінки майже білий, текст темний.
  2. ДОПИШИ ТУТ 1: під коментарем — правило для h2: властивість color, значення #2e86de. Як правило для body вище: селектор, { }, двокрапка, крапка з комою. Має вийти: заголовок «Мій кіт» — синій.
  3. ДОПИШИ ТУТ 2: правило для footer з двома властивостями — background-color: #22313f; і color: #ffffff;. Має вийти: унизу темна смуга, на ній білий напис «© 2026 Світ котів».

Що надіслати

Натисни Save у CodePen і надішли посилання на свій Pen з адресного рядка. Робив у VS Code — надішли весь код із style.css текстом.
