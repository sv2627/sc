Hierarchy

Сім одиниць, від найменшої

bit0 або 1
nibble4 біти
byte8 бітів
kilobyte1000 B
megabyte1000 KB
gigabyte1000 MB
terabyte1000 GB
Nibble — «шматочок», половина байта. Назву треба знати, хоч у житті її майже не вживають. Від kilobyte і вище правило одне: кожен наступний більший у 1000 разів.
⚖️
Nuance

1000 чи 1024?

kilobyte = 1000 bytes

Рахуємо так. Усі обчислення на уроці й у роздатці — на тисячу

kibibyte = 1024 bytes

Теж правильне значення, і його часто вживають. Просто це інша одиниця, з іншою назвою

Вище за terabyte теж є: petabyte, exabyte. Правило те саме — 1000 терабайтів у петабайті.
🧮
Як рахувати

Угору — ділимо, вниз — множимо

Із більшої одиниці в меншу — × 1000
Із меншої у більшу — ÷ 1000
Через одну сходинку — × 1 000 000

Два приклади

Порахуй, потім клацни.

3 KB → 3 000 bytes

5 GB → 5 000 MB

Решта — у роздатці. Рахувати вміємо; тут важливо назвати дію: convert.

New

Character — рівно один символ

String вміщає скільки завгодно символів. Character — тільки один.

1 Вибір пункту меню на екрані: 1, 2, 3 або a, b, c
2 Коли треба дістати окремий символ рядка або розбити рядок на частини
3 Коли зберігаємо значення, з яким порівнюватимемо ввід
💾
Why bother

Навіщо окремий тип на один символ

saves memory space

string резервує памʼять із запасом, character має fixed memory size

not all languages

Не всі мови мають character. У Python є лише string

🐍
Ми програмуємо на Python — тож character треба знати й уміти назвати, навіть якщо в коді він виглядатиме як рядок довжиною один.

Why types

Навіщо взагалі різні типи

  • щоб не дати ввести хибні дані
  • щоб можна було рахувати те, що є числом
  • щоб обмежити, які дані взагалі приймаються
  • щоб економити памʼять
І окремо, найкоротше формулювання різниці: string зберігає один або більше символів, character — рівно один.
