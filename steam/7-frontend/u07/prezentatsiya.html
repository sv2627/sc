Крок 1 Папка й каркас5 хвилин
Приклад — робимо разом
1. Нова папка pr1, у ній — папка img 2. VS Code → File → Open Folder… → pr1 3. Новий файл index.html → Ctrl+S 4. Каркас — руками: <!DOCTYPE html> <html lang="uk"> <head> <meta charset="UTF-8"> <title>Світ котів</title> </head> <body> </body> </html>
Тепер самостійно
  • Папка pr1 з папкою img — у себе
  • Каркас руками, у <title> — назва своєї теми
  • У <body> — коментар з назвою теми
  • Відкрий index.html у Chrome. Назва на вкладці — твоя? Літери і, ї, є видно?
  • ⭐⭐ Набери каркас, не дивлячись на дошку
  • ⭐⭐⭐ F12 → Elements: що лежить усередині head?
⚡ Швидше <tit → Enter — підказка після > закривний тег — сам Ctrl+/ — коментар
Крок 2 Шапка: header, h1, nav5 хвилин
Приклад — у body
<header> <h1>Світ котів</h1> <nav> <a href="index.html">Головна</a> <a href="https://uk.wikipedia.org" target="_blank">Вікіпедія</a> </nav> </header>
Тепер самостійно — розширюй приклад
  • header з h1 — назва твоєї теми
  • У nav — посилання «Головна» на index.html
  • Ще два посилання на чужі сайти про твою тему — у новій вкладці
  • Ctrl+S → F5, клацни кожне. Твоя сторінка лишилась у вкладці?
  • ⭐⭐ Друга сторінка about.html: каркас копією, посилання туди й назад
  • ⭐⭐⭐ На about.html — та сама шапка з меню
⚡ Швидше адресу — з рядка браузера: Ctrl+L, Ctrl+C схожий рядок — Alt+Shift+↓ у href="" — файл із підказки
Крок 3 Головне: розділ, текст, список7 хвилин
Приклад — після header
<main> <section> <h2>Про котів</h2> <p>Коти сплять <strong>16 годин</strong> на добу.</p> <ul> <li>Мурчать</li> <li>Ловлять мишей</li> </ul> </section> </main>
Тепер самостійно — розширюй приклад
  • main, у ньому section з h2 про твою тему
  • Два абзаци. В одному — strong, в іншому — em
  • Список ul на чотири пункти
  • F12 → Elements: section лежить у main?
  • ⭐⭐ Ще один section: h2 і список ol — три кроки «як…»
  • ⭐⭐⭐ В один пункт списку — вкладений список
⚡ Швидше ще один пункт — Alt+Shift+↓ виділи рядки → Tab — відступ Ctrl+S → F5
Крок 4 Розділ із картинкою6 хвилин
Приклад — у main, другим розділом
1. Картинку з інтернету → у папку img назва латиницею: kit.jpg 2. <section> <h2>Мій улюблений кіт</h2> <img src="img/kit.jpg" alt="Рудий кіт спить" width="400"> </section>
Тепер самостійно — розширюй приклад
  • Картинка твоєї теми — у img, назва латиницею, без пробілів
  • Новий section з h2 і цією картинкою
  • У img — усі три: src, alt, width
  • Зітри одну літеру в src → F5. Видно alt? Поверни літеру
  • ⭐⭐ Під картинкою — абзац-підпис і hr
  • ⭐⭐⭐ Картинка — посилання на сайт про твою тему, у новій вкладці
⚡ Швидше у src="" VS Code сам підказує файли картинка → правий клац → «Зберегти зображення як…»
Крок 5 Новини й підвал6 хвилин
Приклад — кінець main і підвал
<section> <h2>Новини</h2> <article> <h3>Барсик зловив мишу</h3> <p>Сьогодні вранці.</p> </article> </section> </main> <footer> <p>© 2026 Світ котів</p> </footer>
Тепер самостійно — розширюй приклад
  • Останній розділ у main — «Новини» з h2
  • У ньому дві article: у кожної h3 і абзац
  • Після main — footer з «© 2026» і назвою теми
  • F12 → згорни гілки: у body — header, main, footer?
  • ⭐⭐ Третя новина. Одне слово в ній — em
  • ⭐⭐⭐ У footer — ще раз меню, у своєму nav
⚡ Швидше ще одна новина — виділи article → Ctrl+C → Ctrl+V Alt+↑/↓ — перенести рядок

Перевір себе

Шість перевірок — у коді й у F12

1 На вкладці — твоя назва, літери і, ї, є — на місці
2 h1 — один, і він у header
3 main — один. У кожного section — свій h2
4 Картинку видно, у неї є alt
5 Кожне посилання клацається. Чужі сайти — у новій вкладці
6 F12 → згорни гілки: у body — header, main, footer
Усе є? Повернись до сусіда й перевір його екран за цим списком.

Банк завдань — бери будь-яке

Друга сторінка. about.html з тією самою шапкою. Посилання туди й назад
Галерея. Розділ із трьома картинками, у кожної свій alt і width="200"
Інструкція. Розділ «Як…» зі списком ol на п'ять кроків. У кожному кроці — strong
Цікаве поруч. aside з трьома посиланнями на чужі сайти — у новій вкладці
Підписи. Над кожним section — коментар: що в цьому розділі
Вірш. Розділ із віршем або піснею: рядки через br, куплети — окремими p
Справжній сайт. Відкрий uk.wikipedia.org → F12. Знайди там header і footer
