Урок · старт · для всіх, у кого немає папки gamestore

У VS Code: нова папка gamestore, у ній два файли — index.html і style.css. Скопіюй у кожен свій блок, Ctrl+S, відкрий index.html у Chrome.

  <meta charset="UTF-8">

4 · gamestore/style.css — що дописали в кінець 
/* ціни: клас price — крапка перед іменем */
.price {
  color: red;
  font-weight: bold;
  font-size: 20px;
}

/* картки — описи ігор */
.card {
  background-color: white;
  color: black;                       /* клас сильніший за тег p */
}

/* примітки — на будь-якому тезі */
.note {
  color: gray;
  font-style: italic;
}

/* розпродаж — другий клас поруч з price */
.sale {
  background-color: yellow;
}

/* тег + клас: тільки абзаци з класом note */
p.note {
  font-size: 14px;
}
