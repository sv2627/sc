Створити елемент — заповнити — вставити

script.js
const h = document.createElement('h3'); // 1 h.textContent = 'Minecraft'; // 2 h.classList.add('title'); catalog.append(h); // 3
1createElement('h3') — новий елемент у памʼяті: на сторінці його ще немає

createElement · у циклі

Картка з трьох частин

script.js
for (const g of games) { const card = document.createElement('div'); card.classList.add('card'); const h = document.createElement('h3'); h.textContent = g.name; const p = document.createElement('p'); p.classList.add('price'); p.textContent = `${g.price} грн`; card.append(h, p); // дітей — у картку catalog.append(card); // картку — на сторінку }
append приймає кілька елементів через кому — у такому порядку й стануть
Спершу збираємо картку в памʼяті, потім одним append ставимо на сторінку
Довше, ніж innerHTML, але кожен елемент — у змінній: з ним можна працювати далі
🧰
Уся родина

Вставити, переставити, прибрати

ЗаписЩо робить
parent.append(a, b)у кінець батька; можна кілька і навіть рядок
parent.prepend(a)на початок батька
parent.appendChild(a)старший брат append: лише один елемент
el.before(a) · el.after(a)поруч з елементом — перед ним або після
el.remove()прибрати елемент зі сторінки
parent.insertAdjacentHTML('beforeend', '…')як innerHTML +=, але не перемальовує те, що вже є
Елемент, який уже на сторінці, після append переїжджає, а не копіюється
🛡️
innerHTML чи textContent

Чужий текст — лише через textContent

innerHTML — текст стає кодом
const name = prompt('Назва гри?'); catalog.innerHTML += `<h3>${name}</h3>`; // ввели: <img src=x onerror="alert('злам')"> // → на сторінці виконався чужий JavaScript
textContent — текст лишається текстом
const name = prompt('Назва гри?'); const h = document.createElement('h3'); h.textContent = name; catalog.append(h); // на сторінці просто видно <img src=x …>
Свої дані з масиву — innerHTML можна. Те, що ввела людина, — тільки textContent
Так ламають справжні сайти: коментар із «кодом» виконується в кожного, хто його відкрив

Передбач

У якому порядку стануть назви?

#list порожній
function mk(t) { const p = document.createElement('p'); p.textContent = t; return p; } list.append(mk('B')); list.append(mk('C')); list.prepend(mk('A')); list.append('D');

Що на сторінці?

Простеж після кожного рядка, потім клацни

B ← append B C ← append A B C ← prepend — на початок A B C D ← append рядка

A B C D. D — просто текст, без <p>: append приймає й рядок
