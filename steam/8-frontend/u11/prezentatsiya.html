Передбач

Порахуй, потім клацни

width: 250px; padding: 15px; border: 5px solid;

Яка ширина на екрані?

290px = 250 + 15 + 15 + 5 + 5

width: 250px; padding: 15px; border: 5px solid; box-sizing: border-box;

А тепер?

250px. Відступ і рамка — всередині цих 250

body — 1200px завширшки

main { max-width: 800px; margin: 0 auto; }

Скільки по боках?

main — 800px, зліва й справа по 200px

body — 600px завширшки

main { max-width: 800px; margin: 0 auto; }

Яка ширина main?

600px, по боках нуль. max-width — «не ширше», а не «рівно»

Крок 3 Цитата й примітка5 хвилин
Приклад
<p class="quote">Земля — колиска людства.</p> <p class="note">Костянтин Ціолковський</p> .quote { border-left: 5px solid #1b5e20; padding: 10px 20px; font-style: italic; } .note { font-size: 14px; color: gray; text-align: right; }
Тепер самостійно
  • Цитата на свою тему з класом quote: рамка лише зліва, відступи, курсив
  • Під нею примітка note: дрібніше, іншим кольором, праворуч

  • Цитаті — світлий фон і margin-bottom: 20px
  • ⭐⭐ Рамка лише знизу для кожного h2 — border-bottom
  • ⭐⭐⭐ Цитаті дай ще id з іншим кольором рамки. Передбач, хто переможе, — перевір у F12 → Styles

Тепер самостійно

  • Підвал: рамка лише зверху, дрібний текст по центру
  • Шапці — id="top", у підвалі — посилання «Нагору ↑»
  • ⭐⭐ Назва сайту — великими літерами з розрідкою 3px
  • ⭐⭐⭐ Шапка на півекрана: min-height: 50vh. Звуж і розтягни вікно
