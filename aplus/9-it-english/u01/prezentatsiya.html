Check yourself · Звіряємось

1 · Що робить

клікни

2 · Ключові частини

клікни

Два inputs, одне обчислення, один output. Рішень (decisions) тут немає — жодного if.

клікни

Тільки sequence — кроки один за одним, згори вниз. Ні розгалуження, ні повторення.

Три питання, які ви щойно поставили, — робочий інструмент на весь рік. З них починається читання будь-якого чужого алгоритму: що робить · з чого складається · якими прийомами.

Pseudocode · Псевдокод

Що це

Запис алгоритму, який читає людина. Мета — щоб інша людина зрозуміла задум однозначно, ще до того, як обрано мову програмування.

Чим воно НЕ є

  • Не мова програмування — не запускається.
  • Не має єдиного стандарту.
  • Не коментарі: псевдокод пишеться до коду.
🔍
Доказ, що це не Python. У прикладах Cambridge далі трапиться elseif. У Python такого слова немає — там elif. Псевдокод бере від мови вигляд, але не зобов'язаний їй підкорятися: його виконує людина, а не інтерпретатор.

Change the calculation · Зміни обчислення

A · Change it so it multiplies instead of adding

result = number1 + number2

клікніть, коли пари відповіли

result = number1 * number2

B · Subtract the second from the first, then multiply by the first

result = number1 / number2

клікніть, коли пари відповіли

result = (number1 - number2) * number1
🎯
У завданні B дужки обов'язкові. Без них спершу виконається множення — і алгоритм тихо порахує не те. Це logic error: програма не падає, просто відповідь хибна.

Add a branch · Додай гілку

Change this algorithm so that if the user enters the "+" symbol, the two numbers are added together.
було
number1 = input("Enter a number") number2 = input("Enter a number") symbol = input("Enter the symbol") if(symbol == "*"): print(number1 * number2)

Стало

клікніть, коли пари відповіли

if(symbol == "*"): print(number1 * number2) elseif(symbol == "+"): print(number1 + number2)
💬
Питання класу вголос: чому не можна просто написати другий if замість elseif? Тут — можна, результат той самий. Але elseif каже читачеві: це та сама розвилка, а не нова перевірка.

It does not meet the requirements

Вимога до програми:
порахувати середню з трьох оцінок і вивести її.
someone-elses · pseudocode
mark1 = input("Enter mark 1") mark2 = input("Enter mark 2") mark3 = input("Enter mark 3") average = mark1 + mark2 + mark3 / 3 print(average)

У чому проблема?

спершу в парі, тоді клікніть

Ділення виконається раніше за додавання — поділиться тільки mark3. Для оцінок 10, 11, 12 вийде 25 замість 11.

average = (mark1 + mark2 + mark3) / 3
👑
Алгоритм працює — і саме тому помилку важко побачити. Перевіряти треба не «чи запускається», а чи відповідає вимозі.
