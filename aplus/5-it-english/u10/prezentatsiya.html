Read aloud · по черзі

Each variable needs a clear name

Один читає речення англійською — наступний перекладає. Клацни — переклад.

1. Each variable has different information. Кожна змінна має різну інформацію.
2. Each variable needs a clear name. Кожній змінній потрібне зрозуміле імʼя.
3. A clear name says what is in the variable. Зрозуміле імʼя каже, що лежить у змінній.
4. A good name is short. Хороше імʼя — коротке.
