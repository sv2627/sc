1 · KEY WORDS 1.1 · дослівно з книжкис. 9–10

  • analogue data — a continuous stream of data that is processed by humans. Аналогові дані — неперервний потік.
  • digital data — discrete data that only uses the values 0 and 1. Цифрові дані — дискретні, лише два значення.
  • logic gate — a very small component in a computer system that controls the flow of electricity. Логічний вентиль.
  • register — a small component in a computer system that is used to temporarily store data. Регістр — комірка фіксованої довжини.
  • denary — a base-10 number system that only uses the values 0–9. Десяткова система. На іспиті пишемо denary, не decimal.
  • binary — a base-2 number system that uses the values 0 and 1. Двійкова система.
  • hexadecimal — a base-16 number system that uses the values 0–9 and characters A–F. Шістнадцяткова система.
  • MAC address — a unique address that is given to a computer at the manufacturing stage that can be used to identify the computer. Унікальна адреса пристрою.

3 · KEY WORDS 1.3 · дослівно з книжкис. 21–24

  • character set — it contains all the characters that are in that character set and the binary value that is assigned to each character. Набір символів.
  • pixel — a very small dot of colour that is displayed with many others to create an image. Піксель.
  • resolution — the dimensions of an image. Роздільність — розміри в пікселях.
  • metadata — additional data that is stored with an image that can provide information such as the dimensions of the image and the time and date the image was taken. Дані про самі дані.
  • colour depth — the number of bits that are used to create each colour in an image. Глибина кольору.
  • sound sampling — a little piece of sound that is recorded at regular time intervals. Дискретизація звуку.
  • sample rate — the number of samples recorded each second. Як часто вимірюємо.
  • sample resolution — the number of bits that are used to record each sound sample. Скільки бітів на один вимір.

7 · Questions and answers · Питання й базові відповіді

1. Explain why data needs to be converted to binary to be processed by a computer.
The components that process data are made of logic gates. They cannot process analogue data, only digital data.
2. What is the largest denary number that can be created with a 4-bit binary number?
15.
3. … with an 8-bit binary number? And with a 16-bit register?
255, and 65535. The largest number is always one less than the power of two.
4. Convert the denary number 150 to an 8-bit binary number.
10010110 (128 + 16 + 4 + 2). An even number always ends in 0.
5. Why is hexadecimal used in computer science?
It is a shorter way of representing binary, so it takes up less space · it is easier for a programmer to read, write and understand · it is easier to debug and locate errors in data.
6. Provide examples of the use of hexadecimal.
CSS colours such as #ff7fa0 · MAC addresses · error codes · memory addresses.
7. Why are A–F used for the denary numbers 10–15?
So that only one symbol is needed for the denary number in hexadecimal.
8. Describe what happens in a logical binary shift.
The bit at the end moves out of the register and is lost · the empty place is filled with a zero · a shift left multiplies the value by 2, a shift right divides it by 2.
9. What is an overflow error?
A type of error that occurs when a number larger than a register can store is generated.
10. How do you write −35 in binary?
Write 35 (00100011), invert every bit, then add 1 → 11011101. This is two’s complement.
11. What is a character set, and what are the two main types?
It contains all the characters in that set and the binary value assigned to each character. The two main types are ASCII and Unicode.
12. How many characters can ASCII and Unicode represent?
ASCII uses 8 bits → 256 characters (0 to 255). Unicode uses 16 bits → approximately 65 000.
13. Why was Unicode invented?
Some languages have an alphabet that requires more than 256 characters, and symbols such as emojis are also needed.
14. The letter A is 01000001. What is that in denary?
65.
15. How is a black-and-white image stored?
The image is made of pixels. The value 1 could represent black and 0 white, so the image is a long line of bits. The computer also needs the resolution and the metadata.
16. What is metadata?
Additional data stored with an image, such as the dimensions and the time and date the image was taken.
17. What happens to quality when colour depth is reduced?
If the colour depth of an image is reduced, the quality of the image is often reduced.
18. What makes the file size larger?
Increasing the resolution · increasing the colour depth · increasing the sample rate · increasing the sample resolution. All of them mean more data must be stored.
19. Why does a played-back sound wave differ from the original?
The number of samples taken is too far apart, so vital data in between the time samples has been lost.
20. What is the difference between sample rate and sample resolution?
Sample rate is how often we measure the wave (in hertz; 44.1 kHz = 44 100 samples per second). Sample resolution is how many bits record each sample (commonly 16-bit).
