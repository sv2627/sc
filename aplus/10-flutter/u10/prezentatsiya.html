Приклад — і самостійно: кнопки «-1» і Reset

Приклад · новий метод і кнопка

Тепер самостійно
  • Додай метод і кнопку -1: тричі +, двічі -1 → 1
  • Зламай: напиши onPressed: _decrementCounter() з дужками, прочитай помилку, поверни
  • ⭐⭐  Метод _resetCounter і кнопка Reset → 0
  • ⭐⭐⭐  Не нижче нуля: у setState — if (_counter > 0). Чотири рази -1 з 3 → 0

Пастки

Найчастіші проблеми

1Змінив код — і нічого. Не натиснув Reload або Run
2Без setState — число міняється, екран ні
3Text(_counter) — Text бере лише рядок: Text('$_counter')
4onPressed: _reset() з дужками — помилка type of 'void'. Треба без дужок: onPressed: _reset
5const Text('$_counter') — const не буває зі змінною. Прибери const
6Забута кома між віджетами в children — червоне підкреслення на наступному рядку
