class _MyHomePageState extends State<MyHomePage> { int _counter = 0; // стан: число на екрані void _incrementCounter() { setState(() { _counter++; // змінили і перемалювали }); } @override Widget build(BuildContext context) { return Scaffold( appBar: AppBar(title: Text(widget.title)), body: Center( child: Column(mainAxisAlignment: .center, children: [ const Text('You have pushed the button this many times:'), Text('$_counter'), ]), ), floatingActionButton: FloatingActionButton( onPressed: _incrementCounter, child: const Icon(Icons.add), ), ); } }
Стан — поле _counter. Підкреслення: «тільки для цього класу»
setState — «дані змінились, перемалюй». Без нього число росте, а екран стоїть
onPressed: _incrementCounter — без дужок: передаємо метод, а не викликаємо

Приклад — і самостійно: з «+» зроби «+ і −»

Приклад · уже є в DartPad
void _incrementCounter() { setState(() { _counter++; }); } // ... floatingActionButton: FloatingActionButton( onPressed: _incrementCounter, child: const Icon(Icons.add), ),
Тепер самостійно · dartpad.dev/?sample=counter
  • Метод _decrement(): −1, але не нижче 0
  • Під числом Row із двома ElevatedButton: Icons.remove і Icons.add
  • Пʼять разів +, сім разів − → 0, не -2
  • Зламай: onPressed: _decrement() з дужками — прочитай помилку, поверни
  • ⭐⭐ На нулі − сіра: onPressed: _counter > 0 ? _decrement : null
  • ⭐⭐ Кругла кнопка — _reset() з Icons.refresh, знову 0
  • ⭐⭐⭐ Над числом Count:, число — displayMedium, свій colorSchemeSeed

Практика 2 · перевір себе

Плейлист: що має бути на екрані

Тричі ▶

Спершу сам, потім клацни.

Video 4 / 4 Wrap 1 min Last video

▶ сіра: _index = 3 = videos.length - 1

«Зламай»

Що каже червоний екран?

RangeError (index): Index out of range: index should be less than 4: 4

Елемента з номером 4 немає — номери від 0 до 3

⭐⭐⭐ По колу

З четвертого — куди?

_index = (_index + 1) % videos.length;

(3 + 1) % 4 = 0 — знову перше. Хвилини: 2 + 1 + 1 + 1 = 5

Плейлист — це той самий лічильник: число стало номером у списку. Залишилось замість назви поставити справжній плеєр

int _index = 0; late final YoutubePlayerController _controller; // пульт @override void initState() { // один раз, коли екран зʼявився super.initState(); _controller = YoutubePlayerController.fromVideoId( videoId: videos[_index].id, // 'lHhRhPV--G0' autoPlay: false, ); } @override void dispose() { // екран зник — пульт закрити _controller.close(); super.dispose(); } void _show(int i) { setState(() { _index = i; }); _controller.loadVideoById(videoId: videos[i].id); } // у children, замість Text(назва): YoutubePlayer(controller: _controller),

Банк завдань · для тих, хто закінчив

Ще вісім доробок

1. Лічильник: кнопки -5 і +5; «−5» з 3 дає 0, а не -2
2. Лічильник: не більше 10, на 10 — + сіра і напис Max
3. Лічильник: колір числа — червоний на 0, зелений на 10 (style: TextStyle(color: …))
4. Плейлист: Icons.first_page — одразу на перше відео
5. Плейлист: Left: 3 min — хвилини від поточного відео до кінця (на другому — 3)
6. Плейлист: під назвою Next: Spacer — назва наступного відео, на останньому — End
7. Плейлист: пʼяте відео — свій Video у список; шапка сама стане / 5
8. Плейлист: Icons.shuffle — випадкове відео: Random().nextInt(videos.length) з dart:math

Найчастіші проблеми
