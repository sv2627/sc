Binary search · steps

Compare with the middle number

Ряд чисел у порядку ascending. Шукаємо одне число і його position.

1 Compare the number with the middle number. Equal? — found.
2 Not equal and less than the middle number → select the numbers to the left.
3 Not equal and greater than the middle number → select the numbers to the right.
4 Discard the remaining numbers.
5 Repeat until the number is found or until there are no elements left.

Compare · 9CT.08

Two searching algorithms, one task

linear search

Checks each item in turn, starting with the first item, until the item is found or all items have been searched. Порядок не потрібен.

binary search

Compares with the middle item and discards the remaining items. The data needs to be in an order.

Why are searching algorithms important?

Клацни.

They allow particular data items to be found in a collection of data.

Why are there multiple searching algorithms?

Клацни.

Different algorithms are more appropriate in different scenarios.

A linear search in a dictionary — practical?

Клацни.

No. Довелося б перевірити кожне слово, починаючи з першого.
