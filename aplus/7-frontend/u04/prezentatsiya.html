Проблема

П'ять карток у Flexbox — і останній ряд пливе

Flexbox · 4 і 5 розтяглись ширше за решту

12 345

Grid · колонки рівні в кожному ряду

Flexbox розкладає ряд і кожен ряд рахує окремо. Він не знає, що під першим рядом є другий. Тому колонки не збігаються.

Слова сітки

Контейнер, елементи, доріжки

елементелементелемент елементкоміркаелемент

рамка навколо — контейнер · 3 колонки · 2 рядки

Контейнер — батьківський блок. На ньому пишемо display: grid і все про сітку
Елементи — його прямі діти. Самі стають у комірки, нічого їм писати не треба
Доріжка (track) — колонка або рядок. Проміжок (gap) — відстань між доріжками
1️⃣
Крок 1

display: grid — батькові, не дитині

Так
<div class="gallery"> <div class="card">…</div> <div class="card">…</div> </div> .gallery { display: grid; }
Не так
<div class="gallery"> <div class="card">…</div> <div class="card">…</div> </div> .card { display: grid; }
Сітка розкладає дітей того блока, якому її поставили. .card { display: grid } розкладе вміст усередині картки, а самі картки лишаться стовпчиком.
2️⃣
Крок 2

grid-template-columns — скільки колонок і яких

.gallery { display: grid; grid-template-columns: 200px 200px 200px; }
Скільки значень — стільки колонок. Три числа через пробіл — три колонки по 200 точок
Шість карток самі стали 3 × 2: коли колонки закінчились, сітка почала новий рядок

Крок 3

gap — проміжок між доріжками

.gallery { display: grid; grid-template-columns: 200px 200px 200px; gap: 20px; }
123 456
gap: 20px — однаково між рядками й між колонками
gap: 30px 10px — два значення: спершу рядки, потім колонки
row-gap і column-gap — те саме окремими правилами
margin на картках більше не потрібен. Ззовні сітки gap відступу не дає — лише між картками
Практика 1 Перша сітка 3 × 27 хвилин
Приклад — розбираємо разом
.gallery { display: grid; grid-template-columns: 200px 200px 200px; gap: 20px; }
Тепер самостійно
  • Загорнути свої картки з 6 класу в <div class="gallery"> і набрати приклад
  • Карток менше шести? Дописати до шести — скопіювати й змінити текст
  • Зробити 4 колонки замість трьох. Скільки тепер рядків?
  • Прибрати display: grid і подивитись, що сталось. Повернути
  • ⭐⭐ Поставити row-gap: 40px і column-gap: 10px. Потім записати те саме одним gap
  • ⭐⭐⭐ Перенести display: grid на .card і пояснити сусідові, чому сітка зникла
🤔
Передбач

Скільки рядків? Скільки карток в останньому?

.gallery { display: grid; grid-template-columns: 100px 100px 100px 100px; gap: 10px; } /* у .gallery лежить 10 карток */

Намалюй на аркуші, потім клацни.

1234 5678 910

4 колонки — бо чотири значення. 3 рядки: 4 + 4 + 2. В останньому — дві картки, решта комірок порожня

Рядки ніхто не задавав — сітка створила їх сама.

Тягнемо вікно

200px не стискаються. А відсотки?

grid-template-columns: 200px 200px 200px;
Вузьке вікно — три по 200 не влазять. Горизонтальна прокрутка, як на уроці 3
grid-template-columns: 33% 33% 33%; gap: 20px;
33 + 33 + 33 = 99 %. Плюс два проміжки по 20px — разом більше за 100 %. Знову вилазить

Нова одиниця

fr — частка вільного місця

grid-template-columns: 1fr 1fr 1fr; gap: 20px;
1fr1fr1fr
grid-template-columns: 2fr 1fr;
2fr1fr
fr = fraction, «частка». Браузер спершу віднімає проміжки, а решту ділить на частки
Рахуємо: контейнер 900px, два проміжки по 20px → лишилось 860px. Три частки → по ≈287px
2fr 1fr — перша колонка удвічі ширша за другу. Разом три частки
Потягни вікно — колонки стискаються і ніколи не вилазять за край

Уся родина

П'ять видів значень для колонки

ЗначенняЩо означаєКоли брати
200pxрівно 200 точок, завждибічна колонка, меню збоку
25%чверть ширини контейнерарідко: з gap легко вилізти
1frчастка того, що лишилоськартки — майже завжди
autoстільки, скільки займає вмістколонка з кнопкою чи іконкою
repeat(3, 1fr)скорочення: 1fr 1fr 1frбагато однакових колонок
Їх можна змішувати: grid-template-columns: 250px 1fr; — бічна колонка стоїть намертво, а решту місця забирає контент.
🔁
Скорочення

repeat() — не переписувати одне й те саме

Довго
grid-template-columns: 1fr 1fr 1fr 1fr 1fr 1fr;
Коротко — те саме
grid-template-columns: repeat(6, 1fr);
repeat(скільки, що) — перше число каже, скільки разів, друге — яку колонку
repeat(2, 1fr 2fr) повторює пару: 1fr 2fr 1fr 2fr
✂️
Змішувати теж можна: 200px repeat(3, 1fr) — одна фіксована колонка і три гнучкі.
Практика 2 fr і repeat()8 хвилин
Приклад — розбираємо разом
.gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }
Тепер самостійно
  • Замінити 200px на repeat(3, 1fr). Потягнути вікно — що змінилось?
  • Поставити 33% 33% 33% і gap: 20px. Знайти, де з'явилась прокрутка. Повернути fr
  • Зробити першу колонку вдвічі ширшою за інші
  • Зробити 250px 1fr — «бічна колонка + контент». Потягнути вікно: хто стискається?
  • ⭐⭐ Поставити колонку auto і покласти в неї довге слово. Подивитись, як вона росте
  • ⭐⭐⭐ Записати 1fr 2fr 1fr 2fr через repeat — одним коротким рядком
↕️
Друга вісь

grid-template-rows — висота рядків

.gallery { display: grid; grid-template-columns: repeat(3, 1fr); grid-template-rows: 150px 250px; gap: 20px; }
150150150 250250250
Те саме, що з колонками: скільки значень — стільки рядків. Перший 150, другий 250
Не задали — висота рядка за вмістом найвищої картки. Для галереї найчастіше так і лишають
Рядки, які сітка створює сама, налаштовує grid-auto-rows: 200px — усі нові рядки однакові

Передбач

Порахуй ширину кожної колонки

/* ширина .gallery — 900px */ .gallery { display: grid; grid-template-columns: 200px 1fr 1fr; gap: 20px; }
Порядок: спершу px, потім проміжки, те, що лишилось, — ділимо на fr

Відповідь

Порахуй на аркуші, потім клацни.

900 − 200 = 700

700 − 20 − 20 = 660 лишилось

660 ÷ 2 частки = 330

Колонки: 200 · 330 · 330

Перевірка в DevTools: навести на контейнер — Chrome покаже ті самі числа.
