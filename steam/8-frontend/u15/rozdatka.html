Блочні

з нового рядка, на всю ширину

width, height працюють

Рядкові

a strong em span

у рядку з текстом, ширина за вмістом

display: block — зробити блочним

Обгортка

.container {

  max-width: 1000px; margin: 0 auto;

  padding: 0 16px; }
