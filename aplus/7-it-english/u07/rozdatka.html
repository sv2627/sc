4 · Знайди помилку★★

У кожній схемі одна помилка. Напиши, що не так і як виправити.

а) Має перемножити два числа:

INPUT number1 → INPUT number2 → result = number1 / number2 → OUTPUT result

б) Має вивести Hello, потім Goodbye (Run Me First — OUTPUT "Hello", Run Me Second — OUTPUT "Goodbye"):

main: START → Run Me Second → Run Me First → STOP

5 · Своя схема★★★

Намалюй схему: на вхід два числа. Якщо вони однакові — OUTPUT "Same". Якщо різні — вивести більше з двох. Перевір: START і STOP, паралелограми, у кожного ромба дві стрілки true / false.
