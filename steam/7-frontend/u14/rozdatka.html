Довідка

Одиниці

px — точка екрана · % — від батька

rem — від шрифту сторінки, 1rem = 16px

vw / vh — 1% ширини / висоти вікна

Ширина й центр

max-width: 900px; — не ширше за

margin: 0 auto; — блок посередині

text-align: center; — текст посередині

Коробка

ширина = border + padding + width + padding + border

* { box-sizing: border-box; } — width уже разом із ними

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
