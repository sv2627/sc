⭐ Рівень 1 Додає
Каркас
function calculate() { const x = Number(aInput.value); const y = Number(bInput.value); // показати суму в result } calcBtn.addEventListener( 'click', calculate);
Кроки
  • Набери каркас. У calculate — console.log(x, y): числа приходять?
  • Замість Console — у result.textContent: `${x} + ${y} = ${x + y}`
  • Перевір: 3 і 4 дають 7, а не 34
  • На початку функції: хоч одне поле порожнє — «Введи обидва числа» і return
  • F12 → Console: жодного червоного рядка
⭐⭐ Рівень 2 Чотири дії і червона рамка
Приклад — вибір дії
const sign = op.value; let res; if (sign === '+') { res = x + y; } else if (sign === '-') { res = x - y; } // … ще дві гілки
Кроки
  • Чотири гілки: '+', '-', '*', '/' — у результаті знак із sign: «12 * 3 = 36»
  • Порожнє поле — classList.add('error'); заповнене — remove('error')
  • Ділення на 0 — «На нуль ділити не можна», рамка на другому полі
  • 10 / 3 — два знаки: Number(res.toFixed(2)) → 3.33, а 10 / 4 → 2.5
  • Зміни дію в списку і натисни кнопку — результат інший?
⭐⭐⭐ Рівень 3 Історія і живий перерахунок
Кроки
  • Кнопка «Порахувати» — новий <li> з рядком обчислення в #hist: createElement з уроку 18. Нове — зверху: hist.prepend(li)
  • Помилка вводу — у історію нічого не пишемо
  • «Очистити»: обидва поля '', рамки прибрати, результат «—», історія порожня: hist.innerHTML = ''
  • Поля слухають 'input', список — 'change': результат міняється сам, без кнопки
  • Живий перерахунок не пише в історію — лише кнопка. Як розвести — на наступному слайді

Діагностика

Шість бід калькулятора

3 + 4 = 34 — поля лишились рядками. Number() на кожне
Порожні поля — «0 + 0 = 0» — Number('') дає 0. Перевір '' до Number
Кнопка мовчить, червоного немає — calculate() з дужками в addEventListener або знайдено не ту кнопку
TypeError … of null — адреса в querySelector з помилкою або <script> не в кінці body
«12 × 3 = undefined» — порівнюєш із текстом пункту '×', а op.value — '*'
Рамка не зникає — add('error') є, а remove('error') немає
🔦
Число не те — console.log('x =', x, 'y =', y, 'sign =', sign) на початку обробника: видно, що прийшло.
