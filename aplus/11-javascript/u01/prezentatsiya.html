Чому саме там

Скрипт — у кінці <body>

Браузер читає документ зверху вниз. Якщо <script> стоїть у <head>, то на момент виконання коду <h1> ще не існує.

Скрипт угорі

Код виконався → елементів ще немає → у III періоді це дасть null і «Cannot read properties of null».

Скрипт унизу

Розмітка вже прочитана → елементи існують → код працює. Це наш варіант на весь рік.

📅Сьогодні різниці ще не видно — ми нічого на сторінці не шукаємо. У січні буде видно дуже. Звичку ставимо зараз, поки вона нічого не коштує.

Друга половина уроку

Три покоління одного рядка

старий запис · до 2015
var game = 'Hades II'; var price = 499;
сучасний запис
const game = 'Hades II'; let price = 499;
У старих прикладах в інтернеті ви будете бачити var постійно. Він працює — але ми пишемо const і let, і на наступному слайді буде видно чому.
🔒
Нове в коді

let і const

let — значення може змінитись

let score = 0; score = 10; // можна

const — привʼязка назавжди

const shop = 'GameStore'; shop = 'Inshyi'; // TypeError
📌Правило на весь рік: починайте з const. Міняйте на let тільки тоді, коли справді треба перезаписати. Так «випадковий перезапис» стає помилкою одразу, а не тихим неправильним результатом через 40 рядків.
🔬
Чому не var

Що виведе останній рядок?

var
var x = 1; { var x = 2; } console.log(x);
let
let y = 1; { let y = 2; } console.log(y);

Обидва. Клац — перевіримо

Console1
var не бачить фігурних дужок і затирає зовнішню змінну. let живе тільки всередині свого блоку. Ось чому var ми не пишемо.

Знаки

  • + - * / — як у математиці
  • % — остача: 7 % 2 дає 1
  • ** — степінь: 2 ** 10 дає 1024
🟰Спершу рахується права частина, потім результат кладеться в ліву. % знадобиться вже у II періоді — «парне чи непарне».

Читаємо помилки

Чотири написи, які варто впізнавати

1
SyntaxError — помилка запису. Дужка, лапка, кома. Код не запустився взагалі
2
ReferenceError: x is not defined — такої змінної немає. Найчастіше друкарська помилка в назві
3
TypeError — зробили зі значенням те, чого воно не вміє. Наприклад, перезаписали const
4
NaN — не помилка, а результат. «Not a Number»: рахували з тим, що числом не є
Перші три зупиняють код. Четвертий — ні, і саме тому він найпідступніший: програма дійде до кінця й покаже вам беззмістовний результат.
🧪
