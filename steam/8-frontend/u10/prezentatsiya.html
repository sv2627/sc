244px = 200 + 20 + 20 + 2 + 2

width: 200px; padding: 20px; border: 2px solid; box-sizing: border-box;

А тепер?

200px. Сказав 200 — буде 200

Фон картки заливає padding чи margin?

Крок 1 Підключення і кольори6 хвилин
Приклад
<link rel="stylesheet" href="css/style.css"> body { background-color: #f4f9f4; color: #212121; } h1, h2 { color: #1b5e20; }
Тепер самостійно — на своїй сторінці
  • Перевір <link> у <head>: зміни колір фону — сторінка змінилась?
  • Три кольори своєї теми: фон · текст · акцент. Підбирай піпеткою
  • h1, h2 — акцентом, одним правилом через кому
  • Свій фон для header і footer. Текст на ньому читається?
  • ⭐⭐ Темна тема: поміняй місцями фон і текст у body. Що ще довелось змінити?
  • ⭐⭐⭐ F12 → клац на <h2> → Styles: з якого рядка style.css його колір?
⚡
back → Enter → background-color:. Квадратик біля кольору → піпетка
Крок 2 Шрифти, текст, меню6 хвилин
Приклад
body { font-family: Arial, sans-serif; line-height: 1.6; } h1 { font-size: 40px; text-align: center; } nav a { color: white; text-decoration: none; font-weight: bold; }
Тепер самостійно
  • Шрифт із запасним і line-height — для всієї сторінки, у body
  • h1 більший і по центру, h2 — свій розмір
  • Меню: без підкреслення, жирне, колір із палітри
  • Підвал: дрібніше й курсивом — footer p
  • ⭐⭐ Меню великими літерами з розрідкою 1px
  • ⭐⭐⭐ Google-шрифт із кирилицею — для заголовків
⚡
text-d → Enter, після : — none зі списку. Забув назву — Ctrl+␣
Крок 3 Класи, id і меню на розділи6 хвилин
Приклад
<article class="card hot"> .card { background-color: #e8f5e9; } .hot { color: red; } <section id="facts"> <a href="#facts">Факти</a>
Тепер самостійно
  • Кожній article — клас card. Немає карток — зроби три: h3 і p
  • .card: свій фон. Одній картці — ще клас hot з іншим кольором
  • Кожній секції — id латиницею. Меню веде на них через #
  • html { scroll-behavior: smooth; } — звуж вікно й клацни меню
  • ⭐⭐ id="top" на шапці, у підвалі — «Нагору ↑»
  • ⭐⭐⭐ Абзацу дай і клас, і id з різними кольорами. Хто переміг?
⚡
У тезі пробіл → cla → Enter. Меню не веде? Порівняй href="#…" і id="…" — Ctrl+F
Крок 4 Коробка й центр6 хвилин
Приклад
* { box-sizing: border-box; } .card { padding: 16px; border: 2px solid #1b5e20; border-radius: 12px; box-shadow: 0 4px 10px gray; } main { max-width: 800px; margin: 0 auto; }
Тепер самостійно
  • Першим рядком style.css — правило для *
  • Картки: відступ усередині, рамка, кути, тінь, margin-bottom
  • main — не ширше за 800px і по центру. Звуж вікно: прокрутки вбік немає?
  • Картинкам — max-width: 100%
  • ⭐⭐ Меню-кнопки: nav a — padding: 8px 16px, фон, заокруглені кути
  • ⭐⭐⭐ F12 → Ctrl+Shift+M — вигляд телефона. Усе читається?
