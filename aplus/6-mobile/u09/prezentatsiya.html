Нове · блок Text

join — склеює тексти

Blocks → Built-in → Text → join (червоний)

when Button1.Click do
set Label2.Text to join "Привіт, " TextBox1.Text
join склеює по черзі: спершу верхнє гніздо, потім нижнє. Ввели Оля → на екрані Привіт, Оля
Пробіл — теж знак. "Привіт, " — з пробілом після коми, інакше вийде Привіт,Оля

Потрібно три шматки?

Клац по синій шестерні на join → перетягни ще один string у join → з'явиться третє гніздо.

join "Привіт, " TextBox1.Text "!"

→ Привіт, Оля!

🤔

Якщо щось пішло не так

Шість бід і як їх полагодити

«Привіт,Оля» — злиплося — у блоці тексту немає пробілу: "Привіт, "
На екрані слово «TextBox1.Text» — назву вписали в червоний блок. Потрібен зелений із шухляди TextBox1
У полі на старті «Hint for TextBox1» — заміни Hint на свою підказку
Тільки «Привіт, » без імені — у поле нічого не ввели перед натисканням
Не знайду join і length — Built-in → Text, червоні блоки
У join лише два гнізда — синя шестерня → перетягни string у join
