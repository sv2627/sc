Презентації для дошки. Ця папка = **публічний** репозиторій `sv2627.github.io`.

## Навігація: чотири рівні

Відкриваєш головну — і заглиблюєшся кліками, нічого не треба пам'ятати:

```
Головна            →  A+   або   STEAM
   ↓
Школа              →  8 клас · Git, GitHub та публікація проєктів
   ↓
Курс               →  Урок 1 · Навіщо потрібен контроль версій   (01.09.2026)
   ↓
Урок               →  Презентація
```

Готові уроки — активні посилання, решта в списку сірі. Видно одразу, що зроблено.

**Правило назв:** папка курсу — `<клас>-<курс>`, папка уроку — `u01`…`u35`, усередині
`prezentatsiya.html`. Тільки латиниця, без пробілів — кирилиця в URL перетворюється
на `%D0%92%D1%81…`.

**Конспекти вчителя — в окремому приватному репозиторії `2026-27-teacher`**, зі
дзеркальною структурою: `steam/<курс>/uNN/konspekt.md`. Причина: там інтерпретація
діагностики — хто в «ядрі», кому давати ⭐⭐⭐, кому створювати акаунти. Учням цього
бачити не треба.

Щоб додати урок: створити `steam/<курс>/uNN/prezentatsiya.html`, дописати номер у
`ready` в генераторі — і сторінка уроку з'явиться в списку.

## Конспект вчителя — репозиторій `2026-27-teacher`

Обов'язковий до кожної презентації, структура однакова:

1. Шапка — курс, клас, дата, тривалість, попередження
2. **Хронометраж** — таблиця хвилин по слайдах, із позначкою, який слайд різати першим

| IT-англійська 10 | plum `#602857` |

**Контраст у світлій темі** — дзеркало правила з `grades/CLAUDE.md` (там воно написане для
темної): основний текст ≥7:1, вторинний ≥4.5:1 до фону. `--pink` і `--orange` — **тільки
заливки й рамки, ніколи не текст**. Блоки коду теж світлі (`#fdf9f9`) — так вони не
з'їдають тонер при друці на A4.

⚠️ `grades/CLAUDE.md` описує контраст лише для темної теми (мінімум `#cbd5e1`). Для A+
діє правило вище. Варто дописати його туди окремим розділом.

Технічні правила — у **`grades/CLAUDE.md`**, обов'язкові: базовий шрифт ≥18px, `pre`/`code`
≥16px, `h2` ≥2rem, текст не темніший за `#cbd5e1`, ≤16 рядків коду в блоці, і **повний блок
`@media print`** — без нього друкується тільки перший слайд.

Додатково для інтерактивних дошок: кнопки ≥48px, тап-зони по краях екрана (9% ширини),
свайп із відсіканням вертикальних жестів, **fallback-стек шрифтів** на випадок, якщо
Google Fonts не завантажаться.

## Публікація на GitHub Pages

Репозиторій — **[sv2627/sc](https://github.com/sv2627/sc)**, публічний.
Адреса сайту: **https://sv2627.github.io/sc/**

Це *project pages*, тобто сайт лежить у підпапці `/sc/`. Усі посилання в навігації
відносні (`steam/`, `../`, `u01/`), тому підпапка нічого не ламає — перевірено.

```bash
cd 2026-27
git init -b main
git add .
git commit -m "Матеріали 2026/27: урок 1, п'ять курсів STEAM"
git remote add origin git@github.com:sv2627/sc.git
git push -u origin main
```

Далі один раз у браузері: **Settings → Pages → Source: Deploy from a branch → main → / (root)**.
Через ~1 хвилину сайт живий. Наступні оновлення — просто `git push`.

Приклад адреси уроку:
`https://sv2627.github.io/sc/steam/8-git/u01/prezentatsiya.html`

**Що врахувати:**

- Репозиторій **публічний** — Pages з приватного потребує платного тарифу.
  Тому сюди йдуть **тільки презентації**. Ключі до тестів, варіанти й діагностичні
  аркуші лишаються в `office/` і `grades/` — вони не публікуються
- Конспекти вчителя — окремий приватний репозиторій `2026-27-teacher`
- Локальна копія лишається робочою завжди: впав інтернет — відкриваєш `index.html`
  з диска, навігація працює так само
