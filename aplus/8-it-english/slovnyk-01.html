3 · Phrases · Фрази, які ми казали на уроці

  • There is no defined pseudocode that everyone uses. Єдиного псевдокоду, яким користуються всі, не існує.
  • Pseudocode is language independent — anyone should be able to understand it. Псевдокод не залежить від мови програмування — зрозуміти має будь-хто.
  • First I predict the outcome. Then I follow the algorithm. Then I test my prediction. Спершу передбачаю результат. Тоді проходжу алгоритм. Тоді перевіряю передбачення.
  • The three algorithms have five similarities. У трьох алгоритмів п'ять спільних рис.
  • A command word shows what the algorithm does. Командне слово показує, що робить алгоритм.
  • This step is not precise because… Цей крок не точний, тому що… (наш зразок речення)
  • This algorithm outputs the smaller number. Цей алгоритм виводить менше число.
  • selection: an instruction within an algorithm where a decision is made about whether to run a piece of code or not Означення зі схеми, дослівно.
  • Selection is written as a question, or a comparison, that results in true or false. Розгалуження записують як питання або порівняння, яке дає true або false.

4 · Questions and answers · Питання й базові відповіді

1. What is pseudocode?
A form of representing an algorithm without a set syntax.
2. When is it used?
When planning or designing algorithms.
3. Why is it used?
It is language independent — anyone should be able to understand it.
4. What features does it contain?
Command words, assignment symbols, mathematical symbols.
5. What is pseudocode not?
Not a programming language · it does not run · there is no single standard · it is not comments — it is written before the code.
6. What are the four requirements?
short · clear · precise · start and end clearly shown.
7. Name three valid command words for input.
input · enter · read from user (also type data · read line).
8. What is the difference between a syntax error and a logic error?
A syntax error is seen at once. With a logic error the program runs, but the answer is wrong.
9. Your prediction was wrong. What are the two possible reasons?
A prediction error — I read it carelessly. Or an algorithm error — the algorithm does the wrong thing.
10. What is the order of work with someone else’s algorithm?
read · predict · follow · compare.
11. What is selection?
An instruction within an algorithm where a decision is made about whether to run a piece of code or not.
12. How is selection usually written?
As a question, or a comparison, that results in true or false.
13. What do IF, THEN and ELSE mean?
After IF comes the condition. After THEN, the code that runs if it is true. After ELSE, the code that runs if it is false.
14. What are the three parts of a conditional statement?
1 the condition · 2 the code to run if true · 3 the code to run if false.
15. What is the format of a pseudocode conditional statement?
if condition: … else: … The colon is needed, and the code inside is indented.
16. What does indentation show?
What belongs to which branch. A line with no indentation runs every time.
17. mark > 50. Anna has 50, Borys has 51. What is the output?
Anna → "Try again", because 50 > 50 is false. Borys → "Pass". With >= Anna would pass too.
18. Is there one correct pseudocode?
No. The same algorithm can be written in several ways and all of them are correct. That is why following it matters more than learning one form.
