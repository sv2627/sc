Four questions

Sub-routines: what, when, why

What is a sub-routine?

Скажи вголос, потім клацни.

An independent or separate algorithm, that has a name, and can be called from other parts of an algorithm.

What does a sub-routine do?

Скажи вголос, потім клацни.

It runs its steps and then returns control to the algorithm that called it.

When are sub-routines used?

Скажи вголос, потім клацни.

When the same series of steps might need to run more than once.

Why are sub-routines helpful?

Скажи вголос, потім клацни.

You can write the steps once and then call them multiple times.

Key idea · Pattern recognition

What is a pattern?

A pattern is a repeating sequence of data, values, text, images or signs. — те, що повторюється.

How do you recognise a pattern? Як знайти повтор?

in numbers

the same sequence of numbers occurs more than once

in text

the same words or letters appear many times in the same order

in an image

the same colours, shapes, pixels appear in a sequence

Словник · як це вживати

Words in use

sub-routine A sub-routine is a separate algorithm that has a name. It runs its steps and then returns control.
to call Sub-routines are called from the main flowchart. Write the steps once and call them many times.
identifier The identifier is the name of the sub-routine. It is the same when it is called and when it is defined.
in the wrong order Sub-routines called in the wrong order. The incorrect sub-routine is called.
pattern A pattern is a repeating sequence. Identify the pattern: the repeated elements.
pattern recognition The repetition needs to be identified using pattern recognition. Put the repeated elements in a sub-routine.
