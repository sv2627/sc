1 · Кнопка «Скинути»

Що зробити: у Designer під полотном — кнопка ButtonReset з написом «Скинути».

Що має вийти: зловив кота кілька разів, натиснув «Скинути» — у Label1 «Бали: 0», а кіт стоїть у лівому верхньому куті полотна.

Де: Blocks → шухляда ButtonReset → when ButtonReset.Click, у неї — три блоки нижче. set global score to — у шухляді Variables, call ImageSprite1.MoveTo — у шухляді ImageSprite1.

when ButtonReset.Click do
set global score to 0
set Label1.Text to "Бали: 0"
call ImageSprite1.MoveTo x 0 y 0

2 · Порахуй без комп'ютера

Полотно 320 завширшки і 400 заввишки. Кіт — 80 × 80. X і Y кота — його лівий верхній кут.

а) Який найбільший X, щоб кіт не виліз за правий край? Напиши одне число.

б) Який найбільший Y, щоб кіт не виліз за нижній край? Напиши одне число.

Підказка: ширина полотна − ширина кота

Немає проєкту з уроку?

Створи новий проєкт ZlovyKota (Projects → Start new project) і збери за 5 хвилин:

Designer: Label1 — Text «Бали: 0» · Drawing and Animation → Canvas1 — Width і Height 300 pixels · на полотно ImageSprite1 — Picture kit.png (збережи й завантаж у Media), Width і Height 80 pixels.

Або завантаж готовий екран ZlovyKota.aia → Projects → Import project (.aia) from my computer — і склади блоки нижче.

initialize global score to 0
when ImageSprite1.Touched do
set global score to get global score + 1
set Label1.Text to join "Бали: " get global score
call ImageSprite1.MoveTo
x random integer from 0 to 220
y random integer from 0 to 220
