Немає папки pr1? Збери її за дві хвилини: нова папка, у ній два файли. Кнопка «Скопіювати» бере весь блок

pr1/ ├── index.html ├── photos.html └── style.css ← створюєш на уроці, крок 1

VS Code → File → Open Folder… → pr1 → у панелі Explorer кнопка New File. Імена файлів — точно такі. Картинок у папці немає — на їхньому місці буде видно опис з alt, так і має бути

Приклад із кроку 3 · стиль «спокійний»

Звір зі своїм після уроку. Твої кольори — з твого паспорта стилю

style.css 
/* Паспорт: спокійний. Фон #f5f7fa · текст #22313f · акцент #2e86de */

/* фон і текст усієї сторінки */
body {
  background-color: #f5f7fa;
  color: #22313f;
}

/* акцент: заголовки */
h1 {
  color: #2e86de;
}
h2 {
  color: #2e86de;
}

/* підвал: фон — акцент, текст — колір фону */
footer {
  background-color: #2e86de;
  color: #f5f7fa;
}
