Обробник — функція з уроку 10

Віддаємо функцію, а не викликаємо її

так · стрілкова функція на місці
hello.addEventListener('click', () => { msg.textContent = 'Привіт!'; });
так · імʼя готової функції, без ()
function sayHi() { msg.textContent = 'Привіт!'; } hello.addEventListener('click', sayHi);
ні · з дужками
hello.addEventListener('click', sayHi()); // sayHi() виконалась ОДРАЗУ, при відкритті, // а браузеру віддали те, що вона повернула — // undefined. Клік нічого не робить, // і помилки в Console немає
sayHi — сама функція, «ось рецепт». sayHi() — виконати її зараз, «ось готова страва»

render з уроку 18 + клік

Кнопки «Усі» і «Дешеві»

script.js
const cheapGames = []; for (const g of games) { if (g.price < 300) cheapGames.push(g); } document.querySelector('#all') .addEventListener('click', () => render(games)); document.querySelector('#cheap') .addEventListener('click', () => render(cheapGames));
render починає з innerHTML = '' — тому кожен клік перемальовує каталог, а не дописує
Тут обробник — стрілкова, бо render треба передати масив: () => render(games)
addEventListener('click', render(games)) — дужки, той самий слайд 8

Найчастіша помилка уроку

<script> — останнім у body

script у head — кнопки ще немає
<head> <script src="script.js"></script> </head> <body> <button id="plus">+1</button> // Console: // TypeError: Cannot read properties // of null (reading 'addEventListener')
script в кінці — усе вже на сторінці
<body> <button id="plus">+1</button> … <script src="script.js"></script> </body>
Браузер читає HTML згори вниз. Скрипт угорі шукає кнопку, якої ще немає, — querySelector повертає null
Те саме null — коли помилка в селекторі: 'plus' без #

const plus = document.querySelector('plus'); const cheap = document.querySelector('#cheap'); plus.addEventListener('click', () => { let count = 0; count++; out.textContent = count; }); cheap.addEventListener('click', render(cheapGames));

Три біди

Знайди всі три, потім клацни

1. 'plus' без # — null, далі TypeError

2. let count усередині — завжди 1. Винести над обробник

3. render(cheapGames) з дужками — виконалось одразу. Треба () => render(cheapGames)
