Проблема

Сердечко в StatelessWidget не працює

спроба · кнопка «подобається»
class LikeButton extends StatelessWidget { LikeButton({super.key}); bool liked = false; @override Widget build(BuildContext context) { return IconButton( onPressed: () { setState(() { liked = !liked; }); }, icon: Icon(liked ? Icons.favorite : Icons.favorite_border), ); } }
Помилка: The method 'setState' isn't defined for the type 'LikeButton'.
І жовте попередження must_be_immutable: у StatelessWidget усі поля мають бути final
Висновок: віджету, який змінюється від натискання, потрібен стан — окремий обʼєкт, що памʼятає liked і вміє перемальовувати екран

Головне сьогодні

StatefulWidget — це два класи

GameCard зі станом
class GameCard extends StatefulWidget { const GameCard({super.key, required this.game}); final Game game; @override State<GameCard> createState() => _GameCardState(); } class _GameCardState extends State<GameCard> { bool _liked = false; @override Widget build(BuildContext context) { return Text(widget.game.title); } }
ЩоНавіщо
extends StatefulWidgetсам віджет: лише те, що приходить ззовні (game), — final
createStateстворює обʼєкт стану для цього віджета
State<GameCard>стан: поля, що змінюються, методи і build
widget.gameзі стану до полів віджета — через widget.
Чотири частини — чотири рядки таблиці GameCard extends StatefulWidget — віджет, у якого буде стан createState — Flutter викликає його один раз і отримує обʼєкт стану _GameCardState — тут живе _liked і тут тепер build widget.game — так стан бачить поле game свого віджета
Підкреслення _ на початку — «тільки для цього файлу». Стан ніхто ззовні не чіпає

Передбач

А якщо без setState?

три кнопки · у класі стану
int _count = 0; void _addSilently() { _count++; // кнопка A } void _add() { setState(() { _count++; }); // B } Widget build(BuildContext context) { int local = 0; // Text('Count: $_count') // Text('Local: $local') // C: () => setState(() { local++; }) … }

1 · Тричі A

Що написано в Count?

Клацни — відповідь.

Count: 0. У памʼяті вже 3, але build ніхто не викликав

2 · Потім один раз B

Клацни — відповідь.

Count: 4 — стрибок одразу на 4: три «тихі» плюс один

3 · Натисни C

Клацни — відповідь.

Local: 0 завжди: змінна в build щоразу створюється заново. Стан — лише в полях класу

Передбач

Оновиться екран чи ні?

1 · Порожній setState

void _add() { _count++; setState(() {}); }

Клацни — відповідь.

Оновиться. setState лише каже «перемалюй». Але пишемо зміну всередині — так видно, що саме змінилось

2 · final-список

final List<Game> _cart = []; void _buy() { setState(() { _cart.add(games[0]); }); }

Клацни — відповідь.

Оновиться, помилки немає: final забороняє лише _cart = …, а add можна

3 · final-поле

final bool _liked = false; void _toggle() { setState(() { _liked = !_liked; }); }

Клацни — відповідь.

Помилка: '_liked' can't be used as a setter because it's final. Поле стану — без final

Перевір себе · зламай і полагодь

Що скаже редактор?

1 · Без widget.

У build стану напиши Text(game.title)

Що буде?

Помилка: Undefined name 'game'. Поле лежить у віджеті — widget.game.title

2 · Дужки в onPressed

onPressed: _add()

Що буде?

Помилка: This expression has a type of 'void' so its value can't be used. Дужки прибери: onPressed: _add

3 · Без createState

У GameCard extends StatefulWidget зітри рядки з createState

Що буде?

Помилка: Missing concrete implementation of 'StatefulWidget.createState'. Без нього стан не створюється

Ще вісім доробок

1. Перегортання по колу: після останньої гри — знову перша. _index = (_index + 1) % games.length;
2. Кнопка Reset: кошик порожній, _index = 0 — одним setState
3. Під кнопками — назви куплених ігор: for (Game c in _cart) Text(c.title),
4. Кнопка Remove last: _cart.removeLast(), сіра, коли кошик порожній
5. Одну гру не можна купити двічі: if (!_cart.contains(g)), а кнопка Buy показує In cart ✓
6. FloatingActionButton з Icons.shuffle — випадкова гра: Random().nextInt(games.length) (import 'dart:math';)
7. У картці практики 1 — лічильник лайків усіх натискань: int _clicks, рядок Clicks: 5
8. Знижка: кожна третя гра в кошику безкоштовна. Порахуй суму циклом з номером i
