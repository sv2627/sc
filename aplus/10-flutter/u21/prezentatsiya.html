Перевір себе · зламай і полагодь

Що скаже редактор?

1 · bool у Checkbox

onChanged: (bool v) { … } у Checkbox

Що буде?

Помилка: The argument type 'void Function(bool)' can't be assigned to the parameter type 'ValueChanged<bool?>?'. Пиши bool? і v ?? false

2 · int без ?

int qty = int.tryParse(_qty.text);

Що буде?

Помилка: A value of type 'int?' can't be assigned to a variable of type 'int'. tryParse може дати null — пиши int?

3 · Поле в Row

Row(children: [TextField(…), ElevatedButton(…)])

Що буде?

Червоний екран: An InputDecorator, which is typically created by a TextField, cannot have an unbounded width. Обгорни поле в Expanded
