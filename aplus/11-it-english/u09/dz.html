Алгоритм Skills Focus 7.5 (с. 184)

INPUT Value1
INPUT Value2
INPUT Value3
IF Value1 > Value2 AND Value1 > Value3 THEN
    OUTPUT(Value1)
ELSEIF Value2 > Value1 AND Value2 > Value3 THEN
    OUTPUT(Value2)
ELSE
    OUTPUT(Value3)
ENDIF
OUTPUT(Value1 + Value2 + Value3)

  1. Алгоритм вище, input values 4, 8, 2. Напиши два числа, які будуть у колонці OUTPUT.
