ТегЩо це

zapys.html

placeholder

value

почни писати в обидва поля

АтрибутЩо робить
type="text"яке поле: текст
placeholderпідказка: зникає, щойно пишеш; стерти — з'явиться знову
valueсправжній текст у полі — щоб написати своє, треба стерти
Підказка — в placeholder. У value — те, що вже вписано

label · for · id

Підпис знає своє поле

спосіб 1 · for = id
<label for="name">Ім'я</label> <input type="text" id="name">
спосіб 2 · поле всередині label
<label>Нік <input type="text"> </label>

клацни на слово «Ім'я» чи «Нік» — курсор стрибне в поле

for у підписі = id у полі, слово в слово. Не збіглися — підпис «нічий»
🤔

Курсор у полі: поле всередині підпису — for і id не потрібні

Два поля з однаковим id="name", другий підпис — for="name"

Подумай — потім клацни.

Курсор стрибне в перше поле. id на сторінці — один-єдиний

<label for="name"> стоїть після свого поля

Подумай — потім клацни.

Працює. Важить пара for = id, а не порядок. Але читати зручніше, коли підпис перед полем
