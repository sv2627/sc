Що надіслати

Картинку блоків проєкту MoyaGra: у Blocks правий клік на порожньому місці → Download Blocks as Image. І відповідь на пункт 2 — текстом у коментарі до завдання.

1 · Дотик і стрибок

Що зробити: торкнувся персонажа — на екрані напис «Влучив!», а персонаж стрибає в точку X 150, Y 100.

Що має вийти: торкнувся персонажа — напис «Влучив!», персонаж посередині полотна.

Де: Blocks → шухляда ImageSprite1 → when ImageSprite1.Touched, у неї — два блоки нижче. MoveTo — у тій самій шухляді, числа — Built-in → Math.

when ImageSprite1.Touched x y do
set Label1.Text to"Влучив!"
call ImageSprite1.MoveTo x 150 y 100

2 · Де стоїть персонаж?

Полотно 300 × 300, персонаж 80 × 80. Точка X 0, Y 0 — лівий верхній кут полотна, X — скільки праворуч, Y — скільки вниз.

а) X 0, Y 0  ·  б) X 220, Y 220

Напиши словами для кожного, наприклад: «а — лівий верхній кут».

Немає проєкту з уроку?

Створи новий проєкт MoyaGra (Projects → Start new project) і збери за 3 хвилини:

Designer: Label1 — Text «Бали: 0» · Palette → Drawing and Animation → Canvas1 — Width Fill parent, Height 300 pixels · на полотно ImageSprite1 — Picture: картинка персонажа (Media → Upload File…), Width і Height 80 pixels.

Немає картинки — замість ImageSprite1 поклади Ball1 (кулька), а в блоках бери шухляду Ball1.
