Dart і Flutter. Перша програма

Dart — мова. Flutter — фреймворк, набір готових блоків для екрана. Спочатку мова, потім фреймворк.

Скелет програми

// коментар — Dart його не читає
void main() {
  print('Привіт, 10 клас!');
}

Інструмент

  • Адреса: dartpad.dev
  • Реєстрація не потрібна
  • Run — щоразу вручну
  • Вивід — праворуч, у Console
  • DartPad нічого не зберігає — копіюй код у файл

Чотири помилки, які будуть у всіх

  • Print замість print — Dart розрізняє регістр
  • Забув ; наприкінці рядка
  • Не закрив ) або }
  • Забув натиснути Run і думає, що не працює

Дві дрібниці, що плутають

print(2 + 3) → 5
print('2 + 3') → 2 + 3

Лапки міняють не оформлення, а тип: без них Dart рахує, у лапках — це просто текст.

Терміни — лишаються англійською: ними ти шукатимеш відповідь

Я вмію після уроку

  • Пояснити, чим Dart відрізняється від Flutter.
  • Написати з нуля void main() з print — без підказки.
  • Знайти в чужому короткому коді помилку й пояснити, чому компілятор лається саме так.
