7.10 Finding errors in a program and correcting the errors

Довідка · с. 187–189

Error — помилка

To find an error you need to know the purpose of the algorithm. Find the difference between what it does and should do.

Method 1 · trace table

Choose test data, work out the intended outcome, dry run the algorithm and compare.

Method 2 · reading the code

Split the description into requirements. Check each one: has it been met? Look for a wrong identifier.
