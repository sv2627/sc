Згадуємо · правило

Сутність → class. Словник → Map

№Дані
1Товар: назва, ціна, кількість, продати
2Ціна за назвою товару
3Учень: імʼя, оцінки, середній бал
4Скільки разів трапилось кожне слово
5Книжка: назва, автор, видана чи ні
6Хто яку книжку взяв: назва → читач
Ті самі поля й дії у кожного — class. Пари «ключ → значення», що додаються в роботі, — Map

Відповідь

Спершу знайди всі три, потім клацни.

1. Без this. поля лишаються порожні: Product(this.name, this.price);

2. Тип — назва класу з великої: Product p = ...

3. Метод без дужок — не bool: if (p.isCheap())

DartPad покаже третю помилку, коли виправиш перші дві. Вивід: cheap

Приклад — і самостійно: клас Product

Приклад · над main
class Product { String name; int price; int count; Product(this.name, this.price, this.count); String info() => '$name: $price grn, $count pcs'; } // у main: Product pen = Product('pen', 25, 40); print(pen.info()); // pen: 25 grn, 40 pcs
Тепер самостійно
  • int total() — вартість залишку → 1000
  • bool sell(int n): більше, ніж є, — false; інакше мінус n і true. sell(50) → false, sell(5) → true
  • void restock(int n); після restock(10) → 45 pcs
  • Зламай: if (pen.sell) ... — прочитай помилку, поверни дужки
  • ⭐⭐ void discount(int percent) через ~/; discount(20) → 20 grn
  • ⭐⭐⭐ Поле int sold = 0, sell його збільшує; int revenue() → 100
✍️

Пастки

Найчастіші проблеми

1print(p) друкує Instance of 'Product'. Виводь p.info()
2Порядок аргументів. Product('pen', 40, 25) — обидва int, помилки немає, а ціна й кількість переплутані
3Метод без дужок. if (b.borrow) — помилка. Треба b.borrow()
4firstWhere без збігу падає Bad state: No element. Спершу any
5b = a — не копія. Змінив через b — змінилось і в a
6Сутність у Map. {'title': ..., 'author': ...} замість Book — помилку в ключі Dart не покаже
