Algorithm and decomposition

Keep this

algorithm

A solution for a problem: a set of instructions which need to be followed accurately. Instructions: precise · detailed (only the necessary information) · unambiguous.

decomposition · logical reasoning

Decomposition — breaking a complex task down into smaller parts that are easier to understand.
Logical reasoning — analysing a problem, making predictions, finding solutions.

flowchart

A logical representation of a process. oval — start / stop · rectangle — a step · diamond — a decision: Yes / No · arrows — the flow.
