Container: що вийде?

1 · Місце для тексту

Container( width: 200, padding: EdgeInsets.all(20), child: Text('…'), )

Скільки пікселів по ширині дістанеться тексту?

Клацни — відповідь.

160: 200 − 20 зліва − 20 справа

2 · padding чи margin

Container( color: Colors.amber, margin: EdgeInsets.all(20), child: Text('Hi'), )

Чи є жовте поле навколо Hi?

Клацни — відповідь.

Ні: жовте — тільки під текстом. margin — зовні, прозорий. Жовте поле дає padding

3 · Колір двічі

Container( color: Colors.white, decoration: BoxDecoration( borderRadius: BorderRadius.circular(16), ), )

Клацни — відповідь.

Червоний екран: Cannot provide both a color and a decoration. color: Colors.white — у BoxDecoration

Практика 3 · зламай і полагодь

Що покаже Flutter?

1 · Без min

Картка стоїть просто в Center. Прибери mainAxisSize: MainAxisSize.min

Що на екрані?

Рамка тягнеться від шапки до низу екрана, рядки — нагорі. Поверни min

2 · Довга назва

Назва — 'The Legend of Zelda: Tears of the Kingdom'

Що на екрані?

Жовто-чорна смуга справа і A RenderFlex overflowed by … pixels on the right. Рядок не влазить у 320. Коротша назва або менший fontSize

3 · children у Container

Заміни child: Column(children: [ … ]) на children: [ … ]

Що буде?

Червона хвиля: The named parameter 'children' isn't defined. У Container одна дитина — child

Пастки

Найчастіші проблеми

1The named parameter 'children' isn't defined. — у Container, Center, SizedBox одна дитина: child
2Cannot provide both a color and a decoration — color перенеси всередину BoxDecoration
3Жовто-чорна смуга, RenderFlex overflowed — рядок ширший за місце: коротший текст, менший fontSize або ширша картка
4Картка на всю висоту — у Column картки бракує mainAxisSize: MainAxisSize.min
5Вирівнювання «не працює» — не та вісь: у Row вертикаль — це crossAxisAlignment
6Загубились дужки — після кожного ) і ] кома. Вирівняти код: Format у DartPad, Shift + Alt + F у VS Code
