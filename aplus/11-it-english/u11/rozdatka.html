Summary · с. 192

Life cycle

Analysis — the problem is identified and decomposed. Design — the algorithms are planned. Coding — the program is written. Testing — the program is tested.

Algorithms

A linear search checks each item of data in turn. A bubble sort compares the items in pairs repeatedly. Validation — data is reasonable and within bounds. Verification — data has been input accurately.

Command words

define — give precise meaning · identify — name / select / recognise · describe — state the points of a topic · show (that) — provide structured evidence.

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі
