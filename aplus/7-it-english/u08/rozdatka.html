Patterns and choices

Довідка

Pattern

a repeating sequence of data, values, text, images or signs — те, що повторюється. Numbers: the same sequence of numbers · text: the same words in the same order · image: the same colours, shapes

Pattern → sub-routine

1. Find the repeated elements (pattern recognition).
2. Put them in a sub-routine.
3. Call it from the main algorithm.

Constructs

sequence — кроки один за одним.
selection — питання в ромбі, тільки two options: true / false. Which is larger, 2 or 3? → Is 2 > 3?
