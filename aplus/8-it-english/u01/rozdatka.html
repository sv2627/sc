Pseudocode · Псевдокод: правила гри

Запис алгоритму, який читає людина, а не комп'ютер.

Що таке pseudocode

  • Один крок — один рядок
  • Ключові слова — ВЕЛИКИМИ
  • Щоб зрозуміла інша людина

Чим воно НЕ є

  • Не мова програмування
  • Не запускається — текст для людей
  • Немає єдиного стандарту

Four requirements · Чотири вимоги — чек-лист усього року

  1. short — коротко: без зайвих слів, один крок — один рядок.
  2. clear — зрозуміло: do the check — яку саме перевірку?
  3. precise — точно: calculate the result — за якою формулою?
  4. start and end clearly shown — BEGIN … END обов'язкові.

Наш стиль запису

BEGIN
  SET price TO 120
  INPUT tickets
  SET total TO tickets * price
  OUTPUT total
END

Конструкції

  • BEGIN … END — початок і кінець
  • INPUT _ — узяти дані
  • OUTPUT _ — показати результат
  • SET _ TO _ — значення, не =
  • IF _ THEN _ ELSE _ ENDIF
