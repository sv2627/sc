Стан

.card:hover — миша над карткою

:active натиснули · :focus вибрали

Плавно — у звичайне правило

transition: color 0.3s;

ease · linear · ease-in · ease-out · ease-in-out

Рух — один transform

scale(1.1) · rotate(10deg)

translateX(10px) · translateY(-5px)

Далі — олівцем. Комп'ютер не потрібен, можна в сховищі

2 · Допиши CSSтри слова

Кнопка плавно, за 0.5 секунди, міняє все. Під мишею — фон чорний і кнопка більша в 1.1 раза.

.btn {
  transition: ________ 0.5s; }

.btn:________ {
  background-color: black;
  transform: ________(1.1); }

5 · Кнопка в трьох станах★★★

Намалюй кнопку звичайну, під мишею (:hover) і натиснуту (:active). Під кожною — одне правило CSS, наприклад transform: scale(0.95);

6 · Що не так?напиши, як виправити

.card:hover {
  transform: scale(1.1);
  transition: transform 0.4s; }
/* туди плавно, назад різко */
.btn:hover {
  transform: rotate(10);
}
/* кнопка не повертається */
.card:hover {
  transform: scale(1.1);
  transform: rotate(5deg); }
/* картка не збільшується */
