Key word

Знак = в алгоритмі

IF the colour of the animal = yellow, THEN 🦁 ELSE 🐘
= — equal to. Він порівнює: колір тварини — це yellow? Так → THEN. Ні → ELSE.

Колір — yellow

Хто? Клацни.

yellow = yellow — так → THEN → 🦁

Колір — blue

Хто? Клацни.

blue = yellow? Ні → ELSE → 🐘

colour — колір · yellow — жовтий · blue — синій

Which code is shorter?

Клацни.

A — 9 команд. B — 11.

Is code B wrong?

Клацни.

No! Машинка теж доїжджає. B правильний — просто довший.

Why is shorter better?

Клацни.

Швидше написати й перевірити. Менше кроків — менше місць для помилки.

Shorter code

Повтор — пишемо один раз

Було

11 11 11 00

Стало

11(x3) 00

(x3) — «тричі». Три однакові команди підряд записуємо один раз.

Зроби коротшим: 10 11 11 11 11 11 01 11 00
