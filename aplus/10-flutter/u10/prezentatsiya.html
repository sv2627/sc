Відповідь

Спершу знайди всі три, потім клацни.

2. length — без дужок: marks.length

3. У Map немає add: prices['coffee'] = 45;

Приклад — і самостійно: Map-лічильник

Приклад · у main
List<String> orders = ['coffee', 'tea', 'coffee', 'juice', 'coffee', 'tea', 'cocoa']; Map<String, int> counts = {}; for (String o in orders) { counts.update(o, (v) => v + 1, ifAbsent: () => 1); } print(counts); // {coffee: 3, tea: 2, juice: 1, cocoa: 1}
Тепер самостійно
  • Загорни в функцію Map<String, int> countAll(List<String> xs) з return
  • Кожен напій окремим рядком через forEach: coffee: 3 …
  • Скільки різних → 4; скільки всього замовлень (сума values) → 7
  • Найпопулярніший — як чемпіон турніру → coffee
  • Зламай: прибери ifAbsent, прочитай помилку, поверни
  • ⭐⭐ Назви за абеткою: counts.keys.toList(), далі sort() → cocoa, coffee, juice, tea
  • ⭐⭐⭐ Що замовили лише раз: where по keys → juice, cocoa

Пастки

На чому спотикаються всі

1/ у функції int — ділення завжди дає double. Або тип double, або ~/
2length() — у списку й словнику length без дужок
3update без ifAbsent для нового ключа — падіння Key not in map
4print(xs.sort()) — sort нічого не повертає. Спершу xs.sort();, потім print(xs);
5xs[xs.length] — такого номера немає. Останній — xs[xs.length - 1] або xs.last
6Забутий return — функція з типом int не запускається
